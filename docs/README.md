## 文档使用说明

### HTML 版本（推荐用于学习和培训）
每份 HTML 产品文档包含以下 **10 个标准章节**：
1. **背景与定位** — 产品定位、应用场景、技术路线
2. **工作原理** — 芯片级工作原理和信号链路详解
3. **🔬 核心模块深度解析** — 关键子模块的深入技术剖析
4. **电路框图** — SVG 交互式内部模块架构图
5. **核心对比** — 代际/竞品/技术路线对比
6. **核心指标** — 核心性能指标及物理含义（含指标详解卡片）
7. **影响因素** — 指标影响因素网络分析
8. **测试方法** — 完整测试方案（设备、框图、步骤、判定标准）
9. **注意事项** — 测试与使用中的关键注意事项
10. **选型指南** — 应用场景选型决策指南

### Markdown 版本（原始文档）
每份产品文档包含以下 6 个标准章节：
1. **产品概述** - 产品定位、应用场景、技术路线
2. **工作原理** - 芯片级工作原理详解
3. **芯片框图** - 内部模块架构图 (ASCII)
4. **模块详解** - 各子模块工作原理、关键参数
5. **关键指标** - 核心性能指标及其物理含义
6. **测试方法** - ATE/Bench测试方案（know-how）
