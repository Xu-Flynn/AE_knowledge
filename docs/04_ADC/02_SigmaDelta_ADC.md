## 一、产品概述

Sigma-Delta (Σ-Δ) ADC 是**精度最高的 ADC 架构**，通过过采样 (Oversampling) 和噪声整形 (Noise Shaping) 将量化噪声推到高频，再经数字抽取滤波器滤除，实现远超奈奎斯特速率 ADC 的分辨率。广泛应用于高保真音频、精密测量、地震监测和工业称重等低速超高精度场景。

### 产品定位

- **产业链位置**：传感器/模拟前端与数字处理器之间，承担超高精度模拟量到数字量的转换
- **核心价值**：以极高过采样比 (OSR) 换取超高分辨率 (>20 bit)，动态范围可达 120~140 dB
- **本质功能**：Σ-Δ 调制器 (噪声整形) + 数字抽取滤波器 (低通滤波+降采样)

### 典型应用场景

- 高保真音频 (24-bit 192kHz DAC/ADC)
- 精密仪器 (6.5/7.5 位万用表)
- 地震监测 (极低频、亚μV 信号)
- 工业称重传感器 (高精度低速)
- 生物医学信号 (ECG/EEG/EMG)
- 能源计量 (电表、功率监测)

### 技术路线

| 维度 | 规格 | 说明 |
|------|------|------|
| 分辨率 | 16~32 bit | 由 OSR、调制器阶数和量化器位数决定 |
| 采样率 | DC~100 kHz | f_BW = f_s / (2×OSR)，有效带宽由抽取滤波器决定 |
| 调制器架构 | DT (开关电容) / CT (连续时间) | CT-SD 固有抗混叠并适合高频；DT-SD 精度更高 |
| 调制器阶数 | 1~6 阶 | 高阶 → 更强噪声整形，但存在稳定性挑战 |
| OSR | 16~512 | 每翻倍 OSR → SNR 提升 (6L+3) dB (L 阶调制器) |
| 数字滤波器 | CIC + FIR 补偿 + 半带 | 多级级联抽取，决定群延迟和过渡带 |
| 工艺 | CMOS (180nm~28nm) | 开关电容/G_m-C/有源 RC 积分器实现 |
| 功耗特性 | μW~mW (低速) | 运放偏置电流为主要功耗源；动态功耗占比小 |

## 二、工作原理

Sigma-Delta ADC 的核心是**过采样 + 噪声整形 + 数字滤波**三大机制协同工作，将带内量化噪声压制到极低水平。

### 系统级信号流向

```
VIN → Σ(求和) → 环路滤波器 H(z) → 量化器(1~5bit Flash) → 数字抽取滤波器(CIC→FIR→半带) → N-bit PCM 输出
        ↑___________________________ 反馈 DAC (1-bit 或多位+DEM) ___________________________|
fs = OSR×2fBW (MHz级) | NTF 噪声整形: 低频噪声↓ 高频噪声↑ | 抽取滤波: 滤除高频噪声 + 降采样
```

### 1. 过采样 (Oversampling)

以远高于 Nyquist 速率的频率 f_s 采样，将量化噪声功率均匀分布到更宽的频带 [0, f_s/2]，使信号带宽 [0, f_BW] 内的噪声功率密度降低 OSR 倍。

```
OSR = f_s / (2 × f_BW)  |  SNR 提升 = 10log₁₀(OSR) dB (无噪声整形时)
```

### 2. 噪声整形 (Noise Shaping)

通过反馈环路将低频量化噪声推到高频，使信号带内噪声进一步降低。L 阶调制器的噪声传递函数 (NTF) 为 NTF(z) = (1 − z⁻¹)^L，带内噪声衰减率为 20·L dB/dec。

```
SNR 提升 (L阶) = (20L+10)·log₁₀(OSR) − 10·log₁₀(π^(2L)/(2L+1)) dB
```

### 3. 数字抽取滤波 (Decimation Filter)

数字低通滤波器滤除被推到高频的量化噪声，同时将采样率从 f_s 降至 Nyquist 速率 (2f_BW)。多级实现：

- **CIC 滤波器**：无乘法器，高抽取比，但通带衰减大
- **FIR 补偿滤波器**：补偿 CIC 通带衰减，提供锐截止特性
- **半带滤波器**：2x 抽取，近一半系数为零，效率极高

### 4. 离散时间 (DT) vs 连续时间 (CT) 调制器

| 维度 | DT (开关电容) | CT (连续时间) |
|------|---------------|---------------|
| 精度 | 极高 (电容匹配) | 受 RC 时间常数变化影响 |
| 速度 | 受运放 GBW 限制 | 可达到更高 f_s |
| 抗混叠 | 需要前置 AA 滤波器 | 固有抗混叠特性 |
| 功耗 | 较低 | 运放偏置持续消耗 |
| 设计复杂度 | 开关电容电路成熟 | 环路延时补偿复杂 |
| PVT 敏感性 | 低 (取决于电容比) | 需校准 RC 时间常数 |

> **💡 AE 核心认知**：OSR 每翻倍，1 阶 SD 的 SNR 提升 9 dB，2 阶提升 15 dB，3 阶提升 21 dB。但高阶调制器存在稳定性问题——输入超过某一幅度时环路可能振荡。实际设计常在阶数和稳定性之间折中，常用 2~3 阶 + 多位量化器方案。

## 三、核心模块深度解析

### 一、Σ-Δ 调制器 — 噪声整形的核心

Σ-Δ 调制器是 ADC 精度的决定模块，由环路滤波器 H(z)、量化器 (ADC) 和反馈 DAC 组成：

```
Y(z) = STF(z)·X(z) + NTF(z)·E(z)  |  STF(z)=H(z)/(1+H(z)), NTF(z)=1/(1+H(z))
```

信号传递函数 STF 在全频带接近 1，噪声传递函数 NTF 在低频趋近 0。

| 参数 | 公式/关系 | 工程权衡 |
|------|-----------|----------|
| 量化噪声功率 | σ_e² = Δ²/12 | Δ=V_LSB，多位量化可降低噪声 |
| dB 动态范围 | DR = 10log(P_sig,max/P_noise) | 受运放噪声、kT/C、时钟抖动综合限制 |
| 稳定性条件 | max\|NTF\| < 1.5 (经验) | 高阶 NTF 峰值更高，需限制输入幅度 |
| 极限环/空闲音 | DC 输入时出现周期性图案 | 加抖动 (Dither) 或使用多位量化器 |

### 二、环路滤波器 — DT vs CT 实现

环路滤波器决定噪声整形特性。离散时间 (DT) 使用开关电容积分器——精度由电容比例决定，受 kT/C 噪声限制。连续时间 (CT) 使用有源 RC 或 G_m-C 积分器——带宽不受运放建立时间限制，但面临环路延时的稳定性补偿和 RC 时间常数 PVT 漂移。

| DT 积分器 (开关电容) | CT 积分器 (有源 RC/G_m-C) |
|----------------------|---------------------------|
| ✅ 传递函数由电容比决定，精度极高 | ✅ 运放带宽需求低 (~f_s 而非数倍) |
| ✅ 对时钟抖动不敏感 | ✅ 固有抗混叠特性 |
| ✅ 设计成熟、仿真可靠 | ✅ 可实现更高的 f_s |
| ❌ 需要运放快速建立 → 限制 f_s | ❌ RC 时间常数 PVT 漂移需校准 |
| ❌ 需要前置抗混叠滤波器 | ❌ 环路延时 → NTF 恶化 |
| ❌ 开关噪声和电荷注入 | ❌ 对时钟抖动更敏感 |

### 三、量化器

Sigma-Delta 调制器中的量化器通常是低分辨率 (1~5 bit) ADC (Flash)，其量化噪声经 NTF 整形后大部分被滤除。多位量化器可降低量化噪声功率、改善稳定性，但要求反馈 DAC 具有匹配精度。

| 量化器类型 | 优点 | 缺点 |
|------------|------|------|
| 1-bit (比较器) | 天然线性 DAC，无匹配问题 | 量化噪声大、易产生空闲音 |
| 多位 (2~5 bit Flash) | 噪声低、稳定性好、动态范围大 | 反馈 DAC 需 DEM 解决失配 |

### 四、反馈 DAC 与 DEM

反馈 DAC 的非线性会直接污染输入信号 (不经过 NTF 整形)，是 CT-SD 的主要误差源。数据加权平均 (DWA/DEM) 算法通过动态轮换 DAC 单元将失配误差整形到高频，是实现高线性度的关键技术。

```
DEM 本质：将 DAC 失配误差从 DC 搬到高频 → 经 NTF 衰减 → 整体线性度提升至 >14~16 bit
```

### 五、数字抽取滤波器链

| 滤波器级 | 类型 | 抽取比 | 功能 |
|----------|------|--------|------|
| 第一级 | CIC (级联积分梳状) | 高至 OSR/2 | 无乘法器高效粗抽取，衰减高频噪声 |
| 第二级 | FIR 补偿 | 2~4 | 补偿 CIC 通带衰减 (sinc 响应) |
| 第三级 | 半带 FIR | 2 (可多级级联) | 近一半系数为 0，高效 2x 抽取 |
| 最终级 | 可编程 FIR | 最终抽取 | 锐截止，可配置带宽和群延迟 |

## 四、芯片内部电路框图

```
┌────────────────────── 模拟域: Σ-Δ 调制器 ──────────────────────┐
│  VIN → Σ → 积分器1 → 积分器2 → 积分器3(可选L=3)[待确认] → 量化器(1~5bit Flash) │
│         ↑___________________________ 反馈 DAC (1-bit/DEM) ______│
│  Bandgap + VREF (运放偏置 + 参考) ──────────────────────────────→│
└─────────────────────────────────────────────────────────────────┘
┌────────────────── 数字域: 抽取滤波器链 ─────────────────────────┐
│  CIC滤波器 → FIR补偿滤波器 → 半带滤波器 → 可编程FIR → N-bit PCM 输出 │
│  (高抽取比)   (补偿通带衰减)   (2x抽取)   (最终滤波+抽取)          │
└─────────────────────────────────────────────────────────────────┘
时钟 & 电源: 调制器时钟 fs (MHz级) | 抽取滤波时钟 (逐级降频) | AVDD/DVDD 分离 | 时钟抖动 < 10ps RMS
CMOS 工艺 180nm~28nm | 群延迟: 10~100 输出周期 | OSR: 16~512
```

**说明**：Σ-Δ 调制器通过负反馈环路实现噪声整形，将量化噪声推到高频；数字抽取滤波器链逐级降采样并滤除带外噪声，最终输出低速高分辨率 PCM 码。环路滤波器阶数 L 和 OSR 共同决定最终分辨率。

## 六、核心指标

| 参数 | 范围 | 说明 |
|------|------|------|
| 分辨率 | 16~32 bit | 由 OSR + 调制器阶数 + 量化器位数决定 |
| 信号带宽 f_BW | DC~100 kHz | 由 f_s 和 OSR 共同决定 |
| 调制频率 f_s | 100 kHz~20 MHz | 受运放 GBW 和建立时间限制 |
| 动态范围 DR | 90~140 dB | 满幅 SNR + 余量; 万用表级可达 140dB |
| SNDR | 80~130 dB | 含谐波和杂散 |
| ENOB | 13~21.5 bit | (SNDR−1.76)/6.02 |
| SFDR | 90~130 dBc | 最差谐波; CT-SD 受 DAC 非线性限制 |
| INL | ±1~±15 ppm of FS | 极高线性度; 受运放增益非线性限制 |
| OSR | 16~512 | f_s/(2×f_BW); 高 OSR → 高 DR 但低 BW |
| 群延迟 | 10~100 输出周期 | 由数字滤波器链深度决定 |

### 动态范围 (Dynamic Range)（核心指标）

- **定义**：可检测的最小信号 (SNR=0dB) 与满幅输入之间的功率比
- **公式**：DR = 10log(P_max/P_noise,min) ≈ 6.02·N + 1.76 + 10log(OSR) (理想)
- **典型**：24b 音频 SD: 110~120 dB; 32b 测量 SD: 130~140 dB

## 七、影响因素分析

| 指标 | 影响因素 | 影响下游 |
|------|----------|----------|
| DR/SNR | OSR、运放噪声、kT/C、时钟抖动 | ENOB, 精度 |
| INL | 运放增益非线性、DAC 失配、DEM 效能 | SFDR, THD |
| SFDR | DAC 非线性、运放谐波、空闲音 | 频谱纯度 |
| f_BW,max | 运放 GBW、f_s、滤波器延迟 | 信号带宽 |
| 群延迟 | 滤波器阶数、抽取比、输出速率 | 控制环路响应 |
| 功耗 | 运放偏置、f_s、数字滤波规模 | 热预算 |

> **总结**：Sigma-Delta 以时间 (OSR) 和数字复杂度换取模拟精度——模拟电路只需中等精度 (运放增益 >60dB 即可)，超高分辨率由数字滤波实现。关键瓶颈是运放噪声和时钟抖动。

## 八、测试方法

### ⓵ 动态范围/SNR — 正弦波测试法

施加低失真正弦波 (THD 比 DUT 高 >10 dB，幅度 −0.5 dBFS) → 采集 >128K 点 → FFT 分析 (7-Term Blackman-Harris 窗) → 计算 SNR/SNDR/DR。由于 SD 输出速率低，单次 FFT 记录可能需数秒。

**测试框图**：
```
超低失真信号源(APx555 / SMA100B, THD+N<-120dB) → DUT(Σ-Δ ADC) → 采集系统(>128K点, 相干采样) → FFT分析(SNR/SNDR/DR)
低噪声电源(E36313A) ─────────────────────────────────────────────────────────────────────────────→
判定: SNR ≥ 标称−3dB | SNDR ≥ 标称−3dB | DR ≥ 标称−3dB
```

### ⓶ INL/DNL — 低速直流扫描法

由于 SD 延迟大且输出速率低，使用高精度直流源 (Fluke 5730A) 逐点扫描或极低速斜坡输入 (<0.01 LSB/sample)，配合码密度分析。需要稳定温度环境 (23±0.5°C) 和低热 EMF 连接。

**测试框图**：
```
高精度DC源(Fluke 5730A, ±0.05ppm) → DUT(Σ-Δ ADC) → PC分析(INL/DNL计算)
判定: INL < ±15 ppm (16+ bit) | DNL 无失码 | 温度稳定 ±0.5°C | 低热 EMF 连接
```

### ⓷ 空闲音 (Idle Tone) 测试

施加 DC 输入 (通常 0V 或 FS/2) → 采集长序列 (>1M 点) → FFT 分析 → 检查频谱中是否存在离散杂散峰 (极限环/空闲音)。这是低阶 1-bit SD 的特有问题。加 Dither 或使用多位量化器可抑制。

- **设备**：低噪声 DC 源 (Keithley 2450 SMU) + 屏蔽环境 (Faraday Cage)
- **判定**：空闲音峰值 < −120 dBFS (20+ bit SD)；若存在明显杂散，需评估是否启用 Dither 或更换多位量化器方案

## 九、注意事项

| 注意事项 | 说明 |
|----------|------|
| ⏰ 时钟抖动 | 时钟抖动直接调制反馈 DAC 的脉冲宽度——在 CT-SD 中尤其敏感。>100 dB DR 要求抖动 <10 ps RMS。使用低相噪晶振 + 本地 PLL |
| 🔊 空闲音 | 低阶 (1~2) SD 在 DC 或慢变化输入时产生周期性输出图案 (极限环) → 频谱中出现离散杂散。加 Dither 或使用多位量化器可抑制 |
| ⚡ 输入驱动 | SD 调制器输入端可能是开关电容负载——驱动运放需要足够 GBW 和低输出阻抗。驱动不足导致建立误差，直接影响 INL |
| 📡 数字耦合噪声 | 大规模数字抽取滤波器产生同步开关噪声 → 通过衬底和电源耦合到调制器。分离 AVDD/DVDD，Guard Ring，衬底隔离 |
| 📦 滤波器群延迟 | 数字滤波器链的总延迟 → 实时控制环路需考虑。Sinc 滤波器延迟 = (OSR−1)/(2f_s)。实时控制选低延迟滤波器配置 |
| ⚠️ 调制器稳定性 | 高阶 (≥3) 调制器在大信号输入时可能不稳定。输入幅度需留有 −3~−6 dBFS 余量。监控调制器输出是否饱和 |

> **🚨 TOP 5 常见错误**：
> 1. 时钟抖动过大 → SNR 天花板
> 2. 参考电压噪声 → 直接限制 DR
> 3. 输入驱动不足 → 建立误差 → INL 恶化
> 4. 数字与模拟电源共用 → SFDR 显著下降
> 5. 忽略空闲音 → 窄带应用中出现不可接受杂散

## 十、选型指南

### 选用 Sigma-Delta 的场景

- BW < 10 kHz
- 需要 > 18 bit 分辨率
- 需要极高动态范围 (>120 dB)
- 对抗混叠要求极高
- 对延迟不敏感 (可接受 ms 级)
- 信号频率远低于 Nyquist

### 不适合 Sigma-Delta 的场景

- >100 kHz BW + >12b → SAR
- >10 MHz → Pipeline
- 需要 < 1 采样延迟 → Flash/SAR
- 严格功耗限制+中精度 → SAR
- 多通道高速轮询 → SAR+MUX

### 按场景选型

| 场景 | 分辨率 | f_BW | 特点 |
|------|--------|------|------|
| 高保真音频 | 24b | 20~100 kHz | DR>110dB, 多位CT-SD |
| 精密万用表 | 28~32b | <1 kHz | 极高线性度, 前台校准 |
| 地震监测 | 24~32b | DC~100 Hz | 亚μV 噪声, 极低漂移 |
| 工业称重 | 20~24b | 10~1k Hz | 高共模抑制, 低噪声 |
| 能源计量 | 16~24b | 1~10 kHz | 多通道同步采样, 低功耗 |
| ECG/EEG | 20~24b | 100~1k Hz | 极高输入阻抗, 低噪声 |

> **AE认知**：Sigma-Delta 是"以时间换精度"的典范——用 MHz 级采样 + 复杂数字滤波换取音频/测量级的精度。核心选型参数是 OSR 和 f_BW 的乘积，决定了调制频率 f_s。
