## 一、产品概述

SAR ADC (Successive Approximation Register ADC) 是**应用最广泛的奈奎斯特速率 ADC 架构**，通过二分搜索算法将模拟电压逐次逼近转换为数字码。它在功耗、面积、精度和速度之间取得了极优的平衡，是 IoT 传感器、工业控制、医疗电子、电池管理、触摸屏等中低速高精度场景的首选方案。

### 产品定位

- **产业链位置**：传感器/模拟前端与数字处理器之间，承担模拟量到数字量的转换
- **核心价值**：以极低功耗（fJ/conv-step）实现中高精度转换，无静态偏置电流
- **本质功能**：N-bit 逐次逼近量化：电容阵列采样 + 比较器判决 + SAR 逻辑控制

### 典型应用场景

- 工业传感器数据采集 (温度/压力/流量)
- 电池管理系统 (BMS AFE) 电压监测
- 便携医疗设备 (ECG/EEG/血糖仪)
- 触摸屏控制器 (Touch Screen Controller)
- IoT 无线传感器节点 (低占空比采样)
- 电机控制电流检测

### 技术路线

| 维度 | 规格 | 说明 |
|------|------|------|
| 分辨率 | 8~18 bit | 由 CDAC 匹配精度和比较器噪声决定 |
| 采样率 | DC~10 MSPS | 逐次逼近：N bit 需 N+α 个时钟周期 |
| DAC 架构 | 电容 DAC (CDAC) | 二进制权重电容阵列 / 分段式 (Split CDAC) |
| 比较器 | 动态锁存比较器 | 无静态功耗，噪声和速度的折中 |
| 采样开关 | Bootstrapped 开关 | 保证 Ron 恒定以实现高线性度 |
| 工艺 | CMOS (180nm~7nm) | 几乎全数字化趋势，先进工艺受益于开关速度 |
| 功耗特性 | 仅动态功耗 (αCV²f) | 无静态电流，kSPS 级别可做到 nW |
| 通道数 | 1/2/4/8/16 通道可选 | 内置 MUX，适合多传感器系统 |

## 二、工作原理

SAR ADC 的核心是**二分搜索算法**（Binary Search）：从 MSB 到 LSB 逐位确定数字码。每次转换包括采样阶段（Acquisition）和转换阶段（Conversion），期间 DAC 输出逐次逼近输入信号。

### 系统级信号流向

```
VIN → 采样保持(S/H) → N-bit CDAC → 动态比较器 → SAR 控制逻辑 → 输出寄存器 → DOUT
                          ↑_________________DAC 切换反馈 (逐次逼近)________________|
VREF 基准 (Bandgap+Buf) ──────────────────────────────────────────────────────────→
```

### 逐次逼近算法 (4-bit 示例, V_IN=0.65V, V_REF=1V)

| 周期 | 试探位 | DAC 输出 | 比较结果 | 判决 | 当前码 |
|------|--------|----------|----------|------|--------|
| 1 (MSB) | 1000 (0.5V) | V_DAC=0.5V | V_IN>V_DAC | 保留 MSB=1 | 1000 |
| 2 | 1100 (0.75V) | V_DAC=0.75V | V_IN<V_DAC | 清零 2nd=0 | 1000 |
| 3 | 1010 (0.625V) | V_DAC=0.625V | V_IN>V_DAC | 保留 3rd=1 | 1010 |
| 4 (LSB) | 1011 (0.6875V) | V_DAC=0.6875V | V_IN<V_DAC | 清零 LSB=0 | 1010 |

**最终码**: 1010₂ = 10₁₀，V_量化值 = 10 × V_REF / 16 = 0.625V，量化误差: +0.025V (0.25 LSB)

### 转换时序

```
T_total = T_acq + N × T_bit + T_overhead
```

其中 T_acq 是采样/捕获时间（由 CDAC 总容值和开关 R_on 决定 RC 时间常数；需 ≥ 8~10·τ 以达所需精度），T_bit 是每位判决时间（包括 DAC 建立 + 比较器再生 + SAR 逻辑延迟）。

### CDAC 操作原理 (电荷守恒)

电容 DAC 是 SAR ADC 的核心：采样阶段，所有电容下极板接 V_IN，上极板接共模电压 V_CM；转换阶段，从 MSB 电容开始逐次切换下极板到 V_REF 或 GND，比较器监测上极板电压变化——**电荷守恒自动完成减法运算**。

对 N-bit CDAC：总电容 C_total = 2^N·C_unit。MSB 电容 = 2^(N−1)·C_unit = C_total/2。每位切换后，上极板电压变化量 ΔV = V_REF·(被切换电容 / C_total)。

> **💡 AE 核心认知**：SAR ADC 的精度由 CDAC 匹配精度直接决定。不校准条件下，单位电容标准差 σ(C) 决定 INL/DNL 上限；数字校准技术可将分辨率推至 16~18 bit。SAR ADC 是"最少模拟电路 + 最多数字逻辑"理念的典范——仅需一个比较器、一个 CDAC 和数字控制逻辑即可实现完整 ADC 功能。

## 三、核心模块深度解析

### 一、电容 DAC (CDAC) — 精度的物理载体

CDAC 是 SAR ADC 的**核心精度决定模块**。由 N 个二进制权重电容组成，版图使用共质心 (Common-Centroid) 布局以减小梯度误差。

```
C_k = 2^(k-1) · C_unit  |  k = 1 (LSB) … N (MSB)
```

| 参数 | 公式/关系 | 工程权衡 |
|------|-----------|----------|
| 单位电容 C_unit | 由 kT/C 噪声和匹配决定 | C↑ → 噪声↓ 匹配↑ / 面积↑ 速度↓ |
| kT/C 噪声 | v_n,rms = √(kT/C_total) | 需 < LSB/√12 以保证 SNR |
| 电容匹配 σ | σ(ΔC/C) ∝ 1/√area | 分段结构 (Split CDAC) 可减小总电容比 |
| 建立时间 | τ = R_on·C_total | 每位建立需 ≥ τ·ln(2^(N+1)) ≈ τ·(N+1)·ln2 |

### 二、动态锁存比较器 — 速度与噪声的博弈

现代 SAR ADC 几乎全部使用**动态锁存比较器** (StrongARM Latch)，无静态功耗。核心是时钟沿触发再生正反馈：

```
V_o(t) = V_i · e^(t/τ_reg)  |  τ_reg = C_L/g_m
```

| 关键参数 | 典型值 | 设计要点 |
|----------|--------|----------|
| 输入参考噪声 | 50~200 μV_rms | 与 g_m 和再生时间常数相关；噪声 < ½ LSB |
| 失调电压 | 5~20 mV (未校准) | 输入管 V_th 失配主因；校准或冗余可容忍 |
| 再生时间常数 | 10~30 ps (先进工艺) | ∝ (C_L/g_m)，先进工艺下 g_m/I_D 更高 |
| 亚稳态概率 | ~10⁻⁶ ~ 10⁻⁹ | 输入接近判决阈值时产生，需冗余时间 |
| 回踢噪声 | mV 级 | 再生瞬间通过寄生电容耦合到 CDAC |

### 三、SAR 控制逻辑 — 同步 vs 异步

**同步 SAR**：每位固定周期，外部高速时钟驱动。简单但时钟频率需涵盖最坏情况 DAC 建立。
**异步 SAR**：每位转换完成后自动触发下一位，不需要外部高频时钟，速度可提升 2~4×。

| 同步 SAR | 异步 SAR |
|----------|----------|
| ✅ 时序简单，设计易验证 | ✅ 自适应建立时间 |
| ✅ 对 PVT 变化不敏感 | ✅ 不需要高频时钟，降低功耗 |
| ❌ 需要 f_clk > (N+α)/T_conv | ✅ 速度提升显著 |
| ❌ 每位等待最坏建立 | ❌ 需要 Ready 检测电路 |
| ❌ 高时钟频率 → 高功耗 | ❌ PVT 变化需留余量 |

### 四、自举采样开关 (Bootstrapped Switch)

栅源电压 V_GS 恒定的开关技术，使导通电阻 R_on 不随输入信号变化，是实现高线性度采样的关键：

```
R_on = 1 / [μ_n·C_ox·(W/L)·(V_GS − V_th)]  |  当 V_GS=V_DD 恒定 → R_on 仅取决于 V_th
```

### 五、校准技术概览

| 校准类型 | 校准对象 | 方法 | 复杂度 |
|----------|----------|------|--------|
| 数字校准 | 电容失配 | 测量权重误差 → 存储校正系数 → 输出时补偿 | 中 |
| 模拟校准 | 比较器失调 | 输入对管体偏置 / 可调电流源 | 低 |
| 冗余 SAR | 建立不完全 | 子基 (sub-radix-2) 搜索 + 数字纠错 | 中 |
| 前台校准 | 全局非线性 | 注入已知信号 → 测量畸变 → 建立 LUT | 高 |
| 背景校准 | PVT 漂移 | PN 注入 / Split ADC / 相关性检测 | 很高 |

## 四、芯片内部电路框图

```
┌────────────────────────── 模拟域 ──────────────────────────┐
│  VIN → 自举开关 → N-bit CDAC 阵列 → 动态比较器              │
│         (VGS=VDD)   (上极板:VCM→比较器)   (StrongARM)      │
│                      (下极板:VIN→VREF/GND)  ↑              │
│  VREF+Bandgap ─────────────────────────────┘              │
└────────────────────────────────────────────────────────────┘
┌────────────────────────── 数字域 ──────────────────────────┐
│  SAR 控制逻辑 (FSM) → 数字校准 → 输出寄存器 → N-bit 输出    │
│  MSB→LSB 逐位试探判决      (LUT)      (并行/串行)          │
└────────────────────────────────────────────────────────────┘
┌────────────────────── 时钟与电源域 ────────────────────────┐
│  CLK (fs DC~10MHz) | VREF Buffer | AVDD/DVDD 分离          │
│  Tconv = Tacq + N×Tbit | 输出接口: SPI/I²C/并行            │
└────────────────────────────────────────────────────────────┘
```

**说明**：SAR ADC 仅需一个比较器、一个 CDAC 和数字控制逻辑即可实现完整 ADC 功能。模拟域的核心是 CDAC 匹配精度和比较器噪声；数字域实现二分搜索算法；异步 SAR 通过 Ready 检测自适应每位时长，无需外部高频时钟。

## 六、核心指标

| 参数 | 范围 | 说明 |
|------|------|------|
| 分辨率 | 8~18 bit | 由CDAC匹配+CMP噪声决定 |
| 采样率 f_s | DC~10 MSPS | Nyquist=f_s/2 |
| 功耗 | 10nW~10mW | 仅动态功耗，与f_s线性 |
| SNDR | 50~100 dB | f_in近Nyquist |
| ENOB | 8.0~16.3 bit | (SNDR-1.76)/6.02 |
| SFDR | 60~110 dBc | 最差谐波 |
| INL | +/-0.5~+/-4 LSB | 最佳拟合线 |
| DNL | +/-0.2~+/-1 LSB | 无失码(DNL>-1) |
| Walden FoM | <100 fJ/step | P/(2^ENOB x f_s) |
| Schreier FoM | 170~185 dB | SNDR+10log(BW/P) |

### ENOB（核心指标）

- **定义**：从SNDR反算的等效分辨率
- **公式**：ENOB=(SNDR_dB-1.76)/6.02
- **典型**：12b SAR: 10.5~11.5 bit@低频

| 指标 | 影响因素 | 影响下游 |

## 八、测试方法

### ⓵ INL/DNL — 正弦码密度直方图法

施加低失真正弦波 (THD 比 DUT 高 2~3 bit，幅度覆盖 −0.5 dBFS) → 采集 >1M 点 → 统计各输出码出现频次 → 与理想正弦码密度函数对比 → 计算 DNL/INL。

**测试框图**：
```
低噪声信号源(Keysight 33500B, THD<-100dBc) → 带通滤波器(BPF滤除谐波) → DUT(SAR ADC, fs=目标速率) → 逻辑分析仪(Keysight 16860A, >1M采样点) → PC分析(码密度→DNL/INL)
低噪声电源(E36313A) ──────────────────────────────────────────────────────────────────────────────→
判定: DNL < ±1 LSB, INL < ±2 LSB (12b) | >1M 采样点 | 相干采样 fin/fs = M/Nrec
```

### ⓶ 动态性能 — FFT 频谱法 (SNR/SNDR/SFDR)

施加低相噪正弦波 → 相干采样 (f_in/f_s = M/N_record, M 与 N_record 互质) → 采集 N_record 点 (≥65536) → 加窗 FFT (7-Term Blackman-Harris) → 计算 SNR/SNDR/SFDR/THD。

**测试框图**：
```
超低相噪信号源(R&S SMA100B, 相噪<-140dBc/Hz) → DUT(SAR ADC) → 采集卡(Nrec≥65536, 相干采样) → FFT分析(SNR/SNDR/SFDR)
低噪声电源(E36313A) ─────────────────────────────────────────────────────────────────────────────→
判定: SNR ≥ 标称−3dB | SNDR ≥ 标称−3dB | SFDR ≥ 标称−5dBc | fin 近 Nyquist 最严苛
```

### ⓷ 功耗与 FoM 测试

使用精密源表测量各电源轨 (AVDD/DVDD/V_IO) 的电流 → P_total = Σ V_i×I_i。分别测量静态功耗 (f_s=0) 和动态功耗 (目标 f_s) → 计算 Walden FoM = P/(2^ENOB×f_s) 和 Schreier FoM = SNDR + 10log₁₀(BW/P)。

- **设备**：Keysight B2902A SMU / N6705C 直流电源分析仪 + 低噪声电源
- **判定**：Walden FoM < 100 fJ/conv-step (12b SAR 典型值 10~50 fJ/step)，Schreier FoM > 170 dB

## 九、注意事项

| 注意事项 | 说明 |
|----------|------|
| 输入驱动 | CDAC开关电容负载→缓冲器GBW需>N*ln2*f_s/beta。驱动不足→建立误差 |
| VREF噪声 | V_REF噪声直接耦合→10uF+0.1uF去耦。缓冲器噪声<1/2 LSB/sqrt(BW) |
| kT/C下限 | 物理下限→C_total>12kT/V_ref²*2^2N。大C→噪声小速度慢 |
| 回踢噪声 | CMP再生→寄生耦合到CDAC→需中和电容或预放隔离 |
| 数字耦合 | SAR逻辑开关→衬底/电源耦合→AVDD/DVDD分离+Guard Ring |
| 亚稳态 | V_IN约等于V_DAC时CMP亚稳态→冗余SAR+纠错可容忍 |

> **🚨 TOP 5 错误**：
> 1. 输入阻抗过大→建立不足
> 2. VREF去耦不足→SNDR恶化
> 3. f_s过高→CDAC未建立→ENOB降
> 4. 数字走线平行模拟→SFDR降
> 5. 忽略共模范围→失码

## 十、选型指南

### 选用 SAR 的场景

- BW DC~5 MHz
- 10~16 bit
- 严格功耗限制
- 多通道轮询(MUX)
- 零静态功耗
- 延迟不敏感
- 成本/面积敏感

### 不适合 SAR 的场景

- >10MHz+>12b → Pipeline
- >18b → Sigma-Delta
- >100MSPS → Pipeline/TI
- <1 cycle延迟 → Flash
- 强抗混叠 → Sigma-Delta

### 按场景选型

| 场景 | 分辨率 | f_s | 通道 |
|------|--------|-----|------|
| BMS | 12~14b | 10~100k | 6~18 |
| 工业传感器 | 12~16b | 1~100k | 4~8 |
| 医疗(ECG/EEG) | 16~18b | 100~1k | 2~8 |
| 触摸屏 | 10~12b | 100~500k | 4~16 |
| 电机电流 | 12b | 1~5M | 2~4 |
| IoT | 10~14b | 1~100k | 1~4 |
| 通用采集 | 12~16b | 100k~5M | 8~16 |

> **AE认知**：选型关键是确认输入驱动和CDAC建立时间匹配目标f_s。对BMS/工业传感器，SAR通常最优。
