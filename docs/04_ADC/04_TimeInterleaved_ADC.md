# Time-Interleaved ADC 时间交织模数转换器

## 一、产品概述

Time-Interleaved (TI) ADC 是**突破单通道 ADC 速度极限的核心架构**，通过 M 个并行通道以时间交错方式工作，每个通道以 f_s/M 速率采样，总体实现 f_s 的等效采样率。TI 架构可以将 SAR、Pipeline 等成熟 ADC 的速度提升 M 倍，是实现 >1 GSPS 中高分辨率转换的关键技术。广泛应用于高速通信、光网络接收机、宽带雷达和高速仪器仪表。

### 产品定位

- **产业链位置**：超高速模拟前端与数字处理器之间，突破 ADC 单通道速度上限
- **核心价值**：以面积和功耗线性增长换取 M 倍速度提升，可在先进工艺下实现 10+ GSPS @ 8~14 bit
- **本质功能**：M 个并行子 ADC + M 相时钟分配 + 多路复用数字输出 + 校准 (增益/失调/时序偏斜)

### 典型应用场景

- 相干光通信接收机 (>64 GBaud, >128 GSPS)
- 宽带雷达/电子战数字接收机 (瞬时带宽 > 2 GHz)
- 高速示波器 (>10 GSPS 实时采样)
- 5G/6G 毫米波直接采样接收机
- 高速 SerDes/背板接收器
- 粒子物理探测器读出电子学

### 技术路线

| 维度 | 规格 | 说明 |
|------|------|------|
| 分辨率 | 8~14 bit | 由子 ADC 架构和校准精度综合决定 |
| 采样率 | 100 MSPS~100+ GSPS | f_s = M × f_s,ch，M = 2~256 |
| 子 ADC 架构 | SAR / Pipeline / Flash | SAR 最常见 (低功耗)；Pipeline 适合更高每通道速率 |
| 通道数 M | 2~256 | M 翻倍 → 采样率翻倍 → 面积/功耗近似翻倍 |
| 时钟架构 | 多相时钟发生器 (DLL/PLL) | M 相等间距相位，相位噪声/偏斜决定 SNR 极限 |
| 校准 | 增益/失调/时序偏斜 | 三大失配校准是 TI-ADC 设计的核心挑战 |
| 输入缓冲 | 宽带缓冲器/T&H | 驱动 M 个并行通道，带宽需 > f_s/2 |
| 工艺 | CMOS (28nm~5nm) | 先进工艺开关速度和数字校准能力是关键使能因素 |

## 二、工作原理

Time-Interleaved ADC 的核心是将 M 个独立子 ADC 以**时间交错**方式并行工作：每个子 ADC 以 f_s/M 的速率采样，M 个通道的采样时刻均匀分布在 T_s=1/f_s 周期内，交错后等效于单个 f_s 速率的 ADC。

### 系统级信号流向

```
VIN → 输入缓冲(BW>fs/2) → M 个并行子 ADC (时间交错)
                              ├─ 子ADC₀ @Φ₀ (fs/M)
                              ├─ 子ADC₁ @Φ₁ (fs/M)
                              ├─ ...
                              └─ 子ADCM-1 @ΦM-1 (fs/M)
                              ↓ 数字输出
                    数字校准 + MUX (增益/失调/偏斜校正, M:1 拼接 → fs 速率) → DOUT
多相时钟生成 (DLL/PLL) → M相等间距相位移: Δt=Ts/M | 偏斜 < 50 fs RMS (校准后) | 时钟抖动直接影响 SNR
fs = M × fs,ch | 吞吐率 = fs | 延迟 = 子ADC延迟 + 校准延迟
```

### 1. 时间交错原理

M 相时钟 (Φ₀, Φ₁, ..., ΦM−1) 等间距分布在 1/f_s 周期：Φ_k 的采样时刻 = k × T_s/M。子 ADC_k 在 Φ_k 采样，最终输出按 Φ₀, Φ₁, ..., ΦM−1, Φ₀, ... 顺序拼接。

```
f_s = M × f_s,ch  |  T_s,ch = M × T_s  |  相位步进 = T_s/M
```

### 2. 三大失配及其影响

理想 TI-ADC 要求所有子 ADC 完全相同，但实际存在三大失配：

| 失配类型 | 时域表现 | 频域影响 | 典型值 |
|----------|----------|----------|--------|
| 失调失配 (Offset) | 各通道输出存在不同 DC 偏移 | 在 f_s/M 整数倍处产生固定杂散 (与信号无关) | 1~10 mV |
| 增益失配 (Gain) | 各通道对同一信号幅度响应不同 | 在 k·f_s/M ± f_in 处产生调制杂散 (与信号相关) | 0.1~2% |
| 时序偏斜 (Timing Skew) | 各通道实际采样时刻偏离理想相位 | 在 k·f_s/M ± f_in 处产生杂散，且幅度随 f_in 增大而恶化 | 0.1~5 ps |

### 3. 时序偏斜 — 最关键的失配

时序偏斜 (也可视为带宽失配的频率域表现) 是 TI-ADC 性能的主要限制因素，其产生的杂散幅度随输入频率线性增长，在高频 (near-Nyquist) 输入时尤为严重：

```
SFDR_skew ≈ 20log₁₀(1/(M·π·f_in·σ_skew)) dB  |  σ_skew = 偏斜标准差
```

例如：4 通道 TI-ADC @ f_in=10 GHz，若要 SFDR>60 dBc，需 σ_skew < 50 fs。这要求时钟分配网络和版图达到飞秒级精度。

### 4. 带宽失配

各通道输入带宽不同 (由采样开关 R_on、输入电容 C_s 和版图寄生差异导致) → 高频输入时不同通道呈现不同的衰减和相移。带宽失配可等效为频率相关的增益和时序误差：

```
H_k(jω) ≈ (1 + Δg_k) · e^(jω·Δt_k)
```

> **💡 AE 核心认知**：TI-ADC 的 SNR 由子 ADC 性能和失配校准共同决定。4 通道 8-bit TI-ADC 未经校准时 SFDR 可能仅 30~40 dBc；经全数字后台校准后可达 55~65 dBc。时序偏斜校准是 >10 GSPS TI-ADC 的核心技术壁垒。

## 三、核心模块深度解析

### 一、子 ADC 架构选择

子 ADC 架构决定 TI-ADC 的基准精度和每通道功耗。不同架构在速度、精度、面积和功耗之间的权衡：

| 子 ADC 类型 | 每通道 f_s,ch | 每通道分辨率 | 功耗/ch | 适用场景 |
|-------------|---------------|--------------|---------|----------|
| SAR ADC | 100k~200M | 8~14b | 低 (<5 mW) | 中高速中高精度，最常用 |
| Pipeline ADC | 50M~500M | 10~14b | 中高 (10~100 mW) | 每通道高速，减少 M |
| Flash ADC | 500M~5G | 4~8b | 极高 (W) | 超高速低精度，光通信 |
| Folding/Interpolating | 200M~2G | 6~8b | 高 | 高速中低精度 |

### 二、多相时钟生成 — 飞秒级精度

M 相精确等间距时钟是 TI-ADC 的基石。DLL (Delay-Locked Loop) 和 PLL 是两种主流方案：

```
Φ_k 相位 = 2πk/M ± ΔΦ_k  |  ΔΦ_k = 偏斜误差 → 导致杂散
```

| 方案 | 优点 | 缺点 | 偏斜典型值 |
|------|------|------|------------|
| DLL + 相位插值 | 低抖动，对电源噪声不敏感 | 锁定范围有限，需参考时钟 | 0.5~5 ps |
| PLL (多相 VCO) | 频率灵活，可倍频 | VCO 相位噪声积累，功耗高 | 1~10 ps |
| 注入锁定振荡器 | 极低抖动，高频率 | 锁定范围窄，PVT 敏感 | 0.1~2 ps |
| 数字相位校准 | 可编程补偿，灵活 | 受限于检测精度和调整步进 | 经校准 <0.1 ps |

### 三、增益与失调失配校准

增益和失调失配在频域产生确定性杂散，可通过数字域校准消除：

| 前台校准 | 后台校准 |
|----------|----------|
| ✅ 精度高 (可 <0.01%) | ✅ 连续工作，跟踪 PVT 漂移 |
| ✅ 实现简单 | ✅ 不需中断正常转换 |
| ❌ 需中断正常工作 | ❌ 算法复杂，收敛慢 |
| ❌ 无法跟踪温度漂移 | ❌ 对信号统计特性有假设 |
| 方法：注入已知 DC/正弦参考 → 测量各通道输出 → 存储校正系数 | 方法：相关性检测 / PN 注入 / 参考通道 / LMS 自适应 |

### 四、时序偏斜校准 — 核心技术壁垒

时序偏斜校准分为检测和校正两个环节：

**检测方法：**
- **相关法**：相邻通道输出相关性 → 偏斜符号和幅度估计。简单但对信号频谱有要求
- **参考 ADC 法**：额外增加一个低速高精度参考 ADC，分时与各子 ADC 采样同一信号 → 比较各通道与参考的差异 → 最精确
- **FFT 能量检测**：监测偏斜杂散的能量 → 反馈调整。收敛慢但鲁棒

**校正方法：**
- **模拟域**：可调延迟线 (DTC) 调整各通道采样时钟相位 → 精度受 DTC 分辨率限制
- **数字域**：数字分数延迟滤波器 (Farrow 结构) 或多项式插值 → 灵活但消耗数字资源
- **混合域**：模拟粗调 + 数字细校 → 兼顾精度和功耗

```
校准后偏斜残差 < 50 fs (先进设计中可至 10~20 fs)
```

### 五、输入网络与带宽扩展

TI-ADC 的输入网络需要驱动 M 个并行采样开关，总输入电容 = M × C_s,ch。高频下输入阻抗下降，需要片上宽带缓冲器或分布式输入 T-line。输入带宽 BW_in > f_s/2 是基本要求：

```
BW_in = 1/(2πR_s·M·C_s,ch)  |  R_s = 源阻抗+开关R_on
```

高通道数 (M>16) 设计中，常见采用分级缓冲或行波分发 (Traveling Wave Distribution) 架构。

## 四、芯片内部电路框图

```
┌────────────────── 模拟域: M 个并行子 ADC + 输入缓冲 ──────────────────┐
│  宽带输入缓冲(驱动M·Cs, BW>fs/2) → 子ADC₀/子ADC₁/.../子ADCM-1        │
│  (SAR/Pipeline/Flash, fs,ch=fs/M)                                    │
│  多相时钟生成与分配 (DLL/PLL): Φ₀(t=0)→Φ₁(t=Ts/M)→...→ΦM-1          │
│  H-tree 等延迟分配 | DTC 可编程延迟线 (偏斜校准)                      │
│  VREF + Bandgap + 偏置                                               │
└──────────────────────────────────────────────────────────────────────┘
┌──────────────── 数字域: 通道失配校准与输出拼接 ───────────────────────┐
│  失配检测(相关/LMS/参考ADC法) → 数字校正(增益×/失调+/偏移Δ) → M:1 MUX 拼接 → DOUT │
└──────────────────────────────────────────────────────────────────────┘
电源与高速接口域: AVDD/DVDD 分离 | M× 通道电流
子ADC架构选择: SAR(<200M/ch,低功耗) | Pipeline(<500M/ch,中功耗) | Flash(<5G/ch,高功耗)
输出接口: JESD204C/D SerDes | 数据率 = fs×N (可达Tbps)
关键挑战: 时序偏斜 <50fs RMS | 增益/失调/带宽失配 | 通道间串扰 <−70dB | Ptotal=M×Pch
CMOS 工艺 28nm~5nm | fs = 100M~100+ GSPS | 分辨率 8~14 bit | M = 2~256
```

**说明**：TI-ADC 以面积和功耗的线性增长换取速度的 M 倍提升。核心挑战不是子 ADC 本身，而是通道间失配的检测与校准——尤其是随输入频率线性恶化的时序偏斜。现代 TI-ADC 依赖全数字后台校准实现接近单通道 ADC 的 SFDR。

## 五、核心对比：ADC 架构全景

### 四大 ADC 架构对比

| 维度 | Time-Interleaved | Pipeline | SAR | Sigma-Delta |
|------|------------------|----------|-----|-------------|
| 分辨率 | 8~14 bit | 8~16 bit | 8~18 bit | 16~32 bit |
| 采样率 | 100M~100+ GSPS | 10M~1 GSPS | DC~10 MSPS | DC~100 kHz |
| 通道数 | 2~256 (并行) | 1 (流水线级) | 1 | 1 |
| 功耗 | M × P_ch (mW~W) | mW~W | nW~mW | μW~mW |
| 面积 | 极大 (M×面积) | 大 (多级) | 小 | 中 (数字为主) |
| 延迟 | 取决于子 ADC | 6~12 周期 | N 周期 | 大 (滤波) |
| 核心挑战 | 失配校准 (偏斜/增益/失调) | 级间增益精度 | 电容匹配 | 运放噪声/空闲音 |

| 时钟精度要求 | 飞秒级 (偏斜) | ps 级 (非交叠) | 中等 | 低 (OSR 容忍) |

> **决策树**：<100M+>12b → Pipeline | 100M~1G+10~12b → Pipeline | >1G+8~12b → TI-SAR | >10G+6~8b → TI-Flash

## 六、核心指标

| 参数 | 范围 | 说明 |
|------|------|------|
| 分辨率 | 8~14 bit | 由子 ADC 架构和校准精度决定 |
| 采样率 f_s | 100 MSPS~100+ GSPS | = M × f_s,ch |
| 通道数 M | 2~256 | 速度与面积/功耗的线性折中 |
| 每通道速率 | 100k~5G (取决于架构) | SAR: <200M; Pipeline: <500M; Flash: <5G |
| 输入带宽 | > f_s/2 | 需宽带输入缓冲驱动 M 个通道 |
| SNDR | 40~78 dB | 受失配和子 ADC 噪声限制 |
| ENOB | 6.5~12.7 bit | (SNDR−1.76)/6.02 |
| SFDR (校准后) | 55~80 dBc | 时序偏斜杂散通常是 SFDR 瓶颈 |
| 时序偏斜 (校准后) | <50~100 fs RMS | >10 GSPS 时需 <20 fs |
| 功耗效率 | 0.05~2 pJ/step | 先进 TI-SAR 可达 <0.1 pJ/step |

### 时序偏斜 (Timing Skew)（核心指标）

- **定义**：各通道实际采样时刻与理想等间隔时刻的偏差
- **公式**：SFDR ≈ 20log(1/(M·π·f_in·σ_skew))
- **典型**：未校准: 1~5 ps; 前台校准后: 0.1~1 ps; 全数字后台校准: <50 fs

## 七、影响因素分析

| 指标 | 影响因素 | 影响下游 |
|------|----------|----------|
| SFDR | 时序偏斜、增益失配、失调失配、带宽失配 | ENOB, 杂散 |
| SNR/SNDR | 子ADC噪声、时钟抖动、输入缓冲噪声、校准残差 | ENOB, BER |
| f_s,max | 子ADC速度、时钟频率、M、建立时间 | 信号带宽 |
| 输入带宽 | M×C_s、缓冲器GBW、版图寄生 | 高频SFDR |
| 功耗 | M、子ADC功耗、校准数字功耗、时钟生成 | 热预算 |
| 通道间串扰 | 衬底耦合、时钟馈通、输入网络耦合 | SFDR, 杂散 |

> **总结**：TI-ADC 以面积和功耗的线性增长换取速度的 M 倍提升。核心瓶颈不是子 ADC 本身，而是通道间失配——尤其是随输入频率线性恶化的时序偏斜。因此 TI-ADC 竞争力的本质是校准算法的有效性。

## 八、测试方法

### ⓵ 偏斜杂散测试 — 高频 FFT 频谱法

施加高频正弦波 (f_in 接近 f_s/2) → FFT 分析 → 检查 f_s/M ± f_in, 2f_s/M ± f_in 处的杂散幅度。高频输入下偏斜杂散最显著，是 TI-ADC 最关键的测试项。

**测试框图**：
```
超低相噪信号源(R&S SMA100B, 相噪<-140dBc/Hz) → DUT(TI-ADC) → 高速采集系统(>2×fs采样率, Nrec≥128K) → FFT杂散分析(fs/M±fin杂散)
超低相噪晶振(抖动<50fs RMS) ─────────────────────────────────────────────────────────────────────→
判定: 偏斜杂散 < SFDR目标 | 校准后改善 >10~20dB | fin 近 fs/2
```

### ⓶ 增益/失调失配测试

低频正弦输入 (偏斜影响最小) → 分析 f_s/M 整数倍处的杂散 (失调失配) 和 k·f_s/M ± f_in 处的杂散 (增益失配)。也可 DC 输入直接测失调失配，正弦扫幅测增益失配曲线。

**测试框图**：
```
信号源/DC源(AWG/SMU, DC/低频正弦) → DUT(TI-ADC) → 采集+FFT(fs/M杂散分析, 失调±增益杂散) → 自动化脚本(扫频/扫幅分析)
判定: 失调杂散 < −60 dBFS | 增益杂散 < −60 dBFS
```

### ⓷ 通道间串扰测试

特定通道注入满幅信号，其他通道输入接地 → 测量未注入通道输出中的信号泄漏。通过交叉相关分析量化串扰幅度。版图设计阶段需通过 EM 仿真预评估。

- **设备**：多通道 AWG + 高速采集系统 + 交叉相关分析软件
- **判定**：串扰 < −70 dB (10+ bit TI-ADC)；串扰过高 → SFDR 恶化，需版图优化

## 九、注意事项

| 注意事项 | 说明 |
|----------|------|
| ⏰ 时序偏斜 | TI-ADC 头号杀手。飞秒级偏斜在 >10 GSPS 下即可产生 >−40 dBc 杂散。版图对称布局、等长时钟走线、DTC 模拟校准 + 数字分数延迟滤波器是完整解决方案 |
| 📡 通道间串扰 | M 个通道集成在同一芯片上，大信号跳变通过衬底、电源和输入网络耦合到其他通道。版图隔离 (深 N-well, Guard Ring, 分布式去耦) 必不可少 |
| ⚡ 输入缓冲驱动能力 | TI-ADC 输入端等效电容 = M × C_s，大 M 下输入阻抗极低。需要片上宽带缓冲器或分布式输入网络。驱动不足 → 带宽下降 → 高频 SNDR 滚降 |
| 🔌 电源分配网络 (PDN) | M 个通道以 M 相时钟交错工作 → 电源电流在 f_s/M 和 f_s 处有显著纹波 → 通过 PDN 阻抗产生电压波动。需要充分的片上/片外去耦和 PDN 设计 |
| 💥 时钟抖动累积 | TI-ADC 对时钟相位噪声的要求等同于相同 f_s 的单通道 ADC → 在 >10 GSPS 下，时钟抖动需 <50 fs RMS 才能实现 >50 dB SNR。这是整个系统 (晶振+PLL+分配) 的综合挑战 |
| 📦 数字输出带宽 | TI-ADC 总输出数据率 = f_s × N bit/s，在 64 GSPS × 12 bit = 768 Gbps。通常需要 SerDes (JESD204C/JESD204D) 接口传输，通道数可达 16~32 lane |

> **🚨 TOP 5 常见错误**：
> 1. 忽略时序偏斜校准 → SFDR 仅 30~40 dBc
> 2. 输入网络设计不足 → 高频输入严重衰减
> 3. 时钟偏斜末校准 → 看似随机的高杂散
> 4. PDN 设计不充分 → 通道间通过电源耦合
> 5. 数字输出接口带宽不足 → 无法传输完整数据速率

## 十、选型指南

### 选用 Time-Interleaved 的场景

- 需要 >1 GSPS 采样率
- 8~14 bit 分辨率已足够
- 接受多通道面积/功耗代价
- 系统具备校准能力或选择内置校准的 TI-ADC
- 超宽带应用 (瞬时带宽 >500 MHz)
- 光通信/雷达/仪器仪表等高价值应用

### 不适合 Time-Interleaved 的场景

- <500 MSPS + >12b → 单通道 Pipeline
- <10 MSPS + >14b → SAR
- 极低功耗/面积限制 → SAR 或 Pipeline
- 对校准复杂度/成本敏感 → 单通道方案
- 需要即时启动 (无校准时间) → 单通道方案

### 按场景选型

| 场景 | f_s | 分辨率 | 子ADC架构 | M |
|------|-----|--------|-----------|-----|
| 相干光通信 | 128 GSPS | 8b | TI-Flash | 32~64 |
| 宽带雷达接收 | 4~10 GSPS | 10~14b | TI-SAR | 8~32 |
| 5G 毫米波 | 2~6 GSPS | 10~12b | TI-SAR/Pipeline | 4~16 |
| 高速示波器 | 10~256 GSPS | 8~12b | TI-Flash/SAR | 32~256 |
| SerDes/背板 | 28~112 GSPS | 5~8b | TI-Flash | 16~64 |
| 仪器仪表 | 1~5 GSPS | 12~14b | TI-Pipeline | 4~8 |

> **AE认知**：TI-ADC 是突破速度极限的"并行主义"方案。选型核心是确认子 ADC 架构 (决定基础精度) 和校准能力 (决定实际 SFDR)。对于 >10 GSPS 应用，时序偏斜校准是区分 TI-ADC 产品优劣的核心技术指标。
