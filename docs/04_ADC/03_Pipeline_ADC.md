## 一、产品概述

Pipeline ADC 是**中高速、中高精度领域的主流 ADC 架构**，通过多级流水线结构将逐次逼近的串行过程分解为多级并行处理：每一级完成低分辨率量化后，将残差放大并传递到下一级继续量化。在 10 MSPS~1 GSPS 速率范围内，Pipeline ADC 在速度、精度和功耗之间取得了最优平衡，广泛用于无线通信、视频处理、医疗成像和仪器仪表等领域。

### 产品定位

- **产业链位置**：RF/IF 前端与数字基带处理器之间，负责高速高精度模数转换
- **核心价值**：多级流水线并行处理，在 MSPS~GSPS 速率下实现 10~16 bit 分辨率
- **本质功能**：N 级流水线级联：每级 Sub-ADC (粗量化) + Sub-DAC (重构) + 残差放大 (MDAC) + 数字校正

### 典型应用场景

- 无线通信基站 (IF 采样接收机)
- 宽带软件无线电 (SDR) 接收机
- 医疗超声/CT 成像前端
- 高速数据采集卡 (DAQ)
- 雷达数字波束成形接收机
- 视频/图像传感器接口

### 技术路线

| 维度 | 规格 | 说明 |
|------|------|------|
| 分辨率 | 8~16 bit | 由级间增益精度和 comparator offset 校准决定 |
| 采样率 | 10 MSPS~1 GSPS | 流水线延迟 6~12 周期，吞吐率 = f_s |
| 每级位数 | 1~4 bit/级 (典型 1.5b) | 更低/级 → 更易校准但更多级数 |
| 级间增益 | G = 2^k (k=每级分辨率) | 闭环运放实现精确增益，增益误差直接影响 INL |
| 冗余与校正 | 1.5-bit/级 + 数字纠错 | 冗余容忍比较器失调，消除失码 |
| MDAC 架构 | 开关电容 MDAC | 同时完成 DAC 减法、残差采样和增益放大 |
| 工艺 | CMOS (65nm~7nm) | 先进工艺下运放增益下降，需增益增强技术 |
| 功耗特性 | mW~W | 多级运放静态偏置 + 动态开关功耗 |

## 二、工作原理

Pipeline ADC 的核心是将**N-bit 转换分解为多级低分辨率转换流水线**。每一级包含 Sub-ADC (粗量化)、Sub-DAC (重构)、减法器和残差放大器 (MDAC)。级间并行工作，每周期完成一个新采样，延迟由流水线深度决定。

### 系统级信号流向

```
VIN → S/H → Stage1(Sub-ADC 1.5b → DAC重构 → MDAC G=2) → Stage2(Sub-ADC 1.5b → DAC重构 → MDAC G=2) → ... → Stage M(Flash ADC)
              ↓ 数字位 D1                    ↓ 数字位 D2                              ↓ 数字位 DM
              └──────────────→ 数字延迟对齐+纠错 (1.5b冗余 → 移位叠加) ←──────────────┘
                                                                                        ↓
                                                                                      DOUT
⏱ Φ1采样/Φ2放大 | 相邻级时钟交错 | 吞吐率=fs | 延迟=M×Tclk
```

### 1. 单级流水线操作 (1.5-bit 为例)

```
V_residue = G × (V_in − V_DAC)  |  G = 2^(k−1) (1.5b 时 G=2)
```

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1. 采样 | S/H 采样 V_in | 前端 T/H 或 MDAC 自采样 |
| 2. 粗量化 | Sub-ADC (2 个比较器, 3 区间) | 判决 V_in 落在 3 个区间: <-V_REF/4, 中间, >+V_REF/4 |
| 3. DAC 重构 | Sub-DAC 输出对应电平 | −V_REF/2, 0, +V_REF/2 |
| 4. 残差放大 | MDAC 放大 (V_in−V_DAC) ×2 | 残差放大到满幅供下一级量化 |

### 2. 1.5-bit/级 冗余与数字校正

每级使用 1.5-bit (2 个比较器 + 3 区间判决) 而非 2-bit，留出 ±V_REF/4 的冗余区间。比较器失调在冗余范围内被容忍，相邻级输出经移位相加即可完成数字校正——这是 Pipeline ADC 能够容忍较大比较器失调的根本原因。

```
最终码 = D1 × 2^(N−1) + D2 × 2^(N−2) + ... + DM × 2^(N−M)
```

### 3. MDAC — 精度核心

开关电容 MDAC (Multiplying DAC) 同时完成：采样输入、减去 DAC 电平、乘以级间增益。在Φ1 (采样相) 采样输入到电容；在Φ2 (放大相) 切换电容下极板到 DAC 参考电平，运放闭环放大。增益精度取决于电容比例和运放开环增益。

```
G_effective = G_ideal × (1 − 1/(A_OL·β))  |  β = 反馈系数
```

### 4. 流水线时序与吞吐率

每级需要两相非交叠时钟 (Φ1 采样 + Φ2 放大)，相邻级时钟相位交错。采样数据在每个时钟沿依次通过各级，首级处理第 n 个采样时，第二级处理第 n-1 个采样... 形成流水线。延迟 = M×T_clk (M 级)，但每个时钟周期输出一个转换结果。

```
吞吐率 = f_s = 1/T_clk  |  延迟 = M × T_clk (M = 流水线级数)
```

> **💡 AE 核心认知**：Pipeline ADC 的精妙之处在于以 1.5-bit/级 + 数字校正的架构，将比较器精度要求从 N-bit 降低到 ±V_REF/4 (仅需 2-bit 级精度)。真正的精度瓶颈是 MDAC 的级间增益误差和运放建立精度。

## 三、核心模块深度解析

### 一、MDAC (Multiplying DAC) — 精度的物理载体

MDAC 是 Pipeline ADC 最关键的模拟模块，集成 DAC 减法、残差增益放大和采样保持功能于一体：

```
V_out = (C_s/C_f) × V_in − Σ(C_i/C_f) × V_DAC,i
```

| 参数 | 公式/关系 | 工程权衡 |
|------|-----------|----------|
| 理想增益 | G = C_s/C_f = 2^(k−1) | C_s 总面积由 kT/C 噪声决定 |
| 增益误差 | ε_G ≈ 1/(A_OL·β) + ΔC/C | 运放增益 + 电容匹配；直接影响 INL |
| 建立时间 | t_settle = (N+1)ln2×τ/β | 高 β (低增益) → 更快建立 |
| kT/C 噪声 | v_n² = kT/(β·C_total) | C 增大 → 噪声降 → 速度和功耗代价 |

### 二、运放设计 — 速度与功耗的博弈

Pipeline ADC 中的运放必须在半个时钟周期内完成建立，其 GBW 和摆率 (Slew Rate) 要求随采样率提高而急剧增加：

```
GBW > (N+1)·β·ln2 / (2π·t_settle)  |  SR > V_FS/t_slew
```

| 运放架构 | 增益 | 速度 | 功耗 | 适用 |
|----------|------|------|------|------|
| 套筒式 (Telescopic) | 50~60 dB | 高 | 低 | 先进工艺，低压 |
| 折叠式 (Folded Cascode) | 60~70 dB | 中高 | 中 | 通用，输出摆幅大 |
| 两级运放 (Miller) | 80~100 dB | 中 | 中高 | 高线性度，需补偿 |
| 增益增强 (Gain-Boosted) | 100~120 dB | 中 | 高 | 极高精度，>14b |

### 三、Sub-ADC 设计

每级的 Sub-ADC 是低分辨率 Flash ADC (通常 1~4 bit)。对于 1.5-bit/级的方案，仅需 2 个比较器，阈值设为 ±V_REF/4。比较器失调只要不超过 ±V_REF/4 即可被数字校正容忍——这是 1.5-bit 架构的核心优势。先进设计中常使用动态比较器以消除静态功耗。

| 1.5-bit/级 (最常用) | 多位/级 (2.5~3.5b/级) |
|---------------------|------------------------|
| ✅ 最大冗余容忍范围 (±V_REF/4) | ✅ 级数少，延迟小 |
| ✅ 比较器设计最简单 | ✅ 每级完成更多位，总功耗可能更低 |
| ✅ MDAC 增益最低 (G=2) 最易实现 | ❌ MDAC 增益高 (G=4~8) 建立困难 |
| ❌ 级数最多 (N 级 for N-bit) | ❌ 比较器需要更高精度 |
| ❌ 总延迟最大 | ❌ 冗余容忍范围缩小 |
| ❌ 总功耗较高 (多级累加) | ❌ 电容匹配要求更高 |

### 四、时钟分布与级间时序

高速 Pipeline ADC 中，精准的两相非交叠时钟 (Φ1, Φ2) 分布至关重要。每级需要：采样相 (Φ1) + 放大相 (Φ2)，相邻级相位交错。时钟偏斜 (skew) 直接侵蚀建立时间余量：

```
剩余建立时间 = T_clk/2 − t_skew − t_non-overlap
```

在 GSPS 级 Pipeline ADC 中，半周期仅 500 ps，时钟偏斜必须 <10 ps 才能保证运放有足够的建立时间。

### 五、校准技术

| 校准类型 | 校准对象 | 方法 | 复杂度 |
|----------|----------|------|--------|
| 数字后台校准 | 级间增益误差 | PN 注入 + 相关性检测 / Skip-and-Fill | 高 |
| 模拟前台校准 | MDAC 电容失配 | 已知参考电压校准电容权重 | 中 |
| 冗余容忍 | Sub-ADC 比较器失调 | 1.5-bit/级 + 数字纠错 (天然容忍) | 低 |
| 运放增益校准 | 有限 A_OL 引起的增益误差 | 动态偏置 / Gain-Boosting / 后台测量 | 中高 |

## 四、芯片内部电路框图

```
┌────────────────────────── 模拟域: M 级流水线核心 ──────────────────────────┐
│  T/H → Stage1(1.5-bit) → Stage2(1.5-bit) → ... → Flash(M级)              │
│  (输入采样)  Sub-ADC+MDAC   Sub-ADC+MDAC                                  │
│              G=2 | GBW最高   + 比较器冗余容忍                              │
│  非交叠时钟发生器(Φ1/Φ2, 偏斜<10ps) | VREF+偏置电流源(高速缓冲,多级去耦)     │
└────────────────────────────────────────────────────────────────────────────┘
┌────────────────── 数字域: 延迟对齐与数字纠错 ──────────────────────────────┐
│  移位寄存器1 → 移位寄存器2 → ... → 移位寄存器M → 数字纠错加法器 → N-bit     │
│  (可选: 后台校准 PN注入/相关性/Skip-and-Fill)                              │
└────────────────────────────────────────────────────────────────────────────┘
电源与接口: AVDD/DVDD/VIO | 运放架构: 套筒式/折叠式/两级/Gain-Boosted
输出接口: 并行 LVDS/CMOS | 串行 JESD204B/C
关键规格: Stage1 GBW > 数 GHz | 14b → εG < 0.006% | 延迟 = M × Tclk
CMOS 工艺 65nm~7nm | 吞吐率 = fs | 分辨率 8~16 bit | 10 MSPS~1 GSPS
```

**说明**：Pipeline ADC 的核心竞争力在于 1.5-bit/级 + 数字纠错架构——用冗余区间容忍比较器失调，将精度压力转移到 MDAC 的级间增益和运放建立。第一级 MDAC 的设计要求最严苛。

## 六、核心指标

| 参数 | 范围 | 说明 |
|------|------|------|
| 分辨率 | 8~16 bit | 由级间增益精度和 MDAC 建立精度决定 |
| 采样率 f_s | 10 MSPS~1 GSPS | 受运放 GBW 和建立时间限制 |
| 功耗 | 10 mW~2 W | 与级数、f_s 和运放类型直接相关 |
| SNDR | 45~88 dB | f_in 近 Nyquist 时下降 |
| ENOB | 7.2~14.3 bit | (SNDR−1.76)/6.02 |
| SFDR | 55~95 dBc | 受运放谐波和开关非线性影响 |
| INL | ±0.5~±4 LSB | 级间增益误差累积 |
| DNL | ±0.3~±1 LSB | 1.5b/级冗余确保无失码 |
| 流水线延迟 | 6~12 周期 | M×T_clk；对控制环路需考虑 |
| Walden FoM | 0.1~2 pJ/step | P/(2^ENOB×f_s) |

### 级间增益误差 (Inter-stage Gain Error)（核心指标）

- **定义**：MDAC 实际增益与理想增益 (G=2^(k−1)) 的偏差
- **公式**：ε_G = (G_actual−G_ideal)/G_ideal ≈ −1/(A_OL·β) − ΔC/C
- **典型**：未校准: 0.1~1%; 校准后: <0.01%; 14b 需要 <0.006%

## 七、影响因素分析

| 指标 | 影响因素 | 影响下游 |
|------|----------|----------|
| ENOB | MDAC增益误差、运放噪声、时钟抖动、kT/C | SNR, 精度 |
| INL/DNL | 电容失配、运放增益、校准效能 | ENOB, SFDR |
| SFDR | 运放谐波、开关非线性、参考纹波 | EVM, 杂散 |
| f_s,max | 运放GBW/SR、时钟偏斜、建立时间 | 信号带宽 |
| 功耗 | 级数M、f_s、运放偏置 | 热预算 |
| 延迟 | 流水线级数、时钟周期、输出锁存 | 控制环路稳定性 |

> **总结**：Pipeline ADC 性能的决定因素是 MDAC 的增益精度和运放建立速度。先进工艺下运放本征增益下降，使得增益增强 (Gain-Boosting) 和数字校准技术成为 14+ bit 设计的必备手段。

## 八、测试方法

### ⓵ 动态性能 — FFT 频谱法 (SNR/SNDR/SFDR)

施加低相噪正弦波 (f_in 接近 Nyquist/2) → 相干采样 → 采集 128K~1M 点 → 加窗 FFT → 计算 SNR/SNDR/SFDR。高频 near-Nyquist 输入最能暴露运放建立不足和时钟抖动的影响。

**测试框图**：
```
超低相噪信号源(R&S SMA100B, 相噪<-140dBc/Hz) → 带通滤波(BPF滤除谐波) → DUT(Pipeline ADC) → 逻辑分析仪(Keysight 16860A, Nrec≥128K点) → FFT分析(SNR/SNDR/SFDR)
判定: SNDR ≥ 标称−3dB | SFDR ≥ 标称−5dBc | fin 近 Nyquist 最严苛
```

### ⓶ INL/DNL — 码密度直方图法

施加低失真正弦波 → 采集 >1M 点 → 正弦码密度直方图分析。高速 Pipeline 输出码率极高，需保证采集卡时序分辨率充足。也可使用高精度斜坡信号源 → 逐码统计法。

**测试框图**：
```
低失真信号源(THD 比DUT高3bit, 正弦/斜坡) → DUT(Pipeline ADC) → 高速采集卡(>1M采样点, 时序精度充足) → PC分析(DNL/INL计算)
判定: INL < ±2 LSB (14b) | DNL < ±0.5 LSB | 无失码
```

### ⓷ 流水线延迟测量

施加阶跃输入信号 (快速上升沿) → 同时捕获模拟输入和 ADC 数字输出 (高速示波器 + 逻辑探头) → 测量从模拟阶跃到对应数字码出现在输出端口的时间差。

- **设备**：AWG (Keysight 33600A) + 高速示波器 (Keysight MSO-S 系列) + 逻辑探头
- **判定**：延迟 = 标称值 ±1 个时钟周期 (典型 6~12 T_clk)

## 九、注意事项

| 注意事项 | 说明 |
|----------|------|
| ⚡ MDAC 建立时间 | Pipeline ADC 中最关键的设计约束。运放必须在半周期内建立到目标精度 (如 14b = 0.006%)。运放 GBW 和摆率不足直接导致 INL 和 SNDR 恶化。第一级 MDAC 的要求最苛刻 |
| 💥 参考电压缓冲 | MDAC 中 DAC 切换从 V_REF 抽取瞬态电流 → V_REF 纹波。需要片上高速缓冲器 + 片外多级去耦 (10μF + 0.1μF + 10nF)。第一级 MDAC 参考缓冲器的 BW 需 > 数倍 f_s |
| ⏰ 时钟偏斜 | 高速 Pipeline (>200 MSPS) 中，Φ1/Φ2 的非交叠间隔和偏斜直接侵蚀建立时间。偏斜需 <5~10 ps，需在版图中做时钟树平衡。差分时钟 (CML/LVDS) 优于单端 |
| 🔌 前端 T/H 线性度 | 前端采样保持电路的非线性 (尤其是开关 R_on 调制) 直接限制整体 SFDR。自举开关 (Bootstrapped Switch) 是必备技术。高线性度 (>90 dB SFDR) 需底部板采样 |
| 🌊 级间串扰 | 后级 MDAC 的大信号跳变通过衬底和电源耦合到前级 → 记忆效应 (Memory Effect)。版图隔离 (深 N-well, Guard Ring) 和信号路径线性化至关重要 |
| 🌡️ 热梯度 | 多级运放的功耗集中产生热梯度 → 版图需对称布局，关键模块 (第一级 MDAC、Bandgap) 置于芯片等温线上，远离输出驱动等大功耗模块 |

> **🚨 TOP 5 常见错误**：
> 1. MDAC 运放建立不足 → 高频 SNDR 骤降
> 2. V_REF 去耦不足 → 级间串扰 → SFDR 降
> 3. 时钟偏斜过大 → 建立余量不足 → 功能失效
> 4. 前端 T/H 非线性 → 整体 SFDR 天花板
> 5. 数字输出驱动与模拟域隔离不足 → 衬底耦合噪声

## 十、选型指南

### 选用 Pipeline 的场景

- BW 10M~500 MHz
- 10~14 bit 分辨率
- 需要高吞吐率 (每周期 1 次转换)
- 可接受流水线延迟 (6~12 周期)
- 无线通信/视频/雷达等中高频应用

### 不适合 Pipeline 的场景

- <10 MHz + >14b → SAR/Sigma-Delta
- >500 MHz + <10b → Time-Interleaved
- 极低功耗 (<1 mW) → SAR
- 需要单周期延迟 → Flash
- 成本/面积极度敏感 → SAR

### 按场景选型

| 场景 | 分辨率 | f_s | 特点 |
|------|--------|-----|------|
| 基站 IF 接收 | 12~14b | 80~250M | 高 SFDR, 低噪声 |
| 软件无线电 | 12~16b | 50~500M | 宽带, 高线性度 |
| 医疗超声 | 12~14b | 40~80M/ch | 多通道, 低功耗/ch |
| 高速 DAQ | 14~16b | 100~250M | 最高精度, 可接受功耗 |
| 雷达接收 | 12~14b | 100~500M | 宽带, 低延迟 |
| 视频处理 | 10~12b | 50~150M | 中精度, 低成本 |

> **AE认知**：Pipeline ADC 是高速中高精度的最佳选择。选型核心在于确认第一级 MDAC 的建立时间 (运放 GBW) 是否匹配目标 f_s。14b@250MSPS 的 Pipeline ADC 的第一级运放 GBW 通常需达到 5~10 GHz (先进工艺)。
