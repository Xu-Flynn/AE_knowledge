# 储能 BMS AFE (电池管理系统模拟前端)

---

## 一、产品概述

### 1.1 产品定位
储能BMS AFE (Analog Front-End) 是大规模储能系统中电池管理系统的核心模拟芯片，负责对串联电池组中每个电池单元的电压、温度和电流进行高精度监测，以及执行电池均衡。

### 1.2 应用场景
- 大型储能电站 (Grid-scale ESS): >1MWh
- 工商业储能 (C&I ESS): 100kWh~1MWh
- 家庭储能 (Residential ESS): 5~20kWh
- 通信基站备电 (Telecom backup)
- UPS不间断电源

### 1.3 技术路线
- 监测电池串数: 12~18串/芯片 (可堆叠至 >1000V系统)
- 电压测量精度: +/-1mV (关键指标!)
- ADC: 16~18bit Sigma-Delta ADC
- 通信: 可堆叠SPI (daisy-chain) 或 隔离CAN
- 均衡: 被动均衡 (内置MOS开关) 或 主动均衡接口
- 工艺: BCD (Bipolar-CMOS-DMOS), 高压耐受

## 二、工作原理

### 2.1 BMS系统架构

```
电池组 (n串) -> BMS AFE (每12~18串1颗) -> MCU -> 通信 -> 系统控制器
                     |
               均衡电路 (被动/主动)
               温度监测 (NTC)
               电流监测 (Shunt/Hall)
```

### 2.2 AFE核心功能

#### 2.2.1 电压监测 (Cell Voltage Monitoring)

**原理**: 差分测量每个电池单元的正负极电压

```
电池0:  V_cell0 = V0 - GND
电池1:  V_cell1 = V1 - V0
...
电池n:  V_celln = Vn - V(n-1)

每颗AFE测量12~18串, 通过高压MUX逐一切换测量
```

**测量链路**:
```
电池单元 -> 高压MUX -> 电平移位 -> 可编程增益放大器(PGA) -> Sigma-Delta ADC -> 数字滤波 -> 结果
```

**Sigma-Delta ADC原理**:
- 过采样 + 噪声整形
- 1-bit或Multi-bit量化器
- 数字抽取滤波器输出16~18bit结果
- 优点: 高分辨率, 高线性度, 适合DC/低频测量
- 缺点: 转换速率慢 (适合电池这种慢变信号)

#### 2.2.2 温度监测

- 外接NTC热敏电阻
- AFE内部提供激励电流源
- 测量NTC上的电压 -> 换算温度
- 每颗AFE可监测4~8路温度
- 精度: +/-1~2C

#### 2.2.3 电流监测

**两种方案**:
1. 分流电阻 (Shunt): 高精度, 高成本
   - AFE集成高精度电流ADC (16~18bit, 带PGA)
   - 典型Shunt值: 50~100uohm
2. 霍尔传感器 (Hall): 隔离, 大电流
   - AFE读取模拟电压接口

**库仑计数 (Coulomb Counter)**:
- 对电流进行时间积分: SOC = integral(I*dt)
- AFE内部硬件累积器, 无需MCU干预

#### 2.2.4 电池均衡 (Cell Balancing)

**被动均衡 (主流, AFE集成)**:
```
电池单元 -> 均衡开关(MOS, AFE内置) -> 均衡电阻 -> 热量耗散
均衡电流: 50~300mA (由外部电阻设定)
```

**工作原理**:
- 检测到某电池电压高于其他 -> 开启该电池的均衡开关
- 电流通过外部电阻耗散 -> 电池电压降低
- 持续均衡直至所有电池电压在阈值内

**主动均衡 (高端方案)**:
- 通过DC-DC/电容飞跨将高电压电池的能量转移到低电压电池
- 效率高但成本高, 通常需要外部电路

### 2.3 堆叠架构 (Stackable)

**Daisy-Chain SPI通信**:
```
MCU -> AFE#1 (底部) -> AFE#2 -> ... -> AFE#n (顶部)
  |         |              |               |
  +----隔离----+----隔离----+-----隔离-------+

每颗AFE有独立地址, MCU通过daisy-chain访问所有AFE
```

**高压隔离需求**:
- 底部AFE工作在地电位, 顶部AFE可能工作于 >1000V
- 芯片间通信需要电容/变压器隔离
- AFE内部集成隔离通信接口

## 四、关键指标

### 4.1 电压测量

| 指标 | 规格 | 含义 |
|------|------|------|
| 测量范围 | 0~5V/cell | 覆盖所有锂电池类型(LFP/NMC/LTO) |
| 测量精度 | +/-1mV @25C | 全温度校准后 |
| 温漂 | <10uV/C | 基准源温漂 |
| ADC分辨率 | 16~18bit | Sigma-Delta |
| 测量速度 | 100us~10ms/cell | 可编程 |
| 共模电压 | >1000V | 高压电池组顶部 |

### 4.2 电流测量

| 指标 | 规格 |
|------|------|
| 分流输入范围 | +/-100mV ~ +/-300mV |
| 电流ADC | 16~18bit, 可编程增益 |
| 库仑计数精度 | <0.5% (满量程) |
| 过流检测响应 | <10us |

### 4.3 均衡

| 指标 | 规格 |
|------|------|
| 均衡通道数 | 18 (每串独立) |
| 均衡电流 | 50~300mA (外部电阻设定) |
| 均衡MOS Ron | <2ohm (降低损耗) |
| 均衡模式 | 手动/自动/定时 |

### 4.4 系统

| 指标 | 规格 |
|------|------|
| 堆叠芯片数 | 最多40颗 (>700V) |
| 通信接口 | Daisy-chain SPI, 隔离CAN |
| 通信速率 | 1~4Mbps (SPI) |
| 功耗 | <10mA 工作, <100uA 待机 |
| 温度范围 | -40~+85C (工业级) |
| 封装 | QFP/TQFP 或 LQFP |

## 五、测试方法

### 5.1 电压测量精度测试

**测试原理**: 使用高精度电压源模拟电池电压, 测量AFE读数与参考电压的偏差

**测试设备**:
- 高精度电压源 (Fluke 5730A, 6.5位以上)
- 高精度万用表 (Keysight 3458A, 8.5位)
- 多通道模拟电池堆 (Battery Simulator)

**测试步骤**:
1. 电池模拟器输出精确电压 (如 3.000V, 3.500V, 4.000V, 4.200V)
2. AFE执行电压扫描
3. 记录AFE读数 vs 参考电压
4. 计算偏差: Error = V_afe - V_ref
5. 多温度重复: -40, +25, +85C
6. 要求: |Error| <1mV (校准后)

### 5.2 均衡功能测试

- 使能某通道均衡
- 测量均衡电流 (通过外部电阻压降)
- 验证均衡MOS开关Ron <2ohm
- 热测试: 长期均衡下芯片温升

### 5.3 堆叠通信测试

- 搭建多芯片(如20颗)堆叠系统
- 验证Daisy-chain通信可靠性
- 测量通信延迟和误码率

### 5.4 保护功能测试

- 过压/欠压: 扫描电压超过/低于阈值 -> 验证硬件比较器触发
- 过温: 加热 -> 验证OT保护
- 响应时间: 示波器测OV/UV Trigger -> Alert信号延迟

### 5.5 库仑计数精度测试

- 注入已知电流(精密电流源)
- 持续一段时间
- 读取AFE累积电荷值
- 偏差 <0.5%

## 六、AE知识要点

1. 电池类型与电压: LFP 3.2V, NMC 3.6~3.7V, LTO 2.3V
2. SOC/SOH估算: SOC(State of Charge), SOH(State of Health)
3. 电压精度是关键: +/-1mV影响SOC估算精度~0.5%
4. 均衡策略: 被动均衡成本低但有热量, 主动均衡效率高
5. 高压安全: >1000V电池堆的安全设计
6. 通信隔离: 高低压域之间的可靠隔离
7. 功能安全: 硬件保护(OV/UV/OT/OC)必须独立于MCU工作
8. 长寿命: 储能系统要求 >15年寿命
