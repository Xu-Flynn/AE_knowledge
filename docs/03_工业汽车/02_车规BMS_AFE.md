# 车规 BMS AFE (汽车电池管理系统模拟前端)

---

## 一、产品概述

### 1.1 产品定位
车规BMS AFE是电动汽车(EV/HEV)电池管理系统的核心芯片，负责对动力电池组中每串电池单元进行高精度、高可靠性的电压/温度/电流监测和均衡控制。

### 1.2 应用场景
- 纯电动汽车 (BEV): 400V/800V平台
- 插电混动 (PHEV)
- 混合动力 (HEV)
- 电动商用车 (电动卡车/大巴)
- 48V轻混系统 (MHEV)

### 1.3 车规 vs 储能的关键差异

| 特性 | 储能 BMS AFE | 车规 BMS AFE |
|------|-------------|-------------|
| 可靠性等级 | 工业级 | AEC-Q100 Grade 0/1 |
| 功能安全 | ASIL-B (可选) | ASIL-D (强制!) |
| 温度范围 | -40~+85C | -40~+125C (Grade 1) / +150C (Grade 0) |
| 振动/冲击 | 基本 | 严苛 |
| EMC | 工业标准 | CISPR 25 Class 5 (极严) |
| 冗余设计 | 可选 | 必须 (双ADC, 双基准, 双通信) |
| 故障诊断覆盖 | 基本 | >99% (ISO 26262) |
| 热插拔 | 不需要 | 需要 (电池包维护) |
| 长寿命 | 15年 | 15年/300000km |
| 认证 | 无特殊 | ISO 26262 ASIL-D |

## 二、工作原理

### 2.1 功能安全 (ISO 26262 ASIL-D)

**安全目标 (Safety Goal):**
- 防止电池过充 (可能导致热失控/起火)
- 防止电池过放 (可能导致永久损坏)
- 防止过温 (可能导致热失控)
- 防止过流 (可能导致火灾)

**ASIL-D 架构要求:**
- 双通道冗余测量 (独立ADC + 独立基准)
- 独立的硬件保护路径 (脱离MCU仍能工作)
- 自检 (BIST, Built-In Self Test)
- 故障注入检测 (测量链诊断)
- 通信CRC/校验
- 看门狗

### 2.2 冗余架构

```
          +-- ADC通道A -- 基准A -- 比较器A --+
电池单元---+                                  +---> 结果比较/表决
          +-- ADC通道B -- 基准B -- 比较器B --+

两通道完全独立 (电源/时钟/基准/ADC), 结果相互校验
```

### 2.3 故障诊断覆盖

| 诊断项 | 方法 |
|--------|------|
| ADC故障 | 周期性测量内部已知基准电压 |
| 基准漂移 | 双基准互比 |
| MUX故障 | 测量开路/短路检测 |
| 通信故障 | CRC, 超时, 序列号 |
| 均衡MOS故障 | 检测均衡电流/电压变化 |
| 温度传感器故障 | 开路/短路检测 |
| 电源故障 | 欠压/过压监测 |

### 2.4 同步测量

**需求**: 所有电池单元的电压必须在同一时刻测量(同步)
- 原因: 电池组中电流同时流过所有电池
- 异步测量会因电流变化导致SOC估算误差
- 实现: 全局同步信号触发所有AFE同时采样

### 4.2 电流测量

| 指标 | 规格 |
|------|------|
| 分流范围 | +/-300mV |

## 五、测试方法

### 5.1 车规特有测试

**AEC-Q100 全套认证测试:**
- HTOL (高温工作寿命): 1000h @125C
- TC (温度循环): 1000 cycles -55~+150C
- HAST (高加速应力): 130C/85%RH/96h
- ESD: HBM 2kV, CDM 750V
- 闩锁: 85C, +/-100mA

**EMC测试:**
- 辐射发射 (RE): CISPR 25 Class 5
- 传导发射 (CE): CISPR 25 Class 5
- BCI (大电流注入): 400mA, 1MHz~400MHz
- DPI (直接功率注入)
- ESD: ISO 10605 (车载ESD, 更高电压)

### 5.2 功能安全测试

**故障注入测试:**
- ADC故障注入: 模拟ADC卡滞/偏移/噪声超大
- 基准故障注入: 模拟基准漂移
- MUX故障注入: 模拟开路/短路
- 通信故障注入: CRC错误/超时/丢包
- 验证: 每次注入 -> 系统检测到故障 -> 进入安全状态

**冗余一致性测试:**
- 比较通道A和通道B测量结果
- 偏差 >阈值 -> 触发报警
- 验证双通道独立性

### 5.3 常规BMS测试
(与储能BMS AFE类似: 电压精度、均衡、堆叠通信、保护功能)

### 5.4 同步精度测试
- 多颗AFE堆叠(如20颗)
- 触发同步信号
- 示波器测量各AFE采样时刻差异
- 要求: <1us (全堆叠)

## 六、AE知识要点

1. ISO 26262功能安全是车规芯片的门槛
2. ASIL-D要求: 双冗余 + 独立保护路径 + >99%诊断覆盖率
3. AEC-Q100是车规芯片的可靠性认证基础
4. 车规EMC要求远严于工业级
5. 同步测量对SOC精度至关重要
6. 800V高压平台要求更好的隔离和安规设计
7. 热失控防护是最高安全目标
8. 汽车15年/30万km寿命要求极高的可靠性
9. 功能安全文档 (Safety Manual, FMEA, FMEDA) 是交付物的一部分
