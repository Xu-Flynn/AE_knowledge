# 高性能 SerDes (Serializer/Deserializer IP)

---

## 一、产品概述

### 1.1 产品定位
高性能SerDes是核心基础IP，应用于各类高速数据通信芯片中。SerDes将并行数据转换为高速串行数据(及反向转换)，是高速互联的物理层核心技术。

### 1.2 应用场景
- 数据中心交换芯片 (Switch ASIC)
- AI/ML加速器互联 (NVLINK, CXL)
- 光模块电接口 (oDSP的Host-Side SerDes)
- PCIe 6.0 PHY, CXL 3.0 PHY
- 芯片间Die-to-Die互联 (UCIe)

### 1.3 技术路线

| 参数 | 112G SerDes | 224G SerDes | 说明 |
|------|------------|------------|------|
| 单lane速率 | 106.25G PAM4 | 212.5G PAM4 | 含FEC开销 |
| 调制 | PAM4 | PAM4 | 4电平 |
| 工艺 | 5nm/3nm | 3nm/2nm | 最先进节点 |
| 面积 | ~0.3 mm^2/lane | ~0.4 mm^2/lane | |
| 功耗 | ~0.5W/lane | ~0.8W/lane | |
| 接口标准 | OIF-CEI-112G | OIF-CEI-224G | |

## 二、工作原理

### 2.1 SerDes基本架构

**发送方向 (Serializer):**
```
并行数据(32/64bit@~1GHz) -> 8b/10b或64b/66b编码 -> FIFO -> 
  -> 并串转换(Serializer) -> TX FIR预加重 -> TX Driver -> 差分输出
```

**接收方向 (Deserializer):**
```
差分输入 -> CTLE/DFE均衡 -> CDR时钟恢复 ->
  -> 数据采样 -> 串并转换(Deserializer) -> 解码 -> 并行数据输出
```

### 2.2 关键子模块

| 模块 | 功能 |
|------|------|
| PLL/CMU | 生成低抖动高速时钟 |
| Serializer | 并行->串行转换 (如 32:1 @112G) |
| Deserializer | 串行->并行转换 (1:32) |
| TX Driver | CML输出驱动, 50ohm端接 |
| CTLE | 接收端模拟均衡 |
| DFE | 接收端判决反馈均衡 |
| CDR | 时钟数据恢复 |
| 编码器 | 8b/10b, 64b/66b, 或 PAM4 Gray |
| FIFO/Elastic Buffer | 跨时钟域 |
| 终端电阻校准 | 精确50/100ohm |
| Eye Monitor | 片内眼图监测 |

### 2.3 发送端

**PISO (Parallel-In-Serial-Out):**
```
并行输入: d0, d1, d2, ..., d31 (32bit)
串行输出: d0, d1, d2, ..., d31 依次输出 (每bit约8.9ps @112Gbps)
```

实现方式:
- 树形Mux结构: 2:1 -> 2:1 -> ... 级联
- 最终级: 半速率架构 (使用双沿时钟)

**TX FIR:**
```
3-tap: Vout[n] = c_pre*Vin[n+1] + c_main*Vin[n] + c_post*Vin[n-1]
输出幅度: 200~1200mVppd 可编程
```

### 2.4 接收端

**CTLE + DFE + CDR** 架构与oDSP RX类似，但通常更简化:
- CTLE: 0~15dB peaking
- DFE: 1~3 tap
- CDR: 二阶PLL, BW可编程
- 无需FEC (由上层协议处理)
- 无需MLSD (延迟要求更严)

## 五、测试方法

### 5.1 环回测试 (Loopback)

**内部环回 (Internal Loopback):**
```
TX -> 内部环路 -> RX
测试SerDes核心功能，排除外部信道影响
```

**外部环回 (External Loopback):**
```
TX -> PCB trace -> RX
测试完整链路(含封装/PCB)
```

### 5.2 BERT测试

标准PRBS测试，评估BER vs 输入幅度/信道损耗。

### 5.3 抖动容限/抖动传递

按OIF-CEI规范执行:
- JTOL模板验证
- JTF模板验证
- 恢复时钟抖动测量

### 5.4 多lane相位对齐

Skew测试: 不同lane间的相对延迟
- 测量条件: 最长/最短路径
- 要求: Skew <5 UI (可通过FIFO补偿)

### 5.5 PVT测试

- 工艺角: SS/TT/FF (5~10个samples/corner)
- 电压: +/-5% (Vmin, Vnom, Vmax)
- 温度: -40C, 25C, 85C, 105C

## 六、AE知识要点

1. SerDes是物理层通信的基础构建块
2. PAM4 SerDes在每bit能效(pJ/bit)持续优化是核心竞争力
3. 224Gbps SerDes是下一代的核心挑战
4. Die-to-Die SerDes (UCIe) 是新兴高增长领域
5. 时钟分布和PLL设计是SerDes系统集成的关键
6. PVT补偿和校准电路是量产可靠性的保障
7. 了解OIF-CEI/IEEE标准规范是AE的基本功
