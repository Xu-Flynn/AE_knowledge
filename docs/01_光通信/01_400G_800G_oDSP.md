# 400G & 800G oDSP (光数字信号处理器)

---

## 一、产品概述

### 1.1 产品定位
400G/800G oDSP (Optical Digital Signal Processor) 是数据中心光互连的核心芯片，部署于光模块（QSFP-DD、OSFP）内部，负责对经过光纤传输后严重劣化的高速光信号进行数字信号恢复与补偿。

### 1.2 应用场景
- 数据中心内部互联 (DCI, Data Center Interconnect)
- 400GBASE-DR4/FR4/LR4/ER4 光模块
- 800GBASE-2xFR4/2xLR4 光模块
- 400G/600G/800G 相干光通信系统

### 1.3 技术路线
- **制程节点**: 7nm/5nm FinFET CMOS 先进工艺
- **调制格式**: PAM4 (4电平脉冲幅度调制) 为主，相干产品支持 QPSK/8QAM/16QAM
- **封装形式**: Flip-chip BGA (0.8mm pitch), Co-Packaged Optics (CPO)
- **接口标准**: 800GAUI-8 / 400GAUI-8, OIF-CEI-112G-VSR/LR

## 二、工作原理

### 2.1 系统级信号链路

oDSP位于光模块内部，接收链路中处于ADC之后、Host ASIC之前，发送链路反之：

**接收方向 (RX Path):**
```
光信号 -> PD + TIA -> ADC -> oDSP (均衡+CDR+FEC解码) -> Host SerDes -> Host ASIC
```

**发送方向 (TX Path):**
```
Host ASIC -> Host SerDes -> oDSP (FEC编码+预均衡+PAM4调制) -> DAC -> Driver -> 光调制器
```

### 2.2 接收端信号处理流程

1. **光电转换**: 光信号经PD(光电探测器)+TIA(跨阻放大器)转为电信号
2. **模数转换**: 高速ADC以56/112 GS/s采样率将模拟信号数字化(8bit分辨率)
3. **Skew补偿**: 补偿多通道间的时间偏移（4通道Rx需精确对齐到<0.5ps）
4. **IQ不平衡补偿** (相干): 补偿I/Q路的幅度和相位失配
5. **色散补偿(CD Comp)**: 频域/时域补偿光纤色散引起的信号展宽
6. **线性均衡(FFE)**: 15-tap前馈均衡器补偿信道线性失真
7. **非线性均衡(DFE+MLSE)**: 消除严重码间干扰(ISI)
8. **载波恢复** (相干): 补偿激光器频偏和相位噪声
9. **时钟数据恢复(CDR)**: 从数据中恢复同步时钟
10. **FEC解码**: KP4-FEC / C-FEC / oFEC 纠错解码
11. **输出至Host**: 通过800GAUI-8电气接口输出至Host ASIC

### 2.3 发送端信号处理流程

1. **FEC编码**: 添加冗余校验符号
2. **PAM4/QAM符号映射**: Gray编码映射到多电平/星座点
3. **频谱整形 (Pulse Shaping)**: 升余弦/根升余弦滤波降带外辐射
4. **预均衡(Pre-emphasis)**: 3~5-tap FIR预补偿信道高频损耗
5. **非线性预补偿**: 补偿光调制器(MZM/EML)的非线性传输函数
6. **DAC输出**: 驱动外部Driver/调制器

## 四、模块详解

### 4.1 RX模拟前端接口 (RX AFE Interface)

接收外部ADC高速数字数据流，完成串并转换、偏移校准和多通道对齐。

子模块功能:
- CML接收器: 100ohm差分端接, 接收112Gbps PAM4, 阻抗匹配<5%
- CTLE: 模拟域高频补偿(可选), DC增益0~12dB可调
- 偏移校准: 消除ADC输出直流失调, 自动/手动, 残留<2mV
- 解串器(Deserializer): 1:64或1:128串并转换, 降频至DSP时钟域~1GHz
- 弹性缓冲(Elastic Buffer): 跨时钟域数据同步, 深度16~64 UI
- 通道对齐(Lane Deskew): 4通道Rx精确时间对齐, 精度<0.5ps

关键指标:
| 参数 | 规格 |
|------|------|
| 输入数据速率 | 53.125 Gbaud (106.25Gbps PAM4) |
| 差分输入阻抗 | 100 ohm +/-10% |
| 接收灵敏度 | <50mVppd @ BER=2.4e-4 |
| 回波损耗 | <-10dB up to 40GHz |

### 4.2 前馈均衡器 (FFE)

FFE是一种线性FIR均衡器，通过加权组合延迟的输入信号补偿信道频率选择性衰落。

数字域实现: y[n] = SUM(k=-N to M) c[k] * x[n-k]

400G/800G oDSP采用15-tap自适应FFE:
- 前向抽头(c[-1], c[-2]...): 补偿pre-cursor ISI(反射)
- 主抽头(c[0]): 信号主路径, 归一化为1
- 后向抽头(c[1], c[2]...): 补偿post-cursor ISI(信道损耗)

LMS自适应算法:
  c[k]^(n+1) = c[k]^(n) + mu * e(n) * x(n-k)
  其中 e(n) = d(n) - y(n), mu为收敛步长

步长mu的折中: 大(1e-3)->收敛快但误差大; 小(1e-5)->收敛慢但精度高

关键参数:
| 参数 | 典型值 | 含义 |
|------|--------|------|
| 总抽头数 | 15 | FIR阶数 |
| 前向抽头 | 3~5 | 补偿反射 |
| 后向抽头 | 9~11 | 补偿信道损耗 |
| 最大补偿@14GHz | >30dB | Nyquist频率增益 |
| 系数位宽 | 8~10 bit | 计算精度 |

### 4.3 判决反馈均衡器 (DFE)

DFE利用已判决符号的加权反馈消除后向ISI，不放大噪声，是其核心优势。

数学表达:
  y[n] = x[n] - SUM(k=1 to N) d[n-k] * b[k]
  d[n] = Slicer(y[n])

PAM4判决器: 阈值-2, 0, +2分割四个电平(-3, -1, +1, +3)

Speculative DFE (推测式) - 满足1UI时序约束:
  并行计算所有4种可能的反馈值(-3/-1/+1/+3 * b[1])
  根据d[n-1]选择正确路径 -> T_total < 18.8ps @53Gbaud

错误传播: 3-tap DFE下, 一个错误最多传播3个符号。MLSD可有效缓解。

关键参数:
| 参数 | 典型值 |
|------|--------|
| 反馈抽头数 | 3-tap |
| h1系数 | 0~0.7(归一化) |
| h2/h3系数 | 0~0.3 |
| 判决延迟 | <1 UI |
| 眼图改善 | >50% |

### 4.4 最大似然序列检测器 (MLSD)

MLSD基于Viterbi算法寻找最小欧氏距离的发送序列，是AWGN信道下的理论最优检测。

Viterbi四步:
1. 状态定义: 状态数=4^L, L=2时16状态, L=3时64状态
2. 分支度量(BM): BM = |r[n] - s_expected|^2
3. 加-比-选(ACS): 每个状态4条入径，选最小路径度量
4. 回溯(Traceback): 32~64步回溯，输出判决序列

MLSD vs DFE:
| 特性 | DFE | MLSD |
|------|-----|------|
| SNR增益 | 基准 | +1~2dB |
| 复杂度 | O(N) | O(4^L) |
| 延迟 | ~5UI | 32~64UI |
| 错误传播 | 有 | 极少 |
| 功耗 | ~0.3W/lane | ~1W/lane |

使用策略: 短距->FFE+DFE; 中距->+16-state MLSD; 长距->+64-state MLSD+CD补偿

### 4.5 时钟数据恢复 (CDR)

CDR从输入数据流恢复时钟，同时跟踪频率偏移和相位抖动。

Mueller-Muller PD (波特率采样):
  相位误差 = e(n)*d(n-1) - e(n-1)*d(n)
  仅需每符号1个采样点

二阶PLL: PD -> 环路滤波器(Kp+Ki/s) -> VCO/DCO -> 恢复时钟

关键参数:
| 参数 | 400G | 800G |
|------|------|------|
| 锁定范围 | +/-300ppm | +/-350ppm |
| 锁定时间 | <100us | <100us |
| 恢复时钟RJ | <200fs | <180fs |
| 环路带宽 | 1~10MHz | 2~15MHz |
| SJ容限@10MHz | >0.5UI | >0.4UI |

JTF: 低通特性,f<<BW时0dB(跟踪), f>>BW时-40dB/dec(抑制)

### 4.6 FEC编解码器

#### KP4-FEC (RS(544,514))
- 码型: RS over GF(2^10), n=544, k=514符号
- 校验: 30符号, 纠错: t=15符号/码字
- 效率: 94.5%, 冗余: 5.5%
- NCG: ~6.2dB @BER=1e-15
- Pre-FEC门限: 2.4e-4

RS解码: 伴随式计算->Berlekamp-Massey->Chien Search->Forney算法

#### C-FEC (级联,相干用)
| 参数 | KP4-FEC | C-FEC |
|------|---------|-------|
| 冗余度 | 5.8% | ~15% |
| NCG@1e-15 | 6.2dB | 10.5dB |
| Pre-FEC | 2.4e-4 | 1.5e-2 |
| 延迟 | <100ns | <500ns |

### 4.7 TX发送端DSP

PAM4 Gray映射: 00->-3, 01->-1, 11->+1, 10->+3 (相邻仅1bit不同)

预均衡3-tap FIR:
  Vout[n] = c_pre*Vin[n+1] + c_main*Vin[n] + c_post*Vin[n-1]
  c_main: 0~60, c_pre: -20~+20, c_post: -20~+20

非线性预补偿(NLC): 补偿MZM调制器sin^2非线性

TX关键指标:
| 参数 | 规格 |
|------|------|
| 输出幅度 | 100~1200mVppd |
| TDECQ | <3.4dB |
| RLM | >0.92 |
| EW5 | >0.2UI |
| EH5 | >32mV |
| 上升/下降 | <9ps |

### 4.8 监测与诊断

- 眼图监测器: 2D扫描, 1/64 UI水平, 1/256 FSR垂直, 生成BER热图
- PRBS Gen/Check: PRBS7/9/11/13/15/23/31/31Q
- BER计数器: Pre-FEC + Post-FEC + FEC纠错统计
- 温度传感器: +/-2C精度

## 六、测试方法 (Know-How)

### 6.1 接收灵敏度与BER测试

#### 6.1.1 测试原理
通过受控衰减(或噪声注入)测量不同输入幅度下的BER，确定满足Pre-FEC BER=2.4e-4所需的最小输入幅度(即接收灵敏度)。

#### 6.1.2 影响因素

**硬件因素:**
1. 信号源质量: BERT PPG的本征随机抖动(RJ<150fs)、上升/下降时间
2. 信道建模精度: PCB trace/cable的S参数，需VNA精确提取至40GHz以上
3. 连接器质量: SMA/精密同轴连接器的回波损耗(<-20dB@26.5GHz)
4. 阻抗匹配: 全程50ohm/100ohm差分阻抗控制(+/-5%)
5. 电源完整性(PDN): DC-DC开关纹波、PDN谐振引起的电源噪声

**环境因素:**
1. 温度: 结温影响模拟电路偏置、BJT的gm、MOSFET的Vth
2. 湿度: PCB介质Dk变化影响传输线阻抗
3. EMI: 外部电磁干扰耦合到高速信号路径
4. 电源噪声: 板上DC-DC ripple、地弹

**DUT内部因素:**
1. 工艺角(PVT): SS/TT/FF corner下性能差异可达3dB
2. CDR锁定状态: 未完全锁定时BER显著恶化
3. DFE收敛状态: 自适应未稳定时系数不准
4. FEC同步状态: FEC失步时无纠错能力

#### 6.1.5 详细测试流程

**Phase 0: 测试准备**
```
- 所有仪器预热 >30分钟
- BERT校准: 示波器确认输出幅度误差<2%
- 信道S参数: VNA校准至DUT输入参考面, 确认Nyquist频率插损
- 电源校准: DMM确认各轨, 示波器AC耦合确认纹波<10mVpp
- RF连接器: 扭矩8 in-lb, 目检无损伤
```

**Phase 1: DUT初始化**
```
1. 上电时序(严格): Vcore(0.8V) -> 10ms -> Vio(1.2V) -> 10ms -> Vana(1.8V)
2. 参考时钟: 156.25MHz/312.5MHz LVDS, 等待CMU PLL锁定
3. MDIO初始化(Clause 45):
   - RX通道使能, CDR auto-lock mode
   - DFE adaptive enable, FEC enable
   - PRBS Checker: PRBS31Q mode
4. 等待: CDR锁定(<10ms) + DFE收敛(<50ms) + PRBS同步确认
```

**Phase 2: 灵敏度扫描**
```
1. 基线: 衰减0dB, PPG=800mVppd -> BER <1e-12基线确认
2. 衰减扫描: 从0dB开始, 每次+0.5dB
   每步: 等待BER稳定(>1e11 bits), 记录:
   - 衰减值, 输入幅度(补偿线损后)
   - Pre-FEC BER, Post-FEC BER
   - DFE系数, CDR lock状态
3. 确定灵敏度: Pre-FEC=2.4e-4时的输入幅度
4. 继续扫描至Pre-FEC~5e-3, 观察FEC行为
5. 绘制BER瀑布曲线(Pre-FEC vs Post-FEC)
```

**Phase 3: 三温重复**
```
- T=-40C: 低温极限, 防结露(dry air purge), 稳定>30min
- T=+25C: 室温基准
- T=+85C: 典型工作温度(Tcase)
- T=+105C: 极限抽检(热裕量评估)
每温度点: 重复Phase 2全部测试
变温速率: <0.5C/min
```

**Phase 4: 电源噪声敏感度(PSRR)**
```
- DUT设置于灵敏度边界(Pre-FEC~2e-4)
- 注入正弦扰动:
  频率: 100k, 200k, 500k, 1M, 5M, 10M, 20MHz
  幅度: 10, 20, 30, 50mVpp
- 记录BER退化 vs 频率/幅度
- 绘制PSRR曲线
- 判定: 50mVpp下BER恶化<10x为可接受
```

#### 6.1.6 测试意义
1. 确定产品规格边界: 灵敏度是oDSP最核心指标, 直接影响链路预算
2. 验证FEC性能: 确保KP4标准符合性
3. 温度特性评估: 为系统热设计提供全温数据
4. PDN验证: PSRR测试指导客户电源设计
5. 量产ATE limits基准
6. 客户支持核心数据

### 6.2 发射机TDECQ测试

#### 测试原理
TDECQ (Transmitter and Dispersion Eye Closure for PAM4) 是IEEE 802.3定义的关键发射机指标，衡量理想参考接收机因发射机不理想而看到的眼图闭合程度。

公式: TDECQ = 10*log10(OMA_TX / OMA_ideal)

TDECQ值越大 = 发射机性能越差。IEEE 802.3ck要求800G模块 TDECQ < 3.4dB。

TDECQ分解:
- TDECQ_noise: 发射机噪声引起的闭合 (~1.0~1.5dB)
- TDECQ_ISI: 带宽限制/非线性引起的闭合 (~1.0~2.0dB)

#### 测试设备
| 设备 | 推荐型号 | 关键规格 |
|------|----------|----------|
| 实时示波器 | Keysight UXR1104A | 110GHz BW, 256GS/s |
| PAM4分析软件 | Keysight D9010PAMA | TDECQ, RLM, EW, EH |
| 参考时钟 | 来自DUT板 | 同步触发 |
| RF稳相电缆 | Gore PhaseFlex | DC~50GHz |

#### 测试框图

```
+==================+        +===========================+
|  DUT oDSP EVB    | 差分   |  实时示波器                |
|  (TX输出模式)     | RF Cable|  Keysight UXR 110GHz      |
|                  +------->+                            |
| PRBS31Q内部生成   |        | 设置:                      |
| TX FIR: 最优     |        | - 256GS/s, >40GHz BW      |
| 输出: 600mVppd   |        | - 2M+ UI记录长度           |
+==========+=======+        | - PAM4 TDECQ分析           |
           |                +==========+=================+
   +-------+--------+                  |
   | Power Supply   |          分析输出:
   +----------------+          TDECQ, RLM, EW5, EH5, Eye
```

#### 详细测试步骤

```
Step 1: 示波器校准
- 垂直校准(DC精度)
- 时基校准
- 通道去嵌入(若有外部衰减器)

Step 2: PAM4软件配置
- 调制格式: PAM4
- 符号率: 53.125 Gbaud
- 参考接收机均衡:
  CTLE: Auto-optimize (DC/peaking gain可调)
  FFE: 5-tap adaptive
  DFE: 3-tap adaptive
- BER目标: 2.4e-4 (Pre-FEC门限)
- CDR: 二阶PLL, BW = Baud/1667 = 31.9MHz

Step 3: 数据采集
- 采集长度: >2M UI (IEEE最小), 建议>5M UI
- 采集次数: 10次独立, 取平均
- 每次重新触发

Step 4: 分析输出
- TDECQ (dB)
- RLM (ratio, >0.92)
- EW5 (UI) @ 1e-5 contour (>0.2UI)
- EH5 (mV) @ 1e-5 contour (>32mV)
- 眼图轮廓(3层)

Step 5: TX FIR优化
扫描 c_main[20~60], c_pre[-10~10], c_post[-10~10]
目标: 最小TDECQ + 保持RLM>0.92

Step 6: STDF测试
- 加载STDF滤波器(模拟最差反射信道)
- 重新计算TDECQ@STDF
- 要求: <3.4dB
```

#### 影响因素与控制

| 影响因素 | 影响机制 | 控制方法 |
|----------|----------|----------|
| 电缆损耗 | 2~3dB@26.5GHz使眼图闭合 | 去嵌入补偿 |
| 示波器噪声 | 增加垂直不确定性 | 低噪声前端 |
| CDR设置 | BW影响捕获抖动 | 严格IEEE规范 |
| 阻抗失配 | 反射引起ISI | 全程阻抗控制 |
| 温度 | DAC输出温漂 | 三温覆盖 |

#### 常见问题诊断

| 问题 | 可能原因 | 解决 |
|------|----------|------|
| TDECQ>4dB | TX FIR不当 / DAC非线性 | 优化FIR / 检查DAC电源 |
| RLM<0.9 | DAC加权误差 / 缓冲非线性 | 检查偏置 / 减少幅度 |
| EH5<20mV | 输出过低 / 预加重过度 | 增大c_main / 减小c_pre |
| 眼图不对称 | 电源噪声 / DC失调 | 检查PDN / 校准offset |

### 6.3 CDR性能测试

#### 6.3.1 抖动容限 (Jitter Tolerance)

**测试原理**: 在数据流中注入不同频率/幅度的正弦抖动(SJ)，测量CDR保持BER<2.4e-4时可容忍的最大SJ。

**OIF-CEI-112G-VSR模板**:
| 频率 | 模板(UIpp) |
|------|-----------|
| 10 kHz | >5.0 |
| 100 kHz | >5.0 |
| 1 MHz | >0.5 |
| 10 MHz | >0.05 |
| 50 MHz | >0.05 |
| 100 MHz | >0.05 |

步骤: 固定频率 -> 递增SJ -> 记录BER=2.4e-4时的SJ -> 绘制JTOL曲线 -> 对照模板。

#### 6.3.2 频率偏移容限
- 缓慢增加频率偏移(10ppm/s)
- 监测CDR Lock Status和BER
- 失锁判定: Lock=0 或 BER突然恶化>2 orders
- 记录正/负偏最大值
- 要求: +/-350ppm

#### 6.3.3 恢复时钟抖动
- 相噪分析仪(E5052B): CDR恢复时钟->相噪积分10k~100MHz
- 要求: RJ <200fs RMS

#### 6.3.4 锁定时间
- 速率阶跃: 标称 -> 标称+200ppm
- 示波器测CDR Lock信号延迟
- 要求: <100us

### 6.4 FEC性能测试

#### BER瀑布曲线
- 靶向Pre-FEC点: [5e-3, 2e-3, 1e-3, 5e-4, 2.4e-4, 1e-4, 5e-5]
- 每点调节衰减使Pre-FEC接近目标
- 记录Post-FEC BER, FEC统计
- 期望: Pre-FEC=2.4e-4时Post-FEC<1e-15
- 考察: 无错误平层(Error Floor)在低Pre-FEC区域

#### 突发纠错测试
- 注入连续错误Burst: 5, 10, 15, 20, 25符号
- 5~15符号: 全部纠正(Post-FEC=0)
- 16~25符号: 部分不可纠
- 验证uncorrectable counter正确

#### FEC同步/失步
- 信号突然中断 -> FEC检测失步 -> 恢复后自动重同步
- 高BER恢复后FEC重新同步时间测量

## 七、AE核心知识体系

### 7.1 PAM4信号基础

```
          NRZ              PAM4
电平数:    2                4
bit/sym:   1                2
SNR代价:   基准             ~9.54dB
Nyquist:  BitRate/2        BitRate/4
电平间距: Vpp              Vpp/3
判决阈值: 1个(0)           3个(-2,0,+2)
复杂度:   低               高
```

Gray编码映射:
- 00 -> -3 (最低电平)
- 01 -> -1
- 11 -> +1
- 10 -> +3 (最高电平)
- 优点: 相邻电平仅1bit不同, 最可能的错误仅1bit错误

### 7.2 关键公式速查表

| 公式 | 说明 | 应用场景 |
|------|------|----------|
| Baud = BitRate / 2 | PAM4符号率 | 系统设计 |
| f_Nyq = Baud / 2 = BitRate / 4 | 奈奎斯特频率 | 带宽规划 |
| SNR_PAM4 = SNR_NRZ - 9.54dB | PAM4信噪比代价 | 链路预算 |
| TDECQ = 10*log10((sigma^2+Q^2)/Q^2) | 发射机关闭度 | TX测试 |
| FEC_NCG = 10*log10(R*G) | FEC净编码增益 | FEC选型 |
| BER_PAM4 ~ (3/4)*erfc(Vpp/(6*sigma))/2 | 理想PAM4 BER(AWGN) | 理论分析 |
| JTF(f) = |H_PLL(f)|^2 | CDR抖动传递 | CDR设计 |

### 7.4 客户支持关键要点

**参考设计交付物:**
1. 完整原理图(电源、时钟、MDIO、高速信号)
2. PCB Layout指南(100ohm差分阻抗、等长、参考层完整)
3. BOM清单(推荐电源芯片、连接器、去耦电容)
4. 散热设计指南(散热器要求、TIM材料建议)

**上电时序(绝对关键!):**
- 上电: Vcore(0.8V) -> 等待>10ms -> Vio(1.2V) -> 等待>10ms -> Vana(1.8V)
- 断电: Vana -> Vio -> Vcore (反向!)
- 绝对禁止颠倒! 否则可能永久损坏芯片!

**参考时钟要求:**
- 频率: 156.25MHz 或 312.5MHz
- 格式: LVDS 或 LVPECL
- 抖动: <200fs RMS (12kHz~20MHz积分)
- 相噪: -145dBc/Hz @10kHz offset
- 精度: +/-50ppm (含温度老化)

**MDIO接口:**
- 协议: IEEE 802.3 Clause 45
- 速率: 最高4MHz (MDC)
- 电压: 1.2V/1.8V/2.5V (可配置)
- 提供完整寄存器映射表

**ESD防护:**
- HBM: 2kV, CDM: 500V
- 客户SMT产线需ESD管控
- 建议PCB添加TVS保护

**散热设计:**
- theta-JC: ~2C/W (典型)
- Tj_max: 125C
- 推荐: 散热片+导热硅脂/TIM+模块外壳导热
