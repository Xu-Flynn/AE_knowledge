# 400G & 800G Retimer (重定时器)

---

## 一、产品概述

### 1.1 产品定位
Retimer是一种高速信号再生芯片，位于两个高速SerDes链路之间。与Redriver(仅信号放大/均衡)不同，Retimer执行完整的CDR(时钟数据恢复)和信号重新发送，彻底消除累积抖动。

### 1.2 应用场景
- 数据中心交换机背板互联
- 长距离PCB trace信号延伸 (>15 inch)
- 线缆/背板中继
- 光模块Host侧信号清洁
- PCIe 5.0/6.0 Retimer
- 400GAUI-8/800GAUI-8 信号再生

### 1.3 Retimer vs Redriver

| 特性 | Redriver | Retimer |
|------|----------|---------|
| 信号处理 | 模拟均衡+放大 | CDR+信号重新生成 |
| 抖动消除 | 有限(仅均衡) | 完全(CDR重定时) |
| 延迟 | <100ps | 1~10ns (含FIFO) |
| 功耗 | 低 (<0.3W/lane) | 中 (0.5~1W/lane) |
| 协议感知 | 无 (透明) | 部分 (需CDR锁定到协议速率) |
| 适用距离 | 短距延伸(<10dB) | 长距延伸(>20dB) |
| 复杂度 | 低 | 高(含CDR/DFE) |
| 成本 | 低 | 中-高 |

## 二、工作原理

### 2.1 Retimer信号处理流程

```
输入信号 -> CTLE(模拟均衡) -> CDR(时钟恢复) -> DFE(判决反馈) -> TX FIR(预加重) -> 输出信号

具体步骤:
1. CTLE: 模拟域补偿Nyquist频率附近的信道损耗
2. CDR: 从输入数据恢复纯净时钟
   - 使用恢复时钟重新采样数据
   - 消除输入抖动 (包括RJ和DJ)
3. DFE: 数字域消除残留ISI
4. Elastic Buffer: 跨时钟域同步
5. TX FIR: 预加重补偿输出信道损耗
6. 输出驱动: 驱动输出信道
```

### 2.2 抖动消除机制

**关键原理 - Retimer的抖动传递函数:**
```
Jitter_Out = JTF * Jitter_In + Jitter_Generated

其中:
- JTF (Jitter Transfer Function): CDR低通特性
  f << CDR_BW: JTF ~0dB (低频抖动通过)
  f >> CDR_BW: JTF -> -40dB/dec (高频抖动抑制)
- Jitter_Generated: Retimer自身产生的抖动
```

**实测抖动改善:**
| 抖动类型 | 输入 | 输出(Retimer后) | 改善 |
|----------|------|-----------------|------|
| RJ (RMS) | 500fs | 200fs | 60% |
| DJ (pk-pk) | 0.3UI | 0.1UI | 67% |
| TJ @1e-15 | 0.5UI | 0.25UI | 50% |

## 四、模块详解

### 4.1 CTLE (连续时间线性均衡器)

**功能**: 在模拟域对输入信号进行初步高频补偿，扩展CDR的接收范围。

**结构与参数**:
```
CTLE是高通滤波器，提供频率相关的增益:
- DC增益: 0dB (通过低频)
- 高频Peaking: 6~18dB @ Nyquist频率 (可编程)
- Peaking频率: 可调 (匹配信道损耗拐点)
- 级数: 通常2~4级级联
```

**CTLE调节参数**:
- DC gain
- Peaking gain (最大补偿量)
- Peaking frequency (补偿频点)
- 输出共模电压

### 4.2 CDR (时钟数据恢复)

**与oDSP中CDR的异同**:

| 特性 | oDSP CDR | Retimer CDR |
|------|----------|-------------|
| 时钟来源 | 从ADC采样数据恢复 | 从模拟信号直接恢复 |
| PD类型 | MM-PD (数字) | Hogge/Linear PD (模拟) 或 MM-PD |
| 抖动要求 | <200fs | <250fs (稍宽松) |
| 锁定范围 | +/-350ppm | +/-500ppm (更宽) |
| 锁定时间 | <100us | <50us (更快要求) |

**Retimer CDR特殊考量**:
- 需支持多速率 (10G/25G/50G/100G per lane)
- 需快速锁定以支持热插拔
- 参考时钟可能不精确 (从Host恢复)

### 4.3 DFE (判决反馈均衡器)

Retimer中的DFE与oDSP类似但略有简化:
- 通常1~3 tap
- 重点补偿短距信道的后向ISI
- 通常不需要MLSD (延迟要求更严)

### 4.4 弹性缓冲 (Elastic Buffer/FIFO)

**功能**: 在恢复时钟域和本地发送时钟域之间进行数据同步。

**关键参数**:
- FIFO深度: 32~128 UI
- 处理频率偏差: +/-500ppm
- 上溢/下溢保护: 插入/删除Skip符号
- 延迟贡献: 1~5ns

### 4.5 TX FIR (发送端预加重)

**功能**: 对输出信号预补偿，驱动下游信道。

与oDSP TX类似:
- 3~5-tap FIR
- c_main: 0~63
- c_pre/c_post: -20~+20
- 输出幅度: 200~1200mVppd可编程

## 六、测试方法

### 6.1 抖动传递测试 (Jitter Transfer)

**测试原理**: 测量Retimer的JTF (Jitter Transfer Function)，即输出抖动与输入抖动之比随频率的变化。

**测试框图**:
```
BERT (PPG + SJ注入) -> DUT Retimer -> BERT (ED)
                                |
                          实时示波器 (测量输入/输出抖动)
```

**测试步骤**:
1. BERT输出带SJ的PRBS31Q数据
2. SJ频率扫描: 10kHz ~ 100MHz
3. 每个频率点测量:
   - 输入到Retimer的信号抖动 (使用示波器)
   - Retimer输出信号的抖动 (使用示波器或BERT ED)
4. 计算 JTF = Jitter_Out / Jitter_In (dB)
5. 绘制JTF vs 频率曲线
6. 要求: JTF峰值<0.1dB, 高频抑制>20dB@10MHz

### 6.2 抖动容限测试

类似oDSP CDR测试，但需额外验证Retimer级联场景:
```
BERT PPG -> ISI Channel 1 -> Retimer #1 -> ISI Channel 2 -> Retimer #2 -> BERT ED
```
验证级联抖动不累积超过单个Retimer的2倍。

### 6.3 延迟测试

**方法**: 使用示波器的TDR/TDT模式测量Retimer的转发延迟。
- 输入: 阶跃/脉冲信号
- 测量: 输入到输出的时间差
- 要求: <5ns (400G) / <8ns (800G)

### 6.4 多速率兼容性测试

Retimer需支持多种协议速率:
- 25.78G NRZ (25GE)
- 53.125G PAM4 (100GE per lane)
- 106.25G PAM4 (200GE per lane)
验证各速率CDR均能正常锁定。

## 七、AE知识要点

1. **Retimer的核心价值是抖动消除**, 不是信号放大(那是Redriver)
2. **CDR是Retimer的灵魂**, JTF必须严格符合规范
3. **级联应用**是Retimer的典型场景, 需要验证级联性能
4. **延迟敏感应用**(如HPC/金融)需关注Retimer的转发延迟
5. **多协议兼容**要求CDR支持宽范围速率检测和自动锁定
6. **热插拔**需要CDR极快锁定(<50us)
