# 800G & 1.6T oDSP (光数字信号处理器)

---

## 一、产品概述

### 1.1 产品定位
800G/1.6T oDSP是面向下一代超大规模数据中心光互连的核心芯片，部署于800G OSFP/QSFP-DD800及1.6T OSFP-XD光模块中。相比400G/800G一代，1.6T oDSP在单通道速率、调制阶数和DSP复杂度上均有大幅提升。

### 1.2 应用场景
- 超大规模数据中心 Spine-Leaf 互联
- AI/ML 集群的 800G/1.6T 光互联
- 800GBASE-DR8/2xFR4 光模块
- 1.6T OSFP-XD 光模块 (8x200G 或 4x400G)
- 下一代相干 800G/1.2T DWDM

### 1.3 技术演进路线

| 参数 | 400G/800G oDSP | 800G/1.6T oDSP | 提升 |
|------|---------------|----------------|------|
| 单lane速率 | 106Gbps PAM4 | 212Gbps PAM4 | 2x |
| 最高总速率 | 850Gbps | 1.7Tbps | 2x |
| 调制格式 | PAM4 | PAM4/PAM6 | 更高阶可选 |
| 制程 | 7nm | 5nm/3nm | 更先进 |
| FEC | KP4-FEC | KP4 + iFEC | 更强纠错 |
| 均衡 | FFE+DFE+MLSD | FFE+DFE+MLSD+NLC | 更复杂 |
| 最大功耗 | <14W | <20W | 效率提升 |

## 二、工作原理

### 2.1 核心技术挑战

**212Gbps PAM4 (106Gbaud) 的关键挑战:**
1. **超低UI**: 1UI = 9.43ps, DFE反馈路径时序极其紧张
2. **高频损耗**: Nyquist频率=53GHz, PCB损耗可达40dB+
3. **SNR要求更严**: PAM4本身SNR代价9.54dB, 更高Baud进一步压缩SNR
4. **时钟抖动要求**: 恢复时钟需 <150fs RMS
5. **ADC/DAC性能**: 需>6 ENOB @53GHz, 非常困难

### 2.2 信号链路

**接收方向:**
```
光信号 -> PD+TIA -> 高速ADC(224GS/s) -> oDSP:
  1. Skew Compensation (多通道对齐)
  2. IQ Imbalance Correction (相干)
  3. CD Compensation (色散补偿, 频域)
  4. FFE (15~21 tap自适应)
  5. DFE (3~5 tap, Speculative架构)
  6. MLSD (64~256 State Viterbi)
  7. NLC (非线性补偿, 光纤Kerr效应)
  8. CDR (Mueller-Muller, 二阶PLL)
  9. FEC Decode (级联: iFEC + KP4)
  -> Host SerDes (1.6TAUI-8)
```

**发送方向:**
```
Host SerDes -> oDSP:
  1. FEC Encode (KP4 + iFEC)
  2. PAM4/PAM6 Symbol Mapping
  3. Pulse Shaping (RRC filter)
  4. Pre-emphasis (5-tap FIR)
  5. NLC Pre-compensation (调制器+光纤非线性)
  6. DAC (8~10bit, 224GS/s)
  -> Driver -> 光调制器
```

## 四、模块详解

### 4.1 超高速RX AFE接口

**核心挑战**: 212Gbps PAM4 (106Gbaud) — 1UI仅9.43ps!

**关键子模块升级**:
| 子模块 | 400G/800G | 800G/1.6T | 升级说明 |
|--------|-----------|-----------|----------|
| 输入带宽 | >30GHz | >50GHz | 需更宽带模拟前端 |
| ADC I/F | 8b 112GS/s | 8b 224GS/s | 2x采样率 |
| Deskew精度 | <0.5ps | <0.3ps | 更严格对齐 |
| CTLE | 0~12dB | 0~18dB | 更大高频补偿范围 |
| Elastic Buffer | 16~64 UI | 32~128 UI | 更大跨时钟域缓冲 |

### 4.2 增强型FFE (21-tap)

升级到21-tap以应对更高频损耗:
- 前向抽头: 5~7 (更多反射补偿)
- 后向抽头: 13~15 (更深ISl补偿)
- 最大补偿@53GHz: >35dB

自适应算法升级:
- 主算法: 仍为LMS, 但增加变步长机制(mu自适应)
- 初始阶段: 大mu快速收敛 -> 稳态阶段: 小mu低误差
- 增加系数约束防漂移

### 4.3 高阶DFE (5-tap Speculative)

从3-tap升级到5-tap:
- PAM4+5-tap Speculative = 需要并行计算 4^5=1024条路径!
- 实际采用混合架构: h1/h2 Speculative, h3~h5 Direct feedback
- h1系数: 0~0.8 (更大补偿范围)

### 4.4 256-State MLSD

为应对更严重ISI，支持高达256状态(信道记忆L=4):
- 每状态4条入径, 共1024次ACS运算/符号周期
- 采用全并行架构，功耗~2W/lane
- 回溯深度: 64~128

### 4.5 非线性补偿 (NLC)

1.6T长距应用中光纤Kerr非线性不可忽略:
- 数字反向传播 (DBP, Digital Back-Propagation)
- 在DSP中数值求解非线性薛定谔方程(NLSE)
- 分段: 每段线性(CD补偿)+非线性(SPM相位旋转)

### 4.6 增强型FEC

采用级联FEC架构:
- 内码: iFEC (增强型软判决FEC, 类似OFEC)
  - 码率 ~0.87, NCG ~9.5dB
- 外码: KP4-FEC (RS(544,514))
  - 清除内码残留错误
- 总冗余度: ~20%
- 总NCG: ~11dB

### 4.7 PAM6 调制 (可选)

部分1.6T方案探索PAM6 (6电平):
- 3 bit/symbol, 比PAM4效率高50%
- 但SNR代价更大 (~14dB vs NRZ)
- 判决更复杂 (5个阈值)

## 六、测试方法要点

### 6.1 测试设备升级

212Gbps PAM4测试需要更高级设备:
- BERT: Keysight M8050A (120GBaud PAM4) 或 Anritsu MP1900A升级版
- 示波器: Keysight UXR 110GHz (256GS/s) 或更高
- VNA: 需 >67GHz 或 110GHz扩展到Nyquist
- 电缆/连接器: 1.0mm或0.8mm连接器系统

### 6.2 特殊测试挑战

**212Gbps下的额外挑战:**
1. 电缆损耗: 每米损耗更大, 需更短或更高品质电缆
2. 连接器效应: 更小连接器(1.0mm), 更易损坏
3. 去嵌入精度: 高频S参数测量误差放大
4. 温度敏感性: 高频下更敏感, 温控精度需<0.1C
5. 电源噪声: 更高频段PDN设计更难

### 6.3 测试方法差异

相比400G/800G, 主要差异:
- BER统计时间: 相同BER需更长时间 (低Baud但更严格门限)
- 眼图分析: PAM4眼图更闭合, 分析更依赖均衡后
- CDR测试: 环路带宽更高(15~20MHz)
- FEC测试: 级联FEC的瀑布曲线更陡峭

## 七、AE知识要点

1. **212Gbps是分水岭**: 1UI=9.4ps, 迫使所有子模块重新设计
2. **NLC成为必选项**: 长距场景必须补偿光纤非线性
3. **级联FEC是趋势**: 单一码型无法满足日益增长的NCG需求
4. **PAM6探索**: 进一步提升频谱效率, 但SNR代价大
5. **CPO集成**: 1.6T时代, oDSP与光引擎的CPO集成是方向
6. **热管理更关键**: 20W功耗在光模块尺寸内散热极其困难
