# 800G & 1.6T TIA & Driver (跨阻放大器 & 驱动芯片)

---

## 一、产品概述

### 1.1 产品定位
800G/1.6T TIA (Trans-Impedance Amplifier, 跨阻放大器) 和 Driver (调制器驱动芯片) 是光模块中位于oDSP与光学器件之间的关键模拟芯片。

- **TIA**: 位于光接收链路，将光电探测器(PD)输出的微弱光电流转换为电压信号，并提供足够的增益驱动后续ADC
- **Driver**: 位于光发送链路，接收oDSP DAC输出的电压信号，提供大摆幅驱动光调制器(MZM/EML)

### 1.2 应用场景
- 800G/1.6T 光模块 (OSFP, QSFP-DD800)
- 相干光模块 (IC-TIA + Driver)
- 直接检测 & 相干检测

### 1.3 技术路线
- **工艺**: SiGe BiCMOS (高频性能) 或 InP (最高频) 或 CMOS (集成度高)
- **通道数**: 4通道 / 8通道
- **速率**: 单通道 106Gbaud / 212Gbaud
- **封装**: 裸片 (wire-bonding 或 flip-chip), 多芯片集成

## 二、TIA 工作原理

### 2.1 基本工作原理

TIA将PD产生的微弱光电流转换为可用的电压信号:

```
光信号 -> PD (光电二极管) -> I_photo (uA~mA级) -> TIA -> V_out (mV~V级)
```

**核心转换关系:**
```
V_out = I_photo * Z_T
其中 Z_T 为跨阻增益 (Trans-impedance Gain), 单位 ohm
典型值: 1k~10k ohm (差分)
```

### 2.2 TIA 核心设计挑战

| 挑战 | 描述 | 800G/1.6T要求 |
|------|------|--------------|
| 带宽 | 需满足信号带宽 | >50GHz for 106Gbaud |
| 噪声 | 决定接收灵敏度 | 输入参考噪声 <15pA/sqrt(Hz) |
| 增益 | 需足够大驱动ADC | 差分 2k~8k ohm |
| 过载 | 强光下不失真 | 输入电流 >2mA pp |
| 功耗 | 模块热预算限制 | <0.3W/channel |
| 稳定性 | 高频下不振荡 | 相位裕度 >45度 |
| PD接口 | 匹配PD寄生参数 | 输入电容 <100fF |

### 2.3 TIA 架构

**基本架构 (Shunt-Feedback TIA):**
```
         R_feedback
    +----/\/\/\----+
    |              |
PD -+---> 放大器 ---+---> V_out
    |              |
   C_pd           R_load
    |              |
   GND            GND

跨阻增益: Z_T ~ -R_f (理想运放近似)
带宽: BW ~ sqrt(GBW / (2*pi*R_f*C_pd))
  其中 GBW = 运放增益带宽积, C_pd = PD结电容
```

**高级架构 (Regulated Cascode TIA):**
- 通过有源反馈降低输入阻抗
- 在保持增益的同时扩展带宽
- 适合超高速应用

**差分TIA (Differential TIA):**
- 差分输出 vs 单端: 更好的共模噪声抑制
- 需要差分PD或Balun

### 2.4 关键子模块

| 模块 | 功能 |
|------|------|
| 输入级 (Input Stage) | 与PD接口，提供低输入阻抗和偏置 |
| 增益级 (Gain Stage) | 提供跨阻增益，多级级联 |
| 输出缓冲 (Output Buffer) | 驱动50/100ohm负载和ADC |
| 自动增益控制 (AGC) | 根据输入光功率自动调节增益 |
| 直流偏移消除 (DC Offset Cancel) | 消除直流失调，防止饱和 |
| 偏置电路 (Bias Circuit) | 为PD提供反向偏压 (2~5V) |
| RSSI (接收信号强度指示) | 输出与平均光功率成比例的电压/电流 |

## 三、Driver 工作原理

### 3.1 基本工作原理

Driver将oDSP DAC输出的中低摆幅电压信号放大为大摆幅信号驱动光调制器:

```
oDSP DAC输出 (Vpp~500mV) -> Driver (放大) -> V_out (Vpp~2~5V) -> 调制器(MZM/EML)
```

**核心参数:**
```
电压增益: A_V = V_out_pp / V_in_pp (典型 4~10x)
输出摆幅: V_out_pp (差分/单端)
带宽: >50GHz for 106Gbaud
```

### 3.2 Driver 核心设计挑战

| 挑战 | 描述 | 800G/1.6T要求 |
|------|------|--------------|
| 输出摆幅 | 需驱动高Vpi调制器 | 差分 >4Vpp |
| 带宽 | 大摆幅下的高频响应 | >50GHz |
| 线性度 | PAM4对线性度要求高 | THD <-25dB |
| 功耗 | 大摆幅 = 大功耗 | <0.5W/channel |
| 阻抗匹配 | 与调制器50ohm匹配 | S22<-10dB @50G |
| 上升/下降时间 | 影响眼图质量 | <6ps (20%-80%) |

### 3.3 Driver 架构

**分布式放大器 (Distributed Amplifier):**
- 多级增益单元通过人工传输线级联
- 吸收晶体管寄生电容入传输线
- 实现超宽带放大
- 缺点: 功耗大, 效率低

**Lumped放大器 + 输出级:**
- 前级: Cherry-Hooper放大器 (宽带)
- 输出级: 开漏/推挽输出
- 优点: 效率更高
- 缺点: 带宽受限于寄生参数

**差分输出级:**
- 推挽 (Push-Pull): 高效, 但线性度稍差
- 开漏 (Open-Drain): 线性度好, 但需外部偏置
- CML (Current Mode Logic): 差分, 恒流偏置

### 3.4 关键子模块

| 模块 | 功能 |
|------|------|
| 输入缓冲 | 50ohm端接, 接收DAC输出 |
| 前级放大 (Pre-Amp) | 电压增益, 宽带设计 |
| 输出驱动级 (Output Stage) | 大摆幅驱动调制器 |
| 偏置网络 (Bias Tee) | 为调制器提供直流偏置 |
| 眼图交叉点调节 | 调节交叉点位置 |
| 输出幅度控制 | 可编程输出摆幅 |

### 4.3 光模块系统链路中的 TIA & Driver

```
发送链路:
oDSP DAC -> Driver -> MZM/EML -> 光纤
  500mVppd -> x4~8 -> 2~4Vpp -> 调制光信号

接收链路:
光纤 -> PD -> TIA -> ADC -> oDSP
  光功率 -15dBm -> I_photo ~100uA -> V_out 500~800mVppd -> 数字域
```

## 五、测试方法

### 5.1 TIA 测试

#### 5.1.1 S参数测试

**测试原理**: 使用VNA测量TIA的S参数(增益、带宽、回损、隔离度)

**测试设备**: Keysight PNA-X + 光波元件分析仪(LCA)

**测试框图**:
```
VNA Port1 -> Bias Tee -> TIA Input (RF probe on-wafer or wire-bond)
                            TIA Output -> VNA Port2
(需注意: TIA输入是电流输入, 非50ohm匹配, 需特殊校准)
```

**关键测量:**
- S21: 跨阻增益频率响应 -> 提取 -3dB带宽
- S11: 输入回损 (PD接口匹配)
- S22: 输出回损
- S12: 反向隔离

#### 5.1.2 噪声测试

**测试原理**: 测量TIA输出噪声谱密度，反推输入参考噪声

**测试设备**: 频谱分析仪 + 低噪声放大器(LNA)

**测试步骤**:
1. TIA输入端接等效PD电容(无光输入)
2. 输出经LNA放大 -> 频谱分析仪
3. 测量输出噪声谱密度 (V^2/Hz)
4. 输入参考噪声 = 输出噪声谱 / |Z_T(f)|^2
5. 积分计算总RMS噪声

#### 5.1.3 时域/眼图测试

**测试原理**: 用高速PRBS信号驱动激光器+PD模拟光信号，测量TIA输出眼图

**测试框图**:
```
BERT PPG -> Driver -> MZM -> VOA -> PD -> TIA(DUT) -> 实时示波器
```

**关键测量:**
- 输出眼图 (眼高、眼宽、抖动)
- 灵敏度 (最小可检测光功率 @BER=2.4e-4)
- 过载特性 (大光功率下眼图)

#### 5.1.4 RSSI精度测试

- 扫描输入光功率 (-20dBm ~ 0dBm)
- 记录RSSI输出电压
- 线性度 <+/-1dB

### 5.2 Driver 测试

#### 5.2.1 S参数测试

**测试原理**: 测量Driver的小信号S参数和大信号特性

**测试框图**:
```
VNA Port1 -> Driver Input -> Driver Output -> VNA Port2 (with attenuator)
                                       -> 实时示波器 (同时监测时域)
```

**关键测量:**
- S21: 电压增益 vs 频率 -> -3dB带宽
- S22: 输出回损
- 群延迟 (Group Delay)

#### 5.2.2 大信号/眼图测试

**测试框图**:
```
BERT PPG -> Driver(DUT) -> 实时示波器
(需在Driver输出加适当衰减保护示波器输入)
```

**关键测量:**
- 输出眼图 (PAM4/NRZ)
- 输出幅度 vs 频率响应
- 上升/下降时间
- 眼图交叉点
- 确定性抖动 (DJ)

#### 5.2.3 线性度测试

**测试原理**: 测量Driver的谐波失真/互调失真

```
正弦波发生器 -> Driver -> 频谱分析仪

单音测试: THD = 10*log10(SUM(P_harmonics) / P_fundamental)
双音测试: IMD3 测量
```

要求: THD <-25dB (保证PAM4线性度)

## 六、AE知识要点

### 6.1 TIA & Driver 与 oDSP 的协同设计

1. **阻抗匹配**: TIA输出与ADC输入, Driver输入与DAC输出的宽带匹配
2. **幅度对齐**: TIA输出幅度需在ADC输入范围; DAC输出需在Driver输入范围
3. **带宽分配**: 全链路带宽 = min(TIA_BW, Driver_BW, oDSP_AFE_BW)
4. **噪声分配**: 系统噪声 = PD散粒噪声 + TIA噪声 + ADC量化噪声
5. **电源域**: TIA/Driver通常需要洁净模拟电源, 与oDSP数字电源隔离

### 6.2 常见问题

| 问题 | 原因 | 排查 |
|------|------|------|
| TIA带宽不足 | 输入电容过大/PD选择不当 | 降低C_pd/F_f偏置 |
| TIA噪声过大 | 偏置不当/电源噪声 | 检查PD bias, 改善PSRR |
| TIA振荡 | 反馈环路相位裕度不足 | 增加补偿电容 |
| Driver输出不足 | 增益不够/输出级压缩 | 调整偏置/级数 |
| Driver非线性 | 偏置点不对/输出级饱和 | 调节工作点/降低输入 |
| 眼图交叉点偏移 | Driver偏置不对称 | 调节交叉点控制 |
| 串扰超标 | PCB布局/封装耦合 | 增加隔离/改layout |

### 6.3 客户支持关键点

- TIA输入对ESD极其敏感! (直接连接PD裸片)
- Driver输出需考虑调制器Vpi和阻抗
- 裸片bonding线的电感效应需仿真
- 电源去耦至关重要 (高频芯片电源纹波敏感)
- 裸片KGD (Known Good Die) 测试是行业难题
