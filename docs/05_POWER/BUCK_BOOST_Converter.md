## 一、产品概述

BUCK-BOOST 转换器是**唯一能够在输入电压高于、等于或低于输出电压时均能稳定工作的非隔离式 DC-DC 拓扑**。它融合了 BUCK 和 BOOST 的功能，解决了单一拓扑 Vin/Vout 范围受限的问题，在电池供电设备、汽车电子和 USB PD 等 Vin 宽范围变化的场景中不可替代。

### 产品定位

- **产业链位置**：位于电压变化范围极宽的输入源（锂电池、汽车电池、USB-C）与要求固定电压的负载之间
- **核心价值**：当 Vin 可能在 Vout 上下波动时（如锂电池 3.0~4.2V→3.3V），只有 BUCK-BOOST 能持续稳压输出
- **本质功能**：通过 4 开关 H-Bridge 或 SEPIC 架构，实现能量在升压/降压模式间的无缝切换

### 典型应用场景

- **锂电池→3.3V/3.6V**：单节锂电池 3.0~4.2V 全范围输出 3.3V
- **汽车冷启动 (Cold Crank)**：12V 电池瞬间跌至 3~5V 仍维持输出
- **USB-C PD 双向**：支持 Vin 5~20V 灵活输入输出
- **超级电容后备电源**：电容电压从满电到放空，持续稳压
- **TWS/可穿戴**：极小封装 4 开关 BUCK-BOOST

### 技术路线

| 维度 | 规格/选择 | 说明 |
|------|-----------|------|
| 拓扑 | 4开关 H-Bridge | 主流方案，效率高，可做降压/升压/升降压三模式 |
| 拓扑 | SEPIC | 单开关+耦合电感/变压器，成本低，输出同极性 |
| 拓扑 | 反激 (Flyback) | 隔离型，多路输出；变压器漏感需 snubber |
| 控制 | 峰值电流模式 | 4开关 BUCK-BOOST 主流控制，逐周期限流 |
| 模式切换 | BUCK → BUCK-BOOST → BOOST | Vin 接近 Vout 时进入 4 开关全切换模式 |
| 工艺 | BCD | 集成 4 个功率 FET（2×NMOS + 2×PMOS） |
| 封装 | QFN / WLCSP / BGA | 4 开关芯片尺寸大于同功率 BUCK |

## 二、工作原理

**4 开关 BUCK-BOOST** 由四个 MOSFET 构成 H-Bridge：A (HS1) 和 B (LS1) 构成 BUCK 半桥，C (HS2) 和 D (LS2) 构成 BOOST 半桥，电感连接在两个半桥的 SW 节点之间。根据 Vin 与 Vout 的关系，控制器自动切换工作模式。

### 三模式工作原理

```
Vin → HS1(A) → SW1 → 电感 L → SW2 → HS2(C) → Vout → R_LOAD
              │                    │
              ↓                    ↓
           LS1(B)                LS2(D)
              │                    │
              ↓                    ↓
            GND                  GND
模式: BUCK(Vin>>Vout) | BUCK-BOOST(Vin~Vout) | BOOST(Vin<<Vout)
```

### 核心关系公式

```
V_out = V_in × D / (1 − D)  |  D = V_out / (V_in + V_out)
BUCK 模式 (Vin>>Vout): V_out ≈ D_buck × V_in  |  BOOST 模式 (Vin<<Vout): V_out ≈ V_in / (1−D_boost)
```

### 关键设计挑战

- **模式切换平滑性**：Vin 跨越 Vout 时，在 BUCK/BOOST 模式间切换可能引起 Vout 扰动 (glitch)，需无缝过渡控制
- **4 开关效率**：BUCK-BOOST 模式下 4 个 FET 全部开关，开关损耗是 BUCK 的 2×，效率约 88~92%
- **EMI**：两个 SW 节点同时动作，EMI 源加倍，滤波和 Layout 难度高于 BUCK 或 BOOST 单独
- **环路设计**：功率级传递函数在三种模式下不同（BUCK 双极点、BOOST 有 RHPZ），需稳定覆盖全部模式
- **最小占空比/最大占空比限制**：t_on(min) 和 t_off(min) 限制使得 Vin 非常接近 Vout 时难以精确稳压

## 三、核心模块深度解析

### 1. 4 开关 H-Bridge 工作机制

4 开关 BUCK-BOOST 通过四个 MOSFET 的不同开关组合实现三种工作模式：

| 模式 | 条件 | HS1 (A) | LS1 (B) | HS2 (C) | LS2 (D) |
|------|------|---------|---------|---------|---------|
| BUCK | Vin >> Vout | PWM 开关 | 同步整流 | 常通 (100%) | 常断 |
| BUCK-BOOST | Vin ≈ Vout | PWM 开关 | 同步整流 | PWM 开关 | 同步整流 |
| BOOST | Vin << Vout | 常通 (100%) | 常断 | 同步整流 | PWM 开关 |

> 关键洞察：BUCK-BOOST 模式的本质是在一个开关周期内先后完成"电感充电"(A+D 导通) 和"电感释能"(B+C 导通) 两个阶段，不同于纯粹 BUCK（始终向输出供电）或 BOOST（电感和输出无直接连接）。这导致 BUCK-BOOST 模式下的输入和输出电流都是脉冲形式，对电容 RMS 电流要求最高。

### 2. 模式切换与无缝过渡

当 Vin 从远高于 Vout 逐渐下降到接近 Vout 并最终低于 Vout 时，控制器需在三种模式间切换。最简单的切换方式是在 Vin 跨越 Vout ± Hysteresis 区间时硬切换，但可能引起 Vout 扰动。优化的方案包括：

- **重叠区控制**：在 Vin ∈ [Vout×0.9, Vout×1.1] 区间使用 BUCK-BOOST 模式作为过渡
- **占空比前馈**：根据 Vin 预测所需 D，在切换瞬间匹配占空比避免扰动
- **自适应死区**：防止模式切换瞬间的 FET 直通

### 3. 环路补偿 — 全模式稳定性

三种模式下功率级传递函数不同，是 BUCK-BOOST 环路设计的核心难题：

```
BUCK 模式：LC 双极点，无 RHPZ → 补偿最易（Type-II/III）
BOOST 模式：LC 双极点 + RHPZ → 补偿最难，带宽必须 ≤ f_RHPZ/5
BUCK-BOOST 模式：类似 BOOST，有 RHPZ，且传递函数中包含更复杂的零极点分布
```

实践中往往以**最恶劣工况（通常是低 Vin、重载的 BOOST 模式）**设计补偿网络，并验证其余模式下的相位/增益裕度。

### 4. SEPIC — 单开关 BUCK-BOOST 替代方案

SEPIC (Single-Ended Primary-Inductor Converter) 只需一个开关管即可实现升降压，且输出与输入同极性。核心是耦合电感（或两个独立电感）和一个耦合电容 C_c：

```
V_out = V_in × D / (1 − D)  （与 BUCK-BOOST 公式相同）
```

优点是单开关（低成本和简单控制）、输出同极性、可做真关断。缺点是耦合电容需承受全部输入电流 + 输出电流的 RMS，且效率通常低于 4 开关 BUCK-BOOST（约 85~90%）。

## 四、芯片内部电路框图

```
┌────────────────── 功率级 H-Bridge (4-Switch) ──────────────────┐
│  Vin → HS1(BUCK) → SW1 → 电感 L → SW2 → HS2(BOOST) → Vout     │
│              │                    │                            │
│              ↓                    ↓                            │
│           LS1                   LS2                           │
│              │                    │                            │
│              ↓                    ↓                            │
│            GND                  GND                           │
│  C_out 输出电容 | R_LOAD 负载                                  │
└───────────────────────────────────────────────────────────────┘
┌────────────── 栅极驱动 + 模式管理 ─────────────────────────────┐
│  4ch 驱动 + 电平移位 | 模式检测: BUCK/BB/BOOST                 │
│  自举×2(HS1+HS2) / 死区 | UVLO 欠压锁定 | 4way Gate out       │
└───────────────────────────────────────────────────────────────┘
┌──────────────── 双 PWM 控制 + 模式切换 ───────────────────────┐
│  误差放大器(EA+环路补偿网络) → PWM_A+PWM_C(双通道比较器)      │
│  OSC+斜坡 (f_SW=2MHz) | 电流检测 I_SENSE                      │
└───────────────────────────────────────────────────────────────┘
┌──────────── 模拟基准与偏置 / 保护与逻辑 ──────────────────────┐
│  Bandgap 基准 (V_ref=0.6V) | 内部 LDO → V_CC                 │
│  软启动 C_SS (t_SS 可编程) | OCP(峰值+平均)/OVP/OTP/UVLO/SCP  │
│  EN / PG / 模式指示                                          │
└───────────────────────────────────────────────────────────────┘
```

4 开关 BUCK-BOOST 芯片的核心是**两组半桥 + 单个电感**构成的 H-Bridge 功率级，以及管理三种模式无缝切换的**双通道 PWM 控制器**。与单一 BUCK 或 BOOST 最大的不同在于，它需要同时管理两个 SW 节点的开关动作。

### 模式切换性能

| 参数 | 典型值 | 单位 | 测试条件 |
|------|--------|------|----------|
| 模式切换扰动 | 20 ~ 100 | mV | Vin 扫过 Vout 时的 Vout glitch |
| 静态电流 I_Q | 10 ~ 80 | µA | 非开关态，EN=High |
| 输出纹波 (BUCK-BOOST) | 15 ~ 60 | mV_pp | 4 开关模式纹波高于单模式 |
| 瞬态响应 | 中等 (~50µs恢复) | — | 受 RHPZ 限制(类似 BOOST) |

### BUCK-BOOST 模式效率（关键指标 #1）

- **定义**：Vin≈Vout 时，4 个 FET 全部以 PWM 方式开关时的转换效率
- **公式**：η_BB = P_out/P_in，损耗 = P_cond×4 + P_sw×4 + P_L(DCR+磁芯)
- **影响分析**：4 FET 同时开关意味着开关损耗约为单模式下的 2×，是 BUCK-BOOST 方案的效率谷底
- **典型值**：Vin=3.6V, Vout=3.3V, Iout=1A: η≈88~91%；同条件 BUCK 约 95%

## 七、影响因素分析

| 关键指标 | 被哪些因素影响 | 该指标又影响哪些下游性能 |
|----------|----------------|--------------------------|
| 效率 η | 工作模式、f_SW、R_DS(on)×4、Vin/Vout比 | 热耗、PCB 散热面积、电池续航 |
| 模式切换稳定性 | 迟滞窗口、补偿、Vin检测精度 | Vout 扰动、负载误触发 OVP/UVP |
| 环路稳定性 | 工作模式、补偿网络、L/C_out、负载 | 振荡风险、瞬态响应、音频噪声 |
| EMI | 2×SW 节点、f_SW、Layout、SSFM | EMC 认证、射频灵敏度 |
| 输出纹波 | 模式、C_out、ESR、f_eff | 后级噪声、传感器精度 |

> **📌 跨领域共同影响因素总结**：BUCK-BOOST 的**模式切换区域（Vin≈Vout）**是性能的"最劣区"——此时效率最低（4 FET 开关）、纹波最大、EMI 最强、环路也最复杂。评估 BUCK-BOOST 方案时，务必确认应用在 Vin≈Vout 区域的工作占比——如果 90% 时间都在 BUCK 模式，BUCK-BOOST 是理想选择；如果长期徘徊在过渡区，应考虑调整 Vout 设定或增加输入/输出电容裕量。

## 八、测试方法与验证

### 测试一：全 Vin 范围效率曲线

**测试原理**：固定 Vout 和 Iout，扫描 Vin 从 V_min 到 V_max（必须覆盖 Vin<<Vout 的 BOOST 区、Vin≈Vout 的过渡区、Vin>>Vout 的 BUCK 区），记录每个 Vin 点的效率。

| 设备 | 推荐型号 | 关键规格 |
|------|----------|----------|
| 直流电源 | Keysight E36313A | 可编程扫描输出 |
| 电子负载 | Chroma 6314A | CC 模式，恒定 I_out |
| 万用表 | Keysight 34465A (x4) | Kelvin 接法 |

**步骤**：
1. **接线与设定**：设定 Vout=R_FB 决定的固定值；I_out 电子负载设为 CC 模式恒流
2. **Vin 扫描**：Vin 从 V_min 到 V_max，步长 0.5V。在 Vin≈Vout 区域加密至 0.1V 步长，捕捉模式切换点效率变化
3. **判定**：效率曲线在过渡区无陡峭跌落；BUCK 和 BOOST 区域效率分别满足规格；过渡区效率 ≥ 规格下限

### 测试二：模式切换瞬态

**测试原理**：使 Vin 快速扫过 Vout（模拟电池充放电或汽车冷启动），用示波器捕捉 Vout 在模式切换时的扰动。

| 设备 | 推荐型号 | 关键规格 |
|------|----------|----------|
| 示波器 | Keysight MSOX3104T | AC 耦合，高分辨率模式 |
| 电源 | 双极电源或函数发生器 + 功放 | 能快速扫变 Vin |

**步骤**：
1. **Vin 斜变设置**：Vin 从 2.5V 缓慢斜变到 5.5V（Vout=3.3V 时），速率 ~0.1V/ms。同时用第二通道监视 SW1/SW2 节点确认模式变化
2. **扰动测量**：AC 耦合测量 Vout，记录 Vin 穿越 Vout 时的最大 glitch 幅值和持续时长
3. **判定**：Vout glitch ≤ ±3%Vout；恢复时间 ≤ 100µs；无振荡或 OVP/UVP 误触发

### 测试三：两节点 SW 波形验证

**测试原理**：同时监测 SW1 和 SW2 节点波形，验证三个模式下开关动作的正确性。

**步骤**：
1. **BUCK 模式验证**：Vin>>Vout 时，SW1 为 PWM 方波，HS2 (C) 常通→SW2≈Vin；LS1 (B) 为 SW1 的互补 PWM
2. **BOOST 模式验证**：Vin<<Vout 时，HS1 (A) 常通→SW1≈Vin；SW2 为 PWM 方波，LS2 (D) 为互补 PWM
3. **BUCK-BOOST 模式验证**：Vin≈Vout 时，SW1 和 SW2 均为 PWM 方波（两者可能相位交错以减少纹波）

## 九、注意事项与踩坑经验

| 注意事项 | 说明 |
|----------|------|
| 🔄 过渡区效率陷阱 | 客户常看到规格书"峰值效率 95%"就以为全输入范围都是这个效率。需明确指出：Vin≈Vout 的 BUCK-BOOST 过渡区效率约 88~92%，是方案的最劣工作点 |
| ⚡ 电感峰值电流 | BUCK-BOOST 模式下 I_L(peak) = I_out/(1−D) + Vin×D/(2×f_s×L) + I_out×D/(1−D)。计算复杂，建议用厂家提供的 Excel 工具验证 |
| 📐 PCB Layout | 两个 SW 节点各自需要最小化铜皮面积和环路。输入和输出电容需各自紧靠 FET 半桥。两对半桥的 GND 回路应独立回芯片 EP 再汇合 |
| 🔄 补偿统一性 | BUCK-BOOST 的补偿网络需在三种模式下都满足稳定性。通常以最苛刻模式（重载 BOOST/BB）优化，并验证 BUCK 模式下的相位裕度 |
| 🔊 纹波模式差异 | BUCK-BOOST 模式下的输出纹波可能与 BUCK 或 BOOST 模式显著不同（频率可能减半或脉冲群变化），选 C_out 时需覆盖所有模式的纹波需求 |
| 🌡️ 热集中 | BUCK-BOOST 模式下 4 个 FET 均发热，芯片内部可能存在热点。需确认规格书 Θ_JA 是针对单 FET 工作还是 4 FET 工作状态给出的 |

> **🔥 最常见错误 TOP 5**：
> 1. **误以为全范围效率一致**：忽略过渡区效率下降 5~8%，导致热设计不足
> 2. **电感饱和电流计算遗漏 BB 模式因子**：BB 模式下 I_L(peak) 比 BUCK 或 BOOST 模式都大
> 3. **模式切换 Vout glitch 被忽略**：对噪声敏感负载（ADC、PLL），需增加输出电容或使用无缝切换 IC
> 4. **未测试过渡区稳定性**：在 BUCK 和 BOOST 模式都稳定不代表 BB 模式也稳定
> 5. **选 L 过小**：BB 模式等效频率可能是设定的 1/2，纹波按 f_eff 计算而非 f_SW

## 十、选型指南与决策建议

### 选用 BUCK-BOOST 的场景

- 输入电压可能高于、等于或低于输出电压
- 锂电池全电压范围输出 3.3V（3.0~4.2V→3.3V）
- 汽车 12V 电池需耐受冷启动低至 3~4V
- USB-C PD 双向供电
- 超级电容掉电保持应用中持续稳压

### 单用 BUCK 或 BOOST 即可的场景

- Vin 始终 > Vout → 用 BUCK（效率更高、成本更低）
- Vin 始终 < Vout → 用 BOOST
- 成本极度敏感且 Vin/Vout 关系确定
- PCB 面积紧张（4开关 IC 尺寸更大）
- 效率要求 >93% 且过渡区占比高

| 应用场景 | V_IN 范围 | V_OUT | I_OUT | 推荐方案 |
|----------|-----------|-------|-------|----------|
| 锂电池→3.3V | 3.0~4.2V | 3.3V | 0.5~3A | 4 开关 BUCK-BOOST，无缝切换 |
| 汽车冷启动→5V | 3.0~40V | 5V | 1~5A | 4 开关，AEC-Q100，宽 Vin |
| USB-C PD 20V | 5~20V | 5~20V | 3~5A | 4 开关 BB 或双向 BB |

> **🧠 AE 核心认知**：BUCK-BOOST 是"为宽范围而生"的拓扑，核心价值在于**用了它就不用纠结输入电压范围**。但代价是：(1) 过渡区效率最低（4 FET 开关），(2) 芯片和 PCB 成本最高，(3) 环路设计和测试验证最复杂。AE 推荐 4 开关 BUCK-BOOST 的黄金法则是——先确认应用在过渡区的时间占比。如果 <10%，BUCK-BOOST 是完美选择；如果 >30%，考虑能否调整 Vout 来避开过渡区，或接受较低的整体效率。
