## 一、产品概述

BOOST 转换器是**将较低的直流输入电压转换为较高的稳定输出电压**的非隔离式 DC-DC 开关电源拓扑。与 BUCK 相反，其输出电压始终大于输入电压。BOOST 是电池供电设备中不可或缺的电源架构，能将单节锂电池 (3.0~4.2V) 提升到 5V、12V 甚至更高来驱动负载。

### 产品定位

- **产业链位置**：位于低电压电源（电池/USB/能量采集）之后、高压负载之前，提供升压与稳压功能
- **核心价值**：使低电压电源能驱动高电压负载，是实现便携设备小型化、高效率供电的关键技术
- **本质功能**：电感储能 + 开关控制，通过伏秒平衡实现 Vin × t_on = (Vout − Vin) × t_off，从而获得 Vout > Vin

### 典型应用场景

- **智能手机/平板**：锂电池 3.7V→5V USB OTG、背光 LED 驱动
- **USB-C PD**：5V→9V/12V/15V/20V 升压输出
- **汽车 LED 照明**：12V 电池→30~60V LED 灯串
- **能量采集**：热电/光伏 mV~V 级升压到可用电压
- **音响功放**：电池→±15V 以上双轨供电

### 技术路线

| 维度 | 规格/选择 | 说明 |
|------|-----------|------|
| 拓扑 | 异步 BOOST (二极管整流) | 低成本，适合 <1A 输出；二极管 V_F 影响效率 |
| 拓扑 | 同步 BOOST (MOSFET 整流) | 高效率，需高侧 FET 驱动（自举或电荷泵） |
| 控制模式 | 电流模式 (CMC) | 主流，逐周期限流，右半平面零点 (RHPZ) 需特殊处理 |
| 控制模式 | 电压模式 (VMC) | 简单，但 RHPZ 补偿更困难 |
| 控制模式 | COT (恒定关断时间) | 快速瞬态，简单补偿；轻载效率好 |
| 输入电压 | 0.5V ~ 40V | 低压启动 (Cold-Start) 需特殊设计；能量采集可低至 20mV |
| 输出电压 | Vin ~ 60V+ | 受限于开关管耐压和电感饱和 |
| 工艺 | BCD / CMOS | 高压 DMOS 集成开关管 |

## 二、工作原理

BOOST 转换器通过**电感储能和释放**实现升压：开关管 (SW) 导通时，电感电流线性上升存储能量；SW 关断时，电感通过整流管（二极管/同步 FET）向输出释放能量，电感上的反电动势与输入电压叠加，使 Vout 高于 Vin。

### 系统级信号流

```
Vin → 电感 L → SW → 整流管(肖特基/Sync-FET) → Vout(>Vin) → R_LOAD
              │        │                          │
              ↓        ↓                          ↓
            C_in    SW-FET(N-MOS)              C_out
              │        │                          │
              ↓        ↓                          ↓
            GND      GND                        GND
反馈环路: Vout → FB 反馈分压网络 → EA + RHPZ补偿 → PWM + 栅极驱动 → SW-FET
```

### 核心关系公式

```
V_out = V_in / (1 − D)          |  ΔI_L = V_in × D × T_s / L
I_out(max) = I_L(avg) × (1 − D)  |  I_L(peak) = I_in + ΔI_L / 2
```

其中 D 为开关管导通占空比。当 D→1 时理论 Vout→∞，但受寄生参数限制，实际升压比通常 ≤5~8×。

### 关键设计挑战

- **右半平面零点 (RHPZ)**：BOOST 特有的非最小相位特性，限制环路带宽必须远低于 RHPZ 频率，导致瞬态响应慢
- **启动浪涌电流**：上电瞬间输出电容未充电，通过电感和二极管直通形成大电流，需软启动/预充电
- **无负载过压**：轻载时若未跳过脉冲，输出电容持续充电导致 Vout 飙升，需 OVP 或强制 PWM 跳脉冲
- **同步整流驱动**：高侧 FET 需要浮动驱动（自举或电荷泵），复杂度高于 BUCK
- **输入电流纹波**：电感直接连接 Vin，输入电流纹波大，输入电容需承受高 RMS 电流

## 三、核心模块深度解析

### 1. 右半平面零点 (RHPZ) — BOOST 的根本设计约束

BOOST 控制的 CCM 模式中，功率级传递函数含有一个**右半平面零点**，这是其与 BUCK 最本质的区别：

```
f_RHPZ = V_out × (1−D)² / (2π × L × I_out)
```

RHPZ 对环路设计的影响是根本性的：环路带宽 f_c 必须 ≤ f_RHPZ/3 ~ f_RHPZ/5，否则不稳定。RHPZ 在重载 (I_out↑)、小电感 (L↓)、高占空比 (D↑) 时频率最低，是带宽的瓶颈。

> 工程直觉：RHPZ 的本质物理原因是——当负载增大导致 Vout 下降时，控制器增大 D 让电感储能更多，但增大 D 意味着电感向输出释能的时间 (1−D) 缩短，瞬时会进一步降低输出电流。这种"先恶化再改善"的非最小相位响应是 BOOST 瞬态较差的根源。

### 2. 电感选型 — 峰值电流限制与饱和

BOOST 的电感峰值电流远大于输出电流，这是 BOOST 区别于 BUCK 的重要特征：

```
I_L(peak) = I_out / (1−D) + V_in × D / (2 × f_s × L)
```

例如：Vin=5V, Vout=12V, Iout=2A→D≈0.583，I_L(avg)=4.8A。电感需承受的峰值电流可能是输出电流的 3~5×。电感饱和电流 I_SAT 必须 > I_L(peak)，并考虑高温退化。

### 3. 同步 BOOST 高侧驱动

同步 BOOST 中，整流 MOSFET 的源极连接 Vout（高电位），栅极需要 Vout + V_gs 的驱动电压。常见方案：

| 方案 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 自举电容 | LS 导通时对 C_BOOT 充电 | 简单、成本低 | 100% 占空比不可用 |
| 电荷泵 | 振荡器 + 多级倍压 | 可 100% 占空比 | 驱动能力有限 |
| 隔离电源 | 独立隔离 DC-DC | 最可靠 | 成本高、面积大 |

### 4. 输出断开 (True Load Disconnect)

异步 BOOST 在关断时，输入通过电感和二极管仍连接到输出（"直通"状态），负载无法完全断开。同步 BOOST 可通过关断高侧 FET 实现**真负载断开 (True Load Disconnect)**，这对电池供电设备的安全性至关重要。部分芯片内置背靠背 P-MOS 开关或在 Vout 端串联隔离 FET。

## 四、芯片内部电路框图

```
┌────────────────── 功率级 Power Stage (BOOST) ──────────────────┐
│  Vin → 电感 L → SW → HS-FET(同步整流) → Vout(>Vin) → R_LOAD   │
│              │        │                          │            │
│              ↓        ↓                          ↓            │
│            C_in    SW-FET(R_DS(on)=8mΩ)        C_out          │
│  真关断 Load Disconnect                                      │
└───────────────────────────────────────────────────────────────┘
┌────────────── 栅极驱动器 Gate Driver ─────────────────────────┐
│  半桥驱动 + HS浮动 | 自举/电荷泵/死区控制                      │
│  HS Gate = Vout + 5V | UVLO 欠压锁定                          │
└───────────────────────────────────────────────────────────────┘
┌──────────────── 控制环路 (RHPZ补偿) ──────────────────────────┐
│  误差放大器(EA + RHPZ补偿网络) → PWM比较器(EA vs RAMP)        │
│  OSC + 斜坡 (f_SW=2MHz) | 电流检测 I_SENSE                    │
└───────────────────────────────────────────────────────────────┘
┌──────────── 模拟基准与偏置 / 保护与逻辑 ──────────────────────┐
│  Bandgap 基准 (V_ref=0.6V/0.8V) | 内部 LDO → V_CC            │
│  软启动 + 限流(防启动浪涌直通) | OVP/OCP/OTP/SCP              │
│  无负载过压保护 / UVLO | EN / PG / 模式选择                   │
└───────────────────────────────────────────────────────────────┘
```

同步 BOOST 的内部架构与 BUCK 类似但功率级拓扑不同：**电感在输入端（而非输出端）**；LS-FET 为主动开关管，HS-FET 为同步整流管（替代二极管）。栅极驱动需处理 HS-FET 的浮动源极（连接 Vout）。控制环路必须应对 RHPZ 约束。

## 五、核心对比 — BUCK vs BOOST vs BUCK-BOOST

| 对比维度 | BUCK (降压) | BOOST (升压) | BUCK-BOOST (升降压) |
|----------|-------------|--------------|---------------------|
| Vout 范围 | 0 < Vout < Vin | Vout > Vin | Vout 可高可低 |
| 占空比公式 | D = Vout/Vin | D = 1 − Vin/Vout | D = Vout/(Vin+Vout) |
| 电感位置 | 输出端滤波 | 输入端储能 | 中间储能 |
| 输入电流 | 断续 (脉冲) | 连续 (有纹波) | 断续 (脉冲) |
| 输出电流 | 连续 (有纹波) | 断续 (脉冲) | 断续 (脉冲) |
| 环路特性 | LC 双极点，无 RHPZ | 有 RHPZ，带宽受限 | 有 RHPZ，带宽受限 |
| 峰值效率 | 最高 (~97%) | 较高 (~93%) | 中等 (~90%) |
| 复杂度 | 最低 | 中等 | 最高 (4开关) |

### 异步 vs 同步 BOOST

| 维度 | 异步 BOOST | 同步 BOOST |
|------|------------|------------|
| 整流器件 | 肖特基二极管 | P-MOS 或 N-MOS (高侧) |
| 效率 | ~88% (V_F 损耗) | ~93% |
| 真关断 | 否 (Vin 直通 Vout) | 是 (关断 HS-FET) |
| 驱动复杂度 | 简单 | 需浮动 HS 驱动 |
| 适用电流 | <1~2A | 无上限 |

## 六、核心指标与规格

### 系统级指标

| 参数 | 典型值范围 | 单位 | 测试条件/含义 |
|------|------------|------|---------------|
| 输入电压范围 V_IN | 0.5 ~ 40 | V | 低至 20mV 需能量采集专用 IC |
| 输出电压范围 V_OUT | Vin ~ 60 | V | 受 FET 耐压限制 |
| 最大输出电流 I_OUT | 0.1 ~ 10 | A | 受 I_L(peak) = Iout/(1-D) 约束 |
| 峰值效率 η_peak | 88 ~ 95 | % | Vin=3.7V, Vout=5V, Iout=1A |
| 开关频率 f_SW | 500k ~ 3M | Hz | 高频缩小电感，但开关损耗增加 |
| 启动电压 | 0.7 ~ 2.5 | V | UVLO 释放后的最低启动 Vin |

### 输出质量指标

| 参数 | 典型值 | 单位 | 测试条件 |
|------|--------|------|----------|
| 输出电压纹波 | 10 ~ 50 | mV_pp | 20MHz BW，输出端 ESR 影响大 |
| 负载调整率 | 0.2 ~ 1.0 | % | I_OUT: 0→100% 变化 |
| 线性调整率 | 0.05 ~ 0.2 | %/V | V_IN 全范围变化 |
| 瞬态 Undershoot | 50 ~ 200 | mV | 负载突增，受 RHPZ 限制带宽 |
| 启动时间 t_SS | 0.5 ~ 10 | ms | 软启动电容可编程 |

### RHPZ 频率 f_RHPZ（关键指标 #1）

- **定义**：BOOST 功率级传递函数中右半平面零点的频率，限制了最大可用环路带宽
- **公式**：f_RHPZ = V_out×(1−D)² / (2π×L×I_out) = V_in² / (2π×L×I_out×V_out)
- **影响分析**：环路带宽需 ≤ f_RHPZ/5；重载时 f_RHPZ 最低——意味着重载瞬态最差
- **典型值**：Vin=5V, Vout=12V, L=10µH, Iout=2A: f_RHPZ≈8kHz → f_c≤1.6kHz

### 峰值电感电流 I_L(peak)（关键指标 #2）

- **定义**：电感在开关周期内达到的最大瞬时电流
- **公式**：I_L(peak) = I_out/(1−D) + V_in×D/(2×f_s×L)
- **影响分析**：直接决定电感饱和裕量需求、SW FET 导通损耗和电流检测范围
- **典型值**：5V→12V/2A: I_L(peak)≈5.5A (是Iout的2.75x)；2.7V→5V/2A: I_L(peak)≈5.5A

## 七、影响因素分析

| 关键指标 | 被哪些因素影响 | 该指标又影响哪些下游性能 |
|----------|----------------|--------------------------|
| RHPZ 频率 | I_OUT、L、D、V_out | 环路带宽、瞬态响应速度、系统稳定性 |
| 效率 η | f_SW、R_DS(on)、DCR、V_F、D | 热耗、电池续航、封装选择 |
| I_L(peak) | V_out/V_in 比、I_OUT、L、f_SW | 电感饱和裕量、FET 导通损耗、电流检测范围 |
| 输出纹波 | C_out、ESR、I_OUT、D、f_SW | 后级 PSRR、音频噪声、EMI |
| 启动浪涌 | C_out、C_SS、限流值、Vin | 可靠性、输入电源跌落、OCP 误触发 |

> **📌 跨领域共同影响因素总结**：BOOST 的 **RHPZ** 是所有设计决策的"隐形天花板"。提高 f_SW 可缩小 L（进而提高 RHPZ），但增加开关损耗。占空比 D 越大（升压比越高），RHPZ 越低且 I_L(peak) 越大——这是高升压比 BOOST 设计的两难困境。AO (Always-On) 产品需特别关注**真关断**能力。

## 八、测试方法与验证

### 测试一：效率曲线测试

**测试原理**：与 BUCK 类似，四线 Kelvin 接法测量 V_IN/I_IN/V_OUT/I_OUT。需特别关注两个区域：(1) 高升压比 + 重载区（I_L(peak) 最大，RHPZ 最低）；(2) 轻载 PFM 区（效率易骤降）。

| 设备 | 推荐型号 | 关键规格 |
|------|----------|----------|
| 直流电源 | Keysight E36313A | 0-25V/10A |
| 电子负载 | Chroma 6314A | CR/CC/CV 模式 |
| 万用表 | Keysight 34465A (x4) | 6.5 digit, Kelvin |

**测试框图**：
```
DC 电源(V1/A1) → DUT (BOOST) → 电子负载(V2/A2)
▲ 注意：BOOST 输入电流大，输入线径和 Kelvin 接法尤其重要
```

**步骤**：
1. **接线与预热**：Kelvin 四线接法；输入线径需能承载 I_in = I_out×Vout/(Vin×η)。满载预热 10min
2. **多点扫描**：覆盖 I_OUT=0~I_max；至少测试 2~3 组 Vin/Vout 组合（如 3.7V→5V, 5V→12V, 5V→20V）
3. **判定**：η_peak ≥ 规格书 −1%；全负载范围内无异常效率跌落（可能暗示电感饱和）

### 测试二：SW 节点波形与振铃

**测试原理**：BOOST 的 SW 节点在关断时电压跳变至 Vout + V_F（或更高），寄生 LC 谐振会引起振铃。用示波器（≥200MHz BW）测量 SW 对 GND 波形。

**步骤**：
1. **探头设置**：使用探头 x10 档（最小化负载效应），弹簧地线；或使用差分探头。带宽 ≥ 200MHz
2. **测量点**：SW 引脚（电感与 FET 连接点），关注关断瞬间的电压过冲和振铃频率/幅值
3. **判定**：SW 过冲 ≤ FET V_DS 额定值的 80%；振铃在 3 个周期内衰减到 10% 以下。否则需加 RC Snubber

### 测试三：启动与关断行为

**测试原理**：BOOST 启动和关断行为因直通路径和浪涌电流而特殊。用双通道示波器同时捕捉 Vin、Vout、EN 和 SW 节点。

**步骤**：
1. **启动测试**：EN 拉高瞬间触发，记录 Vout 单调上升无台阶/回沟，I_in 峰值 ≤ 限流值。软启动时间可编程
2. **关断测试**：EN 拉低后 Vout 应在规定时间内下降到安全电平。异步 BOOST（有直通）Vout≈Vin−V_F；同步 BOOST（真关断）Vout→0
3. **判定**：启动无 OCP 误触发；Vout 单调性正常；关断后 Vout 满足安全要求（真关断类 <0.5V）

## 九、注意事项与踩坑经验

| 注意事项 | 说明 |
|----------|------|
| 📐 RHPZ 带宽约束 | BOOST 环路带宽必须远低于 RHPZ 频率（≤1/5）。带宽过高会导致振荡失稳。如果瞬态响应不满足，需增大输出电容（而不是试图提高带宽来提高响应速度） |
| ⚡ 电感饱和 | BOOST 电感峰值电流 >80% 占空比时可达 I_out 的 5×+。务必检查 I_SAT 在全温范围的退化（铁氧体磁芯 −20~−30% @125°C）。饱和后电感量骤降→I_L 急剧上升→烧 FET |
| 🔄 真关断需求 | 异步 BOOST 关断时 Vin 通过电感和二极管直通 Vout，无法完全切断负载。若应用需要真正断电，必须选同步 BOOST（含真关断功能） |
| 📊 输出电容 ESR | BOOST 输出电流为脉冲形式（HS 导通时），输出电容承受的 RMS 纹波电流远超 BUCK。需选用低 ESR 电容并校核 RMS 电流额定值 |
| 🔌 输入电容选型 | BOOST 电感在输入端，输入电流为三角波（连续但有大纹波），输入电容需承受 RMS 纹波 I_Cin(rms) ≈ ΔI_L/√12。推荐 MLCC + 电解并联 |
| 🌡️ 占空比极限 | D ≥ 85% 时效率急剧下降（I_L(peak) 极大）且 RHPZ 极低。高升压比（如 3V→48V）应优先用 Flyback、SEPIC 或两级方案，而非单级 BOOST |

> **🔥 最常见错误 TOP 5**：
> 1. **电感饱和电流计算遗漏 (1−D) 因子**：习惯用 BUCK 思维选电感，忽略 I_L = Iout/(1−D) 的关系
> 2. **未评估 RHPZ 影响**：直接套用 BUCK 补偿设计，导致带宽过高引发振荡
> 3. **真关断需求遗漏**：异步 BOOST 无法关断输出，导致电池漏电或负载损坏
> 4. **输出电容 RMS 电流超额定值**：BOOST 输出脉动电流对电容 ESR 要求高于 BUCK
> 5. **SW 节点振铃未处理**：振铃电压尖峰可能超过 FET 耐压并显著增加 EMI

## 十、选型指南与决策建议

### 选用 BOOST 的场景

- Vin 固定低于所需 Vout（如 3.7V 电池→5V/12V）
- 输入为电池/超级电容等低压源
- LED 灯串驱动（需高压恒流）
- 升压比 ≤5~6×（单级可满足）
- 对真关断有需求→选同步 BOOST

### 避免用 BOOST 的场景

- Vin 可能高于 Vout→用 BUCK-BOOST
- 升压比 >8×→用 Flyback/SEPIC
- 输入输出需要隔离→用 Flyback
- 需要多路隔离输出→用 Flyback
- 超低功耗待机（同步 BOOST 真关断功耗优于异步）

### 选型决策表

| 应用场景 | V_IN | V_OUT | I_OUT | 推荐方案 |
|----------|------|-------|-------|----------|
| 手机 OTG 5V | 3.0~4.4V | 5V | 0.5~2A | 同步 BOOST，PFM/PWM，真关断 |
| USB-C PD 输出 | 5~12V | 9~20V | 1~3A | 同步 BOOST，电流模式 |
| 汽车 LED 背光 | 9~16V | 30~50V | 0.1~0.5A | 异步 BOOST（高电压），电流模式 |
| 能量采集 | 20mV~0.5V | 1.8~3.3V | µA~mA | 低压启动 BOOST IC，变压器耦合 |
| 音响功放升压 | 3.7V | ±12~15V | 0.5~2A | 同步 BOOST + 电荷泵反相 |

> **🧠 AE 核心认知**：BOOST 的核心约束是**RHPZ 对环路带宽的刚性限制**——这不是靠更好的补偿网络就能"优化"掉的，而是拓扑自带的物理约束。AE 在面对客户的瞬态响应抱怨时，第一反应不应是"调补偿"，而应检查：(1) RHPZ 是否已经成为瓶颈？(2) 输出电容是否足够？(3) 是否需要降低升压比？理解 RHPZ 的频率位置和重载关系，是评估 BOOST 方案可行性的第一步。
