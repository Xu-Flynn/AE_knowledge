## 一、产品概述

BUCK 转换器是**最广泛使用的 DC-DC 开关电源拓扑之一**，功能是将较高的直流输入电压转换为较低的稳定输出电压。它是非隔离式开关电源中最基本的降压拓扑，以高效率（通常 ≥90%）、高功率密度覆盖从消费电子到汽车电子几乎所有电源管理领域。

### 产品定位

- **产业链位置**：电源管理 IC (PMIC) 的核心子类，位于 AC-DC 适配器/电池之后、负载之前，提供精准的电压转换与稳压
- **核心价值**：以极高效率将"不干净"或"过高"的直流电压转换为精确稳压的低压输出，是 SoC、FPGA、DDR 等数字芯片供电的关键
- **本质功能**：通过 PWM 调制开关管占空比，利用 LC 滤波实现降压 + 稳压

### 典型应用场景

- **数据中心/服务器**：48V→12V/5V/1.8V 多级 POL (Point-of-Load)
- **汽车电子**：12V/48V 电池→5V/3.3V/1.2V 各域供电
- **PC/笔记本主板**：19V→Vcore (~1.0V)、DDR5 VDD/VDDQ
- **通信基站**：−48V→28V/12V 二次电源
- **工业自动化**：24V 总线→各传感器/控制器供电

### 技术路线

| 维度 | 规格/选择 | 说明 |
|------|-----------|------|
| 拓扑 | 异步 BUCK (二极管整流) | 低成本，轻载效率低；适用于 ≤5A 简单场景 |
| 拓扑 | 同步 BUCK (MOSFET 整流) | 高效率，主流选择；需死区控制 |
| 控制模式 | 电压模式 (VMC) | 单环控制，补偿简单；对输入变化响应慢 |
| 控制模式 | 电流模式 (CMC) | 双环控制，逐周期限流；需斜率补偿防次谐波振荡 |
| 控制模式 | COT (Constant-On-Time) | 快速瞬态响应，无需补偿；频率随 Vin/Vout 变化 |
| 调制 | PWM / PFM / PSM | 重载 PWM，轻载切 PFM 提升效率 |
| 功率级工艺 | BCD (Bipolar-CMOS-DMOS) | 集成高压 DMOS + 精密模拟 + 数字控制 |
| 封装 | QFN / WLCSP / Module (SIP) | 模块化集成电感减少 PCB 敏感度 |

## 二、工作原理

BUCK 转换器通过**高频开关 + LC 低通滤波**实现电压变换：高侧开关管（HS-FET）导通时，电流从 Vin 经电感对输出电容充电并供给负载；HS-FET 关断时，电感电流通过低侧开关（LS-FET，或续流二极管）续流。稳态下电感伏秒平衡决定 Vout = D × Vin。

### 系统级信号流

```
Vin → HS-FET → SW → 电感 L → Vout → R_LOAD
                  │              │
                  ↓              ↓
               LS-FET          C_out
                  │              │
                  ↓              ↓
                 GND            GND
反馈环路: Vout → FB 反馈分压网络 → EA + 补偿网络 → PWM + 栅极驱动 → HS/LS-FET
```

### 核心关系公式

```
V_out = D × V_in          |  ΔI_L = (V_in − V_out) × D × T_s / L
ΔV_out = ΔI_L / (8 × f_s × C_out)  |  I_out(max) = I_L(avg) + ΔI_L / 2
```

其中 D 为占空比，T_s = 1/f_s 为开关周期，ΔI_L 为电感电流纹波峰峰值。

### 关键设计挑战

- **效率 vs 频率**：高频缩小 LC 尺寸但增加开关损耗；GaN FET 可缓解此矛盾
- **瞬态响应**：负载突增/突减时输出电压 overshoot/undershoot，受控于带宽和 LC 双极点
- **EMI**：SW 节点快速 dV/dt 产生共模/差模噪声，需布局优化 + 扩频 (SSFM)
- **轻载效率**：固定 PWM 在轻载时开关损耗占比大，需 PFM/突发模式 (Burst Mode)
- **最小导通时间**：极高降压比（如 48V→1V）时需极小占空比，受限于控制器 t_on(min)

## 三、核心模块深度解析

### 1. 功率级 (Power Stage) — HS-FET + LS-FET + 电感 + 电容

功率级是能量处理的核心。同步 BUCK 使用两颗 MOSFET 替代传统的二极管整流：

```
导通损耗：P_cond = I_L(rms)² × ( D·R_DS(on)HS + (1-D)·R_DS(on)LS )
开关损耗：P_sw = 0.5 × V_in × I_out × (t_r + t_f) × f_s
```

| 参数 | HS-FET 要求 | LS-FET 要求 |
|------|-------------|-------------|
| R_DS(on) | 低（但受 C_gd 制约） | 极低，导通时间更长 (1-D) |
| Q_g | 低，开关损耗比例大 | 中等，ZVS 可降低 |
| V_DS 耐压 | ≥ Vin(max) + 尖峰裕量 | ≈ Vin(max) + 尖峰裕量 |

> 工程权衡：HS-FET 选 Q_g 小的 FET 以降低开关损耗；LS-FET 选 R_DS(on) 极小的 FET，因其导通占空比为 (1−D)。高频应用中 C_gd 引起的误导通（dv/dt induced turn-on）需通过负压关断或米勒钳位解决。

### 2. 电感选型 — 纹波 vs 瞬态 vs 尺寸的核心权衡

电感值 L 是最重要的设计参数之一，直接影响纹波电流、瞬态响应和磁芯损耗：

```
L = (V_in − V_out) × D / (f_s × ΔI_L)
```

| 设计选择 | 纹波 ΔI_L | 瞬态响应 | 磁芯尺寸 | 适用场景 |
|----------|-----------|----------|----------|----------|
| 大 L (r=0.2) | 小，输出纹波低 | 慢，di/dt 受限 | 大，更多匝数 | 噪声敏感模拟供电 |
| 小 L (r=0.4) | 大，输出纹波高 | 快，di/dt 大 | 小 | 快速瞬态数字负载 |

r = ΔI_L / I_out(max) 是电感电流纹波比，通常取 0.2~0.4。

### 3. 控制环路 — 补偿网络设计与稳定性

BUCK 功率级传递函数含有一个由 LC 滤波产生的**双极点**（谐振频率 f_0 = 1/(2π√(LC))），需要在反馈回路中加入 Type-II 或 Type-III 补偿器来保证相位裕度 ≥45°。

```
Type-III 补偿：两个零点(f_z1,f_z2)抵消 LC 双极点，三个极点(f_p1=0,f_p2,f_p3)提供高频衰减
```

电流模式控制 (CMC) 将电感电流引入内环，将功率级传递函数简化为一阶（单极点），使补偿更容易，并天然具有逐周期限流能力。代价是需要斜率补偿以防止 D>0.5 时的次谐波振荡。

### 4. 栅极驱动器 (Gate Driver) — 死区时间与自举电容

同步 BUCK 的 HS-FET 栅极需要 **Bootstrap（自举）电路**提供高于 Vin 的栅极驱动电压（通常 V_gs = Vin + 5V）。自举电容 C_BOOT 在 LS-FET 导通时从 VCC 充电，在 HS-FET 导通时"浮动"为 HS-FET 提供栅极驱动能量。

**死区时间 (Dead Time)** 是 HS 和 LS 同时关断的短暂间隔，防止**直通 (Shoot-Through)**。死区过长→二极管续流损耗增加；死区过短→直通风险。自适应死区控制可优化效率。

## 四、芯片内部电路框图

```
┌────────────────── 功率级 Power Stage ──────────────────┐
│  Vin → HS-FET → SW → 电感 L → Vout → R_LOAD           │
│              │        │                                │
│              ↓        ↓                                │
│           LS-FET    C_out                              │
│  C_in 输入电容 | 反馈分压 R_FB1/R_FB2                   │
└────────────────────────────────────────────────────────┘
┌────────────── 栅极驱动器 Gate Driver ──────────────────┐
│  半桥驱动 + 电平移位 | 自适应死区 / C_BOOT 自举          │
│  HS浮动驱动=SW+5V | 欠压锁定 UVLO                      │
└────────────────────────────────────────────────────────┘
┌──────────────── 控制环路 Control Loop ─────────────────┐
│  误差放大器(EA + Type-III) → PWM比较器(EA vs RAMP)     │
│  OSC + 斜坡 (f_SW=2MHz) | 电流检测 I_SENSE             │
└────────────────────────────────────────────────────────┘
┌──────────── 模拟基准与偏置 / 保护与逻辑 ────────────────┐
│  Bandgap 基准 (V_ref=0.6V/0.8V) | 内部 LDO → V_CC      │
│  软启动 C_SS | OCP/OVP/OTP/SCP | UVLO/热关断(160°C)    │
│  EN / PG 逻辑                                          │
└────────────────────────────────────────────────────────┘
```

同步 BUCK 芯片的内部核心模块包括：**功率 FET 对（HS + LS）**处理主功率流；**栅极驱动器**提供合适的 V_gs 驱动电压和死区控制；**控制环路**（EA + PWM 比较器 + 振荡器）根据输出电压反馈调节占空比；**保护电路**涵盖过流 (OCP)、过压 (OVP)、过温 (OTP) 及欠压锁定 (UVLO)。

## 五、核心对比 — 异步 vs 同步 BUCK

| 对比维度 | 异步 BUCK (二极管整流) | 同步 BUCK (MOSFET 整流) |
|----------|------------------------|-------------------------|
| 整流器件 | 肖特基二极管 | 低侧 N-MOSFET |
| 满负载效率 | ~85% (VF≈0.4V 压降损耗) | ~95% (R_DS(on) 低压降) |
| 轻载效率 | 一般（无 FET 开关损耗） | 较差，需 PFM/Burst 改善 |
| 死区控制 | 不需要（二极管天然续流） | 必须（防止直通烧毁） |
| 成本 | 低 | 中（芯片面积 + 控制复杂度增加） |
| EMI | 较好 | 较差（高速开关 dV/dt 大） |
| 适用电流 | <3~5A | 无上限（多相并联可 >200A） |
| 典型应用 | 辅助电源、低功耗 IoT | CPU/GPU Vcore、汽车、电信 |

### 控制模式对比

| 维度 | 电压模式 (VMC) | 电流模式 (CMC) | COT |
|------|----------------|----------------|-----|
| 反馈量 | 仅输出电压 | 输出电压 + 电感电流 | 输出电压（纹波触发） |
| 补偿网络 | Type-III（复杂） | Type-II（简单） | 无需补偿 |
| 瞬态响应 | 慢 | 中 | 极快 |
| 逐周期限流 | 无 | 有（天然） | 有限 |
| 抗噪性 | 好 | 对开关噪声敏感 | 对纹波敏感 |
| 轻载 | 需 Burst Mode | 可切 PFM | 天然频率降低 |

## 六、核心指标与规格

### 系统级指标

| 参数 | 典型值范围 | 单位 | 测试条件/含义 |
|------|------------|------|---------------|
| 输入电压范围 V_IN | 2.7 ~ 60 | V | 取决于工艺耐压和产品定位 |
| 输出电压范围 V_OUT | 0.6 ~ V_IN×0.9 | V | 受 t_on(min) 限制最低输出电压 |
| 最大输出电流 I_OUT | 0.5 ~ 40 | A | 内置 FET 或外置 FET 决定 |
| 峰值效率 η_peak | 92 ~ 97 | % | V_IN=12V, V_OUT=5V, I_OUT=50%max |
| 开关频率 f_SW | 200k ~ 4M | Hz | 可固定或可调；高频缩小 LC 尺寸 |
| 静态电流 I_Q | 5 ~ 100 | µA | 非开关状态下的芯片自身功耗 |

### 输出质量指标

| 参数 | 典型值 | 单位 | 测试条件 |
|------|--------|------|----------|
| 输出电压纹波 | 5 ~ 30 | mV_pp | 20MHz 带宽限制，满负载 |
| 负载调整率 | 0.1 ~ 0.5 | % | I_OUT: 0→100% 变化 |
| 线性调整率 | 0.02 ~ 0.1 | %/V | V_IN 全范围变化 |
| 瞬态 Overshoot | 20 ~ 80 | mV | 负载步进 50%→100%，dI/dt=1A/µs |
| 恢复时间 | 10 ~ 50 | µs | 瞬态后恢复到 ±1% 的时间 |

### 峰值效率 η_peak（关键指标 #1）

- **定义**：稳态下输出功率与输入功率之比的最大值：η = P_OUT / P_IN × 100%
- **公式**：η = V_OUT·I_OUT / (V_IN·I_IN)，损耗 = P_cond + P_sw + P_L + P_IC
- **影响分析**：每 1% 效率下降意味着多 >1% 发热；在 40A 输出时，η 从 95% 降至 93% 意味着额外 3.5W 热耗
- **典型值**：12V→5V/3A: ~95%；12V→1.0V/20A: ~88%；48V→12V/5A: ~96%

### 瞬态响应 ΔV_out（关键指标 #2）

- **定义**：负载电流突变时输出电压的最大偏离值
- **公式**：ΔV_out ≈ ΔI_step × (1/(2π·f_c·C_out) + ESL·dI/dt)，其中 f_c 为环路带宽
- **影响分析**：过大 overshoot 可能触发负载 OVP；undershoot 可能导致数字芯片复位
- **典型值**：f_c=100kHz, C_out=100µF, ΔI=10A → ΔV≈50mV；增加 C_out 或 f_c 可降低

## 七、影响因素分析

| 关键指标 | 被哪些因素影响 | 该指标又影响哪些下游性能 |
|----------|----------------|--------------------------|
| 效率 η | f_SW、R_DS(on)、Q_g、V_IN、死区 | 热耗、系统温升、散热方案、电池续航、封装选择 |
| 输出纹波 V_ripple | L、C_out、f_SW、ESR、负载 | 后级 PSRR 裕量、模拟电路 SNR、数字芯片 jitter |
| 瞬态响应 | f_c、C_out、L、f_SW、控制模式 | 负载动态性能、OVP/UVP 触发风险、系统稳定性 |
| EMI 噪声 | f_SW、dV/dt、Layout、C_boot、SSFM | EMC 认证通过率、射频电路灵敏度退化 |
| 热性能 T_J | η、Θ_JA、I_OUT、环境温度、PCB 铜皮 | 长期可靠性、MTBF、热关断触发概率 |

> **📌 跨领域共同影响因素总结**：开关频率 f_SW 是 BUCK 设计中最核心的"杠杆参数"——提高 f_SW 可缩小 LC 尺寸并改善瞬态，但直接牺牲效率并恶化 EMI。PCB Layout（尤其是 SW 节点环路面积和输入电容位置）几乎影响所有性能指标，是最容易被低估的设计因素。

## 八、测试方法与验证

### 测试一：效率曲线测试

**测试原理**：在固定 V_IN/V_OUT 条件下，逐点扫描 I_OUT (0~I_max)，用高精度万用表同步测量 V_IN/I_IN/V_OUT/I_OUT，计算 η = P_OUT/P_IN。

| 设备 | 推荐型号 | 关键规格 |
|------|----------|----------|
| 直流电源 | Keysight E36313A | 0-25V/10A, 精度 0.03%+5mV |
| 电子负载 | Chroma 6314A+63102A | 0-80V/40A, CR/CC/CV 模式 |
| 万用表 | Keysight 34465A (x4) | 6.5 digit, 四线 Kelvin 接法 |

**测试框图**：
```
DC 电源(V1/A1) → DUT (BUCK) → 电子负载(V2/A2)
▲ 四线 Kelvin 接法消除线压降误差；V 和 I 分开测量
```

**步骤**：
1. **接线与预热**：按框图使用 Kelvin 四线接法；DUT 上电后满载预热 10 分钟使结温稳定
2. **扫描测试点**：从 0A 开始，每 10% I_max 记录一次 V_IN, I_IN, V_OUT, I_OUT，重点加密 0~20% 轻载区和峰值效率区
3. **计算与绘图**：η = (V_OUT×I_OUT) / (V_IN×I_IN) × 100%；绘制 η vs I_OUT 曲线
4. **判定**：峰值效率 ≥ 规格书 −1%；轻载(10%)效率 ≥ 规格书 −2%

### 测试二：负载瞬态响应

**测试原理**：使用电子负载的动态模式，产生快速电流阶跃，示波器捕获 V_OUT 的 overshoot/undershoot 波形。

| 设备 | 推荐型号 | 关键规格 |
|------|----------|----------|
| 示波器 | Keysight MSOX3104T | 1GHz BW, 被动探头 + 差分探头 |
| 电子负载 | Chroma 63640-80-80 | dI/dt ≥ 2.5A/µs, Dynamic Mode |

**步骤**：
1. **探头设置**：使用 1x 探头 + 弹簧地线（或差分探头），V_OUT 测量点尽量靠近输出电容端，最小化环路面积
2. **设置动态负载**：电子负载设为 CC Dynamic 模式：Level A=50%I_max, Level B=100%I_max，频率 100Hz，占空比 50%
3. **捕获波形**：示波器触发于负载电流上升沿，水平 100µs/div；测量 overshoot/undershoot 峰值和恢复时间(±1%)
4. **判定**：Overshoot/Undershoot ≤ 规格书 ±20%；恢复时间 ≤ 规格书 +30%

### 测试三：输出电压纹波

**测试原理**：用示波器 AC 耦合 + 20MHz 带宽限制测量 V_OUT 纹波电压。

| 设备 | 推荐型号 | 关键规格 |
|------|----------|----------|
| 示波器 | Keysight MSOX3104T | 1GHz, 20MHz BW Limit, AC 耦合 |
| 探头 | 1x 被动探头 + 弹簧地线 | 或同轴探头 (Coaxial probe) 更好 |

**步骤**：
1. **测量设置**：探头 AC 耦合，20MHz 带宽限制开启。弹簧地线直接焊接到输出电容两端（避免长地线引入 EMI）
2. **数据记录**：分别在 10%/50%/100% I_max 三个负载点记录纹波 V_pp；PFM 模式需额外记录 Burst 包络纹波
3. **判定**：纹波 V_pp ≤ 规格书 + 50%（考虑 PCB Layout 差异）。高频尖峰幅值 ≤ 纹波基波的 3x

## 九、注意事项与踩坑经验

| 注意事项 | 说明 |
|----------|------|
| 🔌 SW 节点 Layout | SW 节点是 BUCK 中 dV/dt 最大的节点（>1V/ns），其铜皮面积必须最小化以降低辐射 EMI。输入电容必须紧靠 HS-FET 漏极和 LS-FET 源极，最小化功率环路面积 |
| 🌡️ 热设计裕量 | 实际结温 ≈ T_A + P_loss × Θ_JA。R_DS(on) 高温增加 ~40% (25→125°C)，会进一步恶化效率形成正反馈。建议留 15°C+ 裕量 |
| ⚡ 自举电容取值 | C_BOOT 取值不当会导致 HS-FET 栅极驱动不足，效率骤降甚至 FET 进入线性区烧毁。需 ≥ Q_g/ΔV_BOOT × 10（10x 裕量），必须用 X7R 低 ESR 电容 |
| 📐 反馈走线 | FB 引脚是高阻抗节点，需远离 SW 和电感等噪声源。FB 分压电阻应紧靠 FB 引脚放置，走线短、细、且下方铺 GND 屏蔽 |
| 🔄 环路稳定性 | 输出电容的 ESR 对环路稳定性影响巨大——电解电容 ESR 太高导致零点频率低，陶瓷电容 ESR 太低可能导致相位裕度不足。需根据实际电容调整补偿网络 |
| 🔊 可闻噪声 | PFM 模式下脉冲群频率落入 20Hz~20kHz 可闻范围时，MLCC 压电效应会产生"啸叫"。解决：避开可闻频率、使用抗啸叫电容、或全胶灌封 |

> **🔥 最常见错误 TOP 5**：
> 1. **电感饱和电流选型不足**：必须满足 I_SAT ≥ I_L(peak) = I_out(max) + ΔI_L/2，且考虑高温退化（~15%）
> 2. **输入电容不足**：需承受 RMS 纹波电流 I_Cin(rms) ≈ I_out × √(D(1−D))，最大发生在 D=0.5
> 3. **使能 (EN) 引脚悬空**：EN 不可悬空，必须外接分压或直连 Vin/GND
> 4. **未考虑软启动**：启动瞬间大电容充电电流可能触发 OCP 导致打嗝 (hiccup)，需增大 C_SS 延长软启动时间
> 5. **忽视 PCB 铜厚**：大电流路径需足够铜宽/铜厚，按 <80mil/A (1oz) 估算

## 十、选型指南与决策建议

### 选用同步 BUCK 的场景

- 输出电流 >3A（二极管压降损耗不可接受）
- 效率要求高（>90%）且散热受限
- 需要多相并联扩展电流
- 汽车/工业级可靠性要求
- 数字芯片核心供电（Vcore、DDR、FPGA）

### 异步 BUCK 仍可用的场景

- 输出电流 <2A，效率非首要考量
- 成本极度敏感（消费电子配件）
- 输出高压差（二极管 V_F 占比小）
- PCB 面积有限（无需死区控制电路）
- 噪声敏感（无 LS-FET 开关噪声）

### 选型决策表

| 应用场景 | V_IN | V_OUT | I_OUT | 推荐方案 | 关键考量 |
|----------|------|-------|-------|----------|----------|
| SoC/MCU 供电 | 3.3/5V | 1.0/1.2V | 0.1~3A | 同步 BUCK，COT 模式，内置 FET | 瞬态响应快，无需补偿 |
| DDR5 VDDQ | 5/12V | 1.1V | 2~6A | 同步 BUCK，CMC | 高精度 ±1%，VTT 跟踪 |
| 汽车 ECU 供电 | 12/24V | 5V/3.3V | 0.5~5A | 同步 BUCK，AEC-Q100 | 宽温、低 EMI、展频 |

| 低功耗 IoT | 3.7V Li-ion | 1.8V | µA~100mA | 异步 BUCK 或 PFM Buck | I_Q 优先级 > 效率 |

> **🧠 AE 核心认知**：BUCK 是电源管理中最基础的拓扑，但"基础"不等于"简单"。AE 必须理解：**BUCK 的"好与坏"70% 取决于 PCB Layout 和外围元件选型，而非芯片本身。**效率优化是开关损耗、导通损耗、磁芯损耗三者之间的精细平衡；环路稳定性需要结合实际电容 ESR 的 Type-II/III 补偿设计。在推荐方案时，务必确认客户关注的是峰值效率区域还是轻载区域——两者对应完全不同的优化方向。
