## 一、整体电路拓扑框图

典型手机电池供电路径由四大部分组成，按照功率流方向依次为：VBUS/USB 输入端 → 充电芯片（Charger IC）→ 电池保护芯片（Protection IC）→ 锂电池电芯（Battery Cell），同时电量计（Fuel Gauge）并联监测。

**关键路径总结：**

- **充电**：VBUS(5V) → Charger IC (CC/CV 降压) → Protection IC (MOSFET 导通) → Battery Cell
- **放电**：Battery Cell → Protection IC (MOSFET 导通) → Charger IC (Power Path) → System Load
- **直连供电**：VBUS(5V) → Charger IC (Bypass/OTG) → System Load（电池不参与充放电）

## 二、VBUS / USB 输入端

### 2.1 功能与角色

VBUS 来自 USB 适配器或电脑的 5V 供电线。在 USB Type-C 快充场景中，VBUS 电压可经 PD/PPS 协议协商到 9V、12V 甚至 20V。

### 2.2 典型输入保护电路

| 保护元件 | 作用 | 典型参数 |
|----------|------|----------|
| TVS 管 | ESD 静电保护 (±8kV / ±15kV) | VRWM=5V, Vc |
| OVP 芯片 | 输入过压保护，超过阈值关断通路 | OVP Threshold = 6.0V~7.0V (可调) |
| 共模扼流圈 | 抑制共模噪声，改善 EMI | 90Ω @ 100MHz |
| 输入电容 | 去耦、滤波 | 10μF MLCC + 0.1μF |
| 自恢复保险丝 | 输入过流保护（可选） | Ihold = 1.5~3A |

### 2.3 USB Type-C CC 检测

Type-C 接口通过 CC1/CC2 引脚进行插入方向检测和供电能力广播：

- **Rd (5.1kΩ 下拉)**：Sink 端 (手机端) 标配，表示自己是受电设备
- **Rp (上拉)**：Source 端 (适配器端)，通过不同阻值/电流广播供电能力：Default USB (500mA / 900mA), 1.5A, 3.0A
- **PD 协议**：通过 CC 线上的 BMC 编码进行 USB PD 通信，协商更高的 VBUS 电压

> **AE 测试关注点**：VBUS 上电/下电时的浪涌电流、OVP 响应时间、TVS 残压是否满足后端耐压要求。

## 三、充电芯片 (Charger IC)

### 3.1 CC/CV 充电曲线

锂电池标准充电分为三个阶段：

| 充电阶段 | 条件 | 电流 | 电压 | 占充电时间 |
|----------|------|------|------|------------|
| 涓流 (Trickle) | VBAT < 3.0V | 50~100mA | 缓慢上升 | — |
| CC (恒流) | 3.0V < VBAT < VREG | 0.5C~1C (恒定) | 上升至 VREG | ~60~70% |
| CV (恒压) | VBAT = VREG | 指数衰减至 ITERM | VREG (恒定) | ~25~35% |
| 终止 | ICHG < ITERM | 充电停止 | 略降 | — |

### 3.2 Power Path 管理

现代充电 IC 内置 Power Path (电源路径管理)，通过 BATFET 将系统电源 (SYS) 与电池 (BAT) 隔离：

- **VBUS 接入时**：SYS 由 VBUS 经 Buck 直接供电，同时 BAT 可独立充电，系统运行不受电池电压影响（即使电池深度放电，手机也能立即开机）
- **VBUS 移除时**：BATFET 全导通，SYS 由电池供电，导通阻抗 RDSON 仅 20~50mΩ
- **补充模式 (Supplement Mode)**：当系统峰值电流超过适配器能力时，BATFET 工作在线性区，电池补充供电

## 四、电池保护芯片 (Protection IC)

### 4.1 管脚命名说明

- **B+/B- (电池极耳)**：电芯本体直接引出的正负极，焊接到保护板上
- **PACK+/PACK- (保护板输出)**：经过 Protection IC + Dual MOSFET 后的对外接口，连接到 Charger IC 的 BAT 引脚
- **充电电流路径**：Charger IC BAT → PACK+ → 充电FET(FET1) → B+ → 电芯 → B- → PACK- → Charger IC GND
- **放电电流路径**：电芯 B+ → 放电FET(FET2) → PACK+ → Charger IC BAT → BATFET → SYS → 负载

### 4.2 保护功能详解

| 保护类型 | 触发条件 | 动作 | 恢复条件 | 典型阈值 |
|----------|----------|------|----------|----------|
| 过充保护 (Overcharge) | VBAT > VOVP | OC 引脚拉低 → 充电 FET 关断，切断充电回路 | VBAT < VOVP_REL 或接入负载 | VOVP = 4.28V ± 25mV；VOVP_REL = 4.08V |
| 过放保护 (Over-discharge) | VBAT < VUVP | OD 引脚拉低 → 放电 FET 关断，切断放电回路 | VBAT > VUVP_REL (充电器接入) | VUVP = 2.40V ± 50mV；VUVP_REL = 3.00V |
| 放电过流保护 (Discharge OCP) | IDISCHARGE > IOCP (通过 CS 引脚检测 VCS) | 放电 FET 关断 | 移除负载或充电器接入 | IOCP = 0.15V / RDSON ≈ 3~5A (典型) |
| 充电过流保护 (Charge OCP) | ICHARGE > ICHG_OCP | 充电 FET 关断 | 移除充电器 | ICHG_OCP ≈ −0.15V / RDSON |
| 短路保护 (Short Circuit) | VCS > VSCP (大电流) | 放电 FET 立即关断 (μs 级) | 移除短路或充电器接入 | VSCP = 0.6V~1.0V；响应 ~10μs |
| 0V 充电禁止 | VBAT ≈ 0V (深度放电) | 禁止充电 (安全考虑) | 需外部激活或更换电池 | 部分型号支持 0V 充电 |

**关键设计要点：**

1. R1 和 C1 构成低通滤波器，防止浪涌/ESD 误触发保护；但 R1 太大会导致 VDD 采样不准，通常 ≤ 1kΩ
2. Dual MOSFET 的 RDSON 直接影响充放电效率与发热，手机应用通常选择 ≤ 30mΩ
3. 保护 IC 本身消耗 < 5μA (正常模式)，进入过放保护后 < 0.1μA

## 五、锂电池电芯 (Battery Cell)

### 5.1 电芯类型对比

| 特性 | 锂离子 (Li-ion) | 锂聚合物 (Li-Po) |
|------|-----------------|------------------|
| 电解质 | 液态有机溶剂 | 固态/凝胶聚合物 |
| 外壳 | 金属壳 (钢/铝) | 软包 (铝塑膜) |
| 能量密度 | 较高 (~250 Wh/kg) | 稍低 (~200 Wh/kg) |
| 形状 | 圆柱/方形固定 | 任意形状，可做薄 |
| 安全 | 较好 (硬壳) | 需防穿刺/鼓包 |
| 手机应用 | 早期 | 当前主流 |

### 5.2 电芯关键化学参数

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 标称电压 Vnom | 3.6V / 3.7V / 3.8V | 取决于正极材料 (LCO / NMC / LFP) |
| 满充电压 Vfull | 4.20V / 4.35V / 4.40V / 4.45V | 高电压电芯 (HV Li-Po) 可到 4.45V |
| 放电终止电压 | 3.0V (软关断) / 2.5V (硬关断) | 低于此电压可能损伤电芯 |
| 额定容量 | 4000~5000mAh (手机) | 1C 放电至 3.0V 测得 |
| 内阻 DC IR | 50~150mΩ (新电芯) | 随老化增大，> 300mΩ 需更换 |
| 充放电效率 | > 99% (库仑效率) | 充入容量 / 放出容量 × 100% |
| 循环寿命 | 300~500 次 (至 80% 容量) | 0.5C 充放，25°C |
| 自放电率 | < 3% / 月 | 25°C 存储 |

### 5.3 电池等效电路模型 (2RC-ECM)

二阶 RC 等效电路模型 (2nd-order RC-ECM) 是电池建模的工业标准：

- **OCV (Open Circuit Voltage)**：电池开路电压，是 SOC 和温度的函数，由 Nernst 方程决定
- **R0**：欧姆内阻 — 电解液、电极、集流体、极耳等纯电阻性分量，引起瞬时压降
- **R1C1**：电化学极化 — SEI 膜 / 电荷转移，时间常数 ~ ms 级
- **R2C2**：浓差极化 — Li⁺ 扩散，时间常数 ~ s 级

### 5.4 电量计 (Fuel Gauge / 库仑计)

电量计的核心功能是通过高精度电流积分跟踪电池的剩余电量 (SOC)。它需要一个采样电阻 Rsns 串入电池主回路，测量 Rsns 上的压降来计算电流。

**两种常见放置方案**：Pack Side（内置 MCU，独立运行算法，适合可拆卸电池包）与 System Side（仅 ADC+通信，算法在主 SoC 运行，成本更低）。

**电量计估算 SOC 三种主流方法：**

**方法一：电压查表法 (OCV-SOC Lookup)**

- 原理：电池开路电压 (OCV) 与 SOC 存在确定的映射关系。电池静置足够久后，测 OCV → 查表得 SOC
- 优点：不需要电流采样，电路最简单
- 缺点：带负载时端电压 ≠ OCV (有 IR Drop)，必须等电池静置，无法实时跟踪

**方法二：库仑计数 (Coulomb Counting)**

- 原理：对流入/流出电池的电流进行时间积分，计算净电荷量变化

$$SOC(t) = SOC(t_0) + \frac{1}{C_{rated}} \times \int I(\tau) d\tau \times 100\%$$

其中：C_rated = 电池额定容量 (mAh)，I(τ) = 充放电电流 (mA，充电为正、放电为负)。

库仑计硬件实现：

- 采样电阻 Rsns：5~10mΩ 精密电阻，串入电池主回路
- ΔΣ ADC：14~16 bit 高精度 ADC，持续采样 Rsns 两端压降 V = I × Rsns
- 积分器 (Accumulator)：将每个采样周期的电荷量累加：ΔQ = I × Δt

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 采样电阻 Rsns | 5~10mΩ | 太小 → SNR 差；太大 → 损耗大 (I²R) |
| ADC 分辨率 | 14~16 bit | 对应电流分辨率 ~1mA (16-bit @ 5mΩ, ±8A 量程) |
| 采样频率 | 1~8 kHz | 需覆盖脉冲负载 (如 RF PA 突发) |
| 积分周期 | 1s (典型) | 每秒更新一次 SOC |

> **库仑计的固有缺陷 — 累积误差 (Drift)**：每毫安时的测量误差会随时间不断累积。例如 ±1mA 偏置 × 24h = ±24mAh 误差，一周就是 ±168mAh。必须定期校准纠正漂移。

**方法三：阻抗跟踪 (Impedance Track — TI 专利)**

- 原理：将库仑计数与 OCV-电池模型融合。正常运行时用库仑计数追踪电量，当电池进入静置状态 (电流接近零) 时，测 OCV 并查表校准 SOC。同时利用 2RC 等效电路模型估算负载下的"等效 OCV"，无需等待静置即可获得较准确的 SOC

Impedance Track 工作流程：

1. 初始化 (上电/Golden Image)：从 Flash 加载电池的 OCV-SOC 曲线表、R0(SOC,T) 表、R1C1/R2C2 参数表
2. 正常运行：库仑计持续积分 I×dt，同时用电池模型 Vt = OCV − I×Z 反推 OCV
3. 静置校准 (Relaxation)：当 |I| ≈ 0 且持续 >30min，实测 OCV → 查表 → 修正 SOC 累积误差
4. 满充/满放校准：充电终止 (I<ITERM) 时 SOC 置 100%；老化补偿：随循环次数增加，更新 Full Charge Capacity (FCC) 和内部阻抗参数

### 5.5 三芯功能对比：Charger vs Protection vs Fuel Gauge

手机电池管理系统的三颗核心芯片各自承担不同的角色。TI 的产品线演进中，BQ41Z5x 系列把"保护 + 电量计"合为一颗 IC，减少了 PCB 面积和 BOM 成本。

**三颗芯片功能详细对比**

| 功能域 | BQ25890 (Charger) | BQ2980 (Protection) | BQ41Z5x (Protect+Gauge 二合一) |
|--------|-------------------|---------------------|--------------------------------|
| 核心角色 | 充电管理 — 把 VBUS 降压后安全地充入电池 | 安全保护 — 检测故障并切断回路 | 电量监测 + 安全保护 + 电池认证 |
| 供电方式 | 由 VBUS 供电，内部 LDO 产生偏置 | 由电池直接供电 (VDD=B+)，无外部电源 | 由电池供电 (低功耗)，支持 ship mode 关断 |
| 充电控制 | 核心功能：3A Buck, CC/CV, 涓流, 终止, NTC JEITA, Power Path | 不涉及 — 仅被动保护 | 不涉及 — 仅被动保护 |
| 电压保护 | VBUS OVP (6V), BAT OVP 可寄存器配置 | 核心功能：COV 4.28V, CUV 2.40V 硬件阈值 | 核心功能：可编程 OV/UV 阈值，精度优于分立方案 |
| 电流保护 | 输入电流限制 (ILIM), 充电电流限制 (ICHG) | 核心功能：OCD1/OCD2 (放电过流), OCC (充电过流), SCD (短路) | 核心功能：可编程 OCC/OCD/SCD 阈值，支持分级保护 |
| 温度保护 | NTC JEITA 档位 (0/10/45/60°C)，控制充电电流 | 核心功能：OT/UT 硬件关断 (BQ2982 版本) | 核心功能：可编程 OT/UT，集成 NTC 检测 |
| 电量计 (SOC) | ❌ 不具备 | ❌ 不具备 | 核心功能：Impedance Track, SOC/SOH 计算, 剩余时间预测 |
| 库仑计数 | ❌ 不具备 | ❌ 不具备 | 核心功能：高精度电流积分 |
| 通信接口 | I²C (寄存器配置/状态读取) | 无通信接口，全部硬件阈值 | I²C / SMBus (电压/电流/SOC/温度/状态/认证数据) |
| 功耗 | 充电时 ~mW 级，待机 ~30μA | 正常工作 ~3μA，过放后 ~0.1μA | 正常工作 ~100μA，sleep ~10μA，ship mode ~1μA |
| 封装/尺寸 | WCSP 2.5×2.5mm 或 QFN | X2QFN 1.2×1.6mm | VQFN 3.5×4.5mm（比 PROT+FG 分立总和更小） |

**BQ41Z5x 的独特功能**：作为 Protection + Fuel Gauge 二合一，BQ41Z5x 除了覆盖 BQ2980 + BQ27426 的全部功能外，还提供了分立方案无法实现的融合能力：

| 融合功能 | 分立方案做不到的原因 |
|----------|----------------------|
| 自适应保护阈值 | BQ2980 的 OV/UV/OC 阈值是硬件固定值，无法根据电池老化调整。BQ41Z5x 可根据 SOH 动态调整保护阈值（老化电池内阻大 → 适当放宽 OCP 阈值防止误触发） |
| 预判性保护 | 分立保护 IC 只能"事后"检测。BQ41Z5x 利用电量计的实时电流/电压数据 + 电池模型，可预判即将发生的过放/过温并提前降电流 |
| 精准 SOC 触发保护 | 分立方案只能靠电压判断 SOC（不准）。BQ41Z5x 可在 SOC=0% 时精确触发关机，避免"有电压但没容量"导致突然断电 |
| SOH (健康度) 追踪 | 只有电量计能追踪循环次数、容量衰减、内阻增长。BQ41Z5x 将此数据通过 SMBus 上报给系统 |
| SHA-1 电池认证 | 防止劣质/仿冒电池引发安全事故。系统通过 challenge-response 协议验证电池身份，认证失败可拒绝充电 |
| Black Box (黑匣子) | 记录电池的极端事件（过温、过放、短路发生时间和次数），用于售后分析和品质追溯 |

> **一句话总结**：BQ25890 = 充电的"司机" (怎么充)；BQ2980 = 安全的"保险丝" (什么时候必须停)；BQ41Z5x = 安全的"保险丝" + 电量的"油表" + 电池的"身份证"三合一。在实际产品中，BQ41Z5x + BQ25890 两颗 IC 就构成了完整的电池管理系统。

### 6.2 OCVR (开路电压) 测量

目的：通过 OCV 推算电池 SOC，评估电芯一致性。

测试步骤：

1. 将电池以标准充放电程序循环 3 次，确定实际容量
2. 满充至 4.4V (或规格书指定的 Vfull)，截止电流 0.05C
3. 静置 1 小时，记录 OCV → 对应 SOC = 100%
4. 以 0.5C 放电 10% 容量，静置 30 分钟，记录 OCV → SOC = 90%
5. 重复步骤 4，获得 OCV-SOC 曲线 (SOC: 100% → 0%，步长 5%~10%)
6. 0% SOC 定义为放电至 Vcutoff = 3.0V

> **AE 验收关注**：出厂时 OCV 通常在 3.7~3.9V (约 50% SOC)，这是锂电池最佳存储电压。OCV 低于 3.4V 或高于 4.1V 可能暗示电芯异常。

### 6.3 DC IR (直流内阻) 测量 — HPPC 法

HPPC (Hybrid Pulse Power Characterization) 是测电池内阻的标准方法，参考 USABC / FreedomCAR 协议。

放电内阻测试流程：

1. 将电池调整到目标 SOC (如 50%)，静置 1 小时
2. 记录静置后的电压 V0
3. 施加 1C 放电脉冲，持续 10 秒 (或 18 秒/30 秒)
4. 记录脉冲开始时刻的电压 V1 (通常取 0.1s 或 1s 后的电压)
5. 记录脉冲结束时刻的电压 V2 (通常取 10s)
6. R0 (欧姆内阻) = (V0 − V1) / Ipulse；Rtotal (总内阻) = (V0 − V2) / Ipulse；Rpolarization = Rtotal − R0

不同 SOC 下的典型内阻测试矩阵（4000mAh Li-Po 新电芯参考值）：

| SOC | 90% | 70% | 50% | 30% | 10% |
|-----|-----|-----|-----|-----|-----|
| R0 (放电) / mΩ | 45~55 | 42~50 | 40~48 | 43~55 | 60~90 |
| R0 (充电) / mΩ | 40~50 | 38~48 | 38~46 | 40~52 | 50~70 |

### 6.4 容量测试

标准充放电制度 (以 4000mAh 电芯为例)：

| 步骤 | 操作 | 参数 | 截止条件 |
|------|------|------|----------|
| 1. 充电 | CC 恒流充电 | I = 0.5C = 2000mA | VBAT = 4.4V |
| 2. 充电 | CV 恒压充电 | V = 4.4V | I < 0.05C |
| 3. 静置 | 开路静置 | — | 30 min |
| 4. 放电 | CC 恒流放电 | I = 0.2C = 800mA | VBAT = 3.0V |
| 5. 计算 | 积分容量 | C = ∫ I·dt | 放电容量即为额定容量 |

$$放电容量 C = I_{discharge} \times T_{discharge} \quad [mAh 或 Ah]$$

$$能量 E = \int V(t) \times I_{discharge} dt \quad [Wh]$$

### 6.5 自放电测试

1. 电池满充至 Vfull，记录容量 C0
2. 在 25°C 环境下开路存储 28 天
3. 以 0.2C 放电至 3.0V，记录剩余容量 C28
4. 自放电率 = (C0 − C28) / C0 × 100%

典型手机电芯自放电率应低于 3%/月。过高的自放电率暗示微短路 (Internal Short) 缺陷。

### 6.6 循环寿命测试

1. 以 0.5C CC/CV 充电至 Vfull，截止 0.05C
2. 以 1C CC 放电至 Vcutoff (3.0V)
3. 循环重复，每 50 次做一次标准容量标定 (0.2C 放)
4. 当标准容量低于初始容量的 80% 时，循环次数即为寿命

> 循环测试通常需 2~3 个月，是电池验证中最耗时的项目。加速老化可在 45°C 下进行，但结果不可直接等同于常温寿命。

## 八、典型故障排查思路

| 故障现象 | 优先排查项 | 可能原因 |
|----------|------------|----------|
| 手机完全不充电 | VBUS 是否到达 Charger 输入？CC 检测是否正常？ | TVS 短路、OVP 触发了、USB 座虚焊、CC 电阻值异常 |
| 充电很慢 | 充电电流是否达到设定值？NTC 阻值是否正常？ | NTC 误判高温 → 降电流；ILIM 设置偏低；电池内阻偏大 → CV 过早进入 |
| 电池充不满 | CV 阶段电压是否达到 VREG？终止电流 ITERM 设置？ | IR Drop 在 BAT 线上导致采样不准；VREG 寄存器配错 |
| 手机自动关机 (有电) | 电池电压 vs 系统电压？保护 IC 是否误触发？ | BATFET RDSON 过大导致大负载时 SYS 跌落；保护 IC UVP 误触发 |
| 电池鼓包 | 满充电压是否超标？充电温度是否过高？ | VREG 超调 → 过充；NTC 失效 → 高温下仍大电流充电 |
| VBUS 插入后不能开机 (电池已过放) | Power Path 是否工作？BATFET 是否导通？ | 保护 IC 处于过放锁死；Charger 的 dead-battery 模式未正常激活 |

> **排障黄金法则**：先量电压、再看波形、最后怀疑 IC。90% 的充电问题出在连接器/PCB/外围无源器件，而非 Charger IC 本身。

## 九、总结与学习建议

### 9.1 核心公式速查

| 公式 | 用途 |
|------|------|
| C = I × T | 容量 (mAh) = 放电电流 (mA) × 时间 (h) |
| R0 = ΔV / I_DC | 内阻 = 脉冲初始压降 / 脉冲电流 |
| η = C_discharge / C_charge × 100% | 充放电库仑效率 |
| η_charger = (VBAT·IBAT) / (VBUS·IBUS) | 充电芯片效率 |
| P_loss = I² × RDSON | MOSFET 导通损耗 |
| I_OCP = V_CS / RDSON | 保护 IC 过流检测阈值 |
| OCV = f(SOC, T) | 电池开路电压 — SOC 映射 |

### 9.2 推荐学习路径

1. 先吃透 DW01 / S-8261 的 datasheet，理解保护 IC 的状态机
2. 选一颗 Charger IC (如 TI BQ25890)，精读 register map，对每个寄存器理解其物理意义
3. 在 EVM 板上实测：CC/CV 切换波形、Power Path 切换瞬态、BATFET RDSON
4. 用电池测试柜跑一次完整的 HPPC + OCV-SOC + 循环寿命，直观感受电池特性
5. 关注 JEITA 标准和 USB PD/PPS 协议规范，这是面试中的加分项

### 9.3 面试高频问题预警

- **Q: CC 切换到 CV 的判据是什么？** → VBAT = VREG
- **Q: 为什么需要涓流充电？** → 深度放电电池内阻大，大电流充电会析锂损伤
- **Q: Power Path 相比传统方案有什么优势？** → 电池没电也能开机、系统电压不受电池电压拖低
- **Q: NTC 电阻选多大？** → 通常 10kΩ @ 25°C, B=3435/3380，与内部 10kΩ 分压匹配
