# 卫星射频收发芯片 (Satellite RF Transceiver)

---

## 一、产品概述

### 1.1 产品定位
卫星射频收发芯片用于低轨(LEO)/中轨(MEO)/高轨(GEO)卫星通信载荷，实现卫星与地面终端、卫星与卫星之间的射频信号收发。

### 1.2 应用场景
- 低轨卫星互联网 (Starlink类, 宽带接入)
- 卫星物联网 (IoT-NTN, 窄带)
- 星间链路 (ISL, Inter-Satellite Link)
- 卫星测控 (TT&C, Telemetry/Tracking/Command)
- 卫星通信终端 (VSAT, 相控阵终端)

### 1.3 技术路线
- 频段: Ku (12-18GHz), K (18-27GHz), Ka (27-40GHz), Q/V (40-75GHz)
- 抗辐射: 需抗空间辐射 (TID >100krad, SEL免疫)
- 工艺: RF-SOI (抗辐射), SiGe BiCMOS, GaAs/GaN
- 架构: 直接变频或超外差
- 特殊要求: 极端温度 (-55~+125C), 真空环境, 抗辐射

---

## 二、工作原理

### 2.1 系统架构

**超外差架构 (卫星通信主流, 镜像抑制好):**
```
RX: 天线 -> LNA -> 镜像抑制滤波器 -> Mixer1 -> IF放大器 -> IF滤波器 -> Mixer2 -> 基带
TX: 基带 -> Mixer1 -> IF滤波器 -> IF放大器 -> Mixer2 -> 带通滤波 -> PA -> 天线
```

**直接变频 (简化方案, 用于低成本LEO):**
类似基站收发芯片的ZIF架构，但需额外考虑抗辐射加固。

### 2.2 卫星通信特殊需求

| 需求 | 说明 |
|------|------|
| 抗辐射加固 | 总剂量TID >100krad(Si), 单粒子闩锁SEL免疫, 单粒子翻转SEU容错 |
| 极端温度 | -55~+125C 全温工作 |
| 高可靠性 | 寿命>7-15年, 无单点故障 |
| 真空兼容 | 无气密封装, 防Outgassing |
| 频率稳定度 | 超稳定参考源, Allan方差要求 |
| Doppler补偿 | 卫星高速运动产生多普勒频移 |

### 2.3 相控阵波束赋形

卫星通信普遍采用有源相控阵:
- 每个天线单元后接独立的收发通道
- 通过相位/幅度控制实现波束扫描
- 芯片集成: 多通道 + 移相器 + 衰减器

## 四、关键指标

### 4.1 接收链路

| 指标 | 规格 | 备注 |
|------|------|------|
| 频率范围 | 17.7~21.2 GHz (Ka下行) | 可扩展到Ku/Q/V |
| 噪声系数 | <3.0 dB | 含LNA |
| 增益 | 30~60 dB | 可编程 |
| 瞬时带宽 | 250/500/1000 MHz | |
| IIP3 | >0 dBm | |
| 抗辐射TID | >100 krad(Si) | |
| SEL免疫 | LET >75 MeV*cm^2/mg | |

### 4.2 发送链路

| 指标 | 规格 |
|------|------|
| 频率范围 | 27.5~31.0 GHz (Ka上行) |
| 输出功率 | 0~+5 dBm (驱动外部PA) |
| ACLR | <-40 dBc |
| EVM | <1.5% |

### 4.3 LO

| 指标 | 规格 |
|------|------|
| 相噪@100kHz | <-105 dBc/Hz |
| 相噪@1MHz | <-130 dBc/Hz |
| 频率稳定度 | <0.1ppm (Allan方差, 1s) |

### 4.4 相控阵

| 指标 | 规格 |
|------|------|
| 通道数 | 4/8/16 per chip |
| 移相器 | 6bit, 360度, RMS误差<3度 |
| 衰减器 | 5bit, 0~31dB, RMS误差<0.5dB |
| 通道间一致性 | 幅度 <+/-0.5dB, 相位 <+/-3度 |

## 五、测试方法

### 5.1 常规RF测试
与基站收发芯片类似 (NF, 增益, 线性度, 相噪, ACLR, EVM)

### 5.2 抗辐射测试
- 总剂量TID: Co-60 gamma射线辐射, 100krad
- 单粒子SEL: 重离子加速器测试
- 单粒子SEU: 质子/中子束测试

### 5.3 极端温度测试
- 温度范围: -55~+125C (比基站更宽)
- 真空/热真空测试

### 5.4 相控阵校准
- 各通道相位/幅度一致性测量
- 移相器/衰减器精度校准
- 波束指向精度验证

### 5.5 Doppler模拟
- 模拟卫星高速运动引起的频率偏移
- 验证Doppler补偿算法

## 六、AE知识要点

1. 卫星通信频率规划: L/S/C/X/Ku/K/Ka/Q/V/W bands
2. 抗辐射加固设计: TMR, EDAC, 冗余, 特殊工艺
3. 相控阵校准: 暗室测量, 近场/远场
4. Doppler效应: LEO卫星相对速度可达7.8km/s, Doppler偏移+/-750kHz @Ka
5. 链路预算: 自由空间损耗 = 20*log10(4*pi*d/lambda), 卫星距离300~36000km
6. 可靠性: 无单点故障, 寿命7~15年, 真空/辐射环境
7. 标准化: DVB-S2X, CCSDS, 5G NTN
