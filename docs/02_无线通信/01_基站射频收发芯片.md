# 基站射频收发芯片 (Base Station RF Transceiver)

---

## 一、产品概述

### 1.1 产品定位
基站射频收发芯片是5G/4G基站RRU(射频拉远单元)或AAU(有源天线单元)的核心射频芯片，负责基带信号与射频信号之间的频率转换和信号调理。

### 1.2 应用场景
- 5G NR 宏基站 (Macro Cell): Sub-6GHz + mmWave
- 5G 小基站 (Small Cell)
- Massive MIMO AAU (64T64R, 32T32R)
- 4G LTE 基站升级和维护

### 1.3 技术路线
- 工艺: RF-SOI, SiGe BiCMOS, 或 RF-CMOS (28nm/22nm)
- 架构: 零中频 (ZIF, Zero-IF) 或 数字中频 (DIF)
- 频段: Sub-6GHz (n77/n78/n79: 3.3~5.0GHz)
- 带宽: 100MHz/200MHz/400MHz 瞬时带宽
- 通道数: 2T2R, 4T4R, 8T8R (单芯片)

## 二、工作原理

### 2.1 零中频收发架构 (ZIF)

接收路径 (RX):
天线 -> LNA -> I/Q Mixer (下变频) -> LPF/AAF -> PGA -> ADC -> DFE -> 数字基带

发送路径 (TX):
数字基带 -> DFE -> DAC -> LPF -> I/Q Mixer (上变频) -> PA Driver -> PA -> 天线

ZIF优势: 无镜像频率问题, 结构简单易于集成
ZIF挑战: DC offset, I/Q imbalance, LO leakage, flicker noise

### 2.2 接收链路 (RX Chain)

| 模块 | 功能 | 关键参数 |
|------|------|----------|
| LNA | 低噪声放大, 设定系统NF | NF<2dB, Gain 15~25dB |
| I/Q Mixer | RF下变频到基带 | IIP3>+10dBm, Conversion Gain 5~10dB |
| TIA | 电流-电压转换 | 噪声<3nV/sqrt(Hz) |
| LPF/AAF | 信道选择, 抗混叠 | BW可编程 20~200MHz |
| PGA/VGA | 可变增益放大 | 0~30dB, 步进0.5dB |
| ADC | 模数转换 | 12~14bit, 200~500MSPS |

链路预算示例 (5G NR 100MHz):
LNA Gain 20dB + Mixer -3dB + LPF -2dB + PGA 10dB = 总增益 25dB, NF ~2.5dB

### 2.3 发送链路 (TX Chain)

| 模块 | 功能 | 关键参数 |
|------|------|----------|
| DAC | 数模转换 | 12~14bit, 400~1000MSPS |
| LPF | 重建滤波, 消除DAC镜像 | BW可编程 |
| I/Q Mixer | 基带上变频到RF | OIP3>+15dBm |
| PA Driver | 预放大 | Gain 10~20dB, P1dB>+10dBm |

TX关键指标:
- 输出功率: 0~+5dBm (PA Driver输出)
- ACLR: <-45dBc @ 100MHz 5G NR
- EVM: <1% (PA Driver输出)
- LO Leakage: <-40dBc, 镜像抑制: >50dBc

### 2.4 频率合成器 (LO/PLL)

架构: TCXO(参考) -> PFD -> 环路滤波器 -> VCO(宽带) -> 分频器 -> Mixer LO

关键指标:
- 频率: 3.3~5.0GHz, 步进 <1kHz
- 相噪: <-110dBc/Hz @100kHz, <-135dBc/Hz @1MHz
- 锁定时间: <50us, 积分抖动: <100fs RMS

### 2.5 数字前端 (DFE)

| 子模块 | 功能 |
|--------|------|
| DDC (数字下变频) | ADC数据 IF/零中频 -> 基带 |
| DUC (数字上变频) | 基带 -> IF/零中频 |
| NCO | 生成数字本振 |
| 抽取/内插滤波 | 采样率转换 |
| CFR | 降低PAPR |
| DPD | PA线性化 |

## 五、测试方法

### 5.1 接收链路噪声系数测试

测试原理: Y因子法 (热/冷噪声源)

测试设备: 噪声系数分析仪 (Keysight N8976B) + 噪声源 (N4002A)

测试框图:
  噪声源 -> DUT RX -> 噪声系数分析仪

步骤:
1. 校准分析仪和噪声源
2. DUT设置最大增益
3. 测量NF vs 频率 (3.3~5.0GHz)
4. 要求: NF <2.5dB @ n78 (3.5GHz)

### 5.2 增益与线性度测试

测试设备: 矢量网络分析仪 + 信号发生器 + 频谱分析仪

增益 (S21): VNA测量增益vs频率, 带内平坦度 <+/-0.5dB

IIP3 (双音测试):
- 双音间隔1MHz, 每音-20dBm
- 测量IM3产物
- IIP3 = P_in + Delta_P/2, >+5dBm

P1dB压缩点: 增益下降1dB时的输入功率

### 5.3 镜像抑制/IQ平衡测试

1. 注入LO+10MHz的RF单音信号
2. 测量基带I/Q输出
3. 计算I/Q幅度和相位不平衡
4. 开启校准后重新测量
5. 镜像抑制 = 20*log10(|Desired|/|Image|) >50dBc

### 5.4 TX ACLR/EVM测试

测试设备: 矢量信号分析仪 (VSA) + 频谱分析仪

测试框图: DUT TX (发5G NR) -> 频谱分析仪/VSA

ACLR: 100MHz 5G NR, 测量邻道功率泄漏, <-47dBc
EVM: VSA解调, 256QAM要求 <3.5% (DUT <0.8%)

### 5.5 LO泄漏和镜像抑制 (TX)

- 关闭基带I/Q -> 测量LO泄漏 <-45dBc
- 注入单音基带 -> 测量镜像频率 >55dBc

### 5.6 LO相噪测试

测试设备: 相噪分析仪 (E5052B) 或 频谱仪+相噪选件

测量:
- 相噪 @100k, 1M, 10MHz offset
- 积分抖动 10k~40MHz
- 锁定时间 (频率阶跃 -> Lock信号延迟)

## 六、AE知识要点

1. 5G NR信号特征: OFDM, 100/400MHz BW, 高PAPR(~10dB), 256QAM
2. ZIF架构固有缺陷需校准: DC offset, I/Q imbalance, LO leakage, flicker noise
3. Massive MIMO挑战: 64通道间相位/幅度一致性 <+/-2度 / <+/-0.5dB
4. ACLR/ACPR: 发射机线性度核心指标
5. DPD是必选项: 5G PAPR要求PA必须结合DPD
6. JESD204B/C: 高速串行数据接口, 确定性延迟是关键
7. 频段覆盖: n77(3.3-4.2G), n78(3.3-3.8G), n79(4.4-5.0G)
8. 校准是关键竞争力: I/Q校准、LO泄漏校准、温度补偿校准
