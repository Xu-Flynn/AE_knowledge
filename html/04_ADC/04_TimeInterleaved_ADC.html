背景与应用定位

Time-Interleaved (TI) ADC 是突破单通道 ADC 速度极限的核心架构，通过 M 个并行通道以时间交错方式工作，每个通道以 fs/M 速率采样，总体实现 fs 的等效采样率。TI 架构可以将 SAR、Pipeline 等成熟 ADC 的速度提升 M 倍，是实现 >1 GSPS 中高分辨率转换的关键技术。广泛应用于高速通信、光网络接收机、宽带雷达和高速仪器仪表。

📌 产品定位

产业链位置：超高速模拟前端与数字处理器之间，突破 ADC 单通道速度上限

核心价值：以面积和功耗线性增长换取 M 倍速度提升，可在先进工艺下实现 10+ GSPS @ 8~14 bit

本质功能：M 个并行子 ADC + M 相时钟分配 + 多路复用数字输出 + 校准 (增益/失调/时序偏斜)

🎯 典型应用场景

  • 相干光通信接收机 (>64 GBaud, >128 GSPS)
  • 宽带雷达/电子战数字接收机 (瞬时带宽 > 2 GHz)
  • 高速示波器 (>10 GSPS 实时采样)
  • 5G/6G 毫米波直接采样接收机
  • 高速 SerDes/背板接收器
  • 粒子物理探测器读出电子学

时间交错与通道失配校准原理

Time-Interleaved ADC 的核心是将 M 个独立子 ADC 以时间交错方式并行工作：每个子 ADC 以 fs/M 的速率采样，M 个通道的采样时刻均匀分布在 Ts=1/fs 周期内，交错后等效于单个 fs 速率的 ADC。

图 2-1 | M 通道 Time-Interleaved ADC 系统级信号流向

1. 时间交错原理

M 相时钟 (Φ0, Φ1, ..., ΦM−1) 等间距分布在 1/fs 周期：Φk 的采样时刻 = k × Ts/M。子 ADCk 在 Φk 采样，最终输出按 Φ0, Φ1, ..., ΦM−1, Φ0, ... 顺序拼接。

fs = M × fs,ch   |   Ts,ch = M × Ts   |   相位步进 = Ts/M

2. 三大失配及其影响

理想 TI-ADC 要求所有子 ADC 完全相同，但实际存在三大失配：

失配类型时域表现频域影响典型值
失调失配 (Offset)各通道输出存在不同 DC 偏移在 fs/M 整数倍处产生固定杂散 (与信号无关)1~10 mV
增益失配 (Gain)各通道对同一信号幅度响应不同在 k·fs/M ± fin 处产生调制杂散 (与信号相关)0.1~2%
时序偏斜 (Timing Skew)各通道实际采样时刻偏离理想相位在 k·fs/M ± fin 处产生杂散，且幅度随 fin 增大而恶化0.1~5 ps

3. 时序偏斜 — 最关键的失配

时序偏斜 (也可视为带宽失配的频率域表现) 是 TI-ADC 性能的主要限制因素，其产生的杂散幅度随输入频率线性增长，在高频 (near-Nyquist) 输入时尤为严重：

SFDRskew ≈ 20log10(1/(M·π·fin·σskew)) dB   |   σskew = 偏斜标准差

例如：4 通道 TI-ADC @ fin=10 GHz，若要 SFDR>60 dBc，需 σskew < 50 fs。这要求时钟分配网络和版图达到飞秒级精度。

4. 带宽失配

各通道输入带宽不同 (由采样开关 Ron、输入电容 Cs 和版图寄生差异导致) → 高频输入时不同通道呈现不同的衰减和相移。带宽失配可等效为频率相关的增益和时序误差：

Hk(jω) ≈ (1 + Δgk) · ejω·Δtk
💡 AE 核心认知：TI-ADC 的 SNR 由子 ADC 性能和失配校准共同决定。4 通道 8-bit TI-ADC 未经校准时 SFDR 可能仅 30~40 dBc；经全数字后台校准后可达 55~65 dBc。时序偏斜校准是 >10 GSPS TI-ADC 的核心技术壁垒。

核心模块深度解析

一、子 ADC 架构选择

子 ADC 架构决定 TI-ADC 的基准精度和每通道功耗。不同架构在速度、精度、面积和功耗之间的权衡：

子 ADC 类型每通道 fs,ch每通道分辨率功耗/ch适用场景
SAR ADC100k~200M8~14b低 (<5 mW)中高速中高精度，最常用
Pipeline ADC50M~500M10~14b中高 (10~100 mW)每通道高速，减少 M
Flash ADC500M~5G4~8b极高 (W)超高速低精度，光通信
Folding/Interpolating200M~2G6~8b高高速中低精度

二、多相时钟生成 — 飞秒级精度

M 相精确等间距时钟是 TI-ADC 的基石。DLL (Delay-Locked Loop) 和 PLL 是两种主流方案：

Φk 相位 = 2πk/M ± Δφk   |   Δφk = 偏斜误差 → 导致杂散
方案优点缺点偏斜典型值
DLL + 相位插值低抖动，对电源噪声不敏感锁定范围有限，需参考时钟0.5~5 ps
PLL (多相 VCO)频率灵活，可倍频VCO 相位噪声积累，功耗高1~10 ps
注入锁定振荡器极低抖动，高频率锁定范围窄，PVT 敏感0.1~2 ps
数字相位校准可编程补偿，灵活受限于检测精度和调整步进经校准 <0.1 ps

三、增益与失调失配校准

增益和失调失配在频域产生确定性杂散，可通过数字域校准消除：

前台校准

✅ 精度高 (可 <0.01%)
✅ 实现简单
❌ 需中断正常工作
❌ 无法跟踪温度漂移
方法：注入已知 DC/正弦参考 → 测量各通道输出 → 存储校正系数

后台校准

✅ 连续工作，跟踪 PVT 漂移
✅ 不需中断正常转换
❌ 算法复杂，收敛慢
❌ 对信号统计特性有假设
方法：相关性检测 / PN 注入 / 参考通道 / LMS 自适应

四、时序偏斜校准 — 核心技术壁垒

时序偏斜校准分为检测和校正两个环节：

检测方法：

  • 相关法：相邻通道输出相关性 → 偏斜符号和幅度估计。简单但对信号频谱有要求
  • 参考 ADC 法：额外增加一个低速高精度参考 ADC，分时与各子 ADC 采样同一信号 → 比较各通道与参考的差异 → 最精确
  • FFT 能量检测：监测偏斜杂散的能量 → 反馈调整。收敛慢但鲁棒

校正方法：

  • 模拟域：可调延迟线 (DTC) 调整各通道采样时钟相位 → 精度受 DTC 分辨率限制
  • 数字域：数字分数延迟滤波器 (Farrow 结构) 或多项式插值 → 灵活但消耗数字资源
  • 混合域：模拟粗调 + 数字细校 → 兼顾精度和功耗
校准后偏斜残差 < 50 fs (先进设计中可至 10~20 fs)

五、输入网络与带宽扩展

TI-ADC 的输入网络需要驱动 M 个并行采样开关，总输入电容 = M × Cs,ch。高频下输入阻抗下降，需要片上宽带缓冲器或分布式输入 T-line。输入带宽 BWin > fs/2 是基本要求：

BWin = 1/(2πRs·M·Cs,ch)   |   Rs = 源阻抗+开关Ron

高通道数 (M>16) 设计中，常见采用分级缓冲或行波分发 (Traveling Wave Distribution) 架构。

测试方法

⓵ 偏斜杂散测试 — 高频 FFT 频谱法

施加高频正弦波 (fin 接近 fs/2) → FFT 分析 → 检查 fs/M ± fin, 2fs/M ± fin 处的杂散幅度。高频输入下偏斜杂散最显著，是 TI-ADC 最关键的测试项。

图 7-1 | 偏斜杂散 FFT 测试框图

⓶ 增益/失调失配测试

低频正弦输入 (偏斜影响最小) → 分析 fs/M 整数倍处的杂散 (失调失配) 和 k·fs/M ± fin 处的杂散 (增益失配)。也可 DC 输入直接测失调失配，正弦扫幅测增益失配曲线。

图 7-2 | 增益/失调失配测试框图

⓷ 通道间串扰测试

特定通道注入满幅信号，其他通道输入接地 → 测量未注入通道输出中的信号泄漏。通过交叉相关分析量化串扰幅度。版图设计阶段需通过 EM 仿真预评估。

设备：多通道 AWG + 高速采集系统 + 交叉相关分析软件。

判定：串扰 < −70 dB (10+ bit TI-ADC)；串扰过高 → SFDR 恶化，需版图优化。

注意事项

⏰ 时序偏斜

TI-ADC 头号杀手。飞秒级偏斜在 >10 GSPS 下即可产生 >−40 dBc 杂散。版图对称布局、等长时钟走线、DTC 模拟校准 + 数字分数延迟滤波器是完整解决方案。

📡 通道间串扰

M 个通道集成在同一芯片上，大信号跳变通过衬底、电源和输入网络耦合到其他通道。版图隔离 (深 N-well, Guard Ring, 分布式去耦) 必不可少。

⚡ 输入缓冲驱动能力

TI-ADC 输入端等效电容 = M × Cs，大 M 下输入阻抗极低。需要片上宽带缓冲器或分布式输入网络。驱动不足 → 带宽下降 → 高频 SNDR 滚降。

🔌 电源分配网络 (PDN)

M 个通道以 M 相时钟交错工作 → 电源电流在 fs/M 和 fs 处有显著纹波 → 通过 PDN 阻抗产生电压波动。需要充分的片上/片外去耦和 PDN 设计。

💥 时钟抖动累积

TI-ADC 对时钟相位噪声的要求等同于相同 fs 的单通道 ADC → 在 >10 GSPS 下，时钟抖动需 <50 fs RMS 才能实现 >50 dB SNR。这是整个系统 (晶振+PLL+分配) 的综合挑战。

📦 数字输出带宽

TI-ADC 总输出数据率 = fs × N bit/s，在 64 GSPS × 12 bit = 768 Gbps。通常需要 SerDes (JESD204C/JESD204D) 接口传输，通道数可达 16~32 lane。

TOP 5 常见错误：
1. 忽略时序偏斜校准 → SFDR 仅 30~40 dBc
2. 输入网络设计不足 → 高频输入严重衰减
3. 时钟偏斜末校准 → 看似随机的高杂散
4. PDN 设计不充分 → 通道间通过电源耦合
5. 数字输出接口带宽不足 → 无法传输完整数据速率

选型指南

选用 Time-Interleaved

  • 需要 >1 GSPS 采样率
  • 8~14 bit 分辨率已足够
  • 接受多通道面积/功耗代价
  • 系统具备校准能力或选择内置校准的 TI-ADC
  • 超宽带应用 (瞬时带宽 >500 MHz)
  • 光通信/雷达/仪器仪表等高价值应用

不适合 Time-Interleaved

  • <500 MSPS + >12b → 单通道 Pipeline
  • <10 MSPS + >14b → SAR
  • 极低功耗/面积限制 → SAR 或 Pipeline
  • 对校准复杂度/成本敏感 → 单通道方案
  • 需要即时启动 (无校准时间) → 单通道方案
