背景与应用定位

SAR ADC (Successive Approximation Register ADC) 是应用最广泛的奈奎斯特速率 ADC 架构，通过二分搜索算法将模拟电压逐次逼近转换为数字码。它在功耗、面积、精度和速度之间取得了极优的平衡，是 IoT 传感器、工业控制、医疗电子、电池管理、触摸屏等中低速高精度场景的首选方案。

📌 产品定位

产业链位置：传感器/模拟前端与数字处理器之间，承担模拟量到数字量的转换

核心价值：以极低功耗（fJ/conv-step）实现中高精度转换，无静态偏置电流

本质功能：N-bit 逐次逼近量化：电容阵列采样 + 比较器判决 + SAR 逻辑控制

🎯 典型应用场景

  • 工业传感器数据采集 (温度/压力/流量)
  • 电池管理系统 (BMS AFE) 电压监测
  • 便携医疗设备 (ECG/EEG/血糖仪)
  • 触摸屏控制器 (Touch Screen Controller)
  • IoT 无线传感器节点 (低占空比采样)
  • 电机控制电流检测

核心工作原理

SAR ADC 的核心是二分搜索算法（Binary Search）：从 MSB 到 LSB 逐位确定数字码。每次转换包括采样阶段（Acquisition）和转换阶段（Conversion），期间 DAC 输出逐次逼近输入信号。

📐 逐次逼近算法 (4-bit 示例, VIN=0.65V, VREF=1V)

周期试探位DAC 输出比较结果判决当前码
1 (MSB)1000 (0.5V)VDAC=0.5VVIN>VDAC保留 MSB=11000
21100 (0.75V)VDAC=0.75VVIN<VDAC清零 2nd=01000
31010 (0.625V)VDAC=0.625VVIN>VDAC保留 3rd=11010
4 (LSB)1011 (0.6875V)VDAC=0.6875VVIN<VDAC清零 LSB=01010
最终码: 10102 = 1010    V量化值 = 10 × VREF / 16 = 0.625V    量化误差: +0.025V (0.25 LSB)

⚡ 转换时序

Ttotal = Tacq + N × Tbit + Toverhead

其中 Tacq 是采样/捕获时间（由 CDAC 总容值和开关 Ron 决定 RC 时间常数；需 ≥ 8~10·τ 以达所需精度），Tbit 是每位判决时间（包括 DAC 建立 + 比较器再生 + SAR 逻辑延迟）。

🧱 CDAC 操作原理 (电荷守恒)

电容 DAC 是 SAR ADC 的核心：采样阶段，所有电容下极板接 VIN，上极板接共模电压 VCM；转换阶段，从 MSB 电容开始逐次切换下极板到 VREF 或 GND，比较器监测上极板电压变化——电荷守恒自动完成减法运算。

对 N-bit CDAC：总电容 Ctotal = 2N·Cunit。MSB 电容 = 2N−1·Cunit = Ctotal/2。每位切换后，上极板电压变化量 ΔV = VREF·(被切换电容 / Ctotal)。

💡 AE 核心认知：SAR ADC 的精度由 CDAC 匹配精度直接决定。不校准条件下，单位电容标准差 σ(C) 决定 INL/DNL 上限；数字校准技术可将分辨率推至 16~18 bit。SAR ADC 是"最少模拟电路 + 最多数字逻辑"理念的典范——仅需一个比较器、一个 CDAC 和数字控制逻辑即可实现完整 ADC 功能。

核心模块深度解析

一、电容 DAC (CDAC) — 精度的物理载体

CDAC 是 SAR ADC 的核心精度决定模块。由 N 个二进制权重电容组成，版图使用共质心 (Common-Centroid) 布局以减小梯度误差。

Ck = 2k-1 · Cunit   |   k = 1 (LSB) … N (MSB)
参数公式/关系工程权衡
单位电容 Cunit由 kT/C 噪声和匹配决定C↑ → 噪声↓ 匹配↑ / 面积↑ 速度↓
kT/C 噪声vn,rms = √(kT/Ctotal)需 < LSB/√12 以保证 SNR
电容匹配 σσ(ΔC/C) ∝ 1/√area分段结构 (Split CDAC) 可减小总电容比
建立时间τ = Ron·Ctotal每位建立需 ≥ τ·ln(2N+1) ≈ τ·(N+1)·ln2

二、动态锁存比较器 — 速度与噪声的博弈

现代 SAR ADC 几乎全部使用动态锁存比较器 (StrongARM Latch)，无静态功耗。核心是时钟沿触发再生正反馈：

Vo(t) = Vi · et/τreg   |   τreg = CL/gm
关键参数典型值设计要点
输入参考噪声50~200 μVrms与 gm 和再生时间常数相关；噪声 < ½ LSB
失调电压5~20 mV (未校准)输入管 Vth 失配主因；校准或冗余可容忍
再生时间常数10~30 ps (先进工艺)∝ (CL/gm)，先进工艺下 gm/ID 更高
亚稳态概率~10−6 ~ 10−9输入接近判决阈值时产生，需冗余时间
回踢噪声mV 级再生瞬间通过寄生电容耦合到 CDAC

三、SAR 控制逻辑 — 同步 vs 异步

同步 SAR：每位固定周期，外部高速时钟驱动。简单但时钟频率需涵盖最坏情况 DAC 建立。异步 SAR：每位转换完成后自动触发下一位，不需要外部高频时钟，速度可提升 2~4×。

同步 SAR

✅ 时序简单，设计易验证
✅ 对 PVT 变化不敏感
❌ 需要 fclk > (N+α)/Tconv
❌ 每位等待最坏建立
❌ 高时钟频率 → 高功耗

异步 SAR

✅ 自适应建立时间
✅ 不需要高频时钟，降低功耗
✅ 速度提升显著
❌ 需要 Ready 检测电路
❌ PVT 变化需留余量
❌ 时序验证复杂

四、自举采样开关 (Bootstrapped Switch)

栅源电压 VGS 恒定的开关技术，使导通电阻 Ron 不随输入信号变化，是实现高线性度采样的关键：

Ron = 1 / [μnCox(W/L)(VGS − Vth)]   |   当 VGS=VDD 恒定 → Ron 仅取决于 Vth

测试方法

⓵ INL/DNL — 正弦码密度直方图法

施加低失真正弦波 (THD 比 DUT 高 2~3 bit，幅度覆盖 −0.5 dBFS) → 采集 >1M 点 → 统计各输出码出现频次 → 与理想正弦码密度函数对比 → 计算 DNL/INL。

图 7-1 | INL/DNL 码密度测试框图

⓶ 动态性能 — FFT 频谱法 (SNR/SNDR/SFDR)

施加低相噪正弦波 → 相干采样 (fin/fs = M/Nrecord, M 与 Nrecord 互质) → 采集 Nrecord 点 (≥65536) → 加窗 FFT (7-Term Blackman-Harris) → 计算 SNR/SNDR/SFDR/THD。

图 7-2 | 动态性能 FFT 测试框图

⓷ 功耗与 FoM 测试

使用精密源表测量各电源轨 (AVDD/DVDD/VIO) 的电流 → Ptotal = Σ Vi×Ii。分别测量静态功耗 (fs=0) 和动态功耗 (目标 fs) → 计算 Walden FoM = P/(2ENOB×fs) 和 Schreier FoM = SNDR + 10log10(BW/P)。

设备：Keysight B2902A SMU / N6705C 直流电源分析仪 + 低噪声电源。

判定：Walden FoM < 100 fJ/conv-step (12b SAR 典型值 10~50 fJ/step)，Schreier FoM > 170 dB。

注意事项

输入驱动

CDAC开关电容负载->缓冲器GBW需>N*ln2*fs/beta。驱动不足->建立误差。

VREF噪声

VREF噪声直接耦合->10uF+0.1uF去耦。缓冲器噪声<1/2 LSB/sqrt(BW)。

kT/C下限

物理下限->Ctotal>12kT/Vref2*22N。大C->噪声小速度慢。

回踢噪声

CMP再生->寄生耦合到CDAC->需中和电容或预放隔离。

数字耦合

SAR逻辑开关->衬底/电源耦合->AVDD/DVDD分离+Guard Ring。

亚稳态

VIN约等于VDAC时CMP亚稳态->冗余SAR+纠错可容忍。

TOP 5 错误：
1.输入阻抗过大->建立不足
2.VREF去耦不足->SNDR恶化
3.fs过高->CDAC未建立->ENOB降
4.数字走线平行模拟->SFDR降
5.忽略共模范围->失码

选型指南

选用 SAR

  • BW DC~5 MHz
  • 10~16 bit
  • 严格功耗限制
  • 多通道轮询(MUX)
  • 零静态功耗
  • 延迟不敏感
  • 成本/面积敏感

不适合 SAR

  • >10MHz+>12b -> Pipeline
  • >18b -> Sigma-Delta
  • >100MSPS -> Pipeline/TI
  • <1 cycle延迟 -> Flash
  • 强抗混叠 -> Sigma-Delta
