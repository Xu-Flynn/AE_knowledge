背景与应用定位

ADC（模数转换器）是连接模拟世界与数字系统的桥梁。按架构分，市面上最主流的中高精度 ADC 主要分为两大家族：SAR ADC 与 Σ-Δ ADC，二者设计哲学截然不同。

SAR Successive Approximation Register ADC

中文名：逐次逼近寄存器型 ADC

诞生背景：1970s 随 CMOS 工艺成熟而普及，利用二分搜索算法将 N 次比较等效为 N-bit 分辨率，实现中等速度与高精度的平衡。

典型应用：

  • 数据采集系统（DAQ）
  • 电池管理系统（BMS / AFE）
  • 工业传感器信号链
  • 便携仪器（万用表、示波器前端）
  • MCU 内置 ADC（8–12bit）

代表精度范围：8 ~ 20-bit，采样率 1 kSPS ~ 10 MSPS

Σ-Δ Sigma-Delta ADC

中文名：Σ-Δ（西格玛-德尔塔）ADC，也写作 ΔΣ

诞生背景：1960s 理论提出，1980s 随 DSP 普及而实用化，通过过采样（Oversampling）+噪声整形（Noise Shaping）+数字抽取滤波（Decimation Filtering）将低分辨率量化器转化为高精度输出。

典型应用：

  • 音频编解码（Hi-Fi、麦克风阵列）
  • 精密仪器（应变计、热电偶测量）
  • 智能电表（电能质量检测）
  • 医疗设备（ECG、EEG 采集）
  • 工业过程控制（慢变量高精度）

代表精度范围：16 ~ 32-bit，采样率 1 SPS ~ 几 MSPS（音频级）

核心工作原理

SAR 二分搜索算法

本质：用硬件实现"猜数字"二分法。

转换流程（N-bit 需 N 个时钟周期）：

  1. 采样保持（S&H）：在采样阶段将模拟输入 VIN 锁存到采样电容
  2. MSB 试探：将 DAC 输出置为 VREF/2，比较器判断 VIN 与 DAC 输出大小
  3. 逐位收敛：若 VIN > DAC，该位为 1，否则为 0，DAC 调整后继续比较下一位
  4. 输出数字码：N 次比较后寄存器中的 N-bit 二进制码即为结果
D[N-1:0] = round(VIN / VREF × 2N)

关键约束：转换过程中 VIN 必须保持稳定 → 需要 S&H 电路

Σ-Δ 过采样 + 噪声整形

本质：用时间换精度，把量化噪声推向高频后滤除。

三步工作机制：

  1. 过采样：以 OSR（过采样率）× fN 的高频率对信号采样，把量化噪声分散到更宽带宽，信号带内噪声降低 3dB/octave
  2. 噪声整形：调制器内的积分器+比较器环路将量化噪声整形到高频（一阶：20 dB/decade；高阶：更陡），信号带内噪声大幅降低
  3. 数字抽取滤波：低通滤波器滤除高频噪声，再以奈奎斯特率降采样，获得高分辨率输出
SNR理论 = 6.02×N + 1.76 + 10×log(OSR) × (2L+1) dB

N=量化位数，L=调制器阶数，OSR=过采样率

💡 关键视角差异：SAR 是精确量化（每次用高分辨率 DAC 比较），Σ-Δ 是统计均值（用低分辨率量化器高速采样，靠滤波求均值）。前者适合捕捉瞬态/多通道，后者适合低速高精度稳态测量。

Σ-Δ 核心原理深度图解

用"一把尺子量书本"的直觉类比理解 Σ-Δ 的三层机制：过采样（OSR）、噪声整形（阶数 L）、1-bit 量化如何"魔法般"实现 20+ bit 精度。

一、书本叠放类比 —— 建立直觉

你提到的类比非常精准，以下是精确版及其电路对应关系：

类比：用一把固定长度（如 30cm）的尺子测量一本书的厚度（约 2cm）。
→ 把100 本书叠在一起，叠高约 200cm
→ 用尺子量出约 6.67 把尺子的叠高
→ 每本书厚度 = (6.67 × 30) / 100 = 2.0cm，精度随书数增加而提高

二、1-bit 量化器 + 1-bit DAC 的逐拍工作机制

很多人困惑："只有 0 和 1，怎么可能表示任意模拟电压？"答案就在密度调制。

以下以 Vin = 0.3 × Vref 为例，展示一阶调制器的前 5 个时钟周期：

图 🔬-2 | 1-bit Σ-Δ 调制器逐拍时序（Vin = 0.3 Vref）
🧠 关键理解： "1-bit DAC 不追求单次精度，它只提供两个可靠电平（+Vref / -Vref）。 负反馈环路保证长时间平均输出 1 的比例等于 Vin/Vref。 这就是为什么 1-bit DAC 天然线性——它只切换两个电平，不存在多 bit DAC 的 INL/DNL 失配问题。"

三、OSR —— 为精度"分摊噪声"

1-bit 量化器的总噪声能量 ≈ 固定值（由量化步长 q²/12 决定）。OSR 增大不会减少总噪声，而是把噪声稀释到更宽的频带：

图 🔬-3 | OSR 对带内噪声的影响示意
SNR 提升 = 10 × log10(OSR) dB
即：OSR 每翻 4 倍 → SNR +6dB → 等效多 1-bit 精度（纯过采样，无噪声整形）
📚 类比解读：书叠得越多 → 每本书分摊的测量误差越小 → 精度越高。 OSR 的本质就是"在同一输入下多采 N 个样点，求平均值压制随机噪声"。

四、阶数 L —— 噪声整形的"推力"

如果只靠 OSR 增加精度太慢（×4 才 +1 bit），积分器的引入带来了噪声整形。 每个积分器相当于给量化噪声加了一个 高通滤波器，把低频噪声"推"到高频，阶数越高推力越大。

图 🔬-4 | 噪声整形频谱 — 1/2/3 阶对比
SNRtotal = 6.02N + 1.76 + 10 × log10[ (2L+1) × OSR(2L+1) / π2L ] dB
N = 量化器位数（通常 1~5 bit），L = 调制器阶数，OSR = 过采样率
📚 类比解读：阶数是"修正误差的智慧"——每多一个积分器，就等于在每次叠书时回顾历史误差并主动修正，让估算更准。
直观效应：L=1时 OSR 翻2倍 → +1.5 bit；L=2时 OSR 翻2倍 → +2.5 bit；L=3时 OSR 翻2倍 → +3.5 bit。

六、一张脑图总结

📚 OSR（过采样率）

物理含义：同一时间窗口内采多少个 1-bit 样点

书本类比：叠书的数量

噪声效果：把固定总噪声稀释到更宽频带

精度增益：OSR×4 → SNR+6dB → +1bit（纯过采样）

🧠 L（调制器阶数）

物理含义：几个积分器串联

书本类比：每次叠书时的误差修正智慧层数

噪声效果：把低频噪声"推"到高频，每增1阶推力+20dB/dec

精度增益：L+1 → SNR+约15dB @OSR=64 → +2.5bit

💡 选型直觉："快用 SAR，精用 Σ-Δ" 的本质 —— SAR 靠硬件二分搜索在 N 个时钟周期内给出 N-bit 结果；Σ-Δ 靠"大量低精度测量 + 数学" 在 OSR×N 个周期后给出远超 N-bit 的结果。时间是代价，精度是回报。

说明：输入信号经过求和节点（Σ，与反馈差分）→ 积分器累积误差 → 1-bit 量化器（高速比较器）→ 输出位流（Bit Stream）→ 数字低通滤波+抽取 → N-bit 高精度输出。积分器的记忆效应使量化噪声搬移到高频（噪声整形），这是 Σ-Δ 的精髓。
⚡ 高阶 Σ-Δ 调制器：工业/音频级产品通常采用 2~5 阶调制器（多个积分器级联），每增加一阶噪声整形斜率增加 20 dB/decade，SNR 提升更显著，但需要稳定性设计（高阶调制器存在不稳定风险，需加 Zero-optimization 或 CRFF/CIFB 拓扑）。

核心性能指标定义

📌 5.1 静态指标（DC Performance）

偏置误差 · Offset Error

Offset
定义实际转换曲线与理想曲线在零输入时的偏差，表示 ADC 的系统零漂。
单位LSB 或 mV（相对 VREF）
Offset = VOUT,actual(code=0) − VOUT,ideal(code=0)
SAR 特点由比较器输入失调（Comparator Offset）及 DAC 零码泄漏贡献，通常为 ±几 LSB，可通过数字校准消除。
Σ-Δ 特点积分器天然积分可部分消除偏置，通常优于 SAR；高精度版本可达到 sub-LSB 量级。

增益误差 · Gain Error

Gain Error
定义实际满量程与理想满量程的比值偏差（满量程斜率误差）。
Gain Error = (FSactual − FSideal) / FSideal × 100% 或以 %FSR / LSB 表示
来源参考电压 VREF 误差；DAC 参考缩放误差（SAR）；调制器积分增益误差（Σ-Δ）。

微分非线性 · Differential Nonlinearity

DNL
定义相邻两个输出码字对应的模拟输入宽度与 1 LSB 的偏差，描述"步距均匀性"。
DNL[k] = (Vtransition,k+1 − Vtransition,k) / 1LSB − 1
关键判据若 DNL ≤ −1 LSB → 出现"丢失码（Missing Code）"；若 DNL > +1 LSB → 出现"不单调（Non-monotonic）"。
SAR 特点直接由 DAC 电容阵列的电容匹配精度决定。工艺级 16-bit SAR DAC 单个 cap 失配 ≤ 0.1% 即可满足 ≤ ±1 LSB。
Σ-Δ 特点Σ-Δ 不直接定义 DNL（其量化器仅 1-bit，无步距概念），通常用噪声底和动态范围描述。

积分非线性 · Integral Nonlinearity

INL
定义实际转换曲线与理想直线（两端点连线或最佳直线拟合）的最大偏差，描述"整体线性度"。
INL[k] = (Vactual[k] − Videal[k]) / 1LSB
与 DNL 关系INL[k] = Σ DNL[0..k]（积分关系，故名）
SAR 影响DAC 二进制权电容的全局匹配误差，表现为 S 形或弓形 INL 曲线。
Σ-Δ 影响通过调制器非线性和反馈 DAC 线性度共同决定，高阶多 bit 量化器需关注 DAC INL。

📌 5.2 动态指标（AC Performance）

信噪比 · Signal-to-Noise Ratio

SNR
定义输出信号基波功率与所有噪声功率（不含谐波）之比，以 dB 表示。
SNR = 10·log₁₀(Psignal / Pnoise)，理论最大 = 6.02·N + 1.76 dB（满幅正弦）
SAR 关联受热噪声（kT/C，采样电容）、比较器噪声、参考噪声限制；典型 16-bit SAR 约 92~95 dB SNR。
Σ-Δ 关联通过 OSR 和调制器阶数 L 大幅提升；24-bit 高精度 Σ-Δ 可达 110~130 dB SNR。

总谐波失真 · Total Harmonic Distortion

THD
定义输出所有谐波分量功率之和与基波功率之比（通常取前 5 次谐波），以 dBc 表示，越负越好。
THD = 20·log₁₀(√(V₂²+V₃²+...+Vₙ²) / V₁) dBc
SAR 来源DAC 电容非线性（电压系数）、比较器非线性、采样电路非线性（Ron 调制）。
Σ-Δ 来源调制器积分器非线性、反馈 DAC 非线性（多 bit 结构），时钟 jitter 引起的调制。

信噪失真比 · Signal-to-Noise and Distortion Ratio

SINAD / SNDR
定义信号功率与所有噪声+谐波功率之比，是 SNR 和 THD 的综合指标。
SINAD = 10·log₁₀(Psignal / (Pnoise+Pdistortion)) dB
关系1/SINAD ≈ 1/SNR + 1/THD（功率叠加）；SINAD 是决定 ENOB 的直接指标。

有效位数 · Effective Number of Bits

ENOB
定义用 SINAD 折算出的等效分辨率，综合评估真实精度（噪声+失真共同作用后的实际分辨率）。
ENOB = (SINAD − 1.76) / 6.02 (bit)
工程意义标称 16-bit ADC 的 ENOB 可能仅 13.5-bit（受噪声+THD 降额），ENOB 越接近名义分辨率，ADC 越"干净"。
SAR 典型16-bit SAR 的 ENOB 通常 13~15.5 bit；Σ-Δ 24-bit 的 ENOB 通常 18~22 bit。

无杂散动态范围 · Spurious-Free Dynamic Range

SFDR
定义基波功率与最大杂散（谐波或互调分量）功率之比，以 dBc 或 dBFS 表示，衡量频谱纯度。
SFDR = Psignal − Pmax_spur (dBc)
关键场景通信 / 频谱分析应用中，SFDR 决定能否"看到"小信号旁边的杂散，直接影响动态范围需求。
SAR 典型100~110 dBc（中速，依赖 DAC 单调性）
Σ-Δ 典型100~120 dBc（低速高精度版）

📌 5.3 Σ-Δ 特有指标

过采样率 · Oversampling Ratio

OSR
OSR = fs / (2 × BWsignal)，其中 fs 为调制器采样频率
工程意义OSR 每翻倍，一阶调制器 SNR 提升 9 dB（1.5 bit ENOB 增益）；L 阶调制器 SNR 提升 (2L+1)×3 dB。
典型值音频：OSR = 64~256；工业精密测量：OSR = 512~4096

抽取滤波器建立时间 · Settling Time / Filter Latency

tsettle
定义从通道切换/复位到输出数据有效所需的时间，由抽取滤波器阶数和 OSR 决定。
tsettle ≈ (Filter_Order × OSR) / fs 个输出样本周期
影响在多通道快速扫描时，每次切换通道后必须等待 tsettle 再读取有效数据，否则读出的仍是前一通道的残留。

📌 5.4 SAR 特有指标

转换时间 · Conversion Time

tconv
tconv = (N + tSH + textra) / fCLK
说明N = 分辨率位数；tSH = 采样保持时间；textra = 读取/复位时钟。转换时间直接决定吞吐率（Throughput Rate）。

采样电容 · Sampling Capacitor

CS
定义用于采样保持的电容阵列（CDAC）的总值，决定热噪声底（kT/C 噪声）和驱动要求。
Vnoise,kT/C = √(kT/CS) [Vrms]
影响CS 越大 → 热噪声越小 → SNR 越高，但驱动放大器需要在采样时间内充电到 0.5 LSB 精度，对驱动 amp 带宽/压摆率要求更高。

✅ 关键共同影响因素（SAR & Σ-Δ 均适用）：
  • 参考电压（VREF）质量：噪声、纹波直接加到量化结果上，是精度天花板；VREF 温漂引起增益随温度飘移
  • 时钟质量（Jitter）：对高速 SAR 和高 OSR Σ-Δ 均影响 SNR，公式：SNRjitter = −20·log(2π·fin·σjitter)
  • 电源去耦：AVDD/DVDD 分离、就近去耦电容；数字开关噪声通过基底耦合到模拟电路
  • PCB 布局：模拟地/数字地分离，输入信号走线屏蔽，减少寄生电容/电阻
  • 温度：所有半导体参数随温度变化，全温度范围测试是 ATE 工程的关键

测试方法详解

📐 7.1 静态指标测试（Offset / Gain / INL / DNL）

方法一：码密度直方图法（Histogram）

适用于低成本批量测试，不需要高精度 DAC 激励源。

1
施加线性斜坡或正弦激励

输入覆盖整个量程，速率保证每个 code 有足够样本（每码至少 100~200 hits）。

2
统计各码出现频次

理想 ADC 各码等概率出现（斜坡）或满足正弦分布；实际分布偏差 → 线性度误差。

3
计算 DNL / INL

DNL[k] = (count[k] / expected_count) − 1；INL 为 DNL 的累加。

方法二：逐码测试法（Step-by-Step）

需高精度 DAC 激励，精度高，适合实验室级验证。

1
逐步扫描输入电压

用 16-bit 以上精度的 DAC（如 Keithley 2450）扫描从 0 到 VREF，步进 < 0.1 LSB。

2
记录每个码跳变点电压

找出每个 code 从 k-1 跳到 k 的精确阈值电压 Vtransition,k。

3
计算 DNL / INL / Offset / Gain

DNL[k] = (Vt,k+1−Vt,k) / LSB_ideal − 1；Offset = Vt,0；Gain = (Vt,FS−Vt,0)/(FS_ideal)。

🔊 7.2 动态指标测试（SNR / THD / SINAD / ENOB / SFDR）

核心方法：FFT 频谱分析（时域采样 → 频域分析） — 所有动态指标均从一段采样数据的 FFT 频谱计算得出。
1
选择测试频率与采样点数

相干采样条件（Coherent Sampling）：f_in/f_s = M/N（M, N 互质），避免频谱泄漏（Spectral Leakage）。若无法相干采样，必须加窗函数（Hann、Blackman-Harris）。

2
施加高纯度正弦激励（低失真源）

激励源的 THD 至少比被测 ADC 好 10~20 dB；一般用 SR785 / AP SYS-2722 等高精度音频分析仪或外部 DDS + 带通滤波器（消除 DDS 谐波）。

3
采集数据，执行 FFT

采样点数 N ≥ 4096（至少 1024 以上），保证频率分辨率。对 Σ-Δ，需等待抽取滤波器建立后才开始采集有效数据。

4
频谱分析计算各指标

SNR：基波功率 / 除去谐波后的噪声功率（DC 和基波 bin 排除，不含谐波）
THD：H2~H5（或更多次）谐波功率之和 / 基波功率
SINAD：基波功率 / (噪声+谐波)总功率
SFDR：基波功率 / 最大杂散 bin 功率
ENOB：(SINAD−1.76)/6.02

5
扫描频率点，绘制性能曲线

ENOB vs fin；SNR vs 输入幅度（-1 dBFS，-3 dBFS，-6 dBFS）；确认在整个 Nyquist 带宽内的性能。

🔴 7.3 Σ-Δ 特有测试项目

测试项目 测试方法 判定标准
建立时间 / Latency 通道切换后，施加阶跃输入，记录输出达到 ±0.5 LSB 稳定所需的输出样本数 通常 = 抽取率 × 滤波器阶数（Sinc³ = 3×OSR 个 modulator cycles）
调制器稳定性 施加满幅输入（≥ 99% FS），观察连续输出，看是否出现长串全 0 或全 1（调制器锁死） 无连续超过 4 个同极性位，输出码字无异常跳变
噪声谱密度（NSD） 输入接地（或精密 DC），采集长序列数据，FFT → 按频率计算各 bin 噪声功率/Hz 单位：nV/√Hz 或 dBFS/Hz；越平坦代表热噪声主导（好），上翘代表 1/f 噪声
数字滤波器频响 扫描输入频率，记录输出幅度变化（pass-band 平坦度、截止频率、stopband 抑制） 参考 datasheet 的 Sinc³ 频响曲线；信号带内 ±0.1 dB 平坦度
OSR 验证 通过读取内部寄存器或测量输出数据率与调制器时钟关系确认 OSR 配置 foutput = fCLK / (OSR × 抽取比)

🔵 7.4 SAR 特有测试项目

测试项目 测试方法 判定标准
单调性（Monotonicity） 逐码扫描，检查输出码字是否严格单调递增（无反转） 无 Missing Code；DNL > −1 LSB
吞吐率（Throughput） 在最高时钟频率下，连续触发，测量实际输出数据率 等于 fCLK / (N+2) 或 datasheet 标注值
输入带宽（Input BW） 固定采样率，扫描输入正弦频率，记录幅度下降 3 dB 的频率 满量程 −3 dB 带宽，SAR 通常远大于采样率的 1/2
通道间串扰（Mux Crosstalk） 多通道 ADC：一路输入大幅信号，相邻通道接地，测量地通道输出中的串扰分量 通常规格 ≤ −70 dBFS（依精度而定）
温度漂移 在 −40 / 25 / 85°C（或按产品规格）分别测 Offset / Gain / INL，计算 TC Offset TC ≤ x ppm/°C 或 LSB/°C（参 datasheet）

⚠️

测试与使用注意事项

⚡ 通用注意事项（SAR & Σ-Δ）

⚡ 参考电压质量

VREF 的噪声 / 纹波直接叠加到 ADC 量化结果，必须使用低噪声 LDO 或专用基准（如 LT6657），并用 LC / RC 滤波去耦。测试时 VREF 需精确测量并输入校准程序。

🕐 时钟 Jitter

高速（SAR）或高 OSR（Σ-Δ）应用中，时钟相位噪声直接恶化 SNR：SNRjitter = −20·log(2π·fin·σt)。使用低 jitter 晶振或专用时钟芯片（如 Si5351）；测试夹具时钟布线最短，避免容性负载。

🔌 电源隔离与去耦

AVDD 与 DVDD 必须分开供电，就近放置 100 nF + 10 μF 去耦电容；数字 I/O 开关产生的高频噪声会通过衬底/电源耦合到模拟前端，需在 PCB 布局层面隔离。

📐 PCB 布局规范

模拟地平面与数字地平面单点连接（Star Ground 或在 ADC 下方连接）；输入信号走线远离时钟线；避免跨越地分割；保护环（Guard Ring）包围敏感模拟引脚。

📏 驱动放大器选择

SAR ADC 的 CDAC 在采样瞬间产生充电电流尖峰，驱动 amp 必须在采样时间内稳定到 0.5 LSB 精度（需要足够 GBW 和低 Zout）；建议使用专为 ADC 驱动设计的放大器（如 ADA4807、OPA189）。

🌡️ 温度测试充分性

ADC 的 Offset/Gain/INL 均有温度系数；仅室温测试不足以表征产品全温性能。ATE 测试应覆盖 −40 / 25 / 85°C 三温度点，关注温漂导致的系统精度降级。

🔵 SAR ADC 专项注意事项

⏱ 采样时间充足

外部 RC 滤波器与 ADC 内部 CDAC 共同决定充电时间常数：tsettle ≥ (N+2)·ln(2)·R·CS。采样时间不足导致 S&H 建立不充分 → DNL 恶化 → ENOB 下降。

🔄 通道切换等待

多路复用（MUX）切换后，需等待输入网络重新建立稳定，否则前通道信号"记忆"仍残留，引起通道间串扰（Memory Effect）。等待时间 = 至少 10τ（τ=Rsource×CS）。

📊 INL/DNL 测试样本量

直方图法中，每个码需 ≥100 hits，总样本 = 2N×100。16-bit ADC 需约 655 万次采样；测试时间需估算，选择合适斜坡频率在时间约束内完成。

🚫 输入过压保护

大多数 SAR ADC 的模拟输入不能超过 AVDD + 0.3V 或 GND − 0.3V，ESD 前仍需限流电阻（100 Ω ~ 1 kΩ）；测试夹具必须确保激励源输出不超出 ADC 输入范围。

🔴 Σ-Δ ADC 专项注意事项

⏳ 建立时间必须等待

上电、复位、配置变更（OSR/增益/通道）后，抽取滤波器需要充填（Fill）才输出有效数据。读取前必须丢弃前 N 个输出样本（N = 滤波器阶数 × OSR）；未等待直接读取是 Σ-Δ 系统中最常见的错误！

📈 不可过量程

调制器输入若持续超过满量程（通常 ±VREF），积分器饱和 → 调制器进入不稳定状态 → 位流锁死 → 输出全错。需在 ADC 前端加钳位电路，或在软件中监测 SATURATION 状态位并触发复位。

🔍 多通道测量串扰

Σ-Δ 不适合高速多通道扫描（每次切换需等待建立），若需多路，优选内置多路复用器并在 datasheet 规定的扫描速率下操作；注意相邻通道的低频漏电（内部积分器残留）。

🔇 数字滤波器陷波

Sinc³ 抽取滤波器在 foutput、2×foutput... 处有陷波（零点），可用于消除工频干扰（50/60 Hz）：将输出数据率设为 50 Hz 整数分之一（如数据率 = 50 SPS → 50 Hz 抑制 ≥80 dB）。利用这一特性时需精确调整 OSR。

🚨 FFT 测试最常见错误：
  • 未做相干采样：频谱泄漏导致 SNR/SFDR 虚低；解决：用 Hann 窗，或精确设置 fin/fs = M/N（互质）
  • 激励源自身失真太大：测出的 THD 是激励源而非 ADC 的；解决：激励 THD 比被测 ADC 好 ≥15 dB，或加高品质带通滤波器
  • Σ-Δ 未等待 Settling：包含调制器瞬态数据，SINAD/SNR 虚低
  • FFT 点数不足：频率分辨率不足，谐波 bin 之间相互混叠；建议 ≥4096 点
  • 输入幅度设置错误：SNR 测试应在 −0.5 dBFS ~ −1 dBFS 附近，过小 → 量化噪声主导，过大 → 削波失真

选型决策指南

选 SAR 的场景

  • 需要高速多通道快速扫描（BMS、DAQ）
  • 需要低延迟响应（实时控制环）
  • 采样率 > 200 kSPS，分辨率 ≤ 18-bit
  • 无法忍受 Σ-Δ 的长建立时间
  • 需要精确知道每个采样时刻（同步采样）
  • 功耗预算适中，信号带宽较宽
典型应用：BMS 电压电流采集（ADS131E04）、工业 DAQ（AD7616）、MCU 内置 ADC（STM32 12-bit SAR）

选 Σ-Δ 的场景

  • 需要超高精度（20-bit 以上），信号变化慢
  • 信号带宽窄（DC ~ 数 kHz），如应变计、热电偶
  • 需要极低噪声底（精密称重、医疗 ECG）
  • 对抗混叠要求高，不想外加大量滤波器
  • 音频应用（Hi-Fi ADC/DAC）
  • 电能质量、智能电表高精度电流电压测量
典型应用：高精度仪表（ADS1256 24-bit）、音频编解码（PCM4202）、智能电表（CS5460A）
💡 工程权衡口诀： "快用 SAR，精用 Σ-Δ；SAR 看 INL/ENOB，Σ-Δ 看 OSR/Settling；共同看 VREF、时钟、驱动和布局。"
