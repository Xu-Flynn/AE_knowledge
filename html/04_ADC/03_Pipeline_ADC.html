背景与应用定位

Pipeline ADC 是中高速、中高精度领域的主流 ADC 架构，通过多级流水线结构将逐次逼近的串行过程分解为多级并行处理：每一级完成低分辨率量化后，将残差放大并传递到下一级继续量化。在 10 MSPS~1 GSPS 速率范围内，Pipeline ADC 在速度、精度和功耗之间取得了最优平衡，广泛用于无线通信、视频处理、医疗成像和仪器仪表等领域。

📌 产品定位

产业链位置：RF/IF 前端与数字基带处理器之间，负责高速高精度模数转换

核心价值：多级流水线并行处理，在 MSPS~GSPS 速率下实现 10~16 bit 分辨率

本质功能：N 级流水线级联：每级 Sub-ADC (粗量化) + Sub-DAC (重构) + 残差放大 (MDAC) + 数字校正

🎯 典型应用场景

  • 无线通信基站 (IF 采样接收机)
  • 宽带软件无线电 (SDR) 接收机
  • 医疗超声/CT 成像前端
  • 高速数据采集卡 (DAQ)
  • 雷达数字波束成形接收机
  • 视频/图像传感器接口

多级流水线转换原理

Pipeline ADC 的核心是将N-bit 转换分解为多级低分辨率转换流水线。每一级包含 Sub-ADC (粗量化)、Sub-DAC (重构)、减法器和残差放大器 (MDAC)。级间并行工作，每周期完成一个新采样，延迟由流水线深度决定。

图 2-1 | Pipeline ADC 多级流水线信号流向

1. 单级流水线操作 (1.5-bit 为例)

Vresidue = G × (Vin − VDAC)   |   G = 2k−1 (1.5b 时 G=2)
步骤操作说明
1. 采样S/H 采样 Vin前端 T/H 或 MDAC 自采样
2. 粗量化Sub-ADC (2 个比较器, 3 区间)判决 Vin 落在 3 个区间: <-VREF/4, 中间, >+VREF/4
3. DAC 重构Sub-DAC 输出对应电平−VREF/2, 0, +VREF/2
4. 残差放大MDAC 放大 (Vin−VDAC) ×2残差放大到满幅供下一级量化

2. 1.5-bit/级 冗余与数字校正

每级使用 1.5-bit (2 个比较器 + 3 区间判决) 而非 2-bit，留出 ±VREF/4 的冗余区间。比较器失调在冗余范围内被容忍，相邻级输出经移位相加即可完成数字校正——这是 Pipeline ADC 能够容忍较大比较器失调的根本原因。

最终码 = D1 × 2N−1 + D2 × 2N−2 + ... + DM × 2N−M

3. MDAC — 精度核心

开关电容 MDAC (Multiplying DAC) 同时完成：采样输入、减去 DAC 电平、乘以级间增益。在Φ1 (采样相) 采样输入到电容；在Φ2 (放大相) 切换电容下极板到 DAC 参考电平，运放闭环放大。增益精度取决于电容比例和运放开环增益。

Geffective = Gideal × (1 − 1/(AOLβ))   |   β = 反馈系数

4. 流水线时序与吞吐率

每级需要两相非交叠时钟 (Φ1 采样 + Φ2 放大)，相邻级时钟相位交错。采样数据在每个时钟沿依次通过各级，首级处理第 n 个采样时，第二级处理第 n-1 个采样... 形成流水线。延迟 = M×Tclk (M 级)，但每个时钟周期输出一个转换结果。

吞吐率 = fs = 1/Tclk   |   延迟 = M × Tclk (M = 流水线级数)
💡 AE 核心认知：Pipeline ADC 的精妙之处在于以 1.5-bit/级 + 数字校正的架构，将比较器精度要求从 N-bit 降低到 ±VREF/4 (仅需 2-bit 级精度)。真正的精度瓶颈是 MDAC 的级间增益误差和运放建立精度。

核心模块深度解析

一、MDAC (Multiplying DAC) — 精度的物理载体

MDAC 是 Pipeline ADC 最关键的模拟模块，集成 DAC 减法、残差增益放大和采样保持功能于一体：

Vout = (Cs/Cf) × Vin − Σ(Ci/Cf) × VDAC,i
参数公式/关系工程权衡
理想增益G = Cs/Cf = 2k−1Cs 总面积由 kT/C 噪声决定
增益误差εG ≈ 1/(AOLβ) + ΔC/C运放增益 + 电容匹配；直接影响 INL
建立时间tsettle = (N+1)ln2×τ/β高 β (低增益) → 更快建立
kT/C 噪声vn2 = kT/(βCtotal)C 增大 → 噪声降 → 速度和功耗代价

二、运放设计 — 速度与功耗的博弈

Pipeline ADC 中的运放必须在半个时钟周期内完成建立，其 GBW 和摆率 (Slew Rate) 要求随采样率提高而急剧增加：

GBW > (N+1)·β·ln2 / (2π·tsettle)   |   SR > VFS/tslew
运放架构增益速度功耗适用
套筒式 (Telescopic)50~60 dB高低先进工艺，低压
折叠式 (Folded Cascode)60~70 dB中高中通用，输出摆幅大
两级运放 (Miller)80~100 dB中中高高线性度，需补偿
增益增强 (Gain-Boosted)100~120 dB中高极高精度，>14b

三、Sub-ADC 设计

每级的 Sub-ADC 是低分辨率 Flash ADC (通常 1~4 bit)。对于 1.5-bit/级的方案，仅需 2 个比较器，阈值设为 ±VREF/4。比较器失调只要不超过 ±VREF/4 即可被数字校正容忍——这是 1.5-bit 架构的核心优势。先进设计中常使用动态比较器以消除静态功耗。

1.5-bit/级 (最常用)

✅ 最大冗余容忍范围 (±VREF/4)
✅ 比较器设计最简单
✅ MDAC 增益最低 (G=2) 最易实现
❌ 级数最多 (N 级 for N-bit)
❌ 总延迟最大
❌ 总功耗较高 (多级累加)

多位/级 (2.5~3.5b/级)

✅ 级数少，延迟小
✅ 每级完成更多位，总功耗可能更低
❌ MDAC 增益高 (G=4~8) 建立困难
❌ 比较器需要更高精度
❌ 冗余容忍范围缩小
❌ 电容匹配要求更高

四、时钟分布与级间时序

高速 Pipeline ADC 中，精准的两相非交叠时钟 (Φ1, Φ2) 分布至关重要。每级需要：采样相 (Φ1) + 放大相 (Φ2)，相邻级相位交错。时钟偏斜 (skew) 直接侵蚀建立时间余量：

剩余建立时间 = Tclk/2 − tskew − tnon-overlap

在 GSPS 级 Pipeline ADC 中，半周期仅 500 ps，时钟偏斜必须 <10 ps 才能保证运放有足够的建立时间。

测试方法

⓵ 动态性能 — FFT 频谱法 (SNR/SNDR/SFDR)

施加低相噪正弦波 (fin 接近 Nyquist/2) → 相干采样 → 采集 128K~1M 点 → 加窗 FFT → 计算 SNR/SNDR/SFDR。高频 near-Nyquist 输入最能暴露运放建立不足和时钟抖动的影响。

图 7-1 | 动态性能 FFT 测试框图

⓶ INL/DNL — 码密度直方图法

施加低失真正弦波 → 采集 >1M 点 → 正弦码密度直方图分析。高速 Pipeline 输出码率极高，需保证采集卡时序分辨率充足。也可使用高精度斜坡信号源 → 逐码统计法。

图 7-2 | INL/DNL 码密度测试框图

⓷ 流水线延迟测量

施加阶跃输入信号 (快速上升沿) → 同时捕获模拟输入和 ADC 数字输出 (高速示波器 + 逻辑探头) → 测量从模拟阶跃到对应数字码出现在输出端口的时间差。

设备：AWG (Keysight 33600A) + 高速示波器 (Keysight MSO-S 系列) + 逻辑探头。

判定：延迟 = 标称值 ±1 个时钟周期 (典型 6~12 Tclk)。

注意事项

⚡ MDAC 建立时间

Pipeline ADC 中最关键的设计约束。运放必须在半周期内建立到目标精度 (如 14b = 0.006%)。运放 GBW 和摆率不足直接导致 INL 和 SNDR 恶化。第一级 MDAC 的要求最苛刻。

💥 参考电压缓冲

MDAC 中 DAC 切换从 VREF 抽取瞬态电流 → VREF 纹波。需要片上高速缓冲器 + 片外多级去耦 (10μF + 0.1μF + 10nF)。第一级 MDAC 参考缓冲器的 BW 需 > 数倍 fs。

⏰ 时钟偏斜

高速 Pipeline (>200 MSPS) 中，Φ1/Φ2 的非交叠间隔和偏斜直接侵蚀建立时间。偏斜需 <5~10 ps，需在版图中做时钟树平衡。差分时钟 (CML/LVDS) 优于单端。

🔌 前端 T/H 线性度

前端采样保持电路的非线性 (尤其是开关 Ron 调制) 直接限制整体 SFDR。自举开关 (Bootstrapped Switch) 是必备技术。高线性度 (>90 dB SFDR) 需底部板采样。

🌊 级间串扰

后级 MDAC 的大信号跳变通过衬底和电源耦合到前级 → 记忆效应 (Memory Effect)。版图隔离 (深 N-well, Guard Ring) 和信号路径线性化至关重要。

🌡 热梯度

多级运放的功耗集中产生热梯度 → 版图需对称布局，关键模块 (第一级 MDAC、Bandgap) 置于芯片等温线上，远离输出驱动等大功耗模块。

TOP 5 常见错误：
1. MDAC 运放建立不足 → 高频 SNDR 骤降
2. VREF 去耦不足 → 级间串扰 → SFDR 降
3. 时钟偏斜过大 → 建立余量不足 → 功能失效
4. 前端 T/H 非线性 → 整体 SFDR 天花板
5. 数字输出驱动与模拟域隔离不足 → 衬底耦合噪声

选型指南

选用 Pipeline

  • BW 10M~500 MHz
  • 10~14 bit 分辨率
  • 需要高吞吐率 (每周期 1 次转换)
  • 可接受流水线延迟 (6~12 周期)
  • 无线通信/视频/雷达等中高频应用

不适合 Pipeline

  • <10 MHz + >14b → SAR/Sigma-Delta
  • >500 MHz + <10b → Time-Interleaved
  • 极低功耗 (<1 mW) → SAR
  • 需要单周期延迟 → Flash
  • 成本/面积极度敏感 → SAR
