背景与应用定位

Sigma-Delta (Σ-Δ) ADC 是精度最高的 ADC 架构，通过过采样 (Oversampling) 和噪声整形 (Noise Shaping) 将量化噪声推到高频，再经数字抽取滤波器滤除，实现远超奈奎斯特速率 ADC 的分辨率。广泛应用于高保真音频、精密测量、地震监测和工业称重等低速超高精度场景。

📌 产品定位

产业链位置：传感器/模拟前端与数字处理器之间，承担超高精度模拟量到数字量的转换

核心价值：以极高过采样比 (OSR) 换取超高分辨率 (>20 bit)，动态范围可达 120~140 dB

本质功能：Σ-Δ 调制器 (噪声整形) + 数字抽取滤波器 (低通滤波+降采样)

🎯 典型应用场景

  • 高保真音频 (24-bit 192kHz DAC/ADC)
  • 精密仪器 (6.5/7.5 位万用表)
  • 地震监测 (极低频、亚μV 信号)
  • 工业称重传感器 (高精度低速)
  • 生物医学信号 (ECG/EEG/EMG)
  • 能源计量 (电表、功率监测)

噪声整形与过采样原理

Sigma-Delta ADC 的核心是过采样 + 噪声整形 + 数字滤波三大机制协同工作，将带内量化噪声压制到极低水平：

图 2-1 | Σ-Δ ADC 系统级信号流向

1. 过采样 (Oversampling)

以远高于 Nyquist 速率的频率 fs 采样，将量化噪声功率均匀分布到更宽的频带 [0, fs/2]，使信号带宽 [0, fBW] 内的噪声功率密度降低 OSR 倍。

OSR = fs / (2 × fBW)   |   SNR 提升 = 10log10(OSR) dB (无噪声整形时)

2. 噪声整形 (Noise Shaping)

通过反馈环路将低频量化噪声推到高频，使信号带内噪声进一步降低。L 阶调制器的噪声传递函数 (NTF) 为 NTF(z) = (1 − z−1)L，带内噪声衰减率为 20·L dB/dec。

SNR 提升 (L阶) = (20L+10)·log10(OSR) − 10·log10(π2L/(2L+1)) dB

3. 数字抽取滤波 (Decimation Filter)

数字低通滤波器滤除被推到高频的量化噪声，同时将采样率从 fs 降至 Nyquist 速率 (2fBW)。多级实现：

  • CIC 滤波器：无乘法器，高抽取比，但通带衰减大
  • FIR 补偿滤波器：补偿 CIC 通带衰减，提供锐截止特性
  • 半带滤波器：2x 抽取，近一半系数为零，效率极高

4. 离散时间 (DT) vs 连续时间 (CT) 调制器

维度DT (开关电容)CT (连续时间)
精度极高 (电容匹配)受 RC 时间常数变化影响

💡 AE 核心认知：OSR 每翻倍，1 阶 SD 的 SNR 提升 9 dB，2 阶提升 15 dB，3 阶提升 21 dB。但高阶调制器存在稳定性问题——输入超过某一幅度时环路可能振荡。实际设计常在阶数和稳定性之间折中，常用 2~3 阶 + 多位量化器方案。

核心模块深度解析

一、Σ-Δ 调制器 — 噪声整形的核心

Σ-Δ 调制器是 ADC 精度的决定模块，由环路滤波器 H(z)、量化器 (ADC) 和反馈 DAC 组成：

Y(z) = STF(z)·X(z) + NTF(z)·E(z)   |   STF(z)=H(z)/(1+H(z)), NTF(z)=1/(1+H(z))

信号传递函数 STF 在全频带接近 1，噪声传递函数 NTF 在低频趋近 0。

参数公式/关系工程权衡
量化噪声功率σe2 = Δ2/12Δ=VLSB，多位量化可降低噪声
dB 动态范围DR = 10log(Psig,max/Pnoise)受运放噪声、kT/C、时钟抖动综合限制
稳定性条件max|NTF| < 1.5 (经验)高阶 NTF 峰值更高，需限制输入幅度
极限环/空闲音DC 输入时出现周期性图案加抖动 (Dither) 或使用多位量化器

二、环路滤波器 — DT vs CT 实现

环路滤波器决定噪声整形特性。离散时间 (DT) 使用开关电容积分器—精度由电容比例决定，受 kT/C 噪声限制。连续时间 (CT) 使用有源 RC 或 Gm-C 积分器—带宽不受运放建立时间限制，但面临环路延时的稳定性补偿和 RC 时间常数 PVT 漂移。

DT 积分器 (开关电容)

✅ 传递函数由电容比决定，精度极高
✅ 对时钟抖动不敏感
✅ 设计成熟、仿真可靠
❌ 需要运放快速建立 → 限制 fs
❌ 需要前置抗混叠滤波器
❌ 开关噪声和电荷注入

CT 积分器 (有源 RC/Gm-C)

✅ 运放带宽需求低 (~fs 而非数倍)
✅ 固有抗混叠特性
✅ 可实现更高的 fs
❌ RC 时间常数 PVT 漂移需校准
❌ 环路延时 → NTF 恶化
❌ 对时钟抖动更敏感

三、量化器

Sigma-Delta 调制器中的量化器通常是低分辨率 (1~5 bit) ADC (Flash)，其量化噪声经 NTF 整形后大部分被滤除。多位量化器可降低量化噪声功率、改善稳定性，但要求反馈 DAC 具有匹配精度。

量化器类型优点缺点
1-bit (比较器)天然线性 DAC，无匹配问题量化噪声大、易产生空闲音
多位 (2~5 bit Flash)噪声低、稳定性好、动态范围大反馈 DAC 需 DEM 解决失配

四、反馈 DAC 与 DEM

反馈 DAC 的非线性会直接污染输入信号 (不经过 NTF 整形)，是 CT-SD 的主要误差源。数据加权平均 (DWA/DEM) 算法通过动态轮换 DAC 单元将失配误差整形到高频，是实现高线性度的关键技术。

DEM 本质：将 DAC 失配误差从 DC 搬到高频 → 经 NTF 衰减 → 整体线性度提升至 >14~16 bit

五、数字抽取滤波器链

滤波器级类型抽取比功能
第一级CIC (级联积分梳状)高至 OSR/2无乘法器高效粗抽取，衰减高频噪声
第二级FIR 补偿2~4补偿 CIC 通带衰减 (sinc 响应)
第三级半带 FIR2 (可多级级联)近一半系数为 0，高效 2x 抽取
最终级可编程 FIR最终抽取锐截止，可配置带宽和群延迟

测试方法

⓵ 动态范围/SNR — 正弦波测试法

施加低失真正弦波 (THD 比 DUT 高 >10 dB，幅度 −0.5 dBFS) → 采集 >128K 点 → FFT 分析 (7-Term Blackman-Harris 窗) → 计算 SNR/SNDR/DR。由于 SD 输出速率低，单次 FFT 记录可能需数秒。

图 7-1 | 动态范围 SNR 测试框图

⓶ INL/DNL — 低速直流扫描法

由于 SD 延迟大且输出速率低，使用高精度直流源 (Fluke 5730A) 逐点扫描或极低速斜坡输入 (<0.01 LSB/sample)，配合码密度分析。需要稳定温度环境 (23±0.5°C) 和低热 EMF 连接。

图 7-2 | INL/DNL 直流扫描测试框图

⓷ 空闲音 (Idle Tone) 测试

施加 DC 输入 (通常 0V 或 FS/2) → 采集长序列 (>1M 点) → FFT 分析 → 检查频谱中是否存在离散杂散峰 (极限环/空闲音)。这是低阶 1-bit SD 的特有问题。加 Dither 或使用多位量化器可抑制。

设备：低噪声 DC 源 (Keithley 2450 SMU) + 屏蔽环境 (Faraday Cage)。

判定：空闲音峰值 < −120 dBFS (20+ bit SD)；若存在明显杂散，需评估是否启用 Dither 或更换多位量化器方案。

注意事项

⏰ 时钟抖动

时钟抖动直接调制反馈 DAC 的脉冲宽度——在 CT-SD 中尤其敏感。>100 dB DR 要求抖动 <10 ps RMS。使用低相噪晶振 + 本地 PLL。

🔊 空闲音

低阶 (1~2) SD 在 DC 或慢变化输入时产生周期性输出图案 (极限环) → 频谱中出现离散杂散。加 Dither 或使用多位量化器可抑制。

⚡ 输入驱动

SD 调制器输入端可能是开关电容负载——驱动运放需要足够 GBW 和低输出阻抗。驱动不足导致建立误差，直接影响 INL。

📡 数字耦合噪声

大规模数字抽取滤波器产生同步开关噪声 → 通过衬底和电源耦合到调制器。分离 AVDD/DVDD，Guard Ring，衬底隔离。

📦 滤波器群延迟

数字滤波器链的总延迟 → 实时控制环路需考虑。Sinc 滤波器延迟 = (OSR−1)/(2fs)。实时控制选低延迟滤波器配置。

⚠ 调制器稳定性

高阶 (≥3) 调制器在大信号输入时可能不稳定。输入幅度需留有 −3~−6 dBFS 余量。监控调制器输出是否饱和。

TOP 5 常见错误：
1. 时钟抖动过大 → SNR 天花板
2. 参考电压噪声 → 直接限制 DR
3. 输入驱动不足 → 建立误差 → INL 恶化
4. 数字与模拟电源共用 → SFDR 显著下降
5. 忽略空闲音 → 窄带应用中出现不可接受杂散

选型指南

选用 Sigma-Delta

  • BW < 10 kHz
  • 需要 > 18 bit 分辨率
  • 需要极高动态范围 (>120 dB)
  • 对抗混叠要求极高
  • 对延迟不敏感 (可接受 ms 级)
  • 信号频率远低于 Nyquist

不适合 Sigma-Delta

  • >100 kHz BW + >12b → SAR
  • >10 MHz → Pipeline
  • 需要 < 1 采样延迟 → Flash/SAR
  • 严格功耗限制+中精度 → SAR
  • 多通道高速轮询 → SAR+MUX
