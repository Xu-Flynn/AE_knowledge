🟢 四、ADC 模数转换器

🔄

SAR ADC

Successive Approximation Register ADC

逐次逼近寄存器 ADC — 中高精度、超低功耗通用方案，二分搜索 CDAC 架构，IoT/工业/医疗首选

8~18 bit DC~10 MSPS nW~mW 功耗
🔢

Sigma-Delta ADC

Σ-Δ Analog-to-Digital Converter

过采样 + 噪声整形 + 数字抽取滤波，实现最高精度 (16~32 bit)，音频/测量/地震监测专用

16~32 bit DC~100 kHz >120 dB DR
🏭

Pipeline ADC

Pipelined Analog-to-Digital Converter

多级流水线并行架构，1.5-bit/级 + 数字纠错，中高速中高精度的最佳平衡，无线/视频/雷达应用

8~16 bit 10M~1 GSPS MDAC 级间增益
🎛️

Time-Interleaved ADC

Time-Interleaved ADC

M 通道时间交错并行采样，突破单通道速度极限，飞秒级时序偏斜校准，光通信/雷达/示波器专用

8~14 bit 100M~100+ GSPS 偏斜 <50fs
