背景与应用定位

BUCK 转换器是最广泛使用的 DC-DC 开关电源拓扑之一，功能是将较高的直流输入电压转换为较低的稳定输出电压。它是非隔离式开关电源中最基本的降压拓扑，以高效率（通常 ≥90%）、高功率密度覆盖从消费电子到汽车电子几乎所有电源管理领域。

📌 产品定位

产业链位置：电源管理 IC (PMIC) 的核心子类，位于 AC-DC 适配器/电池之后、负载之前，提供精准的电压转换与稳压。

核心价值：以极高效率将"不干净"或"过高"的直流电压转换为精确稳压的低压输出，是 SoC、FPGA、DDR 等数字芯片供电的关键。

本质功能：通过 PWM 调制开关管占空比，利用 LC 滤波实现降压 + 稳压。

🎯 典型应用场景

  • 数据中心/服务器：48V→12V/5V/1.8V 多级 POL (Point-of-Load)
  • 汽车电子：12V/48V 电池→5V/3.3V/1.2V 各域供电
  • PC/笔记本主板：19V→Vcore (~1.0V)、DDR5 VDD/VDDQ
  • 通信基站：−48V→28V/12V 二次电源
  • 工业自动化：24V 总线→各传感器/控制器供电

核心工作原理

BUCK 转换器通过高频开关 + LC 低通滤波实现电压变换：高侧开关管（HS-FET）导通时，电流从 Vin 经电感对输出电容充电并供给负载；HS-FET 关断时，电感电流通过低侧开关（LS-FET，或续流二极管）续流。稳态下电感伏秒平衡决定 Vout = D × Vin。

图 2-1 | BUCK 转换器功率级与反馈环路

⚡ 核心关系公式

Vout = D × Vin    |    ΔIL = (Vin − Vout) × D × Ts / L
ΔVout = ΔIL / (8 × fs × Cout)    |    Iout(max) = IL(avg) + ΔIL / 2

其中 D 为占空比，Ts = 1/fs 为开关周期，ΔIL 为电感电流纹波峰峰值。

🔑 关键设计挑战

  • 效率 vs 频率：高频缩小 LC 尺寸但增加开关损耗；GaN FET 可缓解此矛盾
  • 瞬态响应：负载突增/突减时输出电压 overshoot/undershoot，受控于带宽和 LC 双极点
  • EMI：SW 节点快速 dV/dt 产生共模/差模噪声，需布局优化 + 扩频 (SSFM)
  • 轻载效率：固定 PWM 在轻载时开关损耗占比大，需 PFM/突发模式 (Burst Mode)
  • 最小导通时间：极高降压比（如 48V→1V）时需极小占空比，受限于控制器 ton(min)

核心模块深度解析

1. 功率级 (Power Stage) — HS-FET + LS-FET + 电感 + 电容

功率级是能量处理的核心。同步 BUCK 使用两颗 MOSFET 替代传统的二极管整流：

导通损耗：Pcond = IL(rms)2 × ( D·RDS(on)HS + (1-D)·RDS(on)LS )
开关损耗：Psw = 0.5 × Vin × Iout × (tr + tf) × fs
参数HS-FET 要求LS-FET 要求
RDS(on)低（但受 Cgd 制约）极低，导通时间更长 (1-D)
Qg低，开关损耗比例大中等，ZVS 可降低
VDS 耐压≥ Vin(max) + 尖峰裕量≈ Vin(max) + 尖峰裕量
工程权衡：HS-FET 选 Qg 小的 FET 以降低开关损耗；LS-FET 选 RDS(on) 极小的 FET，因其导通占空比为 (1−D)。高频应用中 Cgd 引起的误导通（dv/dt induced turn-on）需通过负压关断或米勒钳位解决。

2. 电感选型 — 纹波 vs 瞬态 vs 尺寸的核心权衡

电感值 L 是最重要的设计参数之一，直接影响纹波电流、瞬态响应和磁芯损耗：

L = (Vin − Vout) × D / (fs × ΔIL)
设计选择纹波 ΔIL瞬态响应磁芯尺寸适用场景
大 L (r=0.2)小，输出纹波低慢，di/dt 受限大，更多匝数噪声敏感模拟供电
小 L (r=0.4)大，输出纹波高快，di/dt 大小快速瞬态数字负载

r = ΔIL / Iout(max) 是电感电流纹波比，通常取 0.2~0.4。

3. 控制环路 — 补偿网络设计与稳定性

BUCK 功率级传递函数含有一个由 LC 滤波产生的双极点（谐振频率 f0 = 1/(2π√(LC))），需要在反馈回路中加入 Type-II 或 Type-III 补偿器来保证相位裕度 ≥45°。

Type-III 补偿：两个零点(fz1,fz2)抵消 LC 双极点，三个极点(fp1=0,fp2,fp3)提供高频衰减

电流模式控制 (CMC) 将电感电流引入内环，将功率级传递函数简化为一阶（单极点），使补偿更容易，并天然具有逐周期限流能力。代价是需要斜率补偿以防止 D>0.5 时的次谐波振荡。

4. 栅极驱动器 (Gate Driver) — 死区时间与自举电容

同步 BUCK 的 HS-FET 栅极需要 Bootstrap（自举）电路提供高于 Vin 的栅极驱动电压（通常 Vgs = Vin + 5V）。自举电容 CBOOT 在 LS-FET 导通时从 VCC 充电，在 HS-FET 导通时"浮动"为 HS-FET 提供栅极驱动能量。

死区时间 (Dead Time) 是 HS 和 LS 同时关断的短暂间隔，防止直通 (Shoot-Through)。死区过长→二极管续流损耗增加；死区过短→直通风险。自适应死区控制可优化效率。

峰值效率 ηpeak

关键指标 #1
定义稳态下输出功率与输入功率之比的最大值：η = POUT / PIN × 100%
公式η = VOUT·IOUT / (VIN·IIN)，损耗 = Pcond + Psw + PL + PIC
影响分析每 1% 效率下降意味着多 >1% 发热；在 40A 输出时，η 从 95% 降至 93% 意味着额外 3.5W 热耗
典型值12V→5V/3A: ~95%；12V→1.0V/20A: ~88%；48V→12V/5A: ~96%

瞬态响应 ΔVout

关键指标 #2
定义负载电流突变时输出电压的最大偏离值
公式ΔVout ≈ ΔIstep × (1/(2π·fc·Cout) + ESL·dI/dt)，其中 fc 为环路带宽
影响分析过大 overshoot 可能触发负载 OVP；undershoot 可能导致数字芯片复位
典型值fc=100kHz, Cout=100µF, ΔI=10A → ΔV≈50mV；增加 Cout 或 fc 可降低

测试方法与验证

测试一：效率曲线测试

测试原理：在固定 VIN/VOUT 条件下，逐点扫描 IOUT (0~Imax)，用高精度万用表同步测量 VIN/IIN/VOUT/IOUT，计算 η = POUT/PIN。

电子负载Chroma 6314A+63102A0-80V/40A, CR/CC/CV 模式
万用表Keysight 34465A (x4)6.5 digit, 四线 Kelvin 接法

1
接线与预热

按框图使用 Kelvin 四线接法；DUT 上电后满载预热 10 分钟使结温稳定。

2
扫描测试点

从 0A 开始，每 10% Imax 记录一次 VIN, IIN, VOUT, IOUT，重点加密 0~20% 轻载区和峰值效率区。

3
计算与绘图

η = (VOUT×IOUT) / (VIN×IIN) × 100%；绘制 η vs IOUT 曲线。

4
判定

峰值效率 ≥ 规格书 −1%；轻载(10%)效率 ≥ 规格书 −2%。

测试二：负载瞬态响应

测试原理：使用电子负载的动态模式，产生快速电流阶跃，示波器捕获 VOUT 的 overshoot/undershoot 波形。

设备推荐型号关键规格
示波器Keysight MSOX3104T1GHz BW, 被动探头 + 差分探头
电子负载Chroma 63640-80-80dI/dt ≥ 2.5A/µs, Dynamic Mode
1
探头设置

使用 1x 探头 + 弹簧地线（或差分探头），VOUT 测量点尽量靠近输出电容端，最小化环路面积。

2
设置动态负载

电子负载设为 CC Dynamic 模式：Level A=50%Imax, Level B=100%Imax，频率 100Hz，占空比 50%。

3
捕获波形

示波器触发于负载电流上升沿，水平 100µs/div；测量 overshoot/undershoot 峰值和恢复时间(±1%)。

4
判定

Overshoot/Undershoot ≤ 规格书 ±20%；恢复时间 ≤ 规格书 +30%。

测试原理：用示波器 AC 耦合 + 20MHz 带宽限制测量 VOUT 纹波电压。

注意事项与踩坑经验

🔌 SW 节点 Layout

SW 节点是 BUCK 中 dV/dt 最大的节点（>1V/ns），其铜皮面积必须最小化以降低辐射 EMI。输入电容必须紧靠 HS-FET 漏极和 LS-FET 源极，最小化功率环路面积。

🌡️ 热设计裕量

实际结温 ≈ TA + Ploss × ΘJA。RDS(on) 高温增加 ~40% (25→125°C)，会进一步恶化效率形成正反馈。建议留 15°C+ 裕量。

⚡ 自举电容取值

CBOOT 取值不当会导致 HS-FET 栅极驱动不足，效率骤降甚至 FET 进入线性区烧毁。需 ≥ Qg/ΔVBOOT × 10（10x 裕量），必须用 X7R 低 ESR 电容。

📐 反馈走线

FB 引脚是高阻抗节点，需远离 SW 和电感等噪声源。FB 分压电阻应紧靠 FB 引脚放置，走线短、细、且下方铺 GND 屏蔽。

🔄 环路稳定性

输出电容的 ESR 对环路稳定性影响巨大——电解电容 ESR 太高导致零点频率低，陶瓷电容 ESR 太低可能导致相位裕度不足。需根据实际电容调整补偿网络。

🔊 可闻噪声

PFM 模式下脉冲群频率落入 20Hz~20kHz 可闻范围时，MLCC 压电效应会产生"啸叫"。解决：避开可闻频率、使用抗啸叫电容、或全胶灌封。

🔥 最常见错误 TOP 5：
  1. 电感饱和电流选型不足：必须满足 ISAT ≥ IL(peak) = Iout(max) + ΔIL/2，且考虑高温退化（~15%）
  2. 输入电容不足：需承受 RMS 纹波电流 ICin(rms) ≈ Iout × √(D(1−D))，最大发生在 D=0.5
  3. 使能 (EN) 引脚悬空：EN 不可悬空，必须外接分压或直连 Vin/GND
  4. 未考虑软启动：启动瞬间大电容充电电流可能触发 OCP 导致打嗝 (hiccup)，需增大 CSS 延长软启动时间
  5. 忽视 PCB 铜厚：大电流路径需足够铜宽/铜厚，按 <80mil/A (1oz) 估算

选型指南与决策建议

✅ 选用同步 BUCK 的场景

  • 输出电流 >3A（二极管压降损耗不可接受）
  • 效率要求高（>90%）且散热受限
  • 需要多相并联扩展电流
  • 汽车/工业级可靠性要求
  • 数字芯片核心供电（Vcore、DDR、FPGA）

❌ 异步 BUCK 仍可用的场景

  • 输出电流 <2A，效率非首要考量
  • 成本极度敏感（消费电子配件）
  • 输出高压差（二极管 VF 占比小）
  • PCB 面积有限（无需死区控制电路）
  • 噪声敏感（无 LS-FET 开关噪声）

🧠 AE 核心认知： BUCK 是电源管理中最基础的拓扑，但"基础"不等于"简单"。AE 必须理解：BUCK 的"好与坏"70% 取决于 PCB Layout 和外围元件选型，而非芯片本身。效率优化是开关损耗、导通损耗、磁芯损耗三者之间的精细平衡；环路稳定性需要结合实际电容 ESR 的 Type-II/III 补偿设计。在推荐方案时，务必确认客户关注的是峰值效率区域还是轻载区域——两者对应完全不同的优化方向。
