1. 整体电路拓扑框图

典型手机电池供电路径由四大部分组成，按照功率流方向依次为：

关键路径总结：
充电：VBUS(5V) → Charger IC (CC/CV 降压) → Protection IC (MOSFET 导通) → Battery Cell
放电：Battery Cell → Protection IC (MOSFET 导通) → Charger IC (Power Path) → System Load
直连供电：VBUS(5V) → Charger IC (Bypass/OTG) → System Load（电池不参与充放电）

2. VBUS / USB 输入端

2.1 功能与角色

VBUS 来自 USB 适配器或电脑的 5V 供电线。在 USB Type-C 快充场景中，VBUS 电压可经 PD/PPS 协议协商到 9V、12V 甚至 20V。

2.3 USB Type-C CC 检测

Type-C 接口通过 CC1/CC2 引脚进行插入方向检测和供电能力广播：

  • Rd (5.1kΩ 下拉): Sink 端 (手机端) 标配，表示自己是受电设备
  • Rp (上拉): Source 端 (适配器端)，通过不同阻值/电流广播供电能力：
    Default USB (500mA / 900mA), 1.5A, 3.0A
  • PD 协议: 通过 CC 线上的 BMC 编码进行 USB PD 通信，协商更高的 VBUS 电压
AE 测试关注点：VBUS 上电/下电时的浪涌电流、OVP 响应时间、TVS 残压是否满足后端耐压要求。

3.3 Power Path 管理

现代充电 IC 内置 Power Path (电源路径管理)，通过 BATFET 将系统电源 (SYS) 与电池 (BAT) 隔离：

  • VBUS 接入时：SYS 由 VBUS 经 Buck 直接供电，同时 BAT 可独立充电，系统运行不受电池电压影响（即使电池深度放电，手机也能立即开机）
  • VBUS 移除时：BATFET 全导通，SYS 由电池供电，导通阻抗 RDSON 仅 20~50mΩ
  • 补充模式 (Supplement Mode)：当系统峰值电流超过适配器能力时，BATFET 工作在线性区，电池补充供电

4. 电池保护芯片 (Protection IC)

4.1 典型电路结构

管脚命名说明：
B+/B- (电池极耳)：电芯本体直接引出的正负极，焊接到保护板上。
PACK+/PACK- (保护板输出)：经过 Protection IC + Dual MOSFET 后的对外接口，连接到 Charger IC 的 BAT 引脚。
充电电流路径：Charger IC BAT → PACK+ → 充电FET(FET1) → B+ → 电芯 → B- → PACK- → Charger IC GND。
放电电流路径：电芯 B+ → 放电FET(FET2) → PACK+ → Charger IC BAT → BATFET → SYS → 负载。

5.3 电池等效电路模型 (2RC-ECM)

二阶 RC 等效电路模型 (2RC-ECM) 是电池建模的工业标准：

  • OCV (Open Circuit Voltage): 电池开路电压，是 SOC 和温度的函数，由 Nernst 方程决定
  • R0: 欧姆内阻 — 电解液、电极、集流体、极耳等纯电阻性分量，引起瞬时压降
  • R1C1: 电化学极化 — SEI 膜 / 电荷转移，时间常数 ~ ms 级
  • R2C2: 浓差极化 — Li⁺ 扩散，时间常数 ~ s 级

5.4 电量计 (Fuel Gauge / 库仑计)

5.4.1 电量计在电路中的位置

5.4.2 电量计工作原理

电量计估算 SOC (State of Charge) 有三种主流方法，从简单到复杂依次为：

方法一：电压查表法 (OCV-SOC Lookup)

原理：电池开路电压 (OCV) 与 SOC 存在确定的映射关系。电池静置足够久后，测 OCV → 查表得 SOC。
优点：不需要电流采样，电路最简单
缺点：带负载时端电压 ≠ OCV (有 IR Drop)，必须等电池静置 (几分钟到几十分钟)，无法实时跟踪

方法二：库仑计数 (Coulomb Counting)

原理：对流入/流出电池的电流进行时间积分，计算净电荷量变化。
SOC(t) = SOC(t0) + (1 / C_rated) × ∫ I(τ) dτ × 100%

其中：C_rated = 电池额定容量 (mAh)，I(τ) = 充放电电流 (mA，充电为正、放电为负)

库仑计硬件实现：

  • 采样电阻 Rsns： 5~10mΩ 精密电阻，串入电池主回路
  • ΔΣ ADC： 14~16 bit 高精度 ADC，持续采样 Rsns 两端压降 V = I × Rsns
  • 积分器 (Accumulator)： 将每个采样周期的电荷量累加：ΔQ = I × Δt
参数典型值说明
采样电阻 Rsns5~10mΩ太小 → SNR 差；太大 → 损耗大 (I²R)
ADC 分辨率14~16 bit对应电流分辨率 ~1mA (16-bit @ 5mΩ, ±8A 量程)
采样频率1~8 kHz需覆盖脉冲负载 (如 RF PA 突发)
积分周期1s (典型)每秒更新一次 SOC
库仑计的固有缺陷 — 累积误差 (Drift)：
每毫安时的测量误差会随时间不断累积。例如 ±1mA 偏置 × 24h = ±24mAh 误差，一周就是 ±168mAh。必须定期校准纠正漂移。

方法三：阻抗跟踪 (Impedance Track — TI 专利)

原理：将库仑计数与 OCV-电池模型融合。正常运行时用库仑计数追踪电量，当电池进入静置状态 (电流接近零) 时，测 OCV 并查表校准 SOC。同时利用 2RC 等效电路模型估算负载下的"等效 OCV"，无需等待静置即可获得较准确的 SOC。

Impedance Track 工作流程：

  1. 初始化 (上电/Golden Image)：从 Flash 加载电池的 OCV-SOC 曲线表、R0(SOC,T) 表、R1C1/R2C2 参数表
  2. 正常运行：库仑计持续积分 I×dt，同时用电池模型 Vt = OCV − I×Z 反推 OCV
  3. 静置校准 (Relaxation)：当 |I| < 阈值 (如 10mA) 且持续 > 30min，实测 OCV → 查表 → 修正 SOC 累积误差
  4. 满充/满放校准：充电终止 (I < I_TERM) → SOC=100%；电压到 V_cutoff → SOC=0%
  5. 老化补偿：随着循环次数增加，更新 Full Charge Capacity (FCC) 和内部阻抗参数

Q: 手机电量从 50% 突然掉到 10%，可能是什么原因？
→ 电池老化导致实际 FCC 远小于 FG 中记录的 Design Capacity；或长时间未满充校准，累积误差过大。
Q: 如何验证电量计精度？
→ 用电池测试柜跑一次完整的 0.2C 放电，以实际放电容量为基准，每秒记录 FG 的 SOC 读数，绘制 SOC Error vs Time 曲线。

5.5.3 BQ41Z5x 的独特功能

作为 Protection + Fuel Gauge 二合一，BQ41Z5x 除了覆盖 BQ2980 + BQ27426 的全部功能外，还提供了分立方案无法实现的融合能力：

融合功能分立方案做不到的原因
自适应保护阈值 BQ2980 的 OV/UV/OC 阈值是硬件固定值，无法根据电池老化调整。BQ41Z5x 可以根据 SOH 动态调整保护阈值（老化电池内阻大 → 适当放宽 OCP 阈值防止误触发）
预判性保护 分立保护 IC 只能"事后"检测（电压/电流超过阈值才动作）。BQ41Z5x 利用电量计的实时电流/电压数据 + 电池模型，可以预判即将发生的过放/过温并提前降电流
精准 SOC 触发保护 分立方案只能靠电压判断 SOC（不准）。BQ41Z5x 可以在 SOC=0% 时精确触发关机，避免"有电压但没容量"导致突然断电
SOH (健康度) 追踪 只有电量计能追踪循环次数、容量衰减、内阻增长。BQ41Z5x 将此数据通过 SMBus 上报给系统，用于电池健康提示
SHA-1 电池认证 防止劣质/仿冒电池引发安全事故。系统通过 challenge-response 协议验证电池身份，认证失败可拒绝充电
Black Box (黑匣子) 记录电池的极端事件（过温、过放、短路发生时间和次数），用于售后分析和品质追溯

5.5.4 系统架构总结

一句话总结：
BQ25890 = 充电的"司机" (怎么充)；BQ2980 = 安全的"保险丝" (什么时候必须停)；BQ41Z5x = 安全的"保险丝" + 电量的"油表" + 电池的"身份证"三合一。在实际产品中，BQ41Z5x + BQ25890 两颗 IC 就构成了完整的电池管理系统。

倍率特性--0.2C / 0.5C / 1C / 2C 各倍率下放电容量电池测试柜

6.2 OCVR (开路电压) 测量

目的：通过 OCV 推算电池 SOC，评估电芯一致性。

测试步骤：

  1. 将电池以标准充放电程序循环 3 次，确定实际容量
  2. 满充至 4.4V (或规格书指定的 Vfull)，截止电流 0.05C
  3. 静置 1 小时，记录 OCV → 对应 SOC = 100%
  4. 以 0.5C 放电 10% 容量，静置 30 分钟，记录 OCV → SOC = 90%
  5. 重复步骤 4，获得 OCV-SOC 曲线 (SOC: 100% → 0%，步长 5%~10%)
  6. 0% SOC 定义为放电至 Vcutoff = 3.0V
AE 验收关注：出厂时 OCV 通常在 3.7~3.9V (约 50% SOC)，这是锂电池最佳存储电压。OCV 低于 3.4V 或高于 4.1V 可能暗示电芯异常。

6.3 DC IR (直流内阻) 测量 — HPPC 法

HPPC (Hybrid Pulse Power Characterization) 是测电池内阻的标准方法，参考 USABC / FreedomCAR 协议。

放电内阻测试流程：

  1. 将电池调整到目标 SOC (如 50%)，静置 1 小时
  2. 记录静置后的电压 V0
  3. 施加 1C 放电脉冲，持续 10 秒 (或 18 秒/30 秒)
  4. 记录脉冲开始时刻的电压 V1 (通常取 0.1s 或 1s 后的电压，取决于标准)
  5. 记录脉冲结束时刻的电压 V2 (通常取 10s)
R0 (欧姆内阻) = (V0 − V1) / Ipulse
Rtotal (总内阻) = (V0 − V2) / Ipulse
Rpolarization = Rtotal − R0

不同 SOC 下的典型内阻测试矩阵：

6.4 容量测试

标准充放电制度 (以 4000mAh 电芯为例)：

步骤操作参数截止条件

6.5 自放电测试

  1. 电池满充至 Vfull，记录容量 C0
  2. 在 25°C 环境下开路存储 28 天
  3. 以 0.2C 放电至 3.0V，记录剩余容量 C28
  4. 自放电率 = (C0 − C28) / C0 × 100%
典型手机电芯自放电率应低于 3%/月。过高的自放电率暗示微短路 (Internal Short) 缺陷。

6.6 循环寿命测试

  1. 以 0.5C CC/CV 充电至 Vfull，截止 0.05C
  2. 以 1C CC 放电至 Vcutoff (3.0V)
  3. 循环重复，每 50 次做一次标准容量标定 (0.2C 放)
  4. 当标准容量低于初始容量的 80% 时，循环次数即为寿命
循环测试通常需 2~3 个月，是电池验证中最耗时的项目。加速老化可在 45°C 下进行，但结果不可直接等同于常温寿命。

9.2 核心公式速查

公式用途
C = I × T容量 (mAh) = 放电电流 (mA) × 时间 (h)

ηcharger = (VBAT·IBAT) / (VBUS·IBUS)充电芯片效率

9.3 推荐学习路径

  1. 先吃透 DW01 / S-8261 的 datasheet，理解保护 IC 的状态机
  2. 选一颗 Charger IC (如 TI BQ25890)，精读 register map，对每个寄存器理解其物理意义
  3. 在 EVM 板上实测：CC/CV 切换波形、Power Path 切换瞬态、BATFET RDSON
  4. 用电池测试柜跑一次完整的 HPPC + OCV-SOC + 循环寿命，直观感受电池特性
  5. 关注 JEITA 标准和 USB PD/PPS 协议规范，这是面试中的加分项
面试高频问题预警：
Q: CC 切换到 CV 的判据是什么？→ VBAT = VREG
Q: 为什么需要涓流充电？→ 深度放电电池内阻大，大电流充电会析锂损伤
Q: Power Path 相比传统方案有什么优势？→ 电池没电也能开机、系统电压不受电池电压拖低
Q: NTC 电阻选多大？→ 通常 10kΩ @ 25°C, B=3435/3380，与内部 10kΩ 分压匹配
