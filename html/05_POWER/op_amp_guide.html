1 运放概述

运算放大器（Operational Amplifier, Op-Amp）是一种高增益、差分输入的电压放大器件。最初在模拟计算机中用于执行数学运算（加、减、积分、微分等），如今已成为模拟电路设计中使用最广泛的核心器件。

⚡ 核心特征
  • 差分输入：同相端 (V+) 和反相端 (V−)，放大两者之差
  • 高开环增益：典型 105 ~ 106（100 dB ~ 120 dB）
  • 高输入阻抗：>MΩ 级别（FET 输入可达 TΩ）
  • 低输出阻抗：< 100 Ω，理想模型中近似为零
  • 单端输出：输出以地为参考

⚠️ VFA vs CFA 速辨

电压反馈型 (VFA)：传统运放，带宽随闭环增益增大而减小（GBW 恒定）。
电流反馈型 (CFA)：同相输入高阻抗、反相输入低阻抗，带宽主要由反馈电阻决定，增益变化对带宽影响小。CFA 的反馈电阻 不可随意更改，必须按 datasheet 推荐值选取。

3 工作原理

3.1 理想运放模型

分析运放电路时，通常先使用理想模型简化推导，再根据实际指标修正误差。

3.2 负反馈与"虚短虚断"

运放几乎总是在负反馈配置下工作。负反馈将输出信号的一部分回送到反相输入端，使净输入趋近于零。由此得出两条核心法则：

📌 虚短 (Virtual Short)

在负反馈且未饱和时，V+ ≈ V−。两个输入端电压几乎相等，但并没有真正短接——这是运放高增益闭环工作的结果，不是物理连接。

V+ − V− = Vout / AOL ≈ 0  (当 AOL → ∞)
📌 虚断 (Virtual Open)

由于输入阻抗极高，流入输入端的电流可忽略：I+ ≈ 0, I− ≈ 0

3.3 开环与闭环

闭环增益：ACL = AOL / (1 + AOL·β) ≈ 1/β  (当 AOL·β ≫ 1)

其中 β 是反馈系数（反馈到反相端的输出信号比例）。闭环增益由外部电阻决定，几乎与开环增益无关——这是运放电路设计灵活性的根源。

OL 开环 ACL 闭环 (40dB) f-3dB −20dB/dec

4 电气指标详解

运放的关键电气参数决定了其在具体应用中的表现。以下逐项介绍，重点说明每个指标影响什么以及被什么影响。

4.1 输入失调电压 VOS

定义

使输出为零时，需要在输入端施加的差分电压。本质是输入级差分对的不对称。

Vout,error = VOS · (1 + Rf/Rin) = VOS · Anoise
影响说明
影响 输出直流偏移被噪声增益放大后叠加到输出
影响 传感器小信号测量VOS 可能淹没问题信号（如热电偶 μV 级）
受影响 温度温漂 TCVOS 通常 0.1~10 μV/°C，斩波运放可 < 0.05 μV/°C
受影响 电源电压PSRR 有限时，VCC 变化会调制 VOS
受影响 时间长期漂移（aging），典型 1~10 μV/月

4.2 输入偏置电流 IB 与失调电流 IOS

定义

偏置电流 IB = (IB+ + IB−)/2，流过两输入端的直流电流平均值。
失调电流 IOS = |IB+ − IB−|，两输入端偏置电流之差。

Vout,error = IB−·Req−·Anoise − IB+·Req+·Anoise

当 Req+ = Req− 时，偏置电流引起的误差抵消，只剩 IOS 的影响。

💡 消除偏置电流误差的经典技巧

在同相输入端到地之间接一个补偿电阻 Rcomp = Rf ∥ Rin，使两输入端看出去的直流等效电阻相等，从而让 IB 引入的电压相互抵消。

4.3 增益带宽积 GBW (GBP)

定义

开环增益下降到 0 dB（单位增益）时的频率，也是开环增益与带宽的乘积（对 VFA 恒定）：

GBW = AOL × f3dB = ACL × fCL,−3dB
影响说明
影响 闭环带宽f−3dB = GBW / ACL,noise，噪声增益越大带宽越窄
影响 信号保真度在闭环带宽附近，增益衰减、相移增大，信号失真
受影响 电源电压低电压下 GBW 可能下降 30%~50%
受影响 负载电容大容性负载可引起不稳定，需串联隔离电阻
⚠️ 设计准则

实际设计中，要求 GBW ≥ 10 × ACL × fsignal,max，留出足够裕量。例如：闭环增益 100 倍，信号最高 20 kHz，则 GBW ≥ 10 × 100 × 20k = 20 MHz。

4.4 压摆率 SR (Slew Rate)

定义

输出电压在阶跃输入下能达到的最大变化速率，由内部补偿电容和驱动电流决定：

SR = Itail / Ccomp  (V/μs)

满功率带宽（FPBW）与 SR 的关系：

FPBW = SR / (2π · Vpp)  — 输出正弦波不失真的最高频率
影响说明
影响 大信号带宽大振幅输出时，SR 限制比 GBW 更先到达
影响 瞬态响应阶跃响应的上升/下降沿线性，不是指数
受影响 电源电压低电压下 Itail 减小，SR 下降
受影响 温度Itail 随温度变化，SR 有温漂

4.5 共模抑制比 CMRR

CMRR = ADM / ACM = 20·log10(ADM/ACM) dB
影响说明
影响 差分放大精度CMRR 不够 → 共模信号泄漏到输出，等效为 VOS 变化
影响 电路对电源纹波的抑制CMRR 与 PSRR 相关但不同
受影响 频率CMRR 在高频急剧下降，典型 −20dB/dec
受影响 外部电阻匹配差分放大电路中，电阻失配 1% 可使 CMRR 降至 40 dB

5 测试方法

5.1 输入失调电压 VOS 测试

测试方法

将运放接成高噪声增益的缓冲器（如 Anoise = 1001），测量输出电压：

VOS = Vout / Anoise = Vout / (1 + Rf/Rin)

例如 Rf = 100 kΩ, Rin = 100 Ω, 测得 Vout = 50 mV → VOS = 50 mV / 1001 ≈ 50 μV

5.2 输入偏置电流 IB 测试

测试方法

在运放输入端串联大阻值电阻 Rs（如 10 MΩ），测量电阻上的压降：

IB = Vdrop / Rs

分别测 IB+ 和 IB−。FET 输入运放 Ib 极小，需用静电计或积分法。

5.3 GBW 测试

测试方法

将运放接成单位增益缓冲器，扫频测量 −3 dB 点频率 fu，即 GBW。或用闭环增益 ACL > 1 的配置：

GBW = ACL × f−3dB

5.4 压摆率 SR 测试

测试方法

单位增益配置，输入方波（大信号，Vpp 接近满幅），测量输出上升沿的斜率：

SR = ΔVout / Δt  (取线性段)

5.5 CMRR 测试

测试方法

将运放接成差分放大电路，同时改变两输入端的共模电压（保持差分输入为零），测量输出变化：

CMRR = ΔVCM / ΔVOS,eff = 20·log10(ΔVCM / ΔVOS,eff) dB

5.6 PSRR 测试

测试方法

在电源引脚叠加交流纹波 ΔVsupply，测量等效输入失调变化 ΔVOS：

PSRR = ΔVsupply / ΔVOS  (dB)

5.7 噪声测试

测试方法

将运放接成高增益配置，输入短路，用频谱分析仪测量输出噪声密度，再除以噪声增益：

en = eout / Anoise  (nV/√Hz)

电流噪声 in 可在输入端接已知电阻，从输出噪声增量反推。

6 基本应用电路

6.1 反相放大器

图 6-1 反相放大器
Av = −Rf / Rin
  • 输入阻抗 = Rin
  • 输出反相，增益绝对值可 > 1 或 < 1
  • 虚地点：反相输入端电压 ≈ 0（虚地）

6.2 同相放大器

图 6-2 同相放大器
Av = 1 + Rf / Rin
  • 输入阻抗极高（= 运放输入阻抗）
  • 增益始终 ≥ 1
  • 输出与输入同相
📌 电压跟随器（特例）

Rf = 0, Rin = ∞ → Av = 1。输入阻抗最高、输出阻抗最低，常用作缓冲器（Buffer）。

6.3 加法器（反相求和放大器）

图 6-3 反相加法器
Vout = −(V1·Rf/R1 + V2·Rf/R2 + V3·Rf/R3)

当 R1 = R2 = R3 = R 时：

Vout = −(Rf/R)·(V1 + V2 + V3)
💡 关键特性
  • 各输入通道之间互相隔离（虚地点）
  • 可独立调整每个通道的加权系数
  • 可扩展为任意多路加法
  • 输出反相，如需同相可后接反相器

6.4 减法器 / 差分放大器

图 6-4 差分放大器（减法器）
Vout = (Rf/R1)·(V2 − V1)  (当 Rf/R1 = R3/R2)

基本差分放大器要求四电阻精密匹配，CMRR 严重依赖电阻匹配度：

电阻匹配精度等效 CMRR
1%≈ 40 dB
0.1%≈ 60 dB
0.01%≈ 80 dB
⚠️ 工程建议

高 CMRR 场景（如电桥传感器）应使用仪表放大器（如 AD620, INA128），内部激光修调电阻，CMRR 可达 100 dB+。普通差分电路中可用集成电阻网络（如 4 个 10 kΩ 同封装 0.01% 匹配）提升 CMRR。

6.5 积分器与微分器

积分器

Rin 串联，Cf 替代 Rf

Vout = −(1/RinCf)∫Vindt

⚠️ 纯积分器直流开环，必须并联大电阻 Rf 限制低频增益

微分器

Cin 串联，Rf 不变

Vout = −RfCin·dVin/dt

⚠️ 高频增益无限大，必须串联小电阻 Rin 限制高频增益

7 有源低通滤波器专题

这是本章的核心。有源滤波器利用运放的增益和缓冲能力，克服无源滤波器固有的负载效应和增益受限问题。

7.1 为什么需要"有源"滤波器？

对比项无源 RC/RLC 滤波器有源 RC 滤波器
增益≤ 1（纯衰减）可有增益
负载效应后级负载改变截止频率运放输出低阻抗，隔离负载
级联后级影响前级各级独立设计
电感低频需大电感（笨重）无需电感
Q 值受限于元件损耗可实现高 Q（但有灵敏度代价）
供电不需要需要供电
噪声仅电阻热噪声加上运放噪声
频率上限可到 GHz受运放 GBW 限制（通常 < 10 MHz）

📌 如何选择逼近类型？
  • 关心信号波形不失真 → Bessel（群延迟最平坦，脉冲响应最好）
  • 关心通带内幅频最平坦 → Butterworth（"最平坦"名副其实）
  • 关心截止最陡、通带纹波可接受 → Chebyshev（同级数最窄过渡带）
  • 过渡带极窄、阻带纹波可接受 → Elliptic（最极端的频率选择性）

7.3 一阶有源低通滤波器

最简单的有源低通，在反相放大器基础上将 Rf 替换为 Rf ∥ Cf：

图 7-2 一阶反相有源低通滤波器（Rf ∥ Cf 反馈）
H(s) = −(Rf/Rin) / (1 + s·Rf·Cf)
fc = 1 / (2π·Rf·Cf)
低频增益 Av = −Rf/Rin，高频以 −20 dB/dec 衰减

一阶滤波器特性：过渡带 −20 dB/decade 衰减率，过于平缓，实际应用中常需二阶或更高阶。

7.4 二阶有源低通滤波器

二阶是实用滤波器的基本构建单元。关键参数：

H(s) = Av·ωc2 / (s2 + (ωc/Q)·s + ωc2)

其中 Q（品质因数）决定了截止频率附近的响应形状：

Q 值对应逼近截止频率处特性
0.577 (1/√3)Bessel−4.7 dB，最平群延迟
0.707 (1/√2)Butterworth−3 dB，最平幅频
0.96 ~ 2Chebyshev (0.5~3 dB 纹波)有峰值，峰值 = Q·Av
⚠️ Q 值过高的危险

Q > 0.707 时截止频率附近出现增益峰值；Q → ∞ 时极点落在虚轴上，电路自激振荡！实际设计中，Q 值一般不超过 2~3，且需考虑元件容差导致 Q 偏移的风险。

7.4.1 Sallen-Key 拓扑

Sallen-Key 是最常用的二阶有源滤波器拓扑，运放接成同相放大或电压跟随器：

图 7-3 Sallen-Key 二阶低通滤波器（单位增益配置）

单位增益 Sallen-Key（最常用配置，运放为电压跟随器）：

fc = 1 / (2π·√(R1·R2·C1·C2))
Q = √(R1·R2·C1·C2) / (R1·C1 + R2·C1)

若取 R1 = R2 = R，则简化为：

fc = 1 / (2π·R·√(C1·C2))   ;   Q = √(C2/C1) / 2
💡 等电阻设计的元件值关系

当 R1 = R2 = R 时：

  • Butterworth (Q = 0.707)：C2/C1 = 2 → 取 C1 = C, C2 = 2C
  • Bessel (Q = 0.577)：C2/C1 ≈ 1.33 → 取 C1 = 3C, C2 = 4C (近似)
  • 0.5 dB Chebyshev (Q ≈ 0.864)：C2/C1 ≈ 2.99

7.4.2 多路反馈 (MFB) 拓扑

多路反馈 (Multiple Feedback) 拓扑，运放工作在反相模式，所有反馈路径汇聚到反相输入端：

MFB 二阶低通滤波器传递函数
H(s) = −(1/R1R3C1C2) / (s2 + s/(R2C1) + 1/(R1R3C1C2))

特点：反相输出、元件灵敏度较低、更适合高 Q 应用。

7.5 Sallen-Key vs MFB 对比

7.6 高阶滤波器：级联设计

实际滤波器通常需要 4 阶、6 阶甚至更高阶来获得足够的阻带衰减。级联法是将高阶传递函数分解为若干二阶节（和可选一个一阶节），每节用独立运放实现：

n 阶滤波器 = ⌊n/2⌋ 个二阶节 + (n 为奇数时) 1 个一阶节

每节有独立的 fc 和 Q 值，由滤波器系数表决定。以下为 Butterworth 低通归一化系数（ωc = 1 rad/s）：

⚠️ 级联顺序原则

低 Q 节放前面，高 Q 节放后面。原因：高 Q 节在截止频率附近有增益峰值，放在后面可以避免前级被峰值信号驱动到饱和。同时，高 Q 节对元件容差更敏感，放在后级有利于减小前级累积误差的影响。

7.7 设计实战：从需求到电路

下面通过一个完整的设计实例，演示有源低通滤波器的系统设计流程。

📋 设计需求
  • 信号频率范围：DC ~ 10 kHz
  • 截止频率 fc = 10 kHz (−3 dB)
  • 通带最大平坦（选用 Butterworth 逼近）
  • 20 kHz 处衰减 ≥ 30 dB
  • 通带增益 = 1（单位增益）
  • 单电源 5V 或双电源 ±5V
Step 1：确定所需阶数

Butterworth 滤波器在 ω 处的衰减量：A = 20·n·log10(ω/ωc) dB

在 f = 20 kHz（即 ω/ωc = 2）处：

  • 2 阶：A = 20 × 2 × log10(2) = 12 dB（不够）
  • 4 阶：A = 20 × 4 × log10(2) = 24 dB（不够）
  • 5 阶：A = 20 × 5 × log10(2) = 30 dB ✓（刚好满足）
  • 6 阶：A = 20 × 6 × log10(2) = 36 dB（有余量，推荐）

选择 5 阶 Butterworth（1 个一阶节 + 2 个二阶节），或 6 阶（3 个二阶节）留裕量。本例取 4 阶重新评估：24 dB 不够，但若实际要求放宽到 24 dB，4 阶也可接受。为了清晰演示，我们按 4 阶 Butterworth 设计。

Step 2：查表获取各节参数

4 阶 Butterworth 分解为 2 个二阶节：

节fnQ
第 1 节1.000 × fc = 10 kHz0.541
第 2 节1.000 × fc = 10 kHz1.306
Step 3：选择拓扑

Butterworth、Q ≤ 1.306，Sallen-Key 完全胜任，且元件少、同相输出。

两个二阶节均采用 Sallen-Key 单位增益配置。

Step 4：计算元件值（第 1 节：Q = 0.541）

取等电阻 R1 = R2 = R，先选 R = 10 kΩ（标准值，噪声和功耗平衡）：

Q = √(C2/C1) / 2  →  C2/C1 = 4Q2 = 4 × 0.5412 = 1.171
fc = 1 / (2π·R·√(C1·C2))  →  √(C1·C2) = 1/(2π·R·fc) = 1/(2π×10k×10k) = 1.592 nF

由 C2 = 1.171·C1，代入 √(C1·C2) = √(1.171·C12) = C1·√1.171：

C1 = 1.592 nF / √1.171 = 1.471 nF ≈ 1.5 nF (标准值)
C2 = 1.171 × 1.471 nF = 1.723 nF ≈ 1.8 nF (标准值)

验证：fc = 1/(2π×10k×√(1.5n×1.8n)) = 1/(2π×10k×1.643n) ≈ 9.69 kHz（偏差 3%，可接受）

Step 5：计算元件值（第 2 节：Q = 1.306）

同样取 R = 10 kΩ：

C2/C1 = 4Q2 = 4 × 1.3062 = 6.822
√(C1·C2) = 1.592 nF (同上)
C1 = 1.592 nF / √6.822 = 0.609 nF ≈ 620 pF (标准值)
C2 = 6.822 × 0.609 nF = 4.154 nF ≈ 4.3 nF (或 3.9 nF + 并联小电容)

验证：fc = 1/(2π×10k×√(620p×4300p)) ≈ 9.77 kHz（偏差 2.3%，可接受）

Step 6：运放选型

滤波器对运放的要求：

  • GBW：≥ 10 × ACL × fc = 10 × 1 × 10k = 100 kHz（非常宽裕）
  • SR：FPBW = SR/(2π·Vpp)，若 Vpp = 4V, FPBW ≥ 10 kHz → SR ≥ 2π×10k×4 = 0.25 V/μs
  • 输入偏置：双电源时 V+ 端有 R2 到地通路，OK
  • 推荐：TL072（GBW 3 MHz, SR 13 V/μs, 双运放正好两级级联）
Step 7：仿真验证与调优

在 SPICE 中仿真，重点检查：

  • −3 dB 频率是否准确（标准值替代引入偏差）
  • 通带是否有意外峰值（Q 偏高时可能）
  • 阻带衰减是否达标
  • 大信号输出时是否因 SR 限制失真
  • 元件 ±5% 容差下，Monte Carlo 仿真确认 Q 偏移不导致振荡
