背景与应用定位

高性能SerDes (Serializer/Deserializer) 是提供的基础IP核心，应用于各类高速数据通信芯片中。SerDes将并行数据转换为高速串行数据(及反向转换)，是高速互联的物理层核心技术。作为最基础的构建块，SerDes的质量决定了整个芯片的信号完整性上限。

📌 产品定位

产业链位置：物理层(PHY)核心IP，位于并行数字逻辑与高速串行接口之间

核心价值：实现"并行⇄串行"高速转换，在最低功耗下提供最高信号质量

本质功能：串化解串 + 时钟恢复 + 均衡补偿 + 终端匹配

🎯 典型应用场景

  • 数据中心交换芯片 (Switch ASIC)
  • AI/ML加速器互联 (NVLINK, CXL)
  • 光模块电接口 (oDSP的Host-Side SerDes)
  • PCIe 6.0 PHY, CXL 3.0 PHY
  • 芯片间Die-to-Die互联 (UCIe)

核心工作原理

SerDes的基本功能是将低速并行数据转换为高速串行数据(及反向转换)。发送端通过编码、FIFO、并串转换(PISO)和预加重驱动输出；接收端通过模拟/数字均衡、时钟恢复(CDR)和串并转换(SIPO)恢复原始并行数据。

核心模块深度解析

一、并串转换器 (PISO) — Tree-Mux 架构

PISO将32bit并行数据转换为单bit串行流。112Gbps下每bit仅~8.9ps，采用树形Mux级联结构和半速率(Half-Rate)最终级实现：

2:1 → 2:1 → 2:1 → ... 最终级: 半速率 (双沿时钟) | 输出: 106.25Gbps PAM4 = 53.125 Gbaud
参数112G 规格224G 规格含义
并行宽度32/64 bit32/64 bit取决于并行时钟频率
最高Mux比32:132:1 / 64:1级联深度
时钟架构Half-RateQuarter-Rate最终级使用多相时钟
时序裕度~0.1UI~0.05UI极严苛

二、串并转换器 (SIPO)

SIPO是PISO的逆过程，将恢复的高速串行bit流转换为并行数据。关键挑战是与CDR恢复时钟严格对齐——任何相位偏差都会直接导致bit错误。

串行输入: d0, d1, d2, ..., d31 (依次, 每bit ~8.9ps @112G) → 并行输出: [d0..d31] @ ~3.3GHz

三、连续时间线性均衡器 (CTLE) — 0~15dB Peaking

CTLE是接收端第一级模拟均衡，通过可编程的高通频率响应补偿信道在Nyquist频率处的损耗。

参数典型值含义
Peaking 范围0~15dB可编程增益提升
Peaking 频率@f_Nyq (~26.5GHz)目标补偿频率
DC 增益0~6dB低频增益
带宽>30GHz−3dB 带宽
噪声系数~8~12dB折中: peaking↑→噪声↑
⚠️ 关键折中：Peaking越大→高频补偿越好→但宽带噪声也越大→后续DFE负担加重。需根据信道损耗仔细优化。

四、判决反馈均衡器 (DFE) — 1~3 Tap

DFE利用已判决符号的加权反馈消除后向ISI，不放大噪声是其核心优势。SerDes通常用1~3 tap（相比oDSP更简，因延迟要求更严、且上层协议有FEC）。

y[n] = x[n] − Σ(k=1 to N) d[n−k] · b[k]   |   N=1~3, PAM4 判决阈值: −2, 0, +2
Tap数补偿能力适用场景关键约束
1-tap~5dB @Nyquist极短距 (Die-to-Die)延迟 <1UI
2-tap~8dB中等损耗信道延迟 <2UI
3-tap~10dB较长PCB/背板Speculative DFE

五、时钟数据恢复 (CDR) — 二阶PLL, BW可编程

CDR从串行数据流中恢复发送端时钟，是SerDes最关键的子模块之一。采用二阶PLL提供更好的频率跟踪能力，环路带宽(BW)可编程以适应不同应用场景。

Mueller-Muller PD: Δφ = e(n)·d(n−1) − e(n−1)·d(n)   |   二阶PLL: H(s) = Kp + Ki/s

六、TX Driver (CML 输出驱动)

TX Driver采用CML (Current Mode Logic) 结构，提供50Ω差分输出阻抗和可编程输出摆幅。

七、编码器 — 64b/66b & PAM4 Gray 映射

64b/66b 编码：将64bit数据编码为66bit，提供2bit同步头。冗余度~3.1%，远低于8b/10b(25%)，适合高速SerDes。

PAM4 Gray 映射：00→−3, 01→−1, 11→+1, 10→+3。相邻电平仅1bit不同，降低符号错误时的bit错误数。

64b/66b: 64bit → 66bit (01/10 同步头) | PAM4 Gray: {MSB, LSB} → 电平 −3/−1/+1/+3

八、校准与监测电路

终端电阻校准 (R-Term Cal)：自动校准片内终端电阻至精确的50Ω/100Ω，补偿PVT变化。通常用外部精密参考电阻 + 逐次逼近算法。

片内眼图监测 (Eye Monitor)：在RX数据路径中内置眼图扫描电路，可实时监测眼图睁开度，无需外部高速示波器即可进行链路诊断。

PRBS生成/校验：内置PRBS7/9/11/15/23/31模式生成器与校验器，支持内部环回自测试。

✅ SerDes性能关键共同影响因素：
  • 电源完整性 (PDN)：SerDes对电源噪声极其敏感——DC-DC纹波、PDN谐振直接耦合到PLL和模拟前端，导致抖动恶化
  • 时钟质量：参考时钟的相噪是SerDes性能的"天花板"——再好的PLL也无法产生比参考时钟更干净的输出
  • 信号完整性 (SI)：PCB trace阻抗控制(±5%)、等长布线、完整参考层、远离噪声源——是SerDes正常工作的物理前提
  • 温度：PVT变化导致偏置漂移、时序变化；高温→漏电流↑→功耗↑；SS corner→性能最差
  • 工艺角 (PVT)：SS/TT/FF corner下性能差异显著——SS corner灵敏度可能恶化3~5dB
  • 终端匹配：50Ω/100Ω阻抗匹配偏差→反射→ISI→BER恶化；需要片内自动校准

测试方法详解

📐 7.1 环回测试 (Loopback Test)

内部环回 (Internal Loopback)：TX → 内部环路 → RX。测试SerDes核心功能（编码/串化/解串/解码），排除外部信道影响——是最先执行的诊断测试。

外部环回 (External Loopback)：TX → PCB trace → RX。测试完整链路（含封装/PCB/连接器），反映真实系统性能。

🔊 7.2 抖动容限/抖动传递测试 (JTOL/JTF)

1
JTOL 模板验证

按 OIF-CEI-112G-VSR 规范注入不同频率/幅度的正弦抖动(SJ)，测量BER=1e-12时的最大容忍SJ。低频段(10k~1MHz)高幅度→高频段(10M~100MHz)低幅度。

2
JTF 模板验证

测量CDR输出恢复时钟相对于输入数据抖动的传递函数。期望：低频段 0dB（跟踪），高频段 −40dB/dec（抑制）。环路BW可编程验证。

3
恢复时钟抖动测量

使用相噪分析仪(E5052B)测量恢复时钟的相位噪声，积分10k~100MHz得RJ RMS。判断标准：112G <200fs, 224G <150fs。

4
CDR锁定范围/时间

缓慢扫频(10ppm/s)偏离标称速率，监测Lock Status → 确定锁定范围。频率阶跃(标称→标称+200ppm)测试锁定时间。

🔴 7.3 多Lane相位对齐测试

测试项目测试方法判定标准
Lane-to-Lane Skew同时触发多lane TX，在RX端测量各lane数据有效沿的时间差Skew <5 UI（可通过FIFO补偿）
最长路径 vs 最短路径在所有PVT corner下重复Skew测量最大Skew差值 <设计裕量
多lane同步启动多lane同时上电，测量所有lane CDR锁定完成的最大时间差<1ms

🟢 7.4 PVT 测试

1
工艺角覆盖

SS (Slow-Slow)、TT (Typical-Typical)、FF (Fast-Fast)，每种 corner 取 5~10 颗芯片 samples。TT 为基准，SS 通常性能最差。

2
电压扫描

Vmin (标称−5%)、Vnom、Vmax (标称+5%)。重点关注 Vmin 下的 CDR 锁定性能和 Vmax 下的功耗。

3
温度扫描

−40°C, 25°C, 85°C, 105°C。每个温度点稳定至少15分钟后测量。高温→漏电↑→眼图变差；低温→PLL可能失锁。

4
组合测试

最坏组合：SS corner + Vmin + −40°C（最差性能）；FF corner + Vmax + 105°C（最大功耗）。所有组合均需通过BER门限。

测试与使用注意事项

⚡ SerDes 通用注意事项

🔌 上电时序

严格按 Vcore → Vio → Vana 顺序上电，每级间隔 >10ms。断电反向！违反时序可能永久损坏芯片！

🕐 参考时钟质量

频率: 25~156MHz LVDS/CMOS；抖动: <150fs RMS (12k~20MHz)；相噪: −150dBc/Hz @10kHz；精度: ±50ppm。时钟是性能天花板！

⏱ CDR 锁定确认

测试前务必通过寄存器读取确认 CDR Lock Status=1！未锁定时BER无意义。锁定后等待 >50ms 让 DFE 系数完全收敛。

📐 阻抗匹配

PCB 差分阻抗 100Ω±5%；单端 50Ω±5%。任何失配 → 反射 → ISI → BER恶化。利用片内 R-Term Cal 自动校准。

⚡ 电源隔离与去耦

AVDD 与 DVDD 独立供电；每个电源引脚放置 100nF||10μF 去耦电容；数字开关噪声通过衬底耦合到模拟前端 → 抖动增加。

📐 PCB 布局规范

差分对等长布线(<1mm mismatch)；参考层完整不分割；高速信号远离时钟线(>5×线距)；保护环包围敏感模拟引脚。

🔵 SerDes 专项注意事项

🔍 电缆/PCB去嵌入

测试电缆和PCB trace的损耗必须在测量结果中补偿。使用VNA提取S参数→示波器/信号源去嵌入功能。

🚫 避免过量程

RX输入不得超过CTLE线性范围(通常~800mVppd)；TX预加重过度→信号削波→谐波增加→眼图恶化。

📊 PVT Corner 关注点

SS corner→性能最差(灵敏度恶化3~5dB)；FF corner→功耗最高；高温→CDR锁定性能下降；低温→PLL可能失锁。

🧪 环回测试要点

内部环回先验证核心功能，再外部环回验证完整链路。注意环回路径的时延可能影响CDR训练——必要时调整环回路径长度。

🚨 SerDes 测试最常见错误：
  • CDR未锁定时测BER：结果完全无意义——必须先确认Lock Status=1
  • DFE未收敛：CDR锁定后前50ms数据不可用——DFE系数需要时间自适应
  • 忽视温度稳定：温度变化过程中测量 → 数据漂移 → 结果不可复现
  • 电缆损耗未补偿：测试电缆在高频(>20GHz)有显著损耗(>3dB/m) → 虚低灵敏度
  • 共模噪声耦合：差分信号对共模干扰敏感——确保差分对布线对称
