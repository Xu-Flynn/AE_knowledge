背景与定位

一、什么是信号调制（Modulation）

在数字通信中，发送端要把 0/1 比特流转换为可以在物理信道（铜线、PCB 走线、光纤）中传输的物理量（电压、光功率、相位），这个转换过程叫调制（Modulation）。接收端再做反向操作（解调，Demodulation），把物理量还原为比特流。

衡量调制技术的核心指标是频谱效率（Spectral Efficiency）：单位带宽每秒能传多少 bit，单位 bit/s/Hz。频谱效率越高，同样带宽下传得越快，但通常对 SNR（信噪比）的要求也越高。

两个基础概念：
  • 比特率（Bit Rate）：每秒传输的 bit 数，单位 bps（Gbps、Tbps）。
  • 符号率（Symbol Rate / Baud Rate）：每秒传输的符号数，单位 Bd（GBaud）。一个符号可携带 N bit，N = log2(M)，M 为调制级数。

两者关系：比特率 = 符号率 × log2(M)。NRZ 的 M=2，所以比特率 = 符号率；PAM4 的 M=4，比特率 = 2 × 符号率。

二、奈奎斯特定理与香农极限

奈奎斯特定理（Nyquist Theorem）：带宽为 B 的理想低通信道，无码间干扰（ISI）的最大符号率为 2B。即：

符号率_max = 2 × 带宽B（无 ISI 条件）

香农-哈特莱定理（Shannon-Hartley）：带宽 B、信噪比 SNR 的信道最大容量：

C = B × log2(1 + SNR)

这两条定理决定了：在带宽受限的信道（如长距离铜缆、背板）上，要提升速率，要么提高 SNR（加强信号、降低噪声），要么提高调制级数 M（用 PAM4/PAM6 替代 NRZ）。前者受物理限制，后者是高速串行通信的主流选择。

四、为什么需要 PAM4：NRZ 的带宽瓶颈

从 10G 到 25G，串行链路还能用 NRZ（二电平）应付。但提升到 50G/通道及以上时，NRZ 遇到了带宽墙：

  • 奈奎斯特频率翻倍：NRZ 信号的主要能量集中在 0 ~ 0.5 × 符号率 的频率范围内。53.125 GBaud NRZ 的奈奎斯特频率约 26.6 GHz，而典型背板/线缆的损耗在 26 GHz 处已达 30~40 dB，信号被严重衰减。
  • 均衡器吃力：要补偿这么大的损耗，接收端需要阶数很高的均衡器（DFE 抽头数↑），不仅功耗高，还会放大噪声，且存在误差传播问题。
  • PCB 材料成本：要把损耗降下来，必须用更低损耗的板材（Megtron 6/7、Tachyon 100G），成本翻倍。

PAM4 把每个符号携带 2 bit，在相同比特率下符号率减半，奈奎斯特频率也减半。例如 100Gbps 信号：NRZ 需 100 GBaud（Nyquist 50 GHz），PAM4 只需 50 GBaud（Nyquist 25 GHz），信道损耗降低 10~15 dB，是性价比最高的提速方案。

关键洞察：PAM4 不是"更快的 NRZ"，而是用 SNR 换带宽 —— 把符号率减半以适应信道带宽，代价是每个电平的间距缩小（4 电平平均间距是 NRZ 的 1/3，对应 ~9.54 dB SNR 损失），需要更强的 DSP 均衡和 FEC 来弥补。

工作原理

一、NRZ 工作原理

NRZ（Non-Return-to-Zero，不归零码）是最基础的二进制调制：用两个电平分别表示 bit 0 和 bit 1，每个 bit 周期内电平保持不变（不归零）。最常见的 NRZ-L（Level）规定：高电平 = 1，低电平 = 0。

图 2.1 NRZ 波形与比特映射（二电平）

NRZ 的核心特征：

  • 1 bit / 符号：比特率 = 符号率，频谱效率 1 bit/symbol。
  • 两电平：电平间距 = V_high − V_low = V_swing，判决阈值取中点。
  • 主要能量集中在 0 ~ 0.5 × 符号率 频段（Nyquist 频率）。例：25.78 GBaud NRZ 的 Nyquist = 12.89 GHz。
  • 无时钟分量：连续相同 bit 时无电平跳变，接收端需要 CDR（Clock Data Recovery）从数据跳变沿提取时钟。
  • DC 分量：取决于 0/1 比例，长串 0 或 1 会导致 DC 漂移，通常加扰码（Scrambling）或 8b/10b、64b/66b 编码平衡。

二、PAM4 工作原理

PAM4（4-Level Pulse Amplitude Modulation，四电平脉冲幅度调制）用 4 个等间距电平表示 2 bit 数据。每个符号携带 2 bit，符号率减半即可达到相同比特率。

图 2.2 PAM4 波形与比特映射（四电平，Gray 编码）

PAM4 的核心特征：

  • 2 bit / 符号：比特率 = 2 × 符号率，频谱效率 2 bit/symbol。
  • 四个等间距电平：L0/L1/L2/L3，电平间距 = V_swing / 3，约为 NRZ 的 1/3。
  • 三个眼图：4 电平在眼图上形成 3 个垂直堆叠的"眼睛"。
  • 主要能量集中在 0 ~ 0.5 × 符号率 频段，相同比特率下 Nyquist 频率为 NRZ 的 1/2。
  • SNR 损失 ~9.54 dB：相比 NRZ，PAM4 的判决电平间距仅为 1/3，等效 SNR 损失 = 20×log10(3) ≈ 9.54 dB（理论值，实际还要更大）。
  • 必须配 FEC：PAM4 的原始 BER 较高（典型 1E-4 ~ 1E-5），必须靠 FEC（如 KP4 RS-FEC）纠正到 1E-15 量级才能正常通信。

三、读/写操作流程（从比特到电平的转换链路）

① 发射链路（TX）流程

1
数据加扰（Scrambling）

用 LFSR（线性反馈移位寄存器）对原始比特流加扰，打散长串 0/1，保证 0/1 等概率分布，使频谱平坦、便于 CDR 提时钟。

2
FEC 编码（Forward Error Correction）

加入纠错冗余位。PAM4 链路必用 RS-FEC（如 KP4：RS(544,514)，开销 5.8%），把原始 BER 1E-4 纠到 1E-15。NRZ 链路部分用更轻的 FEC（如 Fire Code）或不用。

3
比特到符号映射（Symbol Mapping）

NRZ：1 bit → 1 个 2 电平符号；PAM4：2 bit → 1 个 4 电平符号（采用 Gray 编码，相邻电平只差 1 bit，降低错误位权重）。

4
预加重/预均衡（Pre-emphasis / TX Equalization）

用 FIR 滤波器（典型 3-tap: pre/main/post-cursor）对发射波形预失真，预先补偿信道高频损耗。NRZ 用更简单的 de-emphasis；PAM4 需要更精细的多电平预加重。

5
DAC 转换（PAM4）或直接驱动（NRZ）

PAM4 需要高速 DAC（6~8 bit 分辨率，采样率 ≥ 符号率）将数字符号转为模拟电平；NRZ 只需一个限幅驱动器（Limiter/Driver）输出两电平。

6
模拟发送

通过 Driver（电口）或 TOSA/激光器（光口）将电平信号发送到信道。光口还需调制激光器（DML 直接调制 / EML 外调制 / SiPh 调制）。

② 接收链路（RX）流程

1
信号接收与放大

电口：CTLE（连续时间线性均衡器）+ VGA（可变增益放大器）；光口：TIA（跨阻放大器）+ CTLE。CTLE 提供高频补偿，初步抵消信道损耗。

2
ADC 采样（PAM4）或直接判决（NRZ）

PAM4 需高速 ADC（6~8 bit，采样率 ≥ 符号率）将模拟信号转为数字样本；NRZ 通常直接用比较器（Slicer）判决，无需 ADC。

3
数字均衡（FFE + DFE）

FFE（前馈均衡）进一步补偿信道失真；DFE（判决反馈均衡）消除码间干扰（ISI）的后向拖尾。NRZ 通常 1~5 抽头 DFE；PAM4 需 5~20+ 抽头 DFE。

4
CDR 时钟恢复

从均衡后的数据中提取时钟，对齐采样点。Mueller-Müller、Bang-Bang、Hogge 等算法常见。PAM4 因多电平跳变复杂，CDR 设计更难。

5
符号判决与解映射

NRZ：1 个阈值判决 2 电平；PAM4：3 个阈值判决 4 电平，再按 Gray 映射还原 2 bit。

6
FEC 译码

对解映射后的比特流做 FEC 译码，纠正传输中的错误比特。若错误数超过 FEC 纠错能力，则触发链路重传或告警。

7
解扰码与输出

用与发射端相同的 LFSR 解扰码，还原原始比特流，输出到 MAC/上层。

关键区别：NRZ 链路是"模拟判决"为主（CTLE + DFE + Slicer），DSP 相对简单；PAM4 链路是"数字信号处理"为主（ADC + FFE + DFE + MLSD + CDR + FEC），DSP 占整个 SerDes 功耗的 50% 以上。这是 PAM4 链路功耗显著高于 NRZ 的根本原因。

一、NRZ 信号详解

把 NRZ 信号按 bit 周期对齐叠加，就得到眼图（Eye Diagram）。眼图能直观反映信号质量：眼"开"得越大，信号越干净；眼"闭"得越小，噪声/ISI/抖动越严重。

③ NRZ 频谱特性

NRZ 信号的功率谱密度（PSD）呈 sinc² 形状：

PSD_NRZ(f) = T_b × [sin(π·f·T_b) / (π·f·T_b)]²

其中 T_b 为 bit 周期。主要能量集中在 0 ~ 1/T_b（即符号率）以内，第一个零点在 f = 符号率，实际有效带宽取奈奎斯特频率 = 符号率 / 2。例：25.78 Gbps NRZ 的 Nyquist = 12.89 GHz，第一零点 = 25.78 GHz。

二、PAM4 信号详解

① PAM4 的四个电平

电平符号典型电压（Vppd=800mV 差分）Gray 编码（MSB:LSB）
L0（最低）−3−400 mV00
L1−1−133 mV01
L2+1+133 mV11
L3（最高）+3+400 mV10
电平间距计算：假设峰峰值差分摆幅 Vppd = 800 mV，4 个等间距电平的总跨度 800 mV，分成 3 段，每段 800/3 ≈ 266.7 mV。相比之下，相同 Vppd 的 NRZ 只有两电平（±400 mV），间距 800 mV，是 PAM4 的 3 倍。这就是 PAM4 SNR 损失 ~9.54 dB 的根源（20×log10(3) = 9.54 dB）。

② Gray 编码映射

PAM4 采用 Gray 编码（相邻电平只差 1 bit），而不是自然二进制（00/01/10/11）。原因是：噪声导致的判决错误绝大多数发生在相邻电平之间，Gray 编码确保每次错误只翻 1 bit，FEC 译码效率更高、错误权重更小。

图 2.4 自然二进制 vs Gray 编码映射对比
MSB / LSB 分配规则（IEEE 802.3bs 规定）：PAM4 的 2 bit 分MSB（Most Significant Bit）和LSB（Least Significant Bit），发射端映射关系为：
  • 电平 L0 → MSB=0, LSB=0
  • 电平 L1 → MSB=0, LSB=1
  • 电平 L2 → MSB=1, LSB=1
  • 电平 L3 → MSB=1, LSB=0
注意 L2/L3 的 LSB 与自然二进制相反，这正是 Gray 编码的特征。MSB 决定上半区/下半区，LSB 决定区内具体电平。

③ PAM4 眼图（三眼图）

PAM4 信号的眼图由3 个垂直堆叠的眼睛组成，每个眼对应一对相邻电平的判决区域。三个眼的高度相等（理想情况下），但远小于 NRZ 单眼的高度。

图 2.5 PAM4 三眼图（理想 vs 实际）
PAM4 三眼图的关键特征：
  • 三个眼等高（理想）：每个眼高 = Vppd / 3。实际因非线性，中间眼（L1/L2 之间）通常最小，是 PAM4 链路最薄弱的判决点。
  • 三个判决门限 D1/D2/D3：分别判决 L0/L1、L1/L2、L2/L3 之间的边界。门限需自适应跟踪电平漂移。
  • 眼高远小于 NRZ：相同 Vppd 下，PAM4 单眼高 ≈ NRZ 眼高的 1/3，对噪声/抖动极敏感。
  • 三眼非对称：因发射端 DAC 非线性、信道非对称、接收端偏置漂移，三个眼往往不等高，需 DSP 校正。

④ PAM4 频谱特性

PAM4 的功率谱密度形状与 NRZ 相同（sinc²），但因为每个符号携带 2 bit，符号率减半，所以频谱在频率轴上压缩为 NRZ 的一半。第一零点 = 符号率 = 比特率/2。

PSD_PAM4(f) 形状同 NRZ，但第一零点 = 符号率 = 比特率 / 2

例：53.125 Gbps PAM4 的符号率 = 26.5625 GBaud，第一零点 = 26.56 GHz，Nyquist 频率 = 13.28 GHz。而 53.125 Gbps NRZ 的 Nyquist = 26.56 GHz。PAM4 把 Nyquist 频率压缩了一半，这就是它在带宽受限信道中的核心优势。

② PAM4 三眼的不对称问题

实际 PAM4 三眼往往不等高，原因：

  • 发射端 DAC 非线性：DAC 的 INL/DNL 导致 4 电平不等间距，中间眼压扁。
  • Driver 非线性：Linear Driver 的增益压缩在大信号下不一致。
  • 激光器非对称响应（光口）：DML/EML 的上升/下降时间不对称，EML 啁啾不对称。
  • 信道非对称失真：高频损耗 + 反射导致 ISI 不对称。
  • 接收端偏置漂移：判决门限未对齐实际电平中心。

校正方法：发射端用 DPD（Digital Pre-Distortion）预补偿 DAC/Driver 非线性；接收端用自适应门限跟踪（adaptive threshold）实时调整 3 个判决电平。

七、FEC（前向纠错）详解

① 为什么 PAM4 必须用 FEC

PAM4 因电平间距小（SNR 损失 ~9.54 dB），原始 BER（Pre-FEC BER）通常只能做到 1E-4 ~ 1E-5，远达不到以太网要求的 1E-12 后纠错 BER。FEC 通过加入冗余校验位，能在接收端纠正一定数量的错误比特，把 BER 从 1E-4 降到 1E-15 量级。这是 PAM4 能实用的必要前提。

Pre-FEC BER vs Post-FEC BER：
  • Pre-FEC BER（纠错前）：FEC 译码前的原始误码率，反映物理链路质量。PAM4 典型 1E-4 ~ 1E-5。
  • Post-FEC BER（纠错后）：FEC 译码后的误码率，决定链路可用性。要求 ≤ 1E-12（无纠错失败），更严格的应用要求 1E-15。
  • FEC 增益（Coding Gain）：在相同 Post-FEC BER 下，加 FEC 后所需的 Pre-FEC SNR 比不加 FEC 低多少 dB。KP4 FEC 增益约 5~7 dB。

③ FEC 与调制的协同设计

FEC 开销会增加实际符号率：100Gbps PAM4 链路 + KP4 FEC（5.8% 开销）后，实际符号率 = 53.125 GBaud（含 FEC 冗余），有效载荷符号率 = 50.19 GBaud。设计时必须把 FEC 开销算入带宽预算。

实际符号率 = 有效比特率 / (log2(M) × (1 − FEC 开销))

例：100Gbps 有效载荷 + PAM4 + KP4：实际符号率 = 100 / (2 × (1 − 0.058)) = 53.125 GBaud（与 IEEE 802.3cd 标准一致）。

九、SNR 与 BER 的理论关系

对于 M 电平 PAM 信号，理论误码率（Gray 编码，相邻电平错误占主导）：

BER_PAM ≈ (2 / log2(M)) × Q(sqrt( (6 × log2(M) / (M² − 1)) × SNR_linear ))

代入 M=2（NRZ）和 M=4（PAM4），在相同 BER=1E-12 下，PAM4 所需 SNR 比 NRZ 高约 9.54 dB（即 20×log10(3)）。这是PAM4 的 SNR 代价，但换取了带宽减半的收益，在带宽受限信道中净收益为正。

影响因素

一、信道损耗（Insertion Loss）

信道损耗是影响信号质量的最主要因素。PCB 走线、连接器、过孔、线缆都对高频分量衰减，导致 ISI（码间干扰）。

  • 趋肤效应（Skin Effect）：高频电流集中在导体表面，有效截面积减小，电阻随 √f 上升。
  • 介质损耗（Dielectric Loss）：FR4 等板材的介质损耗角正切 tan δ 在高频下导致能量损耗，与频率成正比。
  • 损耗与频率关系：总损耗 ≈ α×√f（趋肤） + β×f（介质），高频下介质损耗主导。
损耗(f) ≈ K1 × √f + K2 × f （dB，K1/K2 与材料/几何相关）

PAM4 优势：相同比特率下 Nyquist 频率减半，信道损耗降低 10~20 dB。这是 PAM4 能在长距背板/旧板材上工作的根本原因。

三、非线性失真

PAM4 的 4 个电平必须等间距，但实际 DAC、Driver、激光器都存在非线性，导致电平压缩或扩张：

  • DAC INL/DNL：积分/微分非线性，导致 4 电平不等间距。
  • Driver 增益压缩：大信号下增益下降，L3/L0 压缩。
  • 激光器非对称响应（光口）：DML 上升/下降时间不对称，EML 啁啾。
  • ADC 非线性：接收端 ADC 的 INL 导致判决门限偏移。

校正：发射端用 DPD（Digital Pre-Distortion）预补偿；接收端用自适应判决门限跟踪。

四、抖动（Jitter）

详见 sec2b 第六节。PAM4 因 UI 短、三眼小，对抖动极敏感。主要来源：

  • PLL 相位噪声：发射/接收时钟源。
  • 电源开关噪声：DC-DC 开关频率耦合到信号。
  • 串扰：相邻通道耦合。
  • ISI 引起的 DDJ：信道损耗导致。

五、串扰（Crosstalk）

高速差分对之间的耦合串扰，PAM4 因电平间距小，对串扰更敏感。应对措施：

  • 增加差分对间距（≥ 3× 线宽）
  • 使用屏蔽过孔（GND via stitching）
  • 相邻层正交走线（垂直交叉）
  • 关键信号用地层隔离

  • 过孔残桩长度（背钻或 blind via）

八、光口特有因素（PAM4 光模块）

  • 色散（CD）：单模光纤色散导致脉冲展宽，PAM4 三眼闭合。FR4 (10km) 容限 ±1600 ps/nm。
  • 激光器啁啾（Chirp）：DML 直接调制引入频率啁啾，与色散交互劣化信号。EML 啁啾小，适合长距。
  • 偏振相关损耗（PDL）：光学器件对偏振敏感。
  • 反射（回光）：光纤连接器反射进入激光器，引起 RIN 升高。需 APC 斜面连接器。
PAM4 vs NRZ 影响因素对比总结：PAM4 对噪声、非线性、抖动、串扰的敏感度均高于 NRZ（因电平间距小、UI 短、三眼小）。但 PAM4 对信道损耗的容限更高（因 Nyquist 频率减半）。设计 PAM4 链路时，需重点控制噪声/非线性/抖动，而 NRZ 链路主要控制信道损耗。

测试方法

一、误码率测试（BERT）

1
设备准备

误码率测试仪（BERT，如 Anritsu MP1900A、Keysight N4991B）、被测链路、衰减器/光纤卷。

2
PRBS 模式配置

选择 PRBS7/PRBS9/PRBS11/PRBS31 测试图案。PRBS7 适合快速测试，PRBS31 适合长时统计。PAM4 链路还需用 SSPR（Short Stress Pattern Random）图案，模拟最坏 ISI 情况。

3
注入损耗

用电衰减器/光纤卷注入指定损耗，模拟实际信道。例如 400G-FR4 需注入 10km SMF + 连接器损耗。

4
测量 Pre-FEC BER

BERT 直接统计纠错前的误码率。对 PAM4，目标 ≤ 2.4E-4（KP4 FEC 阈值）。

5
测量 Post-FEC BER

启用 FEC 译码，统计纠错后误码率。目标 ≤ 1E-12，需长时间（≥ 1 分钟）统计以保证置信度。

6
绘制 BER vs 接收功率曲线

逐步增加衰减，记录 BER，绘制曲线。找到 BER=1E-12 对应的接收功率，即为接收灵敏度。

二、眼图测试

① 实时采样示波器（Real-Time Scope）

  • 设备：Keysight UXR 系列、Tektronix DPO77000SX、LeCroy LabMaster 10 Zi-A
  • 带宽：≥ 4× Nyquist 频率（112G PAM4 需 ≥ 110 GHz 带宽）
  • 采样率：≥ 8× 符号率（112G 需 ≥ 450 GS/s）
  • 测试内容：眼高、眼宽、眼图模板、TDECQ、抖动分解

② 等效采样示波器（Equivalent-Time Scope）

  • 优势：带宽高（≥ 100 GHz）、成本低
  • 限制：需重复信号，不适合捕捉偶发事件
  • 典型：Keysight 86100D DCA-X（光通信主流）

③ TDECQ 测试（PAM4 专用）

TDECQ 测试流程（IEEE 802.3bs 规定）：
  1. 用 PRBS31Q 或 SSPRQ 图案驱动被测发射端
  2. 信号经过参考接收机（含指定 CTLE 滤波器）
  3. 经过指定色散光纤（如 10km SMF for FR4）
  4. 在采样示波器上采集 ≥ 10 个波形
  5. 软件计算三眼图闭合度，与理想参考发射机对比
  6. 得出 TDECQ 值（dB），与标准阈值对比（SR4 ≤ 3.4 dB）

四、SNDR / ENOB 测试（DAC/ADC）

1
输入正弦信号

对 DAC：输入数字正弦波；对 ADC：输入模拟正弦波（信号发生器）。

2
采集输出

用高带宽示波器（DAC）或抓取数字样本（ADC），采集 ≥ 1024 个周期。

3
FFT 分析

对采集数据做 FFT，分离信号、谐波失真、噪声。

4
计算 SNDR

SNDR = 10×log10(信号功率 / (噪声 + 失真功率))。

5
换算 ENOB

ENOB = (SNDR − 1.76) / 6.02 bit。112G PAM4 链路要求 SNDR ≥ 32 dB（ENOB ≥ 5.0 bit）。

五、信道仿真

  • S 参数测量：用 VNA（矢量网络分析仪）测信道 SDD21（差分插入损耗）、SDD11（回损）。
  • IBIS-AMI 模型仿真：用 Keysight ADS、Cadence Sigrity 做 SerDes 链路仿真，导入 IBIS-AMI 模型（发射端 + 信道 + 接收端），预测眼图和 BER。
  • 信道眼图仿真：用脉冲响应卷积法计算信道眼图，评估均衡器配置。

① CMIS 状态机测试（PAM4 光模块）

  1. LowPwr：低功耗待机
  2. Init：上电初始化
  3. Ready：初始化完成，等待使能
  4. Enabled：使能发射，等待数据

注意事项

一、设计陷阱

⚡ ESD 损伤

高速 DAC/ADC/Driver 对 ESD 极敏感，电平间距小的 PAM4 更易受损。操作必须戴防静电手环，工作台接地，模块用防静电包装。

🔆 光安全（Class 1M）

光模块发射不可见红外激光（1270~1330 nm），直视可灼伤视网膜。未接光纤时禁用 TX，清洁端面时断电。

🌡️ 热设计

PAM4 oDSP 功耗高（400G 模块 10~20W），必须保证散热。QSFP-DD 模块壳温 ≤ 70°C，超过会触发热保护降速。

📡 I2C 地址冲突

多模块在同总线时地址冲突。CMIS 用 0x50（页 0-1）/ 0x51（页 2），需确认硬件地址引脚配置。

⏱️ 上电时序

PAM4 模块多路电源（3.3V主、1.8V/0.9V 核）需按时序上电，违反会导致 latch-up 或初始化失败。查 CMIS 状态机确认。

🧹 端面清洁

光纤端面污染是 PAM4 链路故障主因（眼图闭合、BER 升高）。每次插拔前用无尘纸 + 异丙醇清洁，端面检测仪确认。

📋 协议匹配

NRZ 模块和 PAM4 模块引脚兼容但不互通。100G-SR4（NRZ）≠ 100G-DR2（PAM4），混插会导致链路不通。查 CMIS/SFF-8436 协议字段。

🔧 调试盲点

PAM4 链路调试需同时看 Pre-FEC BER（物理层）和 Post-FEC BER（链路层）。只看 Post-FEC 会掩盖物理层劣化，等 FEC 失效时已晚。

三、PAM4 特有注意事项

PAM4 链路必须关注的特殊点：
  • FEC 不能关：PAM4 原始 BER 高（1E-4），关 FEC 必然失败。调试时务必确认双方 FEC 模式一致（KP4）。
  • 三眼不对称：实际 PAM4 三眼往往不等高，调试时需分别检查每个眼的闭合度，不能只看总体眼图。
  • DFE 误差传播：PAM4 DFE 抽头多，误差传播会导致突发错误。FEC 必须能纠突发（KP4 RS 码擅长）。
  • 非线性预补偿：发射端 DPD 对 PAM4 至关重要，调试时需校准 DPD 系数。
  • 判决门限自适应：PAM4 接收端 3 个判决门限需实时跟踪电平漂移，确保自适应算法收敛。

五、选型检查清单

PAM4 链路选型必查项：
  • ☐ 单通道速率 ≥ 50Gbps（否则优先 NRZ）
  • ☐ FEC 模式双方一致（KP4 RS(544,514)）
  • ☐ 信道损耗 ≤ 30~35 dB @ Nyquist
  • ☐ oDSP 支持所需均衡（FFE + DFE 抽头数）
  • ☐ DAC/ADC SNDR ≥ 32 dB
  • ☐ 光口 TDECQ 满足标准（SR4 ≤ 3.4 dB）
  • ☐ 模块功耗与散热设计匹配
  • ☐ CMIS 状态机支持热插拔
  • ☐ I2C 地址与系统其他设备无冲突
  • ☐ 光安全等级（Class 1M）符合应用
选型核心原则：
  • 够用即可：能用 NRZ 就不用 PAM4（成本/功耗/复杂度都低）
  • 带宽瓶颈才升级：信道损耗超过 25 dB 时才考虑 PAM4
  • 速率上限：单通道 ≥ 50Gbps 必须 PAM4；≥ 224G 考虑 PAM6/PAM8
  • 距离匹配：≤10km 用 PAM4 直接检测；≥40km 用相干
  • FEC 必查：PAM4 链路双方 FEC 模式必须一致，否则链路不通
