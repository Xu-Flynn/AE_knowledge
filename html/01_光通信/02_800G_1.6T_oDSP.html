背景与应用定位

800G/1.6T oDSP 是面向下一代超大规模数据中心光互连的核心芯片，部署于 800G OSFP/QSFP-DD800 及 1.6T OSFP-XD 光模块中。相比 400G/800G 一代，1.6T oDSP 在单通道速率（106Gbps 直接翻倍至 212Gbps PAM4）、调制阶数（新增 PAM6 可选）和 DSP 复杂度（新增 NLC 非线性补偿、升级至级联 iFEC+KP4 FEC、MLSD 从 64-State 升级至 256-State）上均有质的飞跃。这是 AI/ML 训练集群 GPU 间互连的关键使能技术，被业界视为光互连的"分水岭"产品。

📌 产品定位

产业链位置：光模块内部，处于超高速 ADC/DAC (224GS/s) 与 Host ASIC 之间

核心价值：在 1UI=9.43ps 的极端条件下，将"被光纤严重破坏"的 212Gbps PAM4 信号恢复至 Post-FEC BER < 1e-15

本质功能：超高速数字信号处理（21-tap FFE + 5-tap Spec DFE + 256-State MLSD + NLC + 级联 FEC）

制程节点：5nm/3nm FinFET CMOS，支撑 >1.7Tbps 总吞吐量和 <20W 功耗

🎯 典型应用场景

  • AI/ML 训练集群的 800G/1.6T 光互联 (GPU-to-GPU, NVLink 跨机架)
  • 超大规模数据中心 Spine-Leaf 互联架构
  • 800GBASE-DR8 / 2xFR4 光模块
  • 1.6T OSFP-XD 光模块 (8x200G 或 4x400G 灵活配置)
  • 下一代相干 800G/1.2T DWDM 长距传输
  • CPO (Co-Packaged Optics) 共封装光学集成

核心工作原理

800G/1.6T oDSP 在 400G/800G 基础上面临速率翻倍带来的全新挑战。212Gbps PAM4 (106Gbaud) 下，1UI 仅 9.43ps，所有 DSP 模块必须在更短的时间内完成更复杂的运算。Nyquist 频率升至 53GHz，PCB 损耗可达 40dB+，对模拟前端 (AFE) 和时钟系统的要求成倍提高。

核心模块深度解析 -- 800G/1.6T 增强版

一、增强型前馈均衡器 (FFE) -- 21-tap 自适应 FIR

800G/1.6T oDSP 的 FFE 从 15-tap 升级为 21-tap，以应对 Nyquist 频率升至 53GHz 后更加严重的信道损耗（PCB 损耗可达 40dB+）。前向抽头用于补偿 pre-cursor ISI（反射引起），后向抽头补偿 post-cursor ISI（信道滚降引起）。自适应算法从固定步长 LMS 升级为变步长 LMS，初始阶段大步长快速收敛，稳态阶段小步长保证低误差。

y[n] = Σ(k=-5 to 15) c[k] . x[n-k] | 变步长 LMS: c[k]^(n+1) = c[k]^(n) + mu(n).e(n).x(n-k)

最大补偿 @Nyquist>30dB @26.5GHz>35dB @53GHz高频损耗远超平方增长

二、高阶判决反馈均衡器 (DFE) -- 5-tap Speculative

DFE 从 3-tap 升级为 5-tap，以消除更长 post-cursor ISI 拖尾。在 PAM4 (4 电平) + 5-tap DFE 下，理论需要 4^5 = 1024 条并行推测路径，这在功耗和面积上不可接受。实际采用混合架构降低复杂度：h1/h2 使用 Speculative（并行 16 条路径），h3~h5 使用 Direct Feedback。这是 212Gbps 速率下满足 1UI=9.43ps 时序约束的唯一可行方案。

y[n] = x[n] - Σ(k=1 to 5) d[n-k] . b[k] | h1/h2: Speculative (16路并行) | h3~h5: Direct Feedback
架构方案并行路径数延迟约束功耗/lane可行性
全 Speculative (5-tap)1024无~5W不可接受
混合架构 (h1/h2 Spec + h3~h5 Direct)16h3~h5 <1UI=9.43ps~1.2W量产方案
全 Direct Feedback1所有 tap <1UI (不可实现)最低物理不可行
⚠️ 错误传播风险：5-tap DFE 下，一个判决错误最长传播 5 个符号周期 (约 47ps @106Gbaud)。256-State MLSD 作为 DFE 的后级可有效缓解此问题，将错误传播概率降低 1~2 个数量级。

三、256-State 最大似然序列检测器 (MLSD) -- Viterbi 算法

256-State MLSD 是 800G/1.6T oDSP 的核心差异化模块，比上一代 64-State 提升 4 倍状态数，带来额外 +2.5~3.5dB SNR 增益。PAM4 调制下，每个状态有 4 条入径，每符号周期需执行 256x4 = 1024 次加-比-选 (ACS) 操作。为在 1UI=9.43ps 内完成，采用全并行 radix-4 ACS 架构和深度流水线。

四、非线性补偿 (NLC) -- 数字反向传播 (DBP)

NLC 是 800G/1.6T 的全新核心模块，用于补偿光纤传输中的 Kerr 非线性效应。在 212Gbps 速率下，光纤非线性引起的信号失真已无法被线性均衡器 (FFE/DFE) 补偿，必须引入非线性 DSP。NLC 基于数字反向传播 (DBP)，在数字域逆向求解非线性薛定谔方程 (NLSE)，将接收信号"虚拟反向传播"通过光纤。

∂A/∂z + (alpha/2)A + (j.beta_2/2).∂^2A/∂t^2 = j.gamma.|A|^2.A (NLSE 非线性薛定谔方程)
步骤操作域补偿目标
1. 线性子步 (Linear Step)CD 补偿 (频域 FFT 相乘)频域群速度色散 (GVD)
2. 非线性子步 (Nonlinear Step)SPM 相位旋转: A.exp(j.gamma.|A|^2.dz_eff)时域自相位调制 (SPM)

分段策略：光纤被划分为 N 段，每段依次执行线性和非线性补偿。分段数 N_steps：短距 1~2 段，中距 3~5 段，长距 8~16 段。每增加一段，NLC 功耗增加约 0.3W，但 SNR 提升逐渐饱和。NLC 的效果高度依赖光纤参数 (gamma, beta_2, alpha) 的精确性 -- 参数误差 >5% 时 NLC 反而可能恶化性能。

五、级联 FEC 编解码器 -- iFEC + KP4-FEC

800G/1.6T 采用级联 FEC 架构，通过内码 (iFEC，软判决) + 外码 (KP4-FEC，硬判决 RS) 的串行级联，将总净编码增益 (NCG) 从单一 KP4 的约 6.2dB 提升至约 11dB。两级编码互补 -- iFEC 擅长纠正随机误码，KP4 擅长清除内码输出中的突发残留错误。

六、PAM6 调制 (可选模式)

PAM6 是 800G/1.6T oDSP 的可选高阶调制格式，每符号传输 3 bit（vs PAM4 的 2 bit），在相同 Baud Rate 下提升 50% 数据吞吐量。代价是 SNR 需求比 NRZ 高约 14dB（PAM4 约 9.5dB），且需要 5 个判决阈值（vs PAM4 的 3 个），阈值间距减半，对噪声和 ISI 更加敏感。

⚠️ PAM6 工程权衡：PAM6 提升 50% 数据率但额外需要约 4.5dB SNR。在 212Gbps 速率下 SNR 已经极度紧张，PAM6 仅适用于极短距 (<100m DR) 或超高功率预算场景。2026 年主流部署仍以 PAM4 为主，PAM6 作为技术储备为未来预留演进空间。

✅ 212Gbps 关键共同影响因素 (比上一代更严苛):
  • 电源完整性 (PDN) -- 头号挑战：224GS/s ADC/DAC 对电源噪声极度敏感。DC-DC 开关纹波、PDN 谐振峰 (通常 10~100MHz) 直接耦合到时钟和模拟前端。要求 PSRR >40dB @1MHz。
  • 时钟质量 -- 决定 BER 下限：参考时钟相噪直接影响 CDR 恢复时钟质量。212Gbps 要求参考时钟相噪 <-145dBc/Hz @10kHz offset, RJ <50fs RMS (12k~20MHz)。时钟路径需独立 LDO 供电。
  • 信号完整性 (SI) -- 更高频率更脆弱：PCB trace @53GHz Nyquist 损耗可达 0.5~1dB/mm。必须使用超低损耗材料 (Megtron 6/7, Rogers 4350B)。连接器需 1.0mm 或 0.8mm 精密同轴。
  • 温度梯度 -- 芯片内部温差：20W 功耗导致芯片内部热点与冷点温差可达 15~30C -> 各 lane PVT 不一致 -> 需要 per-lane 独立校准。
  • 工艺角 (PVT) -- 5nm/3nm 新挑战：先进工艺下 SS/TT/FF corner 性能差异比 7nm 更大 (约 4dB 灵敏度差异)。需要更宽的 Adaptive 系数范围。
  • 光纤非线性 -- 212Gbps 特有：高功率密度下 Kerr 效应显著，NLC 的 DBP 模型精度直接影响补偿效果。光纤参数 (gamma, beta_2) 的测量误差会传递到 NLC 残差。

📊 7.2 级联 FEC 瀑布曲线测试 (212Gbps 专项)

1
Pre-FEC 目标点设置

靶向 Pre-FEC 点: [1e-2, 5e-3, 2e-3, 1e-3, 5e-4, 2.4e-4, 1e-4, 5e-5]。测量每个点对应的 iFEC 输出 BER 和 KP4 输出 (Post-FEC) BER。注意级联 FEC 有两个拐点：iFEC 拐点 (约 1e-2) 和 KP4 拐点 (约 2.4e-4)。

2
双拐点验证

iFEC 拐点: Pre-FEC 约 1e-2 -> Post-iFEC 约 2.4e-4 (验证 iFEC NCG 约 9.5dB)。KP4 拐点: Pre-KP4 约 2.4e-4 -> Post-FEC <1e-15 (验证总 NCG 约 11dB)。两级各自的瀑布曲线斜率不同。

3
长统计时间 (比 106Gbps 更关键)

212Gbps 下 BER 统计: Pre-FEC=1e-4 需 >10^11 bit (约 8min @212Gbps)；Post-FEC<1e-15 验证需 >10^15 bit (不实际，用外推法)。推荐每个衰减点采集 >10^12 bit。

4
FEC 同步/失步测试

信号中断 -> FEC 失步检测 -> 恢复后自动重同步。分别测试 iFEC 失步门限和 KP4 失步门限，两者不同。测量两级重同步时间 (应分别 <1ms)。

5
突发错误容忍

注入连续错误 Burst: 5/10/15/20/25/30 符号。iFEC 可纠 15~20 符号随机错误；KP4 可纠 <=15 符号突发错误 (RS t=15)。级联后可纠更长 Burst (iFEC 先处理随机错误，KP4 处理残留 burst)。

🟢 7.4 TX 发射机 TDECQ 测试 (212Gbps)

1
示波器校准 (110GHz)

UXR1104A: 垂直校准 (DC 精度 +/-1%)、时基校准、通道去嵌入 (110GHz S 参数)。1.0mm 接头扭矩扳手精确拧紧 (⚠ 过紧损坏接头, 扭矩 0.45N.m)。

2
PAM4 参考接收机配置

符号率 106.25 Gbaud (212Gbps)；参考接收机: CTLE Auto + FFE 5-tap + DFE 3-tap；CDR: 二阶 PLL, BW=Baud/1667 约 64MHz (IEEE 802.3ck)。

3
数据采集

采集长度 >5M UI (IEEE 最小 2M, 建议 >10M UI @212Gbps)；20 次独立采集取平均 (高频下噪声更大，需更多平均)。

4
分析输出

TDECQ (<3.0dB)、RLM (>0.93)、EW5 (>0.18UI 约等于 1.7ps)、EH5 (>28mV)、3 层眼图轮廓、PAM4 电平线性度、PAM6 可选分析。

5
TX 5-tap FIR 优化

扫描 c_pre[-15~15], c_main[30~80], c_post[-20~20] (5-tap 搜索空间更大, 125,000 组合) -> 最小 TDECQ + RLM>0.93 + EW5>0.18UI 三目标帕累托前沿优化。

测试与使用注意事项 -- 212Gbps 专项

⚡ 通用注意事项 (与 400G/800G 通用，但更严格)

🔌 上电时序 (绝对关键!)

上电: Vcore(0.75-0.85V) -> 等待>15ms -> Vio(1.2V) -> 等待>15ms -> Vana(1.8V)；断电: 反向! 5nm/3nm 工艺栅氧更薄，对过压更敏感，违反时序可能永久损坏芯片。

🕐 参考时钟质量 -- 212Gbps 更严

频率: 156.25/312.5MHz LVDS；抖动: <50fs RMS (12k~20MHz)；相噪: -145dBc/Hz @10kHz offset；精度: +/-50ppm。时钟质量是 CDR 性能的天花板。

⚡ PDN 电源完整性 -- 212Gbps 首要挑战

224GS/s ADC/DAC 对电源噪声极度敏感。AVDD 与 DVDD 必须分开供电；每 lane 独立 LDO；PDN 目标阻抗 <10mOhm @1MHz；DC-DC 开关频率远离 PLL BW。

📐 PCB 布局 -- 53GHz 高频

100ohm 差分阻抗 (+/-3%, 比上一代更严)；超低损耗板材 (Megtron 6/7)；等长布线 (<50um mismatch)；参考层完整不可分割；过孔 stub 背钻去除。

🌡️ 热管理 -- 20W 功耗

theta-JC 约 1.5C/W (5nm 更优但功耗更大)；Tj_max 125C；推荐高性能 TIM (导热系数 >6W/mK) + 均热板 + 模块外壳导热；每 lane 功耗不均需热仿真。

🛡️ ESD 防护 -- 5nm 更敏感

HBM: 1.5kV (5nm 栅氧更薄, 比 7nm 更敏感), CDM: 250V；客户 SMT 产线须 IEC 61340-5-1 管控；PCB 添加 TVS 保护；操作佩戴接地手环+防静电鞋。

🔵 800G/1.6T oDSP 专项注意事项

⏱ CDR 锁定确认 (BW 15~20MHz)

测试前务必确认 CDR Lock Status=1；未锁定时 BER 无意义；锁定后等待 >100ms 让 DFE(5-tap)+MLSD(256-St)+NLC 全部收敛。212Gbps 收敛时间比上一代长约 2x。

📊 级联 FEC 双同步监控

需同时监控 iFEC Sync 和 KP4-FEC Sync 两个状态；任一未同步则 Post-FEC BER 虚高；每次衰减变更后等待两级 FEC 全部重新同步 (约 1~5ms)。

🔍 110GHz 去嵌入精度

212Gbps Nyquist=53GHz，测试电缆和 PCB trace 损耗可达 20~40dB。去嵌入误差在 53GHz 处被放大 3~5x vs 26.5GHz。必须用 110GHz VNA 提取精确 S 参数。

🧵 1.0mm/0.8mm 连接器操作

212Gbps 需 1.0mm 或 0.8mm 精密同轴连接器。中心针直径仅 0.3~0.4mm，极易弯曲损坏。必须使用扭矩扳手 (0.45N.m)，严禁手拧。寿命仅 500~1000 次插拔。

🌊 NLC 校准 -- 新增关键步骤

NLC (DBP) 需要光纤参数 (gamma, beta_2, alpha, L_eff) 作为输入。参数测量误差会导致 NLC 补偿残差。长距测试前必须用 OTDR+CD 分析仪精确测量光纤参数。参数误差 >5% -> NLC 反而恶化性能!

🔋 功耗/热测试 -- 20W 级

1.6T 全通道模式下功耗近 20W。测试时需确保散热路径通畅 (TIM+散热片+强制风冷)。连续运行 >30min 达到热平衡后再读数。监测各 lane 温度差异 (<5C 目标)。

🚨 212Gbps 测试最常见错误 (比 106Gbps 更容易犯):
  • 使用带宽不足的设备：BERT 必须 >=120GBaud PAM4、示波器必须 >=110GHz。用 70GHz 设备测 212Gbps -> 高频分量丢失 -> 眼图虚好。
  • 连接器类型错误：使用 1.85mm (67GHz) 连接器代替 1.0mm (110GHz) -> 连接器处产生严重反射 (S11 <-10dB @53GHz)。
  • CDR BW 设置不当：沿用 400G/800G 的 BW=10MHz -> CDR 跟踪能力不足 -> 低频抖动未被抑制 -> BER 虚高。
  • 去嵌入误差放大：仅用 67GHz VNA S 参数外推到 110GHz -> 53GHz 处理论值与实际偏差 >2dB -> 测量误差。
  • 忽视 NLC 校准：未校准光纤参数 -> NLC 反而引入额外失真 -> "开了 NLC 比不开还差"。
  • FEC 级联延误：仅看 KP4 Post-FEC 而忽略 iFEC 状态 -> Pre-FEC 1e-2 时 iFEC 已接近临界 -> 微小衰减变化导致 Post-FEC 突变。
  • 忽视温度稳定：20W 功耗下温度稳定时间 >30min；温度变化过程中测量 -> 数据持续漂移。

选型与应用指南 -- 800G vs 1.6T

✅ 选用 800G oDSP (800G/1.6T 系列中的 800G 模式)

  • 800GBASE-DR8 / 2xFR4 光模块设计
  • 单通道 106Gbps PAM4 电接口 (800GAUI-8)
  • 功耗预算 <14W
  • 现有 400G/800G 基础设施兼容
  • 距离覆盖 DR/FR/LR (500m~10km)
  • 向后兼容 400G 光模块生态系统
  • 2026 年主流量产部署推荐

✅ 选用 1.6T oDSP (800G/1.6T 系列中的 1.6T 模式)

  • AI/ML 训练集群超大规模互联 (GPU 集群)
  • 1.6T OSFP-XD 光模块 (8x200G 或 4x400G)
  • 需要最大端口密度和数据吞吐量
  • 单通道 212Gbps PAM4 电接口 (1.6TAUI-8)
  • 功耗预算 <20W (需要先进散热方案)
  • CPO 共封装光学集成场景 (降低功耗)
  • 2027+ 大规模部署预期
