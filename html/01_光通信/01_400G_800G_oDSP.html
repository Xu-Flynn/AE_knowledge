背景与应用定位

400G/800G oDSP (Optical Digital Signal Processor) 是数据中心光互连的核心芯片，部署于光模块（QSFP-DD、OSFP）内部，负责对经过光纤传输后严重劣化的高速光信号进行数字信号恢复与补偿。它是连接光域与电域的关键桥梁，决定了光模块的传输距离和信号质量。

📌 产品定位

产业链位置：光模块内部，处于 ADC/DAC 与 Host ASIC 之间

核心价值：将"被光纤破坏"的信号恢复到"无误码"水平

本质功能：高速数字信号处理（均衡 + CDR + FEC）

🎯 典型应用场景

  • 数据中心内部互联 (DCI)
  • 400GBASE-DR4/FR4/LR4/ER4 光模块
  • 800GBASE-2xFR4/2xLR4 光模块
  • 400G/600G/800G 相干光通信系统

核心工作原理

oDSP 位于光模块内部，接收链路中处于 ADC 之后、Host ASIC 之前，发送链路反之。其核心任务是补偿光/电信道引入的各种信号损伤。

核心模块深度解析

一、前馈均衡器 (FFE) — 15-tap 自适应 FIR

FFE 是一种线性 FIR 均衡器，通过加权组合延迟的输入信号补偿信道频率选择性衰落。400G/800G oDSP 采用 15-tap 自适应 FFE：

y[n] = Σ(k=-3 to 11) c[k] · x[n−k]   |   LMS 自适应: c[k]⁽ⁿ⁺¹⁾ = c[k]⁽ⁿ⁾ + μ · e(n) · x(n−k)
参数典型值含义
前向抽头 (pre-cursor)3~5 tap补偿反射引起的 pre-cursor ISI
后向抽头 (post-cursor)9~11 tap补偿信道损耗引起的 post-cursor ISI
最大补偿 @14GHz>30 dBNyquist 频率处增益
系数位宽8~10 bit计算精度

二、判决反馈均衡器 (DFE) — 3-tap Speculative

DFE 利用已判决符号的加权反馈消除后向 ISI，不放大噪声是其核心优势。

y[n] = x[n] − Σ(k=1 to 3) d[n−k] · b[k]   |   PAM4 判决阈值: −2, 0, +2

Speculative DFE（推测式）：为满足 1UI (≈18.8ps @53Gbaud) 的时序约束，并行计算所有 4 种可能的反馈值，根据 d[n−1] 选择正确路径。

⚠️ 错误传播：3-tap DFE 下，一个判决错误最多传播 3 个符号。MLSD 可有效缓解此问题。

三、最大似然序列检测器 (MLSD) — Viterbi 算法

MLSD 基于 Viterbi 算法寻找最小欧氏距离的发送序列，是 AWGN 信道下的理论最优检测。

特性DFEMLSD (64-State)
SNR 增益基准+1~2dB
复杂度O(N)O(4L)
延迟~5 UI32~64 UI
功耗~0.3W/lane~1W/lane

使用策略：短距 → FFE+DFE；中距 → +16-state MLSD；长距 → +64-state MLSD+CD 补偿

四、时钟数据恢复 (CDR) — Mueller-Muller PD

相位误差 = e(n)·d(n−1) − e(n−1)·d(n)   |   二阶 PLL: Kp + Ki/s
参数400G800G
锁定范围±300ppm±350ppm
锁定时间<100μs<100μs
恢复时钟 RJ<200fs<180fs
环路带宽1~10MHz2~15MHz

JTF 特性：低通 — f ≪ BW 时 0dB（跟踪），f ≫ BW 时 −40dB/dec（抑制）

五、FEC 编解码器 — KP4-FEC

参数KP4-FECC-FEC (相干)
码型RS(544,514) over GF(2¹⁰)级联 FEC
冗余度5.5%~15%
纠错能力t=15 符号/码字更强
NCG @1e-15~6.2dB~10.5dB
Pre-FEC 门限2.4e-41.5e-2

RS 解码流程：伴随式计算 → Berlekamp-Massey 算法 → Chien Search → Forney 算法（错误值求解）

六、TX 发送端 DSP

PAM4 Gray 映射：00→−3, 01→−1, 11→+1, 10→+3（相邻电平仅 1 bit 不同，降低误码影响）

3-tap FIR: Vout[n] = c_pre·Vin[n+1] + c_main·Vin[n] + c_post·Vin[n−1]

非线性预补偿 (NLC)：补偿 MZM 调制器的 sin² 非线性传输函数，提升 PAM4 眼图线性度。

✅ 关键共同影响因素（所有高速芯片均适用）：
  • 电源完整性 (PDN)：DC-DC 开关纹波、PDN 谐振引起的电源噪声直接耦合到敏感模拟电路
  • 时钟质量 (Jitter)：参考时钟相噪直接影响 CDR 恢复时钟质量 → SNR → BER
  • 信号完整性 (SI)：PCB trace 损耗、阻抗失配、连接器反射 → ISI → BER 恶化
  • 温度：PVT 变化 → 模拟偏置漂移、时序变化；高温 → 漏电流增加 → 功耗升高
  • 工艺角 (PVT)：SS/TT/FF corner 下性能差异可达 3dB（灵敏度）

🟢 7.4 FEC 性能测试

1
BER 瀑布曲线

靶向 Pre-FEC 点: [5e-3, 2e-3, 1e-3, 5e-4, 2.4e-4, 1e-4, 5e-5]；期望 Pre-FEC=2.4e-4 时 Post-FEC <1e-15。

2
突发纠错测试

注入连续错误 Burst: 5/10/15/20/25 符号；5~15 符号全部纠正；16~25 符号部分不可纠。

3
FEC 同步/失步

信号突然中断 → FEC 检测失步 → 恢复后自动重同步；测量高 BER 恢复后 FEC 重新同步时间。

测试与使用注意事项

⚡ 通用注意事项

🔌 上电时序（绝对关键！）

上电: Vcore(0.8V) → 等待>10ms → Vio(1.2V) → 等待>10ms → Vana(1.8V)；断电: 反向！绝对禁止颠倒，否则可能永久损坏芯片！

🕐 参考时钟质量

频率: 156.25/312.5MHz LVDS；抖动: <200fs RMS (12k~20MHz)；相噪: −145dBc/Hz @10kHz offset；精度: ±50ppm。

⚡ 电源隔离与去耦

AVDD 与 DVDD 分开供电；就近放 100nF+10μF 去耦电容；数字 I/O 开关噪声通过衬底耦合到模拟前端。

📐 PCB 布局规范

100ohm 差分阻抗 (±5%)；等长布线；参考层完整不分割；高速信号远离时钟线；保护环包围敏感模拟引脚。

🌡️ 散热设计

theta-JC ~2°C/W；Tj_max 125°C；推荐散热片+导热硅脂/TIM+模块外壳导热；800G 全功耗 <14W 需认真对待热设计。

🛡️ ESD 防护

HBM: 2kV, CDM: 500V；客户 SMT 产线需 ESD 管控；建议 PCB 添加 TVS 保护；操作时佩戴接地手环。

🔵 oDSP 专项注意事项

⏱ CDR 锁定确认

测试前务必确认 CDR Lock Status=1；未锁定时 BER 无意义；锁定后建议等待 >50ms 让 DFE 系数收敛。

📊 FEC 同步状态

BER 测试时需同时监控 FEC Sync 状态；FEC 未同步时 Post-FEC BER 虚高；每次衰减变更后等待 FEC 重新同步。

🔍 电缆去嵌入

测试电缆和 PCB trace 的损耗必须在测量结果中补偿；使用 VNA 提取 S 参数 → 示波器去嵌入功能。

🚫 避免过量程

RX 输入不得超过 ADC 满量程；TX 输出预加重过度 → 信号削波 → 谐波增加 → TDECQ 恶化。

🚨 FFT/BER 测试最常见错误：
  • 未做相干采样：频谱泄漏导致 SNR/SFDR 虚低
  • 激励源自身失真太大：测出的 THD 是激励源而非 DUT 的
  • CDR 未锁定时测 BER：结果完全无意义
  • DFE 未收敛：前 50ms 数据不可用
  • 忽视温度稳定：温度变化过程中测量 → 数据漂移

选型与应用指南

✅ 选用 400G oDSP 的场景

  • 400GBASE-DR4/FR4/LR4 光模块设计
  • 单通道 106Gbps PAM4 应用
  • 功耗预算 <8W
  • 成熟供应链，成本敏感
  • 距离 <10km（DR/FR/LR）

✅ 选用 800G oDSP 的场景

  • 800GBASE 光模块设计
  • 需要更高端口密度（1.6T 演进）
  • AI/ML 集群超大规模互联
  • 支持 112Gbps/lane 电接口
  • 功耗预算 <14W
